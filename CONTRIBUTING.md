# Contributing

Contributions should improve a working example, fix documentation, or demonstrate a distinct use case. Include reproduction instructions and a small synthetic fixture. Do not include API tokens, personal datasets, or outputs that you cannot share.

Files listed in `.sync/manifest.json`, including `CATALOG.md`, `actors.json`, and `docs/actors/`, are generated from Apify. Update the source README or schema on Apify and publish the build; the scheduled sync will update these files. Make example changes under `examples/`.

Python examples use the standard library and require Python 3.10 or later. Run a fixture transformation locally and validate example input before submitting changes. Disclose any billable steps. No purchase or promotional engagement is required to contribute.
