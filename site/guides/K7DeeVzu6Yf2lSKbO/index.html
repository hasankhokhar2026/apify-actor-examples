FieldTypeRequiredDescription
placeUrlstringoptionalGoogle Maps URL of the place to scrape photos from.
placeIdstringoptionalCanonical Google Place ID beginning with ChIJ. Use this instead of placeUrl when available.
maxPhotosintegeroptionalMaximum number of photos to extract (1-100000). Google may expose fewer photos for a place or category.
photoCategorystringoptionalFilter photos by category tab.
enrichDetailsbooleanoptionalWhen enabled, reads each photo's metadata: contributor name/URL, observed upload date, original dimensions, aspect ratio, orientation, caption, and tags. Disable for thumbnail-level rows (photo/thumbnail URL, business context, category, video flag and duration). Every surface is walked in both modes, so disabling trims per-photo work instead of skipping the walk.
proxyConfigurationobjectoptionalOptional proxy settings. Direct access is tried first; bounded recovery uses the hardcoded US RESIDENTIAL group unless direct-only mode is explicitly selected with useApifyProxy=false.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/K7DeeVzu6Yf2lSKbO/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
