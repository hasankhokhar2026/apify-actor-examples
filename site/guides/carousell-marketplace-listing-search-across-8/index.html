    Carousell Marketplace Listing Search (Hong Kong): export to CSV, Excel or JSON

    Search Hong Kong Carousell listings by keyword or category, or fetch listing and seller pages: price, condition, photos, seller feedback, location and deal options. No account, user cookies or API key required.

    This tutorial runs Carousell Marketplace Listing Search (Hong Kong) through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 7 columns its publisher puts first: title, price, condition, countryCode, seller, categoryName and listingUrl.
