Use YouTube Channel Contact Email Finder with Python

Find publicly listed contact emails for YouTube channels by scanning each About page and the Instagram, TikTok, and Linktree profiles it links to. No login or API key needed.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "channels": [
    "@mkbhd",
    "@LinusTechTips"
  ],
  "includeVideoDescriptions": true,
  "includeWebsite": true,
  "maxChannels": 2,
  "maxEmailsPerChannel": 5,
  "mode": "channels",
  "onlyWithEmail": false
}

Download input.example.json and save your reviewed copy as input.json.

FieldTypeRequiredDescription
modestringrequiredChoose whether to scrape the channels you provide or discover channels from search queries.
channelsarrayoptionalYouTube channel URLs, @handles, UC... channel IDs, or video URLs (mode=channels). Video URLs resolve to their channel.
searchQueriesarrayoptionalKeywords used to discover channels through YouTube search (mode=search). Each query returns up to about 20 channels; duplicates and maxChannels are applied across queries.
maxChannelsintegeroptionalMaximum number of unique channels processed per run, across both modes.
includeWebsitebooleanoptionalVisit up to two linked websites (home, contact/about pages and common paths) and one link-in-bio hub per channel.
includeVideoDescriptionsbooleanoptionalRead the descriptions of the latest five videos on each channel.
onlyWithEmailbooleanoptionalWhen enabled, channels with no public email are left out of the dataset. Error records are still reported.
emailDomainsarrayoptionalOptional list of domains to keep, for example brand.com or gmail.com. Leave empty to keep every discovered email.
maxEmailsPerChannelintegeroptionalUpper bound on the emails returned for each channel. The highest-value public contact is chosen as primaryEmail.
proxyConfigurationobjectoptionalOptional. The actor works without a proxy; set this only when your runs need a specific Apify Proxy connection.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/iUDQnZLC66Ye2jePm/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
# Inspect and download results in Apify Console once the run succeeds.
