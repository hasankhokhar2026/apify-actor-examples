Use Google News Keyword & Full-Text Article Scraper with Python

Search Google News by keyword with real resolved article links, headlines, sources, and dates, plus optional full article text and image extraction, filterable by date, language, and publisher.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

  "queries": [
    "artificial intelligence",
    "climate change"
  ]

Download input.example.json and save your reviewed copy as input.json.

FieldTypeRequiredDescription
queriesarrayrequiredOne or more search keywords. Each query is processed separately. Results are deduplicated across queries.
maxResultsPerQueryintegeroptionalMaximum number of articles to return per query.
languagestringoptional2-letter BCP-47 language code for Google News results (e.g. 'en', 'de', 'fr', 'es').
countrystringoptionalISO 3166-1 alpha-2 country code for regional news (e.g. 'US', 'GB', 'DE', 'IN').
dateRangestringoptionalFilter articles by recency. Ignored if dateFrom/dateTo are set.
dateFromstringoptionalFilter articles published on or after this date (YYYY-MM-DD). Overrides dateRange.
dateTostringoptionalFilter articles published on or before this date (YYYY-MM-DD). Use with dateFrom.
siteFilterstringoptionalRestrict results to a specific domain (e.g. 'reuters.com', 'bbc.com').
excludeWordsarrayoptionalWords or phrases to exclude from results.
extractFullTextbooleanoptionalFetch each article and extract the full body text using trafilatura. Uses Playwright to render the article page.
includeImagesbooleanoptionalExtract the main og:image URL from each article page. Uses Playwright to render the article page.
maxConcurrencyintegeroptionalNumber of parallel browser pages (for full text/images). Higher = faster but more memory.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/7LV8qekDbhuvsPtdv/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
# Inspect and download results in Apify Console once the run succeeds.
