    Google Earth Location Coordinate Finder: export to CSV, Excel or JSON

    Look up precise latitude/longitude coordinates, place names, short descriptions and Google's internal place IDs for any place name or address, one result per query, as resolved by Google Earth's own location search.

    This tutorial runs Google Earth Location Coordinate Finder through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 8 columns its publisher puts first: place_name, google_place_id, latitude, longitude, description, search_query, data_source and url.

    What people export it for

    • GIS data collection — bulk-resolve a list of place names into coordinates for mapping
    • Travel research — get exact coordinates for landmarks before planning routes or itineraries
    • Location intelligence — attach Google's place ID and coordinates to a list of business names or addresses
    • Dataset enrichment — add latitude/longitude to records that only have a place name
    • Franchise mapping — resolve multiple locations of the same chain into individual coordinate records

    Fix common problems

    Why did a query return no record?

    Google Earth genuinely couldn't resolve that query to a location — a typo, an overly vague query, or a place Google Earth doesn't recognize.

    Why would description or google_place_id be missing?

    Those fields are only included when Google Earth's response actually provides them; many places have coordinates and a name but no short description or place ID.

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.
