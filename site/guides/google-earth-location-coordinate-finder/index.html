    Google Earth Location Coordinate Finder: export to CSV, Excel or JSON

    Look up precise latitude/longitude coordinates, place names, short descriptions and Google's internal place IDs for any place name or address, one result per query, as resolved by Google Earth's own location search.

    This tutorial runs Google Earth Location Coordinate Finder through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 8 columns its publisher puts first: place_name, google_place_id, latitude, longitude, description, search_query, data_source and url.

    Get an API token

    Copy your token from Apify Console, Settings, API and Integrations and keep it in an environment variable rather than in the script.

    Choose the input

    1 field is required:

    • searchQueries: List of location names or addresses to search for on Google Earth. Each query returns ONE result (the primary location Google Earth identifies). For multiple franchise locations (e.g., 'KFC'), use specific queries like 'KFC New York', 'KFC Los Angeles'.

    call() starts the run and waits until it finishes, however long that takes; the results land in the run's default dataset, which the loop reads page by page.

    Download Excel or JSON

    The API can run the Actor and hand back the dataset as a file in one request. format takes xlsx, csv, json, jsonl, xml or html, and fields keeps only the columns you list. The request waits up to 300 seconds; a longer run answers HTTP 408 and carries on, so use the Python script for big runs.

    Fix common problems

    • HTTP 401: the token is missing or wrong; run echo $APIFY_TOKEN in the same shell.
    • An empty file: open the run in Console and read its log; it usually names the input that matched nothing.
    • Odd characters in Excel: open the CSV through Data, From Text/CSV and pick UTF-8, or download xlsx instead.
