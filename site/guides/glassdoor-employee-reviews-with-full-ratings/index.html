Use Glassdoor Review Export - Ratings, Pros, Cons & Replies with Python

Get Glassdoor employee reviews for any company with overall and sub-category ratings, pros, cons, advice to management, job title and employment status.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

FieldTypeRequiredDescription
companiesarrayoptionalGlassdoor company Review or Overview URLs, company names, or employer ids. Add one item per company. Example: https://www.glassdoor.com/Reviews/Google-Reviews-E9079.htm or Google or 9079.
maxItemsintegeroptionalMaximum number of reviews to save across all companies.
maxReviewsPerCompanyintegeroptionalMaximum reviews to save for each company. Set to 0 for no per-company limit.
sortBystringoptionalOrder in which Glassdoor returns reviews.
locationstringoptionalCity, state, metro area, or country to filter reviews by, such as New York, NY or London. Leave empty for all locations. The value is resolved automatically through Glassdoor's location search.
jobFunctionstringoptionalOnly keep reviews whose job function matches this category.
postedWithinDaysstringoptionalOnly keep reviews posted within this many days. Uses newest-first order and stops when older reviews are reached.
dateFromstringoptionalKeep reviews posted on or after this date (YYYY-MM-DD). Applied client-side and forces newest-first order.
dateTostringoptionalKeep reviews posted on or before this date (YYYY-MM-DD). Applied client-side and forces newest-first order.
ratingstringoptionalOnly keep reviews with this exact overall star rating. Use ratings to select several stars.
ratingsarrayoptionalKeep reviews with any of these exact star ratings: 1, 2, 3, 4, 5. Leave empty to use the single rating filter.
employmentTypestringoptionalOnly keep reviews with this employment status.
employmentTypesarrayoptionalKeep reviews with any of these employment statuses: regular, part_time, intern, contract, freelance, temporary. Leave empty to use the single employment type filter.
onlyCurrentEmployeesbooleanoptionalOnly keep reviews written by current employees.
onlyWithEmployerResponsesbooleanoptionalOnly keep reviews that have an official employer response.
jobTitleKeywordsstringoptionalOnly keep reviews whose job title matches these words. Glassdoor may also return closely related titles, such as software developer for software engineer.
keywordstringoptionalOnly keep reviews that mention this word or phrase.
languagestringoptionalLanguage of the reviews to collect. Choose all languages to include every language Glassdoor exposes.
languagesarrayoptionalCollect reviews in any of these languages: eng, fra, deu, nld, por, spa, ita. Leave empty to use the single language filter.
includeWorldwideReviewsbooleanoptionalRemove Glassdoor's default review criteria and include reviews from all countries. This raises the review ceiling but can add much older or non-local reviews.
includeCompanySummarybooleanoptionalAdd one companySummary record per company with saved, available, siteTotal, stopReason, logo, rating, and URL. Summary records are marked with recordType=companySummary.
includeCompanyProfilebooleanoptionalAdd company profile fields such as website, headquarters, size, revenue, industry, CEO, and company sub-ratings to each review. This makes one extra request per company.
onlyNewbooleanoptionalRemember previously seen reviews in a named key-value store and emit only reviews that are new since the last run. Uses newest-first order and stops at the stored review-id watermark. Set the same monitorId on every scheduled run.
monitorIdstringoptionalName of the named key-value store that holds monitoring state. Use the same value on every scheduled run. Default glassdoor-reviews.
emitUnchangedbooleanoptionalWith onlyNew, also emit previously seen reviews that have not changed. Each emitted review gets isNew=false and its original firstSeenAt. Leave off to avoid duplicate dataset records.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/5lWwuQH8dZ6LpE4AU/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])

4. Inspect the actual results

Open the run in Apify Console and wait for a successful completion. Use the published output schema to locate results and the dataset schema to understand declared views. Missing or optional record fields must not be treated as guaranteed values.

Employee reviews scraped from Glassdoor with ratings, pros and cons, reviewer context, language data, employer responses, company context, company logo, and canonical review URLs. With onlyNew, reviews also carry isNew, firstSeenAt, lastSeenAt, changed, and lastChangedAt monitoring fields. The run status and RUN_SUMMARY key-value record expose the saved/available/siteTotal/stopReason completeness contract, plus monitorId/newReviews/unchangedReviews when monitoring is on. Set includeCompanySummary to add companySummary records to the same dataset.

Questions before you run

Which inputs are required?

No top-level fields are marked required in the published schema. Conditional requirements can still apply; check the README.

What does this guide verify?

The fields, prefills, and schema links are rendered from the published build. This is a usage recipe, not a paid live extraction test. Source availability and collection results can vary.

What if the run request times out?

Check Apify Console before retrying. The first request may already have created a run. Do not automatically repeat a run-creation POST.
