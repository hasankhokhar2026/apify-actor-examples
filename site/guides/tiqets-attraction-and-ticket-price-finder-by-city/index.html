    Tiqets Attraction & Ticket Price Finder by City: export to CSV, Excel or JSON

    Search Tiqets by keyword, browse things to do in a city or category, or fetch specific venue and product pages, and get back name, rating, review count, from-price, images and coordinates for each museum, tour or attraction.

    This tutorial runs Tiqets Attraction & Ticket Price Finder by City through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 8 columns its publisher puts first: venueId, name, city, rating, reviewCount, price, priceCurrency and productUrl.

    Fix common problems

    Why do some listing records only have name + URL?

    On city/category pages Tiqets embeds full structured data for the ~10 top attractions and exposes many more venue links. Records from those extra links contain name and URL only — empty fields are always omitted.

    Is there a limit on how many records I can get in one run?

    Yes — maxItems is capped at 1,000 records per run.

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.

    An export of 1,000 results costs $1.39 in Actor charges on the Free plan, plus platform usage (all plans).
