Use Reddit Keyword Search with Advanced Filters with Python

Search Reddit by keyword and filter the matches by subreddit, score, date range, NSFW status, and author before they reach your dataset.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "keywords": [
    "python programming"
  ]
}

Download input.example.json and save your reviewed copy as input.json.

FieldTypeRequiredDescription
keywordsarrayrequiredList of keywords to search. Each runs as a separate search.
resultLimitintegeroptionalMax posts per keyword (1-1000). Default 100. Source caps are real: RSS 100/request with no pagination, Translate partial 24/page, Redlib 7/page, Arctic 100/page. Fewer results are reported as partial rather than silently truncated.
sortstringoptionalHow to sort the search results.
relativeWindowstringoptionalRestrict results to a relative window. Maps to Reddit's t= and Arctic after= filters. Use all for no window.
onlyNewbooleanoptionalEmit only records newer than the stored watermark for this monitorId. Requires a stable monitorId for scheduled runs.
monitorIdstringoptionalKey used to store the onlyNew watermark and seen IDs. Use the same value on every scheduled run of the same monitor.
searchCommentsbooleanoptionalAlso search comment bodies via Redlib, with RSS parent-post discovery + hydration as fallback. Emits recordType=comment records.
commentLimitintegeroptionalMaximum matching comments per keyword when searchComments is enabled (1-1000).
subredditFilterarrayoptionalOnly emit posts/comments from these subreddits (with or without `r/`). Empty = all. When set, the engine prefers the subreddit-scoped Translate listing.
subredditBlocklistarrayoptionalDrop posts/comments from these subreddits.
minScoreintegeroptionalDrop records below this score. Applied only when the source exposes a live or explicitly timestamped score; otherwise the run reports metrics_unavailable instead of silently passing/dropping.
maxAgeDaysintegeroptionalDrop records older than N days.
excludeNsfwbooleanoptionalDrop NSFW records. When the available source cannot expose a per-post NSFW flag, unknown rows are not emitted as safe; the run reports nsfw_status_unavailable.
authorBlocklistarrayoptionalDrop posts/comments by these usernames (case-insensitive).
keywordRequireAllbooleanoptionalWhen multiple keywords are given, keep only records whose title/content contains ALL of them. Default: each keyword runs independently (OR).
dateFromstringoptionalDrop records with `created_at` before this date (inclusive). Format: YYYY-MM-DD or ISO timestamp.
dateTostringoptionalDrop records with `created_at` after this date (inclusive end-of-day). Format: YYYY-MM-DD or ISO timestamp.
includeArchivebooleanoptionalUse Arctic Shift for subreddit-scoped backfill and comment hydration when live sources fail. Archive metrics are snapshots, not live.
redditOAuthTokenstringoptionalOptional user-supplied OAuth Bearer token. Never required; when present, oauth.reddit.com is tried first for live metrics. The actor does not obtain tokens for you.
redlibInstancesarrayoptionalOptional Redlib hostnames to try in order (without https://). Defaults to safereddit.com, redlib.catsarch.com, redlib.perennialte.ch.
resolveChallengesbooleanoptionalAllow a best-effort Playwright browser solve when a Redlib instance returns an Anubis challenge. Disable to keep runs HTTP-only.
proxyConfigurationobjectoptionalOptional Apify proxy configuration. Live HTML/Redlib/RSS availability varies by IP; residential proxies improve success on datacenter runs.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/SG9Ngr95n5Hkk64vN/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])

Which inputs are required?

What does this guide verify?

What if the run request times out?

Check Apify Console before retrying. The first request may already have created a run. Do not automatically repeat a run-creation POST.
