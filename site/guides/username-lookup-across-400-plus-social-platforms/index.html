    Username Lookup Across 400+ Social Platforms: export to CSV, Excel or JSON

    Check a username or nickname against 400+ social, gaming, professional and messaging platforms and get back the public profiles confirmed to exist for it.

    This tutorial runs Username Lookup Across 400+ Social Platforms through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 8 columns its publisher puts first: recordType, query, platform, url, exists, status, availability and confidence.

    Steps

    1. See the columns
    2. Get an API token
    3. Choose the input
    4. Run it and write a CSV
    5. Download Excel or JSON
    6. The same in JavaScript
    7. Fix common problems

    The columns you can export

    The Actor's build declares 21 output fields in 2 dataset views ("Checks & Profiles" and "Run Summary"). The export below keeps these, under the labels the publisher gave them:

    Records can carry more fields than these; the output reference lists all of them. Swap any field into the list to export it.

    Get an API token

    Copy your token from Apify Console, Settings, API and Integrations and keep it in an environment variable rather than in the script.

    Choose the input

    1 field is required:

    • mode: lookup returns found profiles (plus blocked/unknown checks), availability returns one row per platform with available/taken/unknown, and name_search generates handle candidates from a full name.

    The input reference lists every field.

    Run it and write a CSV

    call() starts the run and waits until it finishes, however long that takes; the results land in the run's default dataset, which the loop reads page by page.

    Download Excel or JSON

    The API can run the Actor and hand back the dataset as a file in one request. format takes xlsx, csv, json, jsonl, xml or html, and fields keeps only the columns you list. The request waits up to 300 seconds; a longer run answers HTTP 408 and carries on, so use the Python script for big runs.

    Fix common problems

    • HTTP 401: the token is missing or wrong; run echo $APIFY_TOKEN in the same shell.
    • An empty file: open the run in Console and read its log; it usually names the input that matched nothing.
    • Odd characters in Excel: open the CSV through Data, From Text/CSV and pick UTF-8, or download xlsx instead.
