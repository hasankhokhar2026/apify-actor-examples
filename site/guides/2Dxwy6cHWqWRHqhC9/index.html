Use YouTube Video, Playlist & Channel Downloader with Metadata with Python

Download YouTube videos from direct links, playlists, channels, or search phrases at your chosen quality, with a public file link plus title, stats, description and subtitles per video.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

FieldTypeRequiredDescription
modestringrequiredWhat to return: metadata only, media files, or caption files without media.
videoUrlsarrayoptionalDirect YouTube video, Shorts, live-replay, or youtu.be URLs, or 11-character video IDs.
playlistUrlsarrayoptionalYouTube playlist URLs. Videos are expanded up to maxVideos in total.
channelUrlsarrayoptionalYouTube channel URLs, @handles, or UC channel IDs. The Videos tab is used.
searchQueriesarrayoptionalYouTube search phrases. Each query resolves public results up to maxVideos in total.
videoQualitystringoptionalSDR target quality. 360p-1080p prefer H.264/AAC MP4. 1440p and 2160p require allow4K and are delivered with their real codec and container.
containerstringoptionalAuto uses MP4 H.264/AAC when available and MKV for VP9/AV1. Explicit MP4 never relabels AV1/Opus content as MP4; if no compatible stream exists the video gets a failure row.
audioOnlybooleanoptionalDownload the source audio track without video and without re-encoding.
audioFormatstringoptionalSource audio passthrough format used when audioOnly is enabled.
downloadSubtitlesbooleanoptionalFetch available manual or automatic captions for the requested languages.
subtitleLanguagesarrayoptionalCaption language codes to request. Only tracks that already exist on the video are used; translations are not promised.
subtitleFormatstringoptionalFile format for downloaded captions.
includeTranscriptbooleanoptionalAdd a plain-text transcript from the first requested caption track.
maxVideosintegeroptionalTotal videos processed across all inputs.
maxMinutesintegeroptionalReject a video before download when its duration exceeds this cap. 4K opt-in downloads are additionally capped at 10 minutes.
maxMBintegeroptionalReject oversized downloads. Values above 500 are only used for 4K opt-in downloads, which are capped at 1000 MB.
allow4KbooleanoptionalEnable 1440p/2160p SDR downloads. These are capped at 10 minutes and 1000 MB and may use MKV with VP9/AV1 because YouTube rarely serves H.264 above 1080p.
storagestringoptionalWhere downloaded files are written. Named KVS persists while the store exists; ephemeral KVS follows your Apify account retention.
kvsNamestringoptionalNamed key-value store name when storage=named_kvs. Defaults to youtube-downloader.
storageRetentionDaysintegeroptionalSigned-link lifetime for S3/R2 storage (1-7 days). KVS retention is controlled by your Apify account.
s3BucketstringoptionalBucket name when storage=s3.
s3PrefixstringoptionalObject key prefix when storage=s3.
s3EndpointstringoptionalCustom endpoint for S3-compatible storage such as Cloudflare R2.
s3RegionstringoptionalRegion for S3 or S3-compatible storage.
s3AccessKeyIdstringoptionalOptional access key ID when storage=s3.
s3SecretAccessKeystringoptionalOptional secret access key when storage=s3.
s3PublicBaseUrlstringoptionalOptional public bucket URL. When set, files use public URLs instead of expiring presigned URLs.
cookiesstringoptionalOptional cookies.txt content for age-restricted or members-only videos. Public videos work without cookies.
proxyConfigurationobjectoptionalOptional. Metadata and player extraction use this connection; media bytes are downloaded directly.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/2Dxwy6cHWqWRHqhC9/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
