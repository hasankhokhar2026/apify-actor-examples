    Wine Catalog Search by Type, Region & Vintage: export to CSV, Excel or JSON

    Search a public wine catalog of reds, whites, sparkling, rosé, dessert and port wines by name, winery, country, region, rating or vintage year, returning winery, vintage, rating and review count per wine.

    This tutorial runs Wine Catalog Search by Type, Region & Vintage through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 8 columns its publisher puts first: wineName, winery, vintage, country, region, ratingAverage, reviewsCount and wineType.

    What people export it for

    • Wine list curation — pull a category or region to build a restaurant or shop wine list
    • Cellar research — filter by winery and vintage range to find bottles worth tracking down
    • Tasting app content — seed an app's wine database with structured records by type and region
    • Comparative tasting notes — gather a region's top-rated wines before planning a tasting flight
    • Market mapping — see how wine counts and ratings are distributed across countries and regions

    Fix common problems

    Why do some wines have no vintage?

    The vintage year is parsed out of the wine name text. Non-vintage ("N.V.") wines have no year to extract, so the field is left out.

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.
