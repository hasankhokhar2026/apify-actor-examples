    Wish.com Product Price & Rating Scraper: export to CSV, Excel or JSON

    Search, browse, or look up Wish.com products and get price, rating, merchant ID, and image for each one, filterable by price range, rating, and sale status.

    This tutorial runs Wish.com Product Price & Rating Scraper through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 8 columns its publisher puts first: name, price, rating, ratingCount, isOnSale, discountPercent, merchantId and productUrl.

    1. See the columns
    2. Get an API token

    4. Run it and write a CSV

    The columns you can export

    The Actor's build declares 9 output fields in 1 dataset view ("Products"). The export below keeps these, under the labels the publisher gave them:

    Default export columns
    FieldColumn headerWhat it holds
    namenameProduct name/title.
    pricepriceListed price in USD.

    ratingCountratingCountNumber of reviews shown for the listing, when greater than zero.

    Swap in any field from the output reference to export it too.

    What people export it for

    • Dropshipping research — scan a category or keyword for low-priced, well-rated products worth sourcing.
    • Price monitoring — track price for a set of search results over time.
    • Catalog building — collect product images and listing prices for a category to seed a comparison feed.

    Fix common problems

    Why are some fields missing on certain products?

    Not every product tile exposes every field, and byProductId lookups return a smaller field set than search/byCategory (see Output above). Fields that Wish doesn't provide for a given product, or that this actor doesn't extract for that mode, are omitted rather than filled with a placeholder.

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.
