Use Amazon Best Sellers & Rankings Scraper with Python

Scrape Amazon's Best Sellers, New Releases, Most Wished For, Most Gifted and Movers & Shakers charts. Get rank, ASIN, title, price, rating and category for every product on a chart, with optional deeper category coverage.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "categoryNodeIds": [],
  "categoryUrls": [
    "electronics"
  ],
  "chartType": "bestSellers",
  "domain": "amazon.com",
  "includeProductDetails": false,
  "maxDepth": 0,
  "maxItems": 20,
  "maxItemsPerCategory": 20,
  "maxPages": 2,
  "maxProductDetails": 5,
  "proxyConfiguration": {
    "useApifyProxy": true
  },
  "startPage": 1
}

Download input.example.json and save your reviewed copy as input.json.

FieldTypeRequiredDescription
chartTypestringrequiredWhich Amazon chart to scrape.
domainstringoptionalWhich Amazon marketplace to scrape the chart from.
categoryUrlsarrayoptionalAmazon category slugs (e.g. `electronics`, `electronics/172541`) or full chart URLs to scrape. Each entry is combined with `chartType` and `domain` to build the chart page.
categoryNodeIdsarrayoptionalAmazon browse-node IDs in `rootSlug/nodeId` form (e.g. `electronics/172541` for Headphones). Combined with `categoryUrls` if both are provided.
maxDepthintegeroptionalWhen > 0, also walk each category's left-nav subcategory links this many levels deep, scraping each subcategory's own chart too. 0 = only the given categories.
startPageintegeroptionalFirst chart page to fetch (each page is a separate ranked page on Amazon's site, not a fixed rank count).
maxPagesintegeroptionalMaximum number of chart pages to fetch per category, starting at `startPage`.
maxItemsPerCategoryintegeroptionalHard cap on chart items emitted per category (across all its pages).
maxItemsintegeroptionalHard cap on total chart items emitted across all categories in this run.
includeProductDetailsbooleanoptionalFor each chart item, also fetch its product detail page for purchase-option and additional rating data. Slower and bounded by `maxProductDetails`.
maxProductDetailsintegeroptionalHard cap on how many chart items get product-detail enrichment when `includeProductDetails` is on.
proxyConfigurationobjectoptionalApify proxy used to fetch chart pages. Datacenter (AUTO) is used by default and works for most requests; the actor escalates to residential only after repeated blocks on a session.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/0FAIaQmKaKgbU4Ftg/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
# Inspect and download results in Apify Console once the run succeeds.

Questions before you run

Which inputs are required?

What does this guide verify?

The fields, prefills, and schema links are rendered from the published build. This is a usage recipe, not a paid live extraction test. Source availability and collection results can vary.

What if the run request times out?

Check Apify Console before retrying. The first request may already have created a run. Do not automatically repeat a run-creation POST.
