Use Yelp Business Search & Review Scraper with Python

Search Yelp by keyword and location, or scrape specific business pages directly, to collect business details, ratings, categories, contact details, and customer reviews.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "categories": [],
  "includeReviews": true,
  "location": "",
  "maxItems": 1,
  "maxReviewsPerBusiness": 5,
  "minRating": 0,
  "mode": "direct",
  "price": [],
  "reviewLanguage": "en",
  "reviewRatings": [
    "5",
    "4",
    "3",
    "2",
    "1"
  ],
  "reviewSort": "DATE_DESC",
  "searchQuery": "",
  "sortBy": "recommended",
  "startUrls": [
    "https://www.yelp.com/biz/prince-street-pizza-new-york-2"
  ]
}

Download input.example.json and save your reviewed copy as input.json.

FieldTypeRequiredDescription
modestringrequiredSearch Yelp by keyword and location, or look up specific business URLs, aliases, or 22-character business IDs.
searchQuerystringoptionalKeyword to search for in mode=search, for example 'pizza', 'plumber', or 'coffee shop'.
locationstringoptionalCity, neighborhood, or ZIP code to search in mode=search, for example 'New York, NY' or '10012'.
startUrlsarrayoptionalIn mode=search, paste Yelp search URLs. In mode=direct, paste business URLs, aliases, or 22-character business IDs.
categoriesarrayoptionalOptional Yelp category aliases or names used to narrow search results, for example 'pizza', 'coffee', or 'home_services'. They are combined with the search query.
sortBystringoptionalOrdering for mode=search result pages.
pricearrayoptionalOptional price levels for mode=search. Leave empty for every price level.
minRatingnumberoptionalDrop businesses rated below this value. Set to 0 to keep every rating.
maxItemsintegeroptionalHard cap on business records in the dataset. Search is limited to Yelp's 240-result ceiling per query.
maxReviewsPerBusinessintegeroptionalMaximum reviews collected for each business. Reviews are paged 49 at a time from Yelp's public review feed.
includeReviewsbooleanoptionalTurn off to collect only business profiles and skip the review feed.
reviewSortstringoptionalOrdering applied to each business's review feed.
reviewRatingsarrayoptionalOnly collect reviews with these star ratings. Choose one or more values.
reviewLanguagestringoptionalLanguage for the review feed. Choose 'all' to page through every language Yelp reports for the business.
proxyConfigurationobjectoptionalOptional. The actor automatically uses Apify Proxy when Yelp blocks a request; add a country or custom proxy here only when you need a specific route.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/7GbUL6yEkG5aFcZSk/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
# Inspect and download results in Apify Console once the run succeeds.
