    DoorDash Store Menu & FAQ Data Finder: export to CSV, Excel or JSON

    Find DoorDash restaurant store details and complete menus by store URL, including name, address, cuisine breadcrumbs, menu sections with item names, descriptions, and prices, and the store's published FAQ.

    This tutorial runs DoorDash Store Menu & FAQ Data Finder through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 7 columns its publisher puts first: storeName, address, city, state, menuItemCount, menuSectionCount and storeUrl.

    What people export it for

    • Competitor menu intelligence — track pricing and item offerings for named restaurants over time
    • Cuisine analysis — group restaurants by their breadcrumb cuisine tag
    • Menu engineering research — compare which sections and items are common across similar restaurants
    • Franchise auditing — pull menus for every location of a chain by store URL
    • Customer support/FAQ research — collect how restaurants answer common ordering questions

    Fix common problems

    Why doesn't this return individual customer reviews?

    DoorDash store pages no longer expose individual customer reviews — only aggregate signals surfaced elsewhere on the page. This actor extracts everything the store page actually publishes: menu, address, FAQ, and breadcrumbs.

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.
