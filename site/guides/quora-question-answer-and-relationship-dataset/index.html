    Quora Question, Answer & Relationship Dataset Builder: CSV and Excel export

    Build a structured Quora dataset from question, answer, profile, Topic, Space, and Post URLs or search terms, with the question-answer-comment chain and relationship links kept intact.

    This tutorial runs Quora Question, Answer & Relationship Dataset Builder through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 8 columns its publisher puts first: content_type, event_type, state_snapshot_hash, previous_snapshot_hash, state_scope_fingerprint, state_store_state, state_store_error and only_new_items.

    The columns you can export

    The Actor's build declares 407 output fields in 1 dataset view ("Normalized records"). The export below keeps these, under the labels the publisher gave them:

    Download Excel or JSON

    The API can run the Actor and hand back the dataset as a file in one request. format takes xlsx, csv, json, jsonl, xml or html, and fields keeps only the columns you list. The request waits up to 300 seconds; a longer run answers HTTP 408 and carries on, so use the Python script for big runs.

    Fix common problems

    • HTTP 401: the token is missing or wrong; run echo $APIFY_TOKEN in the same shell.
    • An empty file: open the run in Console and read its log; it usually names the input that matched nothing.
    • Odd characters in Excel: open the CSV through Data, From Text/CSV and pick UTF-8, or download xlsx instead.
