Use Indeed Global Job Scraper with Company Salary Reports with Python

Search Indeed jobs across 62 countries by keyword, location, or filters for job type, remote status, experience, education, and salary. Returns full descriptions, structured salaries, and each employer's ratings and salary-by-title reports.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "country": "US",
  "easyApplyOnly": false,
  "includeCompanyRatings": true,
  "includeDescriptionHtml": false,
  "location": "San Francisco",
  "maxItemsPerSearch": 5,
  "position": "web developer",
  "saveOnlyUniqueItems": true
}

Download input.example.json and save your reviewed copy as input.json.

FieldTypeRequiredDescription
positionstringoptionalJob title, skill or keywords, e.g. `web developer`, `nurse`. Search one company's jobs with `company:Amazon`, titles only with `title:(data analyst)`; quotes, OR and -exclusions work too.
locationstringoptionalCity, region or postal code, e.g. `San Francisco`, `Austin, TX`, `10001`, `London`. Leave empty to search the whole country.
countrystringoptionalIndeed country site to search. Results come in the site's language and salaries in its currency.
maxItemsPerSearchintegeroptionalMaximum number of jobs to save for each search (the keyword search and each search URL). Indeed shows up to about 1,000 jobs for one search; split large searches by location or filters to collect more.
jobTypestringoptionalEmployment type.
workplaceTypestringoptionalWhere the work happens.
datePostedstringoptionalOnly jobs added to Indeed within this period.
experienceLevelstringoptionalRequired experience level.
educationLevelstringoptionalRequired education.
salaryMinintegeroptionalOnly jobs whose salary range reaches at least this yearly amount, in the country's currency (hourly and monthly pay is converted to yearly). Jobs without any salary information are excluded.
easyApplyOnlybooleanoptionalOnly jobs you can apply to directly on Indeed.
radiusintegeroptionalDistance around the location (Indeed's default is 25). Ignored without a location.
radiusUnitstringoptionalUnit of the search radius.
sortstringoptionalOrder of the search results.
startUrlsarrayoptionalIndeed search result URLs (any country, with their filters), job URLs (`…/viewjob?jk=…`) or job IDs. Each search URL is scraped as its own search; job URLs are fetched directly. Filters chosen above are added to search URLs.
includeCompanyRatingsbooleanoptionalAdd each employer's Indeed rating, review count, category ratings (work-life balance, pay & benefits, job security, management, culture), CEO approval, founding year, work wellbeing score and average salaries by job title. Each company is looked up once per run; turn off for the fastest runs with the least proxy traffic.
includeDescriptionHtmlbooleanoptionalAlso save the job description as HTML (`descriptionHtml`) with its formatting. The plain-text `description` is always included.
saveOnlyUniqueItemsbooleanoptionalSave each job once even when several searches find it. Jobs are always unique within one search.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/JCXoFe3h1UxJEFHCg/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])

Questions before you run

Which inputs are required?

No top-level fields are marked required in the published schema. Conditional requirements can still apply; check the README.

What does this guide verify?

The fields, prefills, and schema links are rendered from the published build. This is a usage recipe, not a paid live extraction test. Source availability and collection results can vary.

What if the run request times out?

Check Apify Console before retrying. The first request may already have created a run. Do not automatically repeat a run-creation POST.
