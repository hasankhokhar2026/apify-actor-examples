Use Zillow Upcoming Open House Finder by City or ZIP with Python

Find upcoming Zillow open houses by city, ZIP, or search URL, with showing start and end times plus property price, beds/baths, square footage and location.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "dateFilter": "any",
  "includeAgentContact": false,
  "includeDetails": true,
  "locations": [
    "Austin, TX"
  ],
  "maxItems": 1,
  "timeZone": "America/New_York"
}

startUrlsarrayoptionalZillow search or open-house URLs to scrape instead of, or in addition to, locations. Legacy open-house paths are converted to the filtered 1_open path and the open-house filter is applied automatically.
minPriceintegeroptionalLower bound on the listing price. Leave blank for no minimum.
maxPriceintegeroptionalUpper bound on the listing price. Leave blank for no maximum.
bedsMinnumberoptionalOnly include properties with at least this many bedrooms. Leave blank for no minimum.
bedsMaxnumberoptionalOnly include properties with at most this many bedrooms. Leave blank for no maximum.
bathsMinnumberoptionalOnly include properties with at least this many bathrooms (decimals allowed, e.g. 1.5). Leave blank for no minimum.
homeTypesarrayoptionalLimit results to specific property types. Leave empty for all types.
dateFilterstringoptionalShow only showings in this window. Choose Custom range to use the date fields below. Zillow has no verified server-side date filter, so this is applied to the exact showing dates after collection.
dateFromstringoptionalInclude only showings on or after this date. Used when the date filter is Custom range (or when no preset is selected).
dateTostringoptionalInclude only showings on or before this date. Used when the date filter is Custom range (or when no preset is selected).
includeDetailsbooleanoptionalOpen each listing's detail page for agent/broker, photos, description, year built, lot, HOA, and MLS. Adds one request per listing; rows still return with search-page fields when a detail page fails.
includeAgentContactbooleanoptionalInclude the listing agent and broker phone numbers and any published agent email found on the detail page. Off by default.
maxItemsintegeroptionalMaximum number of open-house showing rows to return across all locations and URLs (1-500). Each row is one showing.
proxyConfigurationobjectoptionalOptional Apify Proxy overrides. Leave empty and the actor picks the working route automatically: direct first, then Apify Proxy AUTO, then a paid unblocker/residential group only after Zillow returns a real 403/PerimeterX block.
timeZonestringoptionalUS time zone used to interpret today/this weekend and to floor open-house dates.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/MJ6qfmpk6MQzUARaD/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])

Questions before you run

Which inputs are required?

No top-level fields are marked required in the published schema. Conditional requirements can still apply; check the README.

What does this guide verify?

The fields, prefills, and schema links are rendered from the published build. This is a usage recipe, not a paid live extraction test. Source availability and collection results can vary.

What if the run request times out?

Check Apify Console before retrying. The first request may already have created a run. Do not automatically repeat a run-creation POST.
