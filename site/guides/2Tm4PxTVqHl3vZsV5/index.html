Use Pinterest Pins, Profiles, Boards & Idea Topics Scraper with Python

Collect Pinterest Pins, creator profiles, boards, idea topics, and search results in one actor, with built-in filters for minimum saves, creator followers, verified accounts, shoppable pins, and image-only results.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

ideaUrlsarrayoptionalPublic Pinterest idea-topic links, for example `https://www.pinterest.com/ideas/beauty/935541271955/`.
ideaSlugsarrayoptionalIdea topic path pairs such as `beauty/935541271955`. Used when `mode=ideas`.
maxItemsintegeroptionalMaximum rows returned across all supplied inputs.
urlsarrayoptionalCompatibility alias for pinUrls, useful with mode=comments.
languagestringoptionalPinterest UI language (affects ranked search results).
maxPagesintegeroptionalMaximum search result pages to walk per keyword or board (1 page ≈ 25 pins). Default 10.
minSavesintegeroptionalKeep Pins whose Pinterest save count is at least N. Pins without a published count are retained as unknown.
minCreatorFollowersintegeroptionalKeep Pins whose public creator follower count reaches N. Unknown counts are retained.
verifiedOnlybooleanoptionalKeep only rows where Pinterest explicitly reports a verified creator or profile.
requireOutboundLinkbooleanoptionalFor Pin results, keep only Pins with a public destination URL supplied by Pinterest.
imageOnlybooleanoptionalDrop video pins, keep image pins only.
excludeAdsbooleanoptionalDrop promoted/sponsored pins.
commerceOnlybooleanoptionalPro filter: when true, return only product/shoppable pins. Equivalent to Pinterest's native 'Products' filter (commerce_only=true).
enrichPinDetailsbooleanoptionalFor `userPins` and `boardPins`, visit each public Pin detail page for detail-only fields. Slower but more complete.
includeCommentsbooleanoptionalAdd real comment/activity rows for collected Pins. Pinterest's public cookieless path is used automatically.
maxCommentsintegeroptionalMaximum public comment/activity rows per Pin when comments are enabled or mode=comments.
limitintegeroptionalCompatibility alias for maxComments.
cookiesarrayoptionalOptional Cookie Editor JSON export. All public modes work without cookies; never share this secret publicly.
cookiesJsonstringoptionalCompatibility alias for pasting a Cookie Editor JSON export.
proxyConfigurationobjectoptionalOptional Apify proxy settings. Public direct-pin pages do not require login; some feed surfaces may be withheld from datacenter traffic.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/2Tm4PxTVqHl3vZsV5/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
