    Google Fonts Library Metadata Extractor: export to CSV, Excel or JSON

    Look up Google Fonts families by name, browse a category, or export the full library with weights, variable-font axes, language subsets, designers, popularity, and ready-to-use CSS embed URLs.

    This tutorial runs Google Fonts Library Metadata Extractor through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 8 columns its publisher puts first: family, category, isVariable, weights, subsets, designers, popularity and trending.

    Steps

    1. See the columns
    2. Get an API token
    3. Choose the input
    4. Run it and write a CSV
    5. Download Excel or JSON
    6. The same in JavaScript
    7. Fix common problems

    Get an API token

    Copy your token from Apify Console, Settings, API and Integrations and keep it in an environment variable rather than in the script.

    Choose the input

    1 field is required:

    • mode: What to fetch from Google Fonts. icons fetches the separate Material icon metadata document once and emits icon records; it does not return font-family records.

    Run it and write a CSV

    call() starts the run and waits until it finishes, however long that takes; the results land in the run's default dataset, which the loop reads page by page.

    Download Excel or JSON

    The API can run the Actor and hand back the dataset as a file in one request. format takes xlsx, csv, json, jsonl, xml or html, and fields keeps only the columns you list. The request waits up to 300 seconds; a longer run answers HTTP 408 and carries on, so use the Python script for big runs.

    Fix common problems

    • HTTP 401: the token is missing or wrong; run echo $APIFY_TOKEN in the same shell.
    • An empty file: open the run in Console and read its log; it usually names the input that matched nothing.
    • Odd characters in Excel: open the CSV through Data, From Text/CSV and pick UTF-8, or download xlsx instead.
