    Google Fonts Library Metadata Extractor: export to CSV, Excel or JSON

    Look up Google Fonts families by name, browse a category, or export the full library with weights, variable-font axes, language subsets, designers, popularity, and ready-to-use CSS embed URLs.

    This tutorial runs Google Fonts Library Metadata Extractor through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 8 columns its publisher puts first: family, category, isVariable, weights, subsets, designers, popularity and trending.

    What people export it for

    • Design systems — build a searchable, filterable font picker from live Google Fonts data
    • Self-hosting / GDPR reviews — pull license, copyright, source repo, woff2/unicode-range, and TTF URLs
    • Web performance — request only the weights/styles and file URLs you need before self-hosting
    • Typography research — analyse the library by category, popularity, trend, variable/color support, or date
    • Icon catalogs — export Material icon names, codepoints, categories, tags, sizes, and family support
    • Localization — filter families by language subset (Cyrillic, Greek, Vietnamese, and more)

    Fix common problems

    Why is menu in subsets?

    It is a synthetic subset Google adds to every family; languageSubsets removes it. About 110 menu-only families have no unicode-range/coverage data.

    Why is languages empty or missing?

    The main catalog's languages array is empty for all 1,959 families upstream. The actor therefore does not publish it from the catalog. includeLicense enrichment fetches the per-family endpoint (one request per family) and writes languages there; even then, a few families (Noto Color Emoji, Noto Emoji, Allkin) have no language list.

    Why are popularity and trending not 1..N?

    They are sparse snapshot ranks from an opaque upstream universe, not catalog positions. In the current snapshot popularity has gaps and values above 2,000, and trending has hundreds of gaps and values above 2,400; both change day to day. Use defaultSort or name when you need deterministic ordering, and treat the ranks as relative signals only.

    More from the publisher:

    • Why do some file lists stop at 200?

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.
