    Website Contact Page Email & Phone Crawler: export to CSV, Excel or JSON

    Crawl a website's contact, about and team pages and collect its public emails, phone numbers, and social media profile links in one normalized record per site.

    This tutorial runs Website Contact Page Email & Phone Crawler through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON.

    Steps

    1. Get an API token
    2. Choose the input
    3. Run it and write a CSV
    4. Download Excel or JSON
    5. The same in JavaScript
    6. Fix common problems

    Get an API token

    Copy your token from Apify Console, Settings, API and Integrations and keep it in an environment variable rather than in the script.

    Choose the input

    1 field is required:

    • urls: Websites to scan for public contact details. You can paste full URLs or bare domains; duplicates are removed.

    Save this as input.json (scan a single company site):

    The input reference lists every field.

    Run it and write a CSV

    call() starts the run and waits until it finishes, however long that takes; the results land in the run's default dataset, which the loop reads page by page.

    Download Excel or JSON

    The API can run the Actor and hand back the dataset as a file in one request. format takes xlsx, csv, json, jsonl, xml or html. The request waits up to 300 seconds; a longer run answers HTTP 408 and carries on, so use the Python script for big runs.

    To download a run that already finished, use its dataset ID from the run page in Console or from run["defaultDatasetId"]:

    The same in JavaScript

    Fix common problems

    • HTTP 401: the token is missing or wrong; run echo $APIFY_TOKEN in the same shell.
    • An empty file: open the run in Console and read its log; it usually names the input that matched nothing.
    • Odd characters in Excel: open the CSV through Data, From Text/CSV and pick UTF-8, or download xlsx instead.
