    X Video Subtitle & Caption Transcript Converter: export to CSV, Excel or JSON

    Convert public X (Twitter) videos into timestamped transcripts and downloadable SRT/VTT subtitle files, using native captions when available and AI speech-to-text otherwise.

    This tutorial runs X Video Subtitle & Caption Transcript Converter through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 8 columns its publisher puts first: type, tweetUrl, tweetId, videoIndex, videoSource, authorUsername, authorName and language.

    The columns you can export

    The Actor's build declares 29 output fields in 2 dataset views ("Transcripts" and "Segments"). The export below keeps these, under the labels the publisher gave them:

    What people export it for

    • Content accessibility — produce subtitles (SRT/VTT) for public videos
    • Media monitoring — transcribe interviews, press clips and announcements into searchable text
    • Research — build text corpora from public video content for analysis
    • Newsrooms — quote-check and index video statements quickly
    • Podcast and clip workflows — repurpose spoken content into articles or show notes
    • RAG / AI pipelines — use chunks and timestampedText directly
    • Social listening — combine transcripts with engagement data to track narratives

    Fix common problems

    Why is a row missing segments or fullTranscript?

    outputFormat controls which fields are filled, and unavailable transcripts never contain transcript fields — they are status rows with an errorCode and message.

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.
