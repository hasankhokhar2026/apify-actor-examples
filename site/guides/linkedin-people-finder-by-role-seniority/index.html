    LinkedIn People Finder by Role, Seniority & Network: CSV and Excel export

    Search LinkedIn people with structured filters for company, school, seniority, job function, years of experience, industry, and connection degree, using your own LinkedIn session.

    This tutorial runs LinkedIn People Finder by Role, Seniority & Network through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 6 columns its publisher puts first: name, headline, location, connectionDegree, profileUrl and scrapedAt.

    What people export it for

    • Recruiting and sourcing — build a candidate shortlist filtered by seniority, function, and years of experience
    • Sales prospecting — find decision-makers at companies of a specific size and industry
    • Talent mapping — see how many people with a given title work at a target company or came from a specific school
    • Freelance/agency hiring — search for people who've flagged themselves as PROVIDING_SERVICES in a niche
    • Alumni and network outreach — find people from a specific school or who follow your company page

    Get an API token

    Copy it from Console, Settings, API and Integrations.

    Choose the input

    2 fields are required:

    • searchQuery: Search keywords for finding people on LinkedIn. Examples: 'software engineer', 'John Smith', 'product manager Google'
    • cookie: Your LinkedIn session cookie. Accepts either: (1) the li_at value from browser DevTools → Application → Cookies, or (2) full cookies JSON array exported from an extension like EditThisCookie.

    The schema gives no example for cookie; supply a value before you run it.

    Fix common problems

    Why does this actor need a LinkedIn cookie?

    People search is only available to logged-in LinkedIn users, so a valid session cookie (li_at or a full cookie export) is required. Without one, or with an expired one, the run returns only the cookie notice row described above.

    Why is connectionDegree sometimes missing from a result?

    LinkedIn only shows a connection-degree badge for profiles it places in your visible network graph; some results simply don't carry one.

    Why don't all profiles have a profilePicture?

    Some LinkedIn users restrict their photo to connections only; the actor returns the picture URL only when the search response actually includes one.

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.
