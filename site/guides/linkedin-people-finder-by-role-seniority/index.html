    LinkedIn People Finder by Role, Seniority & Network: CSV and Excel export

    Search LinkedIn people with structured filters for company, school, seniority, job function, years of experience, industry, and connection degree, using your own LinkedIn session.

    This tutorial runs LinkedIn People Finder by Role, Seniority & Network through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 6 columns its publisher puts first: name, headline, location, connectionDegree, profileUrl and scrapedAt.

    Get an API token

    Copy your token from Apify Console, Settings, API and Integrations and keep it in an environment variable rather than in the script.

    Choose the input

    2 fields are required:

    • searchQuery: Search keywords for finding people on LinkedIn. Examples: 'software engineer', 'John Smith', 'product manager Google'
    • cookie: Your LinkedIn session cookie. Accepts either: (1) the li_at value from browser DevTools → Application → Cookies, or (2) full cookies JSON array exported from an extension like EditThisCookie.

    The schema gives no example for cookie; supply a value before you run it.

    Run it and write a CSV

    call() starts the run and waits until it finishes, however long that takes; the results land in the run's default dataset, which the loop reads page by page.

    Download Excel or JSON

    The API can run the Actor and hand back the dataset as a file in one request. format takes xlsx, csv, json, jsonl, xml or html, and fields keeps only the columns you list. The request waits up to 300 seconds; a longer run answers HTTP 408 and carries on, so use the Python script for big runs.

    Fix common problems

    • HTTP 401: the token is missing or wrong; run echo $APIFY_TOKEN in the same shell.
    • An empty file: open the run in Console and read its log; it usually names the input that matched nothing.
    • Odd characters in Excel: open the CSV through Data, From Text/CSV and pick UTF-8, or download xlsx instead.
