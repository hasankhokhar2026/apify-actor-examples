    Bring a Trailer Auction & Sold Price Tracker: CSV and Excel export

    Track Bring a Trailer car auctions by keyword, make, or listing URL. Get current bids, final sold prices, reserve status, mileage, seller details and photos for enthusiast and collector vehicles.

    This tutorial runs Bring a Trailer Auction & Sold Price Tracker through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 8 columns its publisher puts first: title, year, make, model, currentBid, bidCount, auctionStatus and endDate.

    Steps

    1. See the columns
    2. Get an API token
    3. Choose the input
    4. Run it and write a CSV
    5. Download Excel or JSON
    6. The same in JavaScript
    7. Fix common problems

    The columns you can export

    The Actor's build declares 10 output fields in 1 dataset view ("Auction Listings"). The export below keeps these, under the labels the publisher gave them:

    Default export columns
    FieldColumn headerWhat it holds
    titletitlefull listing title as published
