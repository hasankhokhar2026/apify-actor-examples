    Twitter (X) Screenshot Generator: export to CSV, Excel or JSON

    Capture clean screenshots of public X posts and profiles without login. Choose post cards, profile headers or full profile pages, dark/light theme, PNG/JPEG/WEBP output, 2x/3x pixel density and optional profile or post details.

    This tutorial runs Twitter (X) Screenshot Generator through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 8 columns its publisher puts first: type, targetUrl, captureMode, theme, status, code, billable and format.

    Steps

    1. See the columns
    2. Get an API token
    3. Choose the input
    4. Run it and write a CSV
    5. Download Excel or JSON
    6. The same in JavaScript
    7. Fix common problems

    The columns you can export

    The Actor's build declares 59 output fields in 1 dataset view ("Screenshots"). The export below keeps these, under the labels the publisher gave them:

    Default export columns
    FieldColumn headerWhat it holds
    typeRow Type
    targetUrlTarget URLThe canonical post or profile URL that was captured (the requested URL on failures)
    captureModeModepostCard, thread, profileHeader or fullProfilePage
    themeThemeThe theme captured in this row (dark or light)
    statusStatussuccess or a friendly error description
    codeCodeTyped failure code: not_found, protected, deleted, login_wall, wrong_author, wrong_target, selector_miss, media_error, browser_crash, network_error, invalid_input or capture_error
    billableBillabletrue only for captured screenshot rows
    formatFormatSaved image format (png, jpeg or webp)

    Swap in any field from the output reference to export it too.

    What people export it for

    • Social media reporting — embed clean post captures in decks, newsletters and blogs
    • Brand monitoring — archive screenshots of public posts as evidence
    • Community management — capture profile pages for creator or partner reviews
    • Research — build image datasets of public posts with consistent framing and theme
    • Content creation — generate post images for roundups without manual screenshotting
    • Legal and compliance — timestamped captures of public posts with source URLs, SHA-256 hashes and a DOM snapshot as an evidence trail
