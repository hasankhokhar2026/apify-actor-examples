    Snapchat Spotlight Video Link & Caption Downloader: CSV and Excel export

    Give this actor one or more Snapchat Spotlight links and get back a direct video link, thumbnail, caption, creator info and engagement counts per video, with optional AI-generated metadata, transcript and comments.

    Fix common problems

    Why is viewCount missing from some records?

    Snapchat returns -1 as a sentinel for videos that are too new to have an accurate view count. The actor omits this field rather than storing a misleading -1. A real zero is kept as 0.

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.
