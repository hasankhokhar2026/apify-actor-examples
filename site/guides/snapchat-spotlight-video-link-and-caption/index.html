    Snapchat Spotlight Video Link & Caption Downloader: CSV and Excel export

    Give this actor one or more Snapchat Spotlight links and get back a direct video link, thumbnail, caption, creator info and engagement counts per video, with optional AI-generated metadata, transcript and comments.

    This tutorial runs Snapchat Spotlight Video Link & Caption Downloader through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 8 columns its publisher puts first: snapId, creatorUsername, caption, viewCount, shareCount, commentCount, likeCount and durationSeconds.

    Get an API token

    Copy your token from Apify Console, Settings, API and Integrations and keep it in an environment variable rather than in the script.

    Choose the input

    1 field is required:

    • spotlightUrls: One or more Snapchat Spotlight URLs to download. Supports snapchat.com/spotlight/... (with or without www), snapchat.com/@user/spotlight/..., snapchat.com/t/..., story.snapchat.com/o/... and /s/..., and t.snapchat.com short links.

    Download Excel or JSON

    The API can run the Actor and hand back the dataset as a file in one request. format takes xlsx, csv, json, jsonl, xml or html, and fields keeps only the columns you list. The request waits up to 300 seconds; a longer run answers HTTP 408 and carries on, so use the Python script for big runs.

    Fix common problems

    • HTTP 401: the token is missing or wrong; run echo $APIFY_TOKEN in the same shell.
    • An empty file: open the run in Console and read its log; it usually names the input that matched nothing.
    • Odd characters in Excel: open the CSV through Data, From Text/CSV and pick UTF-8, or download xlsx instead.
