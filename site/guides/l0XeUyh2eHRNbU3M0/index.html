Use IndiaMART B2B Product Listings by City & State with Python

Search IndiaMART's product listings by keyword, optionally narrowed to an Indian state or city, with price, MOQ, supplier name/location, rating, and response rate per listing.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "category": "",
  "city": "",
  "enrichWithProductDetails": false,
  "expandRelatedCategories": false,
  "keyword": "cotton fabric",
  "maxItems": 3,
  "maxPrice": 0,
  "minPrice": 0,
  "minRating": 0,
  "mode": "searchProducts",
  "productUrls": [],
  "state": "",
  "supplierUrls": [],
  "verifiedSuppliersOnly": false
}

Download input.example.json and save your reviewed copy as input.json.

FieldTypeRequiredDescription
modestringrequiredChoose what to collect from IndiaMART.
keywordstringoptionalProduct or material keyword, e.g. 'cotton fabric', 'industrial pump', 'basmati rice'. Required for mode=searchProducts.
categorystringoptionalIndiaMART category slug or category URL, e.g. 'cotton-fabric' or 'https://dir.indiamart.com/impcat/cotton-fabric.html'. Required for mode=browseCategory.
citystringoptionalKeep only suppliers in this Indian city, e.g. 'Surat', 'Mumbai', 'Jaipur'. Works with searchProducts and browseCategory.
statestringoptionalKeep only suppliers in this Indian state or union territory. Leave empty for all of India.
productUrlsarrayoptionalIndiaMART product URLs or numeric product IDs. Used only for mode=productDetails.
supplierUrlsarrayoptionalIndiaMART supplier profile URLs, company IDs, or company aliases. Used only for mode=supplierProfile.
maxItemsintegeroptionalMaximum number of records to return across all keywords and inputs.
expandRelatedCategoriesbooleanoptionalWhen a keyword or category has too few listings, also collect IndiaMART's related product categories. Results are de-duplicated.
enrichWithProductDetailsbooleanoptionalOpen each product page to add description, full specifications, MOQ, contact number, GST, IEC and company details. Adds one request per product.
minPriceintegeroptionalDrop listings priced below this amount. Use 0 for no minimum.
maxPriceintegeroptionalDrop listings priced above this amount. Use 0 for no maximum.
minRatingnumberoptionalDrop suppliers rated below this star rating (0 to 5). Use 0 for no minimum.
verifiedSuppliersOnlybooleanoptionalKeep only suppliers with an IndiaMART verification signal such as TrustSEAL, verified exporter or verified GST.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/l0XeUyh2eHRNbU3M0/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
