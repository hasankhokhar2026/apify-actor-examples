Use LinkedIn Company Headcount & Team Directory Scraper with Python

List current or past employees of any LinkedIn company page with filters for role keyword, seniority, job function, and connection degree. Requires a LinkedIn session cookie.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

  "companyDomains": [
    "stripe.com"

  "companyNames": [],

FieldTypeRequiredDescription
companyUrlsarrayoptionalLinkedIn company page URLs. Accepts https://www.linkedin.com/company/stripe/, linkedin.com/company/stripe, or company/stripe.
companyDomainsarrayoptionalCompany website domains, e.g. stripe.com or notion.so. The resolver follows LinkedIn's page website to pick the correct same-name company.
companyNamesarrayoptionalCompany display names, e.g. Stripe or Microsoft. Name-only input is validated; ambiguous bare names (Notion, Linear, Cal) return an error row asking for a URL or domain.
includeEmployeesbooleanoptionalWhen true, also request the employee roster. Requires a valid LinkedIn session cookie and is capped by LinkedIn at 2,500 visible results per query.
maxEmployeesintegeroptionalRoster cap per company (1-2500). Ignored when includeEmployees is false. Large companies are sampled.
maxItemsTotalintegeroptionalHard cap across company summaries, employee rows, and error rows (1-10000).
startPageintegeroptionalResume the roster from this page (1-250, 10 employees per page). Use it to continue a capped run.
titleKeywordsstringoptionalRoster filter: free-text role or headline match, e.g. Software Engineer or VP Sales. Cookie roster only.
locationstringoptionalRoster filter: best-effort location match on the employee's LinkedIn location, e.g. London. Cookie roster only.
seniorityLevelsarrayoptionalRoster filter: one or more LinkedIn seniority levels. Empty means all levels. Cookie roster only. Allowed values: Entry, Associate, Mid-Senior, Director, Executive.
functionsarrayoptionalRoster filter: one or more LinkedIn job functions. Empty means all functions. Cookie roster only. Allowed values: Engineering, Sales, Marketing, Operations, Finance, Human Resources, Design, Product, Customer Service, Information Technology, Legal, Other.
connectionDegreestringoptionalRoster filter: restrict to 1st, 2nd, or 3rd+ degree connections. Cookie roster only.
languagestringoptionalRoster filter: primary profile language. Cookie roster only.
cookiesstringoptionalOptional LinkedIn session cookie for the employee roster. Accepts the li_at value or a full cookies JSON array. Never required for headcount/firmographics.
proxyConfigurationobjectoptionalOptional advanced override. The actor works without a proxy and chooses a working connection automatically.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/HiQGqCcdufptzP7GA/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
