Use LinkedIn Company Headcount & Team Directory Scraper with Python

List current or past employees of any LinkedIn company page with filters for role keyword, seniority, job function, and connection degree. Requires a LinkedIn session cookie.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

Download input.example.json and save your reviewed copy as input.json.

FieldTypeRequiredDescription
companyUrlsarrayrequiredLinkedIn company page URLs or slugs. Accepts: https://www.linkedin.com/company/microsoft/, https://www.linkedin.com/company/microsoft/about/, or just the slug: microsoft
cookiestringrequiredYour LinkedIn session cookie. Accepts: (1) the li_at value from browser DevTools, or (2) full cookies JSON array from an extension like EditThisCookie.
maxEmployeesintegeroptionalMaximum number of employee profiles to scrape per company. LinkedIn typically surfaces 200-1000 employees for large companies.
keywordsstringoptionalOptional keyword to narrow results (e.g., 'Software Engineer', 'VP Sales'). Leave blank to return all visible employees.
locationstringoptionalFilter employees by location (e.g., 'New York', 'London', 'Remote').
connectionDegreestringoptionalFilter by LinkedIn connection degree: F = 1st, S = 2nd, O = 3rd+
seniorityLevelstringoptionalFilter by seniority level.
functionstringoptionalFilter employees by job function (e.g., Engineering, Sales).
currentCompanybooleanoptionalWhen true, restrict results to people currently working at the company. When false, include past employees as well.
languagestringoptionalFilter by primary profile language.
proxyConfigurationobjectoptionalOptional Apify proxy configuration. Residential proxy recommended for best results.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/HiQGqCcdufptzP7GA/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
