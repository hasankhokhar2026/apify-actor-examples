Use GOC Optician & Optometrist Register Scraper with Python

Search the General Optical Council's public Specialist Register (str.optical.org) for registered UK optometrists, dispensing opticians, students, and optical businesses - by name, GOC number, specialty, or postcode radius.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "address": "",
  "companyName": "",
  "fetchDetails": true,
  "forename": "",
  "gocNumbers": [],
  "maxItems": 50,
  "mode": "registrant",
  "postcode": "",
  "radiusMiles": 50,
  "registerType": "",
  "sortBy": "",
  "soundsLikeSurname": false,
  "speciality": "",
  "surname": "Smith"
}

Download input.example.json and save your reviewed copy as input.json.

FieldTypeRequiredDescription
modestringrequiredSearch individual registrants (optometrists/dispensing opticians) or registered optical businesses (body corporates).
surnamestringoptionalFilter registrants whose surname contains this text. Case-insensitive, matches anywhere in the surname.
soundsLikeSurnamebooleanoptionalWhen enabled, `surname` is matched phonetically (e.g. 'Smyth' also matches 'Smith') instead of as a literal substring.
forenamestringoptionalFilter registrants by first name (contains match).
registerTypestringoptionalRestrict to a specific registration category.
specialitystringoptionalRestrict to registrants holding a specific specialty annotation.
addressstringoptionalFilter registrants by address text (contains match).
sortBystringoptionalSort registrant results by surname.
companyNamestringoptionalFilter optical businesses whose registered name contains this text.
gocNumbersarrayoptionalExact-match one or more GOC registration numbers (e.g. `01-12294` for a registrant or `CO-4310` for a business). Overrides name-based search when provided.
postcodestringoptionalUK postcode to search around. Combined with `radiusMiles`. Works for both registrants and businesses.
radiusMilesintegeroptionalDistance in miles from `postcode` to search within. Only used when `postcode` is set.
fetchDetailsbooleanoptionalVisit each registrant/business detail page to also capture qualifications, town, practice address, and fitness-to-practise decisions. Slower but much richer records. Disable for a faster, list-only run.
maxItemsintegeroptionalHard cap on the number of records returned.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/nM2vtMcH1bZsKtNf3/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
