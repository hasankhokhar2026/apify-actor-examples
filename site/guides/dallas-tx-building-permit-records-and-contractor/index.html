    Dallas TX Building Permit Records & Contractor Lookup: CSV and Excel export

    Search City of Dallas building permit filings by type, land use, ZIP code, contractor, date range, or declared value and area, or look up exact permits by permit number.

    This tutorial runs Dallas TX Building Permit Records & Contractor Lookup through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 8 columns its publisher puts first: permitNumber, permitType, activity, status, issuedDate, createdDate, streetAddress and zipCode.

    Steps

    1. See the columns
    2. Get an API token
    3. Choose the input
    4. Run it and write a CSV
    5. Download Excel or JSON
    6. The same in JavaScript
    7. Fix common problems

    The columns you can export

    The Actor's build declares 14 output fields in 1 dataset view ("Building permits"). The export below keeps these, under the labels the publisher gave them:

    Default export columns
    FieldColumn headerWhat it holds
    permitNumberpermitNumberDallas permit number

    statusstatusStatus when the City extracted the GIS layer in November 2024

    createdDatecreatedDateApplication/creation date in YYYY-MM-DD format

    Swap in any field from the output reference to export it too.
