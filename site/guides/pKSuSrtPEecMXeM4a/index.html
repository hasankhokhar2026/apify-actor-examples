Use Yahoo Finance Market Data & Fundamentals Scraper with Python

Pull live quotes, historical OHLCV candles, financial statements, dividends, splits, news, analyst ratings and holder data from Yahoo Finance for any ticker, ETF, index, currency pair or crypto symbol.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "tickers": [
    "AAPL",
    "MSFT"
  ]
}

Download input.example.json and save your reviewed copy as input.json.

FieldTypeRequiredDescription
tickersarrayrequiredOne or more stock ticker symbols (e.g. `AAPL`, `MSFT`, `BRK-B`). Supports US, ETFs, ADRs, foreign tickers with suffix (e.g. `BABA`, `TSM`, `BP.L`).
startDatestringoptionalEarliest date for historical OHLCV data. Optional — default is 30 days before today.
endDatestringoptionalLatest date for historical OHLCV data. Optional — default is today.
intervalstringoptionalCandle interval for historical data.
includeHistorybooleanoptionalInclude daily OHLCV history (open / high / low / close / volume) in each record.
includeFinancialsbooleanoptionalInclude income statement, balance sheet, and cash flow statement (annual).
includeDividendsbooleanoptionalInclude dividend history.
includeSplitsbooleanoptionalInclude stock-split history.
includeNewsbooleanoptionalInclude latest news headlines linked to the ticker.
includeRecommendationsbooleanoptionalInclude analyst recommendation breakdown (strongBuy / buy / hold / sell / strongSell).
includeHoldersbooleanoptionalInclude major / institutional / mutual-fund holder summaries.
includeOptionsbooleanoptionalInclude the next-expiration options chain (calls + puts) when listed. Capped at first 50 strikes per side to keep dataset compact.
includeEarningsCalendarbooleanoptionalInclude upcoming earnings/dividend dates + analyst earnings/revenue estimates.
includeAnalystPriceTargetsbooleanoptionalInclude analyst price target summary (current / high / low / mean / median).
includeInsiderTransactionsbooleanoptionalInclude the 25 most-recent insider transactions (officers / directors / 10%-owners).
includeSustainabilitybooleanoptionalInclude ESG / sustainability scores when Yahoo publishes them (sparse coverage; many tickers return empty).
includeQuarterlyFinancialsbooleanoptionalInclude quarterly income statement, balance sheet, and cash flow (last ~5 quarters). Takes effect only when `includeFinancials` is also on.
includeEarningsHistorybooleanoptionalInclude the last 4 quarters of earnings: actual EPS, estimate, surprise amount, and surprise percent.
concurrencyintegeroptionalNumber of tickers fetched in parallel. Each fetch is mostly idle waiting on Yahoo, so concurrency speeds up bulk runs significantly. Higher values may trigger Yahoo rate-limits.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/pKSuSrtPEecMXeM4a/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
# Inspect and download results in Apify Console once the run succeeds.

Open the run in Apify Console and wait for a successful completion. Use the published output schema to locate results and the dataset schema to understand declared views. Missing or optional record fields must not be treated as guaranteed values.

What does this guide verify?

What if the run request times out?

Check Apify Console before retrying. The first request may already have created a run. Do not automatically repeat a run-creation POST.
