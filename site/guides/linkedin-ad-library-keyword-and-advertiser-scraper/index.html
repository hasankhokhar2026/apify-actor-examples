    LinkedIn Ad Library Keyword & Advertiser Scraper: export to CSV, Excel or JSON

    Search the public LinkedIn Ad Library by keyword, advertiser, country, or date range, and get headline, body copy, advertiser info, media URLs, and call-to-action for the ads each search returns.

    This tutorial runs LinkedIn Ad Library Keyword & Advertiser Scraper through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 8 columns its publisher puts first: advertiser_name, ad_format, headline, body_text, cta_text, start_date, end_date and total_impressions.

    Fix common problems

    Do I need to configure a proxy?

    No. The actor selects and rotates its proxy automatically.

    Why do some ads lack impressions, dates, or targeting?

    LinkedIn only publishes that transparency block for ads served in the EU. Non-EU ads have no run dates, impression range, country shares, or targeting data. The has_dsa_data flag tells you which is which. This is a source limitation, not a scraper bug.

    Why are media URLs signed?

    LinkedIn CDN URLs carry an e= expiry parameter. The actor exposes the URL and its expiresAt date in media[].expiresAt. Download or archive media before it expires if you need a permanent copy.

    More from the publisher:

    • Why is body_text shorter than body_text_full?

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.
