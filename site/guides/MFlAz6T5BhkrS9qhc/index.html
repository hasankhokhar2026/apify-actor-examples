Use Bluesky Posts, Profiles, Feeds & Threads Scraper with Python

Search Bluesky posts by keyword or hashtag, read a user's timeline and profile, expand a post thread, pull a custom feed, or list followers, follows, and likes, with engagement counts and media on every post.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "actor": "bsky.app",
  "excludeReplies": false,
  "excludeReposts": false,
  "maxItems": 40,
  "mediaOnly": false,
  "mode": "search",
  "searchQuery": "bluesky"
}

Download input.example.json and save your reviewed copy as input.json.

FieldTypeRequiredDescription
modestringrequiredWhat to fetch.
searchQuerystringoptionalKeyword, hashtag (with `#`), or full-text query. Bluesky supports its standard search operators: `from:user`, `since:YYYY-MM-DD`, `lang:en`, etc.
searchSortstringoptionalSort order for `mode=search`. `top` ranks by engagement; `latest` ranks by recency.
actorstringoptionalBluesky handle (e.g. `bsky.app`, `jay.bsky.team`) or full DID (`did:plc:...`). Used by profile / follows / followers / actorLikes modes.
postUristringoptionalFull AT URI of the post (`at://did:plc:.../app.bsky.feed.post/<rkey>`).
postUrisarrayoptionalUp to 25 AT URIs to batch-hydrate. Each must be `at://did:plc:.../app.bsky.feed.post/<rkey>`.
postUrlsarrayoptionalPublic bsky.app post URLs to expand, e.g. `https://bsky.app/profile/bsky.app/post/3kxxxx`.
listUristringoptionalAT URI of a Bluesky list (`at://did:plc:.../app.bsky.graph.list/<rkey>`).
starterPackUristringoptionalAT URI of a Bluesky starter pack (`at://did:plc:.../app.bsky.graph.starterpack/<rkey>`).
feedPresetstringoptionalBuilt-in Bluesky feed preset. Overrides `feedUri` if both are set.
feedUristringoptionalFull AT URI of a feed generator (`at://did:plc:.../app.bsky.feed.generator/<rkey>`). Use this for community feeds not in the preset list.
languagestringoptionalISO 639-1 language code. Drops posts not in this language. Empty = no filter.
excludeRepliesbooleanoptionalDrop posts that are replies to another post.
excludeRepostsbooleanoptionalDrop posts that are reposts of someone else's post.
mediaOnlybooleanoptionalOnly emit posts that have at least one image / video / external embed.
minLikesintegeroptionalDrop posts with fewer than this many likes.
minRepostsintegeroptionalDrop posts with fewer than this many reposts.
sincestringoptionalEarliest post date as `YYYY-MM-DD`. Bluesky search recency-weights its index; use the explicit `since:` filter for strict date bounds.
untilstringoptionalLatest post date as `YYYY-MM-DD`.
fromUserstringoptionalRestrict search to posts authored by this handle (or DID).
maxItemsintegeroptionalHard cap on emitted records.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/MFlAz6T5BhkrS9qhc/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
