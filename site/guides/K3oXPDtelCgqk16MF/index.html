Use YouTube Channel Video Feed Quick Scraper with Python

Quickly list any YouTube channel's videos, sorted newest, most popular or oldest, with channel subscriber count, verification and optional Shorts, playlists and live-stream tabs.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "channelUrls": [
    "https://www.youtube.com/@Apify"
  ],
  "includeAbout": true,
  "includeCommentCounts": false,
  "includeLiveVideos": false,
  "includePlaylists": false,
  "includeShorts": false,
  "language": "en",
  "market": "US",
  "maxLiveVideos": 20,
  "maxPlaylists": 20,
  "maxShorts": 20,
  "maxVideos": 3,
  "onlyNewVideos": false,
  "sortShortsBy": "latest",
  "sortVideosBy": "newest",
  "videoSource": "videosTab"
}

Download input.example.json and save your reviewed copy as input.json.

FieldTypeRequiredDescription
channelUrlsarrayrequiredYouTube channel URLs, handles (@username), or channel IDs (UCxxx). Accepts any format.
maxVideosintegeroptionalMaximum number of videos to scrape per channel. Set to 0 to get only channel info without videos. The 10,000 cap is an intentional policy limit for a bounded run. Exact player metadata refresh has a 900-second budget per actor run; if that budget is reached, remaining rows keep the listing metadata (title, view text, relative date) and the run still emits the full dataset.
videoSourcestringoptionalWhere to read the video list from. The uploads playlist is a complete chronological feed that also includes Shorts and uploads the Videos tab omits. 'Both' merges the two sources, de-duplicated by video ID, then applies the chosen sort.
sortVideosBystringoptionalHow to order the channel's videos. The uploads playlist is already newest-first; Popular/Oldest are applied client-side to a scan window of max(maxVideos, min(2 * maxVideos, 60)) videos. The Videos tab uses YouTube's native sort chips across its full history.
sortShortsBystringoptionalOrder of the Shorts tab when 'Include Channel Shorts' is on. The Shorts tab exposes Latest, Popular and Oldest filters.
includeCommentCountsbooleanoptionalFetch the exact public comment count for every video. Costs up to two extra requests per video: a /next seed (reused from the description-enrichment call when that already ran) plus a comments-continuation request when the count is not in the seed. The field is skipped for videos with comments disabled.
onlyNewVideosbooleanoptionalMonitor mode: return only videos not returned by an earlier run for the same channel. State is kept in the actor's named key-value store, which persists across runs. Only emitted rows are marked seen, so maxVideos pauses the remainder instead of skipping it.
includeAboutbooleanoptionalExtract total views, join date, location, external links and channel analytics from the channel About page and video sample.
includePlaylistsbooleanoptionalScrape the channel Playlists tab and include playlist metadata in the output.
maxPlaylistsintegeroptionalMaximum number of playlists to scrape (when includePlaylists is enabled).
includeShortsbooleanoptionalScrape the channel Shorts tab and include Shorts in the output. Also marks matching uploads-playlist videos with isShort.
maxShortsintegeroptionalMaximum number of Shorts to return (when includeShorts is enabled).
includeLiveVideosbooleanoptionalScrape the channel Live/Streams tab and include live/archived streams.
maxLiveVideosintegeroptionalMaximum live/stream videos to return.
marketstringoptionalCountry context (gl) applied to every page and InnerTube request, including pagination, player and comment endpoints.
languagestringoptionalInterface language (hl) for labels and relative dates. Titles and descriptions stay in the creator's language.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/K3oXPDtelCgqk16MF/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
# Inspect and download results in Apify Console once the run succeeds.

4. Inspect the actual results

Open the run in Apify Console and wait for a successful completion. Use the published output schema to locate results and the dataset schema to understand declared views. Missing or optional record fields must not be treated as guaranteed values.

One row per video with recordType/sourceUrl, exact publish date, like count, category, tags, optional comment count, view/like metrics, Shorts and live flags, plus the channel's authorMetadata with subscriber counts, About-page links and derived channel analytics (lastUploadDate, averageViews, uploadFrequencyDays, videosAnalyzed). recordType is 'video' for video rows, 'channel' for the channel-info-only row (maxVideos=0 or no videos), and 'error' for a failed channel. Optional shorts, playlists and liveVideos arrays are attached to the first row when their include... input is enabled.

Questions before you run

Which inputs are required?

The published required fields are channelUrls

What does this guide verify?

The fields, prefills, and schema links are rendered from the published build. This is a usage recipe, not a paid live extraction test. Source availability and collection results can vary.

What if the run request times out?

Check Apify Console before retrying. The first request may already have created a run. Do not automatically repeat a run-creation POST.
