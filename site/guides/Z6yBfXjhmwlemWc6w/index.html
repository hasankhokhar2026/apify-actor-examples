Use ImportYeti US Importer & Global Supplier Search with Python

Search ImportYeti by company name or product keyword to find US importers or their overseas suppliers, with country, address, lifetime shipment count, most recent shipment date, trademarks, and profile link.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "includeShipments": false,
  "maxItems": 3,
  "mode": "searchImporters",
  "proxyConfiguration": {
    "useApifyProxy": true
  },
  "query": "electronics",
  "startUrls": []
}

Download input.example.json and save your reviewed copy as input.json.

FieldTypeRequiredDescription
modestringrequiredWhat to do. Search by keyword, load specific company/supplier profiles, or explore an HS code.
querystringoptionalCompany name or product keyword for searchImporters/searchSuppliers. Optional in companyProfile (a profile URL here is used when startUrls is empty) and in searchByHsCode (a numeric HS code here is used when hsCode is empty).
startUrlsarrayoptionalFor companyProfile: ImportYeti profile URLs or paths. Accepts company/..., supplier/..., us-export/company/..., mx/company/..., and mx/supplier/... (e.g. https://www.importyeti.com/company/samsung-electronics-america or supplier/foxconn). Bare slugs are treated as US company profiles.
hsCodestringoptionalFor searchByHsCode: 2-10 digits. 2-digit chapters (84) and 4-digit headings (8418) load their page directly; 6+ digit subheadings use the HS search API (e.g. 841810 or 8418.10). 8- and 10-digit HTS codes fall back to the 6-digit subheading when needed.
maxItemsintegeroptionalMaximum number of dataset records across companies, HS summaries, and shipment rows.
includeShipmentsbooleanoptionalAdd one record per recent bill of lading with recordType=shipment. US import profiles expose up to 100 recent BOLs (two 50-row views merged by BOL); US export and Mexico profiles expose up to 50. In search modes this costs one extra profile request per company.
sincestringoptionalOptional recency filter, YYYY-MM-DD or DD/MM/YYYY. Applies to shipment dates and to a company's most recent shipment date. Records without a date are excluded when this is set.
addressContainsstringoptionalOptional case-insensitive filter on the company or supplier address, e.g. a state, city, or street keyword.
proxyConfigurationobjectoptionalOptional proxy settings. ImportYeti allows about 25 requests per IP before a login wall; Apify Proxy AUTO (included in the plan) rotates exit IPs. No residential proxy is required.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/Z6yBfXjhmwlemWc6w/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
# Inspect and download results in Apify Console once the run succeeds.

4. Inspect the actual results

Open the run in Apify Console and wait for a successful completion. Use the published output schema to locate results and the dataset schema to understand declared views. Missing or optional record fields must not be treated as guaranteed values.

One dataset with recordType=company or supplier (US import, US export, and Mexico profile/search data), recordType=hsCode (HS code summary), and optional recordType=shipment rows (one per recent bill of lading).
