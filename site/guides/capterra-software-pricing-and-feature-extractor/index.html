Use Capterra Software Pricing & Feature Extractor with Python

Look up Capterra software products by direct URL or by name and get pricing plans, feature and integration lists, ratings, pros/cons summaries, and vendor details for each product.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

FieldTypeRequiredDescription
modestringrequiredWhat to scrape. Product URLs give the full profile; search queries resolve up to 20 products per query; category URLs walk a ranked category listing.
productUrlsarrayoptionalCapterra product pages to scrape (mode=byProductUrls). Paste full URLs such as https://www.capterra.com/p/135003/Slack/ , /p/id/slug paths, or compare URLs (both products are expanded). Regional capterra.* domains are accepted.
searchQueriesarrayoptionalProduct names or category terms to search on Capterra (mode=bySearchQueries), e.g. `Slack`, `project management software`, `CRM`. Capterra returns up to 20 products per query.
categoryUrlsarrayoptionalCapterra category pages or slugs to browse (mode=byCategoryUrls), e.g. https://www.capterra.com/team-communication-software/ or `team-communication-software`. Use spaces or hyphens in the slug.
sortBystringoptionalOrder of products inside a category listing (mode=byCategoryUrls).
maxItemsintegeroptionalMaximum number of product records to emit.
includeReviewsbooleanoptionalAttach the latest reviews that Capterra publishes on the product page. Set false for the smallest possible run.
maxReviewsintegeroptionalMaximum reviews attached to each product record (used when Include reviews is on).
reviewSortstringoptionalHow attached reviews are ordered before the per-product limit is applied.
minReviewRatingintegeroptionalKeep only reviews with at least this star rating. 0 means no minimum.
maxReviewRatingintegeroptionalKeep only reviews with at most this star rating. 0 means no maximum.
fetchAllReviewsbooleanoptionalAlso walk the dedicated reviews pages to collect more reviews than the product page shows, up to Max reviews. Adds one request per review page.
includeAlternativesbooleanoptionalAttach the products Capterra lists as alternatives (name, rating, price, URL).
includeFaqsbooleanoptionalAttach the product FAQ entries shown on the Capterra profile.
_probeBrowserbooleanoptionalInternal diagnostic mode. Tests the transport matrix and writes one probe record per combination; no product records are produced.
_probeTransportstringoptionalInternal. `full` tests every transport already probed; `auto` tests only the free AUTO datacenter rung.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/LZiSsJmpuWcRPjgRk/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
# Inspect and download results in Apify Console once the run succeeds.
