Use LinkedIn People Finder by Role, Seniority & Network with Python

Search LinkedIn people with structured filters for company, school, seniority, job function, years of experience, industry, and connection degree, using your own LinkedIn session.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

The published schema does not supply an example for these required fields: cookie. Supply them using the reference documentation before execution.

FieldTypeRequiredDescription
searchQuerystringrequiredSearch keywords for finding people on LinkedIn. Examples: 'software engineer', 'John Smith', 'product manager Google'
keywordsstringoptionalOptional companion to Search Query. When both are set, they are combined with a space. Use this to keep a primary role in Search Query and add modifiers (industry buzzwords, tools) here.
cookiestringrequiredYour LinkedIn session cookie. Accepts either: (1) the li_at value from browser DevTools → Application → Cookies, or (2) full cookies JSON array exported from an extension like EditThisCookie.
locationstringoptionalFilter results by location (city, state, or country). Example: 'San Francisco Bay Area', 'New York', 'United Kingdom'
currentCompanystringoptionalFilter by current company. Accepts a company name (e.g. 'Google') or a LinkedIn fsd_company URN/numeric ID. URN format produces the strict structured currentCompany filter; plain names are added to keywords.
pastCompanystringoptionalFilter by past company. Accepts a company name or a LinkedIn fsd_company URN/numeric ID.
schoolstringoptionalFilter by school or university attended. Accepts a school name or a LinkedIn fsd_school URN/numeric ID. Example: 'Stanford University', 'MIT', or '12345'.
firstNameKeywordstringoptionalFilter by first name token. Adds a strict firstName filter to the search.
lastNameKeywordstringoptionalFilter by last name token. Adds a strict lastName filter to the search.
titleKeywordstringoptionalFilter by current job title keyword (e.g. 'Director of Engineering', 'CTO'). Different from Industry / Job Function — this is the free-text title.
serviceCategorystringoptionalFilter by LinkedIn Services Marketplace category (e.g. 'Web Development', 'Marketing Strategy').
companyHeadcountarrayoptionalFilter by employer company size. A=Self-employed, B=1-10, C=11-50, D=51-200, E=201-500, F=501-1,000, G=1,001-5,000, H=5,001-10,000, I=10,001+.
followerOfstringoptionalFilter to people who follow a specific company. Accepts an fsd_company URN or numeric company ID.
geoUrnstringoptionalPrecise location filter using a LinkedIn geo URN or numeric geo ID (e.g. '103644278' for the United States). Use this for strict geographic filtering instead of the free-text Location field.
connectionDegreestringoptionalFilter by connection degree to your account.
industrystringoptionalFilter results by industry. Applied to both Voyager filters and the HTML search URL.
seniorityLevelstringoptionalFilter results by seniority level.
yearsOfExperiencestringoptionalFilter results by years of total professional experience. 1=Less than 1 year, 2=1-2 years, 3=3-5 years, 4=6-10 years, 5=11-15 years, 6=16+ years.
jobFunctionstringoptionalFilter results by job function / department.
openToarrayoptionalFilter people by what they are open to. Select one or more options. HIRING = open to hiring, GETTING_HIRED = open to new jobs, PROVIDING_SERVICES = open to providing freelance/consulting services, JOINING_A_NONPROFIT = open to joining a nonprofit.
profileLanguagesarrayoptionalFilter by the language(s) the person's LinkedIn profile is written in. Use ISO 639-1 codes, e.g. ["en", "es", "fr", "de", "zh", "ar", "pt"].
contactOfstringoptionalFilter to show people who are connections of the specified LinkedIn member. Provide the member's URN (e.g. 'urn:li:member:123456') or numeric profile ID.
talksAboutstringoptionalFilter to people who talk about the specified keyword or topic in their profile. This is appended to the search keywords.
maxResultsintegeroptionalMaximum number of profiles to return.
proxyConfigurationobjectoptionalOptional Apify proxy configuration.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/M7DHH5XpX0Xay3eLy/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
