Use TikTok Follow Graph & Audience Export Scraper with Python

Export who a TikTok account follows, or who follows it, as full profile records with bio, verification status and engagement stats. Following lists need no login; followers lists need a session cookie.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "includeStats": true,
  "listType": "following",
  "maxUsersPerProfile": 30,
  "usernames": [
    "natgeo"
  ]
}

Download input.example.json and save your reviewed copy as input.json.

FieldTypeRequiredDescription
usernamesarrayoptionalTikTok usernames (with or without @) to fetch followers/following for.
profileUrlsarrayoptionalTikTok profile URLs as alternative or additional input. E.g. https://www.tiktok.com/@natgeo
listTypestringoptionalChoose whether to scrape followers, following, or both lists for each profile. NOTE: 'followers' requires a sessionCookie — without it TikTok's API returns a generic list, not the account's real followers. 'following' works without a cookie.
maxUsersPerProfileintegeroptionalMaximum number of follower or following users to fetch per profile.
includeStatsbooleanoptionalInclude follower/following/heart/video counts from statsV2 for each user in the output.
sessionCookiestringoptionalValue of the TikTok `sessionid` cookie. **Required to scrape followers** — without it, TikTok's API ignores the target account and returns a generic regional list. Not needed for 'following' mode. To obtain: install Cookie-Editor extension → log into TikTok → click Cookie-Editor → find 'sessionid' → copy its Value.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/nxE2KWdgv1HXvzAN2/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])

Questions before you run

What does this guide verify?
