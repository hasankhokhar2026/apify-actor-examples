Use TikTok Follow Graph & Audience Export Scraper with Python

Export who a TikTok account follows, or who follows it, as full public profile records with bio, verification status and exact engagement stats. No login or cookie is needed for public accounts.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

  "bioKeywords": [],

  "onlyVerified": false,

FieldTypeRequiredDescription
profilesarrayoptionalTikTok usernames, @handles, or profile URLs. Paste one per line. Examples: natgeo, @sephora, https://www.tiktok.com/@tiktok.
listTypestringoptionalChoose the side of the follow graph: people who follow the profile, accounts the profile follows, or both lists.
maxUsersPerProfileintegeroptionalMaximum rows to return for each requested list. Each list gets this cap. The source may return fewer when accounts are private or deleted.
includeStatsbooleanoptionalAdd follower, following, likes received, video, likes given, and friend counts for each listed account.
includeBioEmailbooleanoptionalAdd a public email address from the bio when one is present. The field is omitted when the bio has no valid email.
onlyVerifiedbooleanoptionalOnly include accounts with a TikTok verified badge.
sellerOnlybooleanoptionalOnly include accounts marked as TikTok Shop sellers.
excludePrivatebooleanoptionalSkip accounts whose profile is private.
minFollowersintegeroptionalOnly include accounts with at least this many followers. 0 = no minimum.
maxFollowersintegeroptionalOnly include accounts with at most this many followers. 0 = no maximum.
bioKeywordsarrayoptionalOnly include accounts whose bio or display name contains any of these keywords. Matching is case-insensitive.
onlyWithEmailbooleanoptionalOnly include accounts with a public email in the bio. This also fills the bioEmail field.
scanLimitintegeroptionalMaximum list rows to scan before stopping. Use a higher value to search deeper for rare filters. 0 = automatic (10x the row cap, up to 10,000).

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/nxE2KWdgv1HXvzAN2/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])

Questions before you run

Which inputs are required?

No top-level fields are marked required in the published schema. Conditional requirements can still apply; check the README.

What does this guide verify?

The fields, prefills, and schema links are rendered from the published build. This is a usage recipe, not a paid live extraction test. Source availability and collection results can vary.

What if the run request times out?

Check Apify Console before retrying. The first request may already have created a run. Do not automatically repeat a run-creation POST.
