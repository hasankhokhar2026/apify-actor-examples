    Skiplagged Route Fare & Booking Provider Finder: CSV and Excel export

    Search Skiplagged flight fares for one route, a batch of routes, or pasted search URLs, returning price, airlines, flight numbers, layovers, stops and the booking provider for each itinerary.

    This tutorial runs Skiplagged Route Fare & Booking Provider Finder through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 8 columns its publisher puts first: originAirport, destinationAirport, departureTime, arrivalTime, airlines, stops, hiddenCity and virtualInterline.

    Steps

    1. See the columns
    2. Get an API token
    3. Choose the input
    4. Run it and write a CSV
    5. Download Excel or JSON
    6. The same in JavaScript
    7. Fix common problems

    Swap in any field from the output reference to export it too.

    Get an API token

    Copy it from Console, Settings, API and Integrations.

    Choose the input

    1 field is required:

    • mode: What to fetch. search uses one origin/destination, byRoutes reads the routes array, byUrls parses pasted Skiplagged URLs, and calendar returns a flexible-date price calendar for one route.

    Save this as input.json (hidden-city only, nonstop to London):

    Keep the first export small. These fields cap how many results a run collects, and so what it costs:

    • maxItems (default 50, maximum 1000)

    call() waits for the run to finish; the loop then reads the results page by page.
