    Welcome to the Jungle Job Listings & Salary Scraper: CSV and Excel export

    Search Welcome to the Jungle job postings by keyword, location, contract type and remote policy. Returns company, salary when disclosed, sector, experience and education requirements for each listing.

    Fix common problems

    Do I need to configure a proxy?

    No. The actor handles its connections automatically; just fill in the input and run it.

    Why is salary missing from some records?

    Many employers do not publish a salary. When they do, the actor returns the range, period and currency when published, plus a normalized yearly minimum when the source provides one. The actor never estimates pay.

    Why are experience or education fields missing?

    Those values are omitted when the posting does not state them.

    More from the publisher:

    • Why does company mode return one record per company?

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.
