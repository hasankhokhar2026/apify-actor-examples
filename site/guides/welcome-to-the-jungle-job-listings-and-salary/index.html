Use Welcome to the Jungle Job Listings & Salary Scraper with Python

Search Welcome to the Jungle job postings by keyword, location, contract type and remote policy. Returns company, salary when disclosed, sector, experience and education requirements for each listing.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

maxExperienceYearsintegeroptionalOnly jobs requiring at most this many years of experience. Jobs without a stated experience level are excluded when this is set. 0 = no maximum.

onlyWithSalarybooleanoptionalKeep only postings that publish a salary amount (yearly, monthly, daily or hourly).

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/RvEKmp5tZp7gMDteQ/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
