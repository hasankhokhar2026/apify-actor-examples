    Complete Page Capture - Screenshot & PDF: export to CSV, Excel or JSON

    Capture complete full-page screenshots or PDFs of any URL list. Scrolls lazy content, waits for images and fonts, removes fixed headers and consent overlays, emulates real devices, and reports blocks and truncation instead of returning a broken image.

    This tutorial runs Complete Page Capture - Screenshot & PDF through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 8 columns its publisher puts first: startUrl, url, pageTitle, status, httpStatus, blocked, format and imageWidth.

    Fix common problems

    Do I need a proxy?

    No. The actor starts with a direct connection and only uses an AUTO datacenter proxy after a real block. If you supply your own proxy, it is used instead.

    Why is a page reported as blocked?

    The actor saw an HTTP 403/429/451, a CAPTCHA/Cloudflare challenge, or a login wall. The block page is not saved as a normal screenshot.

    Why is my image shorter than the page?

    Check truncated and warnings. maxPageHeight or maxScrollSteps may have capped the capture.

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.
