Use Pexels Stock Media Scraper with Python

Scrape free stock photos and videos from Pexels. Search by keyword, browse curated/popular media, a photographer's portfolio, or a curated collection. Get direct image and video file URLs, photographer credit, tags, colors, and more.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

FieldTypeRequiredDescription
modestringrequiredWhat to fetch from Pexels.
searchQuerystringoptionalKeyword to search for (mode=search). Example: `nature`, `city skyline`, `coffee`.
mediaTypestringoptionalWhich kind of media to return. For mode=search this selects between Pexels' separate photo-search and video-search pages (`all` is treated as `photos`). For mode=curated/byUser/byCollection, `all` returns both photos and videos as they naturally appear in the feed.
orientationstringoptionalFilter results by image/video orientation.
minWidthintegeroptionalOnly return media whose width is at least this many pixels. 0 disables the filter.
minHeightintegeroptionalOnly return media whose height is at least this many pixels. 0 disables the filter.
minDurationintegeroptionalOnly return videos at least this many seconds long (videos only; ignored for photos). 0 disables the filter.
maxDurationintegeroptionalOnly return videos at most this many seconds long (videos only; ignored for photos). 0 disables the filter.
peopleCountstringoptionalFilter photo search results by how many people appear in them (mode=search, photos only).
photoIdsarrayoptionalPexels photo IDs or full photo page URLs (mode=byPhotoId: look up these exact photos; mode=similarPhotos: find photos visually/topically similar to each of these). Example: `18872916` or `https://www.pexels.com/photo/18872916/`.
usernamestringoptionalPexels photographer handle or profile URL (mode=byUser). Example: `alex-ivanov-773258579` or `https://www.pexels.com/@alex-ivanov-773258579/`.
collectionSlugstringoptionalPexels curated collection slug or full collection URL (mode=byCollection). Example: `aquatic-aesthetic-bw7dkse` or `https://www.pexels.com/collections/aquatic-aesthetic-bw7dkse/`.
maxItemsintegeroptionalMaximum number of media records to return. NOTE: Pexels' own public search pagination resets to empty results past page 20 (confirmed live: page 20 returns real results, page 21+ returns 0 items regardless of the query), so a single search-style query reliably returns roughly 450 items even when far more matches exist and a higher value is requested here.
proxyConfigurationobjectoptionalOptional Apify proxy. Pexels is generally reachable without a proxy; enable the free Automatic datacenter group only if you experience blocking.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/b6anw2Kxq3xyPpgNC/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
