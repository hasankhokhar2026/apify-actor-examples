    TikTok Post & Slideshow Detail Scraper: export to CSV, Excel or JSON

    Fetch full metadata for any TikTok video or photo-carousel post by URL or ID: engagement stats, author snapshot, music details, hashtags, mentions, and signed media URLs.

    This tutorial runs TikTok Post & Slideshow Detail Scraper through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 8 columns its publisher puts first: postId, postUrl, postType, caption, createdAt, playCount, likeCount and commentCount.

    Fix common problems

    Is a proxy required?

    No. Direct requests are the primary path. If TikTok blocks the request, the actor retries with an Apify datacenter proxy. A proxy is exposed only for users who want to supply their own.

    Why do some rows have more fields than others?

    The embed path is fast but omits a few detail-only values (caption language, collect/repost counts, video tracks). Raise maxDetail to enrich more posts; the actor never fabricates a field it could not read.

    Why is a row missing?

    Check the status view. Inputs that cannot be parsed, resolved, or read are reported there instead of disappearing.

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.
