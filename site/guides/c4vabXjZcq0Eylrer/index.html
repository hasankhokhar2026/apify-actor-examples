Use LinkedIn Ad Library Keyword & Advertiser Scraper with Python

Search the public LinkedIn Ad Library by keyword, advertiser, country, or date range, and get headline, body copy, advertiser info, media URLs, and call-to-action for the ads each search returns.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "maxResults": 3,
  "proxy": {
    "useApifyProxy": true
  }
}

Download input.example.json and save your reviewed copy as input.json.

FieldTypeRequiredDescription
searchTermsarrayoptionalKeyword search queries (e.g., 'AI', 'cloud computing'). The Ad Library matches ads whose copy or advertiser contains any of these terms.
advertisersarrayoptionalAdvertiser / company names to search (e.g., 'Microsoft', 'Salesforce'). LinkedIn matches the advertiser display name.
countriesarrayoptionalISO-3166-1 alpha-2 country codes (e.g., 'US', 'GB', 'IN'). Filters ads to those served in the selected countries.
dateOptionstringoptionalPre-defined date window. Use 'custom' to specify exact dateFrom/dateTo.
dateFromstringoptionalStart date for custom range (YYYY-MM-DD). Only used when dateOption=custom.
dateTostringoptionalEnd date for custom range (YYYY-MM-DD). Only used when dateOption=custom.
directUrlsarrayoptionalPre-built LinkedIn Ad Library URLs. Use this if you've already configured filters on linkedin.com/ad-library and just want to paste the URL.
maxResultsintegeroptionalMaximum number of ads to return across all queries.
enrichWithDetailPagebooleanoptionalWhen true, fetches each ad's detail page (/ad-library/detail/{id}) to enrich records with `paid_for_by` (DSA disclosure), canonical `advertiser_url`, and any longer body copy. Adds ~0.5-1 s per ad. Note: impressions and targeting facets are loaded via XHR after render and are NOT extractable without a full browser session, so they remain unavailable.
proxyobjectoptionalOptional proxy. The LinkedIn Ad Library is fully public and works from datacenter IPs, so the default Apify Proxy is enabled but no residential group is required.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/c4vabXjZcq0Eylrer/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])

Questions before you run

Which inputs are required?

What does this guide verify?

The fields, prefills, and schema links are rendered from the published build. This is a usage recipe, not a paid live extraction test. Source availability and collection results can vary.
