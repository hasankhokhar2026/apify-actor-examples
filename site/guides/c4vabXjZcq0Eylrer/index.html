Use LinkedIn Ad Library Keyword & Advertiser Scraper with Python

Search the public LinkedIn Ad Library by keyword, advertiser, country, or date range, and get headline, body copy, advertiser info, media URLs, and call-to-action for the ads each search returns.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "companyIds": [
    "1035"
  ],
  "dateOption": "last-30-days",
  "includeDetails": true,
  "maxItems": 3,
  "mode": "search"
}

FieldTypeRequiredDescription
modestringoptionalWhat to collect: search the library, open specific ads, process pasted URLs, or count matches only.
searchTermsarrayoptionalOne or more keyword searches, e.g. 'AI' or 'cloud computing'. Each keyword is an independent search (union), not a combination.
advertisersarrayoptionalAdvertiser names (fuzzy accountOwner search) or LinkedIn company URLs. Each name is an independent search. Use companyIds for exact matching.
companyIdsarrayoptionalExact numeric LinkedIn company IDs (for example, Microsoft is 1035). Multiple IDs are OR-ed in one exact search. Company URLs are accepted too.
companyUrlsarrayoptionalLinkedIn company page URLs. The actor resolves each public page to its numeric organization ID and searches it exactly.
payerarrayoptionalSearch ads by the legal entity that paid for them, e.g. 'Microsoft Corporation'. Each payer is an independent search.
advertiserMatchstringoptionalClient-side precision for advertiser-name searches. Exact company IDs are never filtered. 'Starts with' removes partner-noise results while keeping names such as 'Microsoft in Business'.
countriesarrayoptionalISO-3166 alpha-2 delivery country codes (US, GB, DE, ...) or ALL. Multiple codes are sent in one comma-separated filter.
dateOptionstringoptionalLinkedIn's date window. Use custom-date-range with startDate/endDate for an exact period (maximum 12 months back).
startDatestringoptionalStart of a custom range (YYYY-MM-DD). Required when dateOption is custom-date-range.
endDatestringoptionalEnd of a custom range (YYYY-MM-DD). Required when dateOption is custom-date-range.
sortOrderstringoptionalNewest first or oldest first.
impressionsMinValueintegeroptionalLower bound of the impression range (EU transparency data only). LinkedIn requires both a minimum and a maximum value.
impressionsMinUnitstringoptionalUnit for the minimum impression value.
impressionsMaxValueintegeroptionalUpper bound of the impression range (EU transparency data only). Required together with the minimum value.
impressionsMaxUnitstringoptionalUnit for the maximum impression value.
targetingIncludedarrayoptionalFilters ads that target any of these categories (EU transparency data only). Values: LANGUAGE, LOCATION, AUDIENCE, DEMOGRAPHIC, COMPANY, EDUCATION, JOB, INTERESTS_AND_TRAITS.
targetingExcludedarrayoptionalFilters ads that exclude any of these categories (EU transparency data only). Values: LANGUAGE, LOCATION, AUDIENCE, DEMOGRAPHIC, COMPANY, EDUCATION, JOB, INTERESTS_AND_TRAITS.
includeDetailsbooleanoptionalOpen each ad's detail page for full copy, CTA, landing URL, video, payer, and EU transparency data. Adds one request per ad.
decodeShortLinksbooleanoptionalResolve lnkd.in and similar short links to their final landing URL. Adds one request per short link.
adIdsarrayoptionalNumeric ad IDs or linkedin.com/ad-library/detail/... URLs. Used by mode adDetails.
directUrlsarrayoptionalPasted Ad Library search URLs, ad detail URLs, or LinkedIn company page URLs. Search filters are preserved.
maxItemsintegeroptionalGlobal cap on ads returned across all searches (1-4800). Each search can return at most 4,800 ads (200 pages of 24).

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/c4vabXjZcq0Eylrer/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])

Questions before you run

What does this guide verify?

The fields, prefills, and schema links are rendered from the published build. This is a usage recipe, not a paid live extraction test. Source availability and collection results can vary.

What if the run request times out?
