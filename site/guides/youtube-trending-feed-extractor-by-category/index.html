FieldTypeRequiredDescription
modestringrequiredWhat to read. 'charts' uses YouTube's official music, trailer and podcast charts. 'hubs' uses YouTube's category pages such as Gaming trending, News, Sports, Learning and Courses.
chartsarrayoptionalOne or more YouTube charts. Trending music videos is the official replacement for the retired general Trending page. Top songs and top artists are weekly; Shorts songs is daily or weekly. Music and Shorts charts include rank movement and optional history.
categoriesarrayoptionalOne or more category pages. Gaming trending and Gaming live return up to 50 videos. News reads the selected news sections. Sports, Learning and Courses are editorial category feeds.
newsSectionsarrayoptionalWhich News tabs to read. 'Top stories' is the main /news page; the other sections are direct news-destination feeds. Available sections vary by country.
countriesarrayoptionalOne or more markets. The 68 YouTube Charts markets are supported; 'global' is supported only for charts that publish a global ranking (top videos, top songs, top artists, Shorts songs).
periodstringoptionalDaily or weekly ranking. Weekly-only charts automatically use weekly. Current-only charts such as Trending music videos and Trending movie trailers ignore this setting.
datestringoptionalHistorical chart date in YYYY-MM-DD format. Leave empty for the latest chart. Supported by Top music videos, Top songs, Top artists and Shorts songs; current-only charts ignore it.
maxItemsintegeroptionalTotal data rows to return across all charts, categories and countries.
maxItemsPerChartintegeroptionalRows to take from each chart/country or category/country combination. Source ceilings still apply.
includeVideoDetailsbooleanoptionalFetch exact lifetime views, likes, upload dates and descriptions for every video. YouTube category, tags, Shorts eligibility and family-safe flags are filled when YouTube's player response is available and may be omitted on some cloud IPs. Adds one or more detail requests per video.
maxConcurrencyintegeroptionalHow many exact-detail requests may run in parallel.
onlyNewbooleanoptionalSkip rows already emitted by a previous run with the same monitor name.
monitorNamestringoptionalSeparate only-new histories by monitor name.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.

    actor_input = json.load(stream)

    "https://api.apify.com/v2/acts/GnLvTq8m3i6444nUe/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
