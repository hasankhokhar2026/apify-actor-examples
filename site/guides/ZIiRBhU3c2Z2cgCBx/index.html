Use Zillow Market Trends Scraper with Python

Pull Zillow's home value index, listing and sale price metrics, sale-to-list ratio, days to pending, and rental index for any US city or state, with configurable months of history.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "dataset": "zhviAllHomes",
  "geography": "city",
  "historyMetric": "zhvi",
  "historyMonths": 24,
  "locations": [
    "Austin, TX"
  ],
  "maxItems": 3,
  "mode": "regionTrends",
  "nameContains": "",
  "regionIds": [],
  "sortBy": "sizeRank",
  "state": "all"
}

Download input.example.json and save your reviewed copy as input.json.

FieldTypeRequiredDescription
modestringrequiredWhat to collect. regionTrends = one detailed record per location. history = tidy monthly rows per location. marketScan = one row per region from a Zillow Research dataset.
locationsarrayoptional(mode=regionTrends, history) Cities, states, counties, ZIP codes or neighborhoods, e.g. 'Austin, TX', 'Travis County, TX', '78701', 'Barton Hills, Austin, TX', 'Texas'.
historyMonthsintegeroptional(mode=regionTrends, history) Months of monthly history to include per metric. Zillow's page carries up to 100 months; larger values are capped at 100.
historyMetricstringoptional(mode=history) Which monthly series to emit as tidy rows.
datasetstringoptional(mode=marketScan) Zillow Research series to scan. Each dataset supports a subset of geographies; the actor tells you if the selected geography is unavailable.
geographystringoptional(mode=marketScan) Region level to scan. Available levels depend on the dataset.
statestringoptional(mode=marketScan) Keep only regions in this state. 'all' keeps every state.
nameContainsstringoptional(mode=marketScan) Case-insensitive substring filter on the region name, e.g. 'Travis' or 'Springfield'.
regionIdsarrayoptional(mode=marketScan) Exact Zillow RegionIDs to keep, e.g. '3101'. Values not in the selected dataset are ignored.
sortBystringoptional(mode=marketScan) Order rows and assign a 1-based rank over all matches before maxItems truncation.
maxItemsintegeroptionalHard cap on emitted records for this run.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/ZIiRBhU3c2Z2cgCBx/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
# Inspect and download results in Apify Console once the run succeeds.

4. Inspect the actual results

Open the run in Apify Console and wait for a successful completion. Use the published output schema to locate results and the dataset schema to understand declared views. Missing or optional record fields must not be treated as guaranteed values.

One dataset with three record types: regionMarketTrends (ZHVI, ZORI, sale and list metrics, forecasts and benchmarks per location), marketHistoryObservation (monthly rows) and marketObservation (ranked Zillow Research rows).
