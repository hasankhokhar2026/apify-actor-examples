Use M.Video Russia Electronics Product & Review Scraper with Python

Search, browse categories, or fetch full product detail from mvideo.ru, including price, rating, specifications, images, seller info, and customer reviews.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "brands": [],
  "category": "1",
  "inStockOnly": false,
  "maxItems": 10,
  "maxReviews": 5,
  "mode": "search",
  "productUrls": [
    "https://www.mvideo.ru/products/televizor-general-electronics-ge55lqs2-401211841"
  ],
  "proxyConfiguration": {
    "useApifyProxy": true
  },
  "searchQuery": "телевизор",
  "sellers": [],
  "sortOrder": "popularity"
}

FieldTypeRequiredDescription
modestringrequiredWhat to fetch.
searchQuerystringoptionalFree-text product search, e.g. телевизор, ноутбук, холодильник.
categorystringoptionalTop-level mvideo.ru category to browse.
categoryUrlstringoptionalOverrides `category`. Accepts a full mvideo.ru category URL (e.g. https://www.mvideo.ru/televizory-i-cifrovoe-tv-1/televizory-65) or a bare numeric category ID, for sub-categories not in the dropdown.
productUrlsarrayoptionalmvideo.ru product URLs (e.g. https://www.mvideo.ru/products/televizor-...-401211841) or bare numeric product IDs.
sortOrderstringoptionalResult ordering for category browsing.
brandsarrayoptionalOnly return products from these brands, server-side (AND with `category`). Use the brand's mvideo.ru filter slug — for Latin-script brands this is just the lowercase name (e.g. `samsung`, `lg`, `sony`, `xiaomi`, `general-electronics`); look up the exact slug by opening the category on mvideo.ru and checking the brand filter checkboxes if unsure. Multiple values are OR'd together.
sellersarrayoptionalOnly return products from these marketplace sellers, server-side (AND with `category`). Use the seller's mvideo.ru filter slug (e.g. `mvideo` for M.Video itself, `mediamarkt` for MediaMarkt); look up the exact slug from the category's own seller filter if unsure. Multiple values are OR'd together.
minPriceintegeroptionalDrop products cheaper than this (sale price, in Russian rubles). In mode=byCategory this is applied server-side (fewer wasted fetches); other modes filter client-side after fetching.
maxPriceintegeroptionalDrop products more expensive than this (sale price, in Russian rubles). In mode=byCategory this is applied server-side (fewer wasted fetches); other modes filter client-side after fetching.
minRatingnumberoptionalDrop products with a customer rating below this (0-5 stars). Products with no rating are excluded when this filter is set.
inStockOnlybooleanoptionalOnly emit products that are currently available (not sold out).
maxItemsintegeroptionalHard cap on emitted records. Note: mode=search is limited to ~10 results (mvideo.ru's own search-suggestion API caps at 10 matches); use mode=byCategory for larger result sets.
maxReviewsintegeroptionalHow many of the most helpful customer reviews to fetch and attach to each product's `reviews[]` field (also populates `ratingBreakdown` and `recommendPercent`). Only applies to mode=search and mode=productDetails, since those are the modes that fetch full product details. Set to 0 to skip fetching reviews.
proxyConfigurationobjectoptionalApify Proxy to use. The actor tries the free datacenter (AUTO) pool first (Tier 3: Playwright); if mvideo.ru's anti-bot blocks every attempt, it automatically escalates to a residential proxy session (Tier 4: Camoufox) regardless of this setting.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/L2mrRaxKqV5naozzW/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
