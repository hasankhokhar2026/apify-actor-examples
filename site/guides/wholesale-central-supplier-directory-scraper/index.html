    Wholesale Central Supplier Directory Scraper: export to CSV, Excel or JSON

    Browse or search wholesale supplier and dropshipper listings on WholesaleCentral.com by product category, keyword, location, or minimum order, with company name, category, location, and contact details per supplier.

    This tutorial runs Wholesale Central Supplier Directory Scraper through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 8 columns its publisher puts first: name, category, city, stateCode, minimumOrderUSD, phone, websiteUrl and productCount.

    What people export it for

    • US sourcing shortlists — find domestic wholesale suppliers by category and state without browsing the directory by hand
    • Dropship and closeout research — map the Dropshippers and Closeout Suppliers departments, then compare minimum orders
    • B2B lead lists — collect public company phone, address and website data for retail-buyer outreach
    • Catalog discovery — see how many products a supplier carries and which product categories dominate its storefront
    • Geographic market mapping — compare supplier density across states and categories
    • Refresh existing vendor lists — re-scrape a saved set of supplier URLs to pick up changed contacts or catalogs

    Fix common problems

    Does this need a login or a proxy?

    No login. Every supplier page used here is public. The actor connects directly first, solves the site's browser challenge, reuses that session, and automatically picks a working Apify connection if the site blocks it. You do not need to configure a proxy.

    Why are there no wholesale prices?

    The directory shows “Unlock wholesale price” to signed-in buyers. Public pages — and this actor — do not expose wholesale prices, tiers or MOQs beyond the published minimum-order amount.

    Why does search return a different number of suppliers than a category?

    The site's supplier search returns roughly 51–136 matches for common queries, while top-level categories contain 2–90 suppliers each. maxItems still caps what is emitted.

    More from the publisher:

    • Why did state: "NY" previously return an Oregon supplier?
    • Why is includeEmbeddedContact off by default?
    • Why do some records lack a phone, website, description or social links?

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.
