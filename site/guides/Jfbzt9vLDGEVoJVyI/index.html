Use Naukri.com Job Listings Extractor with Salary & Skills with Python

Pull job listings from Naukri.com by search URL or by keyword, location, experience, salary, job age and work-mode filters, with company rating, skills and recruiter detail per posting.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

  "browserFallback": false,
  "companyIds": [],

  "includeDescription": true,

    "221026015762"
  ],

Download input.example.json and save your reviewed copy as input.json.

FieldTypeRequiredDescription
searchesarrayoptionalOne or more search configurations. Each entry can hold several keywords and several locations; every keyword is combined with every location. Leave keywords empty to browse a location or company.
jobIdsarrayoptionalFetch these Naukri job IDs directly. Accepts bare IDs or Naukri job URLs. Job IDs are processed before searches.
companyIdsarrayoptionalNaukri company IDs to search across. When searches are also supplied, each company is combined with every search.
maxItemsintegeroptionalTotal records to return across all queries. Naukri allows at most 3,000 jobs per query (150 pages of 20).
onlyNewbooleanoptionalEmit only jobs that were not emitted by an earlier run with the same state key.
resetStatebooleanoptionalClear the saved job IDs before this run.
stateKeystringoptionalOptional name for the incremental state. Defaults to a hash of the search configuration.
includeDescriptionbooleanoptionalInclude the full job description text. Turn off to keep records smaller.
includeDescriptionHtmlbooleanoptionalInclude the raw HTML job description in addition to plain text.
includeCompanyReviewsbooleanoptionalInclude up to three AmbitionBox review snippets per job. Off by default to keep records small.
strictJobAgebooleanoptionalDrop promoted jobs older than the selected job age using Naukri's posting date.
timeBudgetSecsintegeroptionalStop gracefully after this many seconds. 0 means no time limit.
failOnEmptybooleanoptionalMark the run as failed when no jobs are returned.
browserFallbackbooleanoptionalIf the normal connection is blocked, retry through a browser session. Slower and uses more memory; leave off unless needed.
proxyConfigurationobjectoptionalOptional connection override. By default the actor uses an India-based Apify connection automatically.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/Jfbzt9vLDGEVoJVyI/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])

Questions before you run

Which inputs are required?

No top-level fields are marked required in the published schema. Conditional requirements can still apply; check the README.

What does this guide verify?

The fields, prefills, and schema links are rendered from the published build. This is a usage recipe, not a paid live extraction test. Source availability and collection results can vary.

What if the run request times out?

Check Apify Console before retrying. The first request may already have created a run. Do not automatically repeat a run-creation POST.
