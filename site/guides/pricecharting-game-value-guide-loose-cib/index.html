    PriceCharting Game Value Guide: Loose, CIB & Graded: CSV and Excel export

    Search PriceCharting by game title, browse a console's full price list, or look up one game's page, with loose, complete-in-box, new, and graded prices in USD.

    This tutorial runs PriceCharting Game Value Guide: Loose, CIB & Graded through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 6 columns its publisher puts first: title, consoleName, loosePrice, cibPrice, newPrice and gameUrl.

    Steps

    1. See the columns
    2. Get an API token
    3. Choose the input
    4. Run it and write a CSV
    5. Download Excel or JSON
    6. The same in JavaScript
    7. Fix common problems

    The columns you can export

    The Actor's build declares 6 output fields in 1 dataset view ("Video Game Prices"). The export below keeps these, under the labels the publisher gave them:
