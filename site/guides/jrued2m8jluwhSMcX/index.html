Use YouTube Video Comment & Reply Thread Scraper with Python

Get a YouTube video's comments with nested replies attached, author identity, like counts, and pinned/hearted/verified flags, filterable by keyword and minimum likes.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "includeReplies": false,
  "maxComments": 5,
  "videoUrls": [
    "https://www.youtube.com/watch?v=dQw4w9WgXcQ"
  ]
}

Download input.example.json and save your reviewed copy as input.json.

FieldTypeRequiredDescription
videoUrlsarrayrequiredYouTube video URLs, short links (youtu.be), shorts URLs, or plain video IDs.
maxCommentsintegeroptionalMaximum number of top-level comments to scrape per video. Replies are fetched separately and do not count toward this limit.
includeRepliesbooleanoptionalWhether to fetch reply threads for each comment.
maxRepliesPerCommentintegeroptionalMaximum number of replies to fetch per top-level comment. Set to 0 to skip replies even if Include Replies is enabled.
sortBystringoptionalHow to sort comments. 'Top comments' shows most relevant/liked first. 'Newest first' shows chronologically newest.
commentKeywordFilterstringoptionalOnly return comments (and their replies) whose text contains this word or phrase (case-insensitive). Leave empty to return all comments. A top-level comment that doesn't match is skipped entirely, so its replies are not checked or fetched.
minLikeCountintegeroptionalOnly return comments and replies with at least this many likes. Set to 0 to disable.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/jrued2m8jluwhSMcX/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
