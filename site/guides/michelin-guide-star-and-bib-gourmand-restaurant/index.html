    Michelin Guide Star & Bib Gourmand Restaurant Finder: CSV and Excel export

    Scrape Michelin-starred restaurants from guide.michelin.com. Search by name, filter by city or country, browse all starred restaurants, or fetch individual restaurant pages. Returns name, stars, address, cuisine, price range, coordinates, and more.

    This tutorial runs Michelin Guide Star & Bib Gourmand Restaurant Finder through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 8 columns its publisher puts first: name, stars, bibGourmand, michelinSelected, cuisine, city, country and countryCode.

    Steps

    1. See the columns
    2. Get an API token
    3. Choose the input
    4. Run it and write a CSV
    5. Download Excel or JSON
    6. The same in JavaScript
    7. Fix common problems

    The columns you can export

    The Actor's build declares 11 output fields in 1 dataset view ("Restaurants"). The export below keeps these, under the labels the publisher gave them:
