Use Full-Page Website Screenshot & PDF Capture with Python

Capture full-page screenshots or PDFs of any list of URLs, with a custom viewport size, scroll-to-bottom for lazy-loaded content, cookie-banner hiding, and configurable page-load wait conditions.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "delay": 0,
  "urls": [
    {
      "url": "https://www.apify.com/"
    }
  ],
  "viewportWidth": 1280,
  "waitUntil": "load"
}

Download input.example.json and save your reviewed copy as input.json.

FieldTypeRequiredDescription
urlsarrayrequiredList of web page URLs to capture as screenshots.
formatstringoptionalScreenshot output format. PNG captures a full-page image. PDF generates a printable document.
waitUntilstringoptionalWhen to consider the page loaded before taking the screenshot.
delayintegeroptionalMilliseconds to wait after the page loads before taking the screenshot. Useful for pages with animations or lazy-loaded content.
viewportWidthintegeroptionalBrowser viewport width in pixels. Height is fixed at 1080px.
scrollToBottombooleanoptionalScroll to the bottom of the page before taking the screenshot. Triggers lazy-loaded images and infinite scroll content.
delayAfterScrollingintegeroptionalMilliseconds to wait after scrolling to bottom. Only applies when Scroll to Bottom is enabled and Wait for Network Idle After Scroll is disabled.
waitUntilNetworkIdleAfterScrollbooleanoptionalAfter scrolling, wait until no network requests are made for 500ms. Ensures all lazy-loaded content finishes loading. Overrides Delay After Scrolling.
waitUntilNetworkIdleAfterScrollTimeoutintegeroptionalMaximum time to wait for network idle after scrolling. Only applies when Wait for Network Idle After Scroll is enabled.
proxyConfigurationobjectoptionalOptional proxy settings. The actor works without proxy for most websites.
selectorsToHidestringoptionalComma-separated CSS selectors of elements to hide before taking the screenshot. Example: '.cookie-banner, #popup, .ads'

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/oG0Mque4wwAd1e4EK/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
# Inspect and download results in Apify Console once the run succeeds.
