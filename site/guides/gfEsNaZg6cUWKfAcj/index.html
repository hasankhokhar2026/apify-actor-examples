Use ESPN Live Scores, Schedules & Game Odds Scraper with Python

Get live scores, final results and upcoming fixtures for 16 leagues across basketball, football, baseball, hockey and soccer, with optional per-game leaders, odds, attendance and headlines.

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

startDatestringoptionalFirst day of a custom window (YYYY-MM-DD or YYYYMMDD). Requires End date. (mode=scoreboard, schedule, odds, gameDetail)
endDatestringoptionalLast day of a custom window (YYYY-MM-DD or YYYYMMDD). Maximum 366 days. (mode=scoreboard, schedule, odds, gameDetail)
seasonintegeroptionalESPN season year, for example 2024. Use it with Week for a single football week, or alone for the whole season. (mode=scoreboard, schedule, odds, gameDetail)
seasonTypestringoptionalWhich part of the season to read when Season is set. (mode=scoreboard, schedule, odds, gameDetail)
weekintegeroptionalWeek number for football and other week-based competitions. Requires Season. (mode=scoreboard, schedule, odds, gameDetail)
teamstringoptionalKeep only games or teams matching this ESPN team ID, abbreviation, or name, for example 13, LAL, or Lakers. Prefix with a league code to disambiguate: nba:LAL. (mode=scoreboard, schedule, teams, odds, gameDetail)
eventIdsarrayoptionalESPN event IDs for game detail or odds, for example 401585183. Leave empty to discover games from the date or season. (mode=odds, gameDetail)
statusstringoptionalKeep only games in this state. Postponed and cancelled games are reported as their own values.
includeDetailsbooleanoptionalAdd leaders, odds, attendance, officials, article text, team stats, player stats and injuries to each game. (mode=scoreboard, schedule)
maxItemsintegeroptionalHard cap on records returned across all selected leagues.
timezonestringoptionalIANA timezone used for today/yesterday/tomorrow and for dateLocal, for example America/New_York.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/gfEsNaZg6cUWKfAcj/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
