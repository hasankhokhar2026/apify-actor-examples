Use Snapchat EU Ads Library Impressions & Targeting Extractor with Python

Search Snapchat's EU ad transparency library by advertiser or creator, or browse all sponsored content, returning headline, creative, call to action, per-country impressions and targeting for each ad.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "advertiserMatch": "contains",
  "countries": [],
  "creatorName": "beauty",
  "includeCoverage": true,
  "mode": "adSearch",
  "payingAdvertiserNames": [
    "nike"
  ],
  "status": "ALL"
}

Download input.example.json and save your reviewed copy as input.json.

FieldTypeRequiredDescription
modestringoptionaladSearch searches ads by paying advertiser, sponsoredContent browses all live sponsored content, and creatorSearch searches sponsored content by creator.
payingAdvertiserNamesarrayoptionalFor adSearch mode: one or more paying-advertiser names, e.g. Nike, Amazon, Zalando. The API matches partial names case-insensitively; set Advertiser Match to exact for case-insensitive exact payer matching.
payingAdvertiserNamestringoptionalSingle-advertiser legacy input, still supported. Prefer Advertiser Names. If both are set, the names are merged and deduplicated.
advertiserMatchstringoptionalcontains (default) uses Snap's partial payer-name search. exact keeps only ads whose paying advertiser exactly equals one of your names, ignoring case and extra whitespace.
countriesarrayoptional2-letter country codes to filter ads by. Leave empty for all. Supported: the 27 EU codes at, be, bg, cy, cz, de, dk, ee, el (Greece), es, fi, fr, hr, hu, ie, it, lt, lu, lv, mt, nl, pl, pt, ro, se, si, sk, tr (Turkey). gr is accepted as an alias for el. UK (gb/uk) and US are not in the library.
startDatestringoptionalFilter ads that ran on or after this date (ISO 8601 or YYYY-MM-DD). The library only covers the last 12 months; older dates may return nothing.
endDatestringoptionalFilter ads that ran on or before this date (ISO 8601 or YYYY-MM-DD). The API does not publish an ad end date in records.
statusstringoptionalFilter ads by current status: ACTIVE, PAUSED, or ALL.
creatorNamestringoptionalFor creatorSearch mode: creator username or display name used to search sponsored content.
maxResultsintegeroptionalMaximum records to save per advertiser in adSearch, or total records in sponsoredContent/creatorSearch. The actor paginates the public API automatically (10 ads per request for adSearch, up to 200 items per page for sponsored content).
includeCoveragebooleanoptionalAdd one coverage row per advertiser/creator listing matched payer names, status, pages fetched, duplicates removed, countries, and impression coverage.
proxyConfigurationobjectoptionalOptional proxy. The Ads Library API is public and normally works without a proxy; enable one only if your runs keep hitting rate limits.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/ZYe4UyoXnbwoB7Osj/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])

Questions before you run

What does this guide verify?

The fields, prefills, and schema links are rendered from the published build. This is a usage recipe, not a paid live extraction test. Source availability and collection results can vary.

What if the run request times out?
