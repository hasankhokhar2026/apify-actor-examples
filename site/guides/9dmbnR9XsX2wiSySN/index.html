Use YouTube Ad Creative & Advertiser Tracker with Python

Find the video and image ad creatives an advertiser is running on YouTube, discovered by keyword, advertiser name, or advertiser ID, with country, format, and first/last-shown dates.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

FieldTypeRequiredDescription
advertisersarrayoptionalAdvertiser names, AR-IDs, Transparency Center URLs, or landing domains to scrape YouTube ads for (e.g. 'Nike, Inc.', 'AR16735076323512287233', 'nike.com'). Names are matched to the strongest suggestion (exact name first, then ad count). Leave empty to use searchTerms.
searchTermsarrayoptionalKeywords or domains used to discover advertisers and domains, then scrape their YouTube ads (e.g. 'electric car', 'nike.com'). Keyword searches also use domain suggestions returned by Google.
countriesarrayoptionalISO 3166-1 alpha-2 queried regions sent to the Transparency Center as the ad filter (e.g. US, GB). This is the region the ads were served in, not the advertiser's headquarters country. The advertiser's own country is reported separately as advertiserCountryCode.
dateFromstringoptionalKeep ads whose observed flight overlaps this window. An ad is kept when firstShown <= dateTo and lastShown >= dateFrom, so ads that started earlier but were still running inside the window are included.
dateTostringoptionalKeep ads whose observed flight overlaps this window (inclusive). Works together with dateFrom and is no longer compared only against firstShown.
formatstringoptionalServer-side creative format filter. TEXT, IMAGE and VIDEO map to Google's verified format codes 1, 2 and 3.
includeVideoDetailsbooleanoptionalFetch GetCreativeById for every creative to enrich last-shown dates, served regions and preview assets. Video IDs are resolved from previews even when this is off.
resolveVideoIdsbooleanoptionalExtract videoId, watch URL, thumbnail and duration from creative previews (ytimg/youtube URLs). Missing IDs are omitted, never fabricated. Turn off to save preview requests.
maxAdvertisersPerTermintegeroptionalMaximum advertiser matches (and domain suggestions) to scrape per keyword (when searchTerms is used).
maxAdsPerAdvertiserintegeroptionalCursor-pagination cap per advertiser or domain, applied before the global maxItems cap.
maxItemsintegeroptionalHard cap on total ad records returned (1-5000). Advertiser and run-summary records do not count toward this cap.
maxConcurrencyintegeroptionalAdvertisers scraped in parallel. Higher is faster but increases rate-limit risk.
onlyNewbooleanoptionalOutput only ad IDs not seen in earlier runs and mark them isNew: true. Reuse the same monitorStoreName for the same competitor list. The first run creates the baseline.
monitorStoreNamestringoptionalKey-value store that remembers seen ad IDs for monitor mode (default: youtube-ads-monitor).
outputFormatstringoptionalDataset always receives JSON records. Additionally export results as CSV, Excel, or HTML in the key-value store (OUTPUT.csv / OUTPUT.xlsx / OUTPUT.html).
proxyConfigurationobjectoptionalOptional proxy. For moderate traffic no proxy is needed. Enable Apify proxy for high-volume scraping.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/9dmbnR9XsX2wiSySN/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
# Inspect and download results in Apify Console once the run succeeds.

4. Inspect the actual results

Open the run in Apify Console and wait for a successful completion. Use the published output schema to locate results and the dataset schema to understand declared views. Missing or optional record fields must not be treated as guaranteed values.

Dataset with one record per YouTube ad creative plus advertiser diagnostics and a run summary. Ad records include advertiser, queried region, format, thumbnail, YouTube video ID/watch URL/thumbnail/duration when exposed, first/last shown dates, days shown, and scrapedAt.

Questions before you run

Which inputs are required?

No top-level fields are marked required in the published schema. Conditional requirements can still apply; check the README.

What does this guide verify?

The fields, prefills, and schema links are rendered from the published build. This is a usage recipe, not a paid live extraction test. Source availability and collection results can vary.

What if the run request times out?

Check Apify Console before retrying. The first request may already have created a run. Do not automatically repeat a run-creation POST.
