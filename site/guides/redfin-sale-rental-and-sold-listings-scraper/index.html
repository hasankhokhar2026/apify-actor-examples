Use Redfin Sale, Rental & Sold Listings Scraper with Python

Scrape Redfin real estate listings - search properties for sale, recently sold, and rental listings across the US. Extracts price, beds, baths, sqft, address, coordinates, agent info, images, and more.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "includeDetails": false,
  "location": "Austin, TX",
  "maxItems": 3,
  "mode": "forSale",
  "propertyType": "all",
  "soldWithinDays": "180",
  "sort": "recommended"
}

modestringrequiredWhat type of listings to fetch.
locationstringoptionalCity and state (`Austin, TX`), ZIP (`90210`, `10001`, `78701`), neighborhood (`South Congress, Austin, TX`), Redfin search URL, or a region token such as `6_30818` (city region 30818).

keywordstringoptionalCase-insensitive keyword matched against address, description, listing tags, key facts, subdivision, and building name. Required in `search` mode and optional in other modes.
propertyTypestringoptionalFilter by property type. Applied server-side where Redfin supports it and re-checked in the actor.

minBathsintegeroptionalMinimum number of bathrooms.
minSqftintegeroptionalMinimum interior square footage.
maxSqftintegeroptionalMaximum interior square footage.
soldWithinDaysstringoptionalHow far back to search in recentlySold mode. Ignored in other modes.
sortstringoptionalResult ordering. Verified against Redfin's GIS and rental APIs.
maxItemsintegeroptionalHard cap on emitted records (1-20,000). This is a self-imposed cap; Redfin returned homes at a start offset of 19,950 in verification. Deep offsets in very large regions can return an empty page.
includeDetailsbooleanoptionalFetch each listing's below-the-fold detail payload: price history, tax history, public records (APN, county, year renovated), and amenities. Adds one request per emitted listing.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/SQV9dedFVcwumS0gD/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
