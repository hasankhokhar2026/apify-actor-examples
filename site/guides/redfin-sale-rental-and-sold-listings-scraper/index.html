    Redfin Sale, Rental & Sold Listings Scraper: export to CSV, Excel or JSON

    Scrape Redfin real estate listings - search properties for sale, recently sold, and rental listings across the US. Extracts price, beds, baths, sqft, address, coordinates, agent info, images, and more.

    This tutorial runs Redfin Sale, Rental & Sold Listings Scraper through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 8 columns its publisher puts first: address, city, state, zip, price, listingType, status and beds.

    What people export it for

    • Home search — filter active listings by price, size, and bedroom count across a city
    • Comparable sales — pull recently sold homes with sold price and sold date
    • Rental market tracking — monitor asking rents and available units by building
    • Lead generation — collect listing agents, brokerages, and property details
    • Investment screening — scan price-per-square-foot, days on market, lot size, tax history, and price history

    Fix common problems

    Why are some fields missing?

    Redfin does not expose every detail for every property. Empty fields are omitted, not filled with placeholders.

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.
