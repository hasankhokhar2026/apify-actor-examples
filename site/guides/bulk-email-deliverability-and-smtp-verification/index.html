    Bulk Email Deliverability & SMTP Verification: export to CSV, Excel or JSON

    Check email addresses for syntax, MX records, disposable and role-based domains, and optionally SMTP mailbox existence and catch-all behavior, with a verdict and confidence score per address.

    Fix common problems

    Why did a Gmail address come back unknown in deep mode?

    Gmail and several other large providers reject probe traffic from many IP ranges. The actor reports that honestly instead of calling the address valid or invalid.

    Why is checks.smtp missing instead of false?

    false means the server explicitly rejected the mailbox. A missing value means the probe did not produce a mailbox-level answer (blocked port, policy rejection, timeout or temporary response).

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.
