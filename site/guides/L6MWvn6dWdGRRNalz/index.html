Use Coupang Best Sellers & Rocket Delivery Flags with Python

Collect Coupang best sellers by category (30 per page, optional child fan-out), keyword suggestions, or the category tree. Products include price, unit price, coupon, rating, Rocket delivery, and category breadcrumb. No user proxy, cookies, or login required.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

categorystringoptionalCoupang best-seller category. Each category page returns up to 30 products; enable Include subcategories to continue into child pages until Maximum products is reached.
categoryIdstringoptionalOptional numeric Coupang best100 category ID or /np/categories/ URL. Overrides the category dropdown.
includeSubcategoriesbooleanoptionalWhen true, after the selected category page is fetched, also fetch its child category best-seller pages until Maximum products is reached. Default false; small maxItems values usually need no child pages.
minPriceintegeroptionalOnly return products at or above this price in Korean won.
maxPriceintegeroptionalOnly return products at or below this price in Korean won.
rocketOnlybooleanoptionalKeep only products with Coupang's Rocket delivery badge.
minRatingnumberoptionalKeep only products rated at least this many stars. Products without a rating are skipped.
maxItemsintegeroptionalMaximum number of best-seller products to return. A single best100 page has at most 30; set includeSubcategories=true to continue into child pages, or use category=all.
searchQueriesarrayoptionalKeywords for keyword suggestions (mode=keywordSuggestions). Korean or English.
maxSuggestionsintegeroptionalMaximum suggestions to return per keyword.
maxCategoriesintegeroptionalMaximum category nodes to return from the Coupang category tree.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/L6MWvn6dWdGRRNalz/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
