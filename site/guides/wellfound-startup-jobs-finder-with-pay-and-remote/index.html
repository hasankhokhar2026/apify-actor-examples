Use Wellfound Startup Jobs Finder with Pay & Remote Filters with Python

Find startup jobs on Wellfound and filter by title, keyword, location, remote status, job type, experience level, salary range and company.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "enrichDetails": false,
  "equityOnly": false,
  "expandSimilar": false,
  "includeNoSalary": true,
  "maxItems": 3,
  "mode": "auto",
  "onlyNew": false,
  "remoteOnly": false,
  "remoteWfhFlexible": false,
  "startUrls": [
    {
      "url": "https://wellfound.com/jobs"

rolestringoptionalWellfound role slug for search mode, for example software-engineer, product-manager, designer or machine-learning-engineer.
jobTitlestringoptionalOnly keep jobs whose title contains this phrase (case-insensitive).
keywordstringoptionalOnly keep jobs matching this text across title, company, locations, compensation and description (case-insensitive).
locationstringoptionalUsed as a server-side /location/{location} or /role/l/{role}/{location} path when it is a clean city slug or name, and always as a case-insensitive client filter over locations and accepted remote locations.
remoteOnlybooleanoptionalSearch /remote or /role/r/{role} and keep only jobs flagged as remote.
jobTypestringoptionalExact structured job type from Wellfound. Jobs with a missing/unknown type are dropped when a specific type is selected.
experiencestringoptionalBest-effort filter: title keywords first, then yearsExperienceMin (0-2 junior, 3-4 mid, 5+ senior). Unknown jobs are kept and counted.
minSalaryintegeroptionalKeep jobs whose salary range top is at or above this amount. Currency is the job's listed currency; no FX conversion. 0 = off.
maxSalaryintegeroptionalKeep jobs whose salary range bottom is at or below this amount. 0 = unlimited. This is the documented range-start semantics.
salaryCurrencystringoptionalFilter parsed salaries by currency. No FX conversion is performed.
includeNoSalarybooleanoptionalOnly applies when minSalary or maxSalary is set. When false, jobs with no parsed salary are dropped.
companyCategoriesarrayoptionalMatch Wellfound market, industry and company-type tags or the company high concept. This is not a company-name filter; use includeCompanies for names. Requires enrichDetails=true.
includeCompaniesarrayoptionalOnly keep jobs whose company name or slug contains one of these values (case-insensitive).
excludeCompaniesarrayoptionalDrop jobs whose company name or slug contains one of these values. Exclusions win over includeCompanies.
postedWithinDaysintegeroptionalKeep jobs posted within the last N days. Jobs without a parsed posted date are dropped and counted. 0 = off.
companySizesarrayoptionalKeep jobs or companies whose company size matches one of these values, for example 11-50, 51-200 or SIZE_51_200. Rows without a size are dropped and counted.
companyStagesarrayoptionalKeep jobs or companies whose stage matches one of these values, for example seed, early-stage, growth-stage or scale-stage. Rows without a stage are dropped and counted.
ycOnlybooleanoptionalKeep rows where the YC Funded badge is present.
minCompanyFundingintegeroptionalKeep jobs whose parsed total funding is at or above this amount. Requires detail enrichment; unknown funding is dropped. 0 = off.
minOpenJobsintegeroptionalKeep rows whose company open-job count is at or above this value. Requires detail enrichment for jobs; unknown counts are dropped. 0 = off.
visaSponsorshipOnlybooleanoptionalKeep jobs whose detail page says visa sponsorship is available. Requires detail enrichment; unknown values are dropped.
minEquitynumberoptionalKeep jobs whose equity range top is at or above this percentage. Jobs without equity data are dropped. 0 = off.
maxEquitynumberoptionalKeep jobs whose equity range bottom is at or below this percentage. 0 = unlimited.
equityOnlybooleanoptionalKeep jobs that explicitly offer equity; jobs that say No equity or do not mention equity are dropped.
remoteWfhFlexiblebooleanoptionalKeep jobs whose remote configuration explicitly reports work-from-home flexibility. Requires detail enrichment; unknown values are dropped.
sortstringoptionalnone keeps first-seen source order. newest/oldest sort the whole run by parsed posted date; jobs without a date are last.
pageLimitintegeroptional0 fetches every page up to pageCount. N fetches the first N pages. An explicit ?page=N start URL fetches only that page.
enrichDetailsbooleanoptionalFetch plain and autoOpen detail pages for selected jobs to add description HTML, structured salary/equity, visa/relocation, skills, company funding, founders, socials and benefits. Direct job URLs are always enriched. Default true; the saved prefill turns it off to keep scheduled runs fast.
maxItemsintegeroptionalMaximum jobs or companies pushed after all filters and sorting.
onlyNewbooleanoptionalPush only jobs or companies whose IDs have not been seen for this stateKey. Requires stateKey.
stateKeystringoptionalPersistent key in the wellfound-monitor key-value store used to remember seen job/company IDs between runs. Changing it starts a fresh history.
expandSimilarbooleanoptionalAdd related jobs from the autoOpen detail page similarJobs edges, bounded by similarDepth and similarLimit. Only applies to job modes.
similarDepthintegeroptional1 emits the similar jobs embedded in the enriched page. 2-3 follow additional autoOpen pages within similarLimit.
similarLimitintegeroptionalMaximum additional similar jobs emitted per run, also bounded by maxItems.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/H1emEWZWGH4OE7mUG/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
