    TikTok Video, Audio & Cover Downloader: export to CSV, Excel or JSON

    Download TikTok videos, cover thumbnails, background audio, and slideshow images by post URL, with quality selection and a stable download link per file.

    This tutorial runs TikTok Video, Audio & Cover Downloader through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 8 columns its publisher puts first: postId, postUrl, assetType, variant, quality, mimeType, byteSize and status.

    Get an API token

    Copy it from Console, Settings, API and Integrations.

    Choose the input

    1 field is required:

    • postUrls: TikTok post URLs or IDs. Accepts /@user/video/ID, /@user/photo/ID, /video/ID, /photo/ID, embed URLs (/embed/v2/ID), vm.tiktok.com / vt.tiktok.com / /t/ short links, m.tiktok.com/v/ID.html, and bare numeric post IDs. Duplicates are processed once.

    Fix common problems

    Why can't I get a no-watermark URL without downloading?

    TikTok's clean playAddr returns 403 text/html unless it is fetched with cookies from the same page session. The actor downloads the file in that session and re-hosts it.

    Can I use a proxy?

    It is optional. The actor is direct by default. If you want to route requests through Apify Proxy, select a proxy configuration in the input.

    Why is a clean video row missing on a slideshow?

    Slideshows have no video file. Request slideshow or audio instead; a no_video status row is emitted when video is requested.

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.
