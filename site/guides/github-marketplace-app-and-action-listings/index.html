    GitHub Marketplace App & Action Listings by Category: CSV and Excel export

    Search GitHub Marketplace apps and Actions by keyword, browse an entire category, or fetch listings by slug. Returns pricing plans, categories, publisher verification and install counts.

    This tutorial runs GitHub Marketplace App & Action Listings by Category through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 6 columns its publisher puts first: name, slug, shortDescription, planType, publisherName and url.

    What people export it for

    • DevOps tooling research — find CI/CD, deployment, or monitoring integrations before adding one to your pipeline
    • Vendor and market mapping — catalog every listing in a category to track the competitive landscape
    • Category audits — list every app or Action tagged to a category alongside its description and logo
    • Free-tool shortlisting — filter to free listings before evaluating paid alternatives
    • Link collection — gather canonical GitHub Marketplace URLs for a set of known slugs in one run

    Fix common problems

    Why is planType missing from some listings?

    It's only set when the listing page's visible text clearly states a free or paid plan; when that isn't detectable, the field is omitted instead of guessed.

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.
