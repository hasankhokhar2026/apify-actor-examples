Use Yandex Market Price & Seller Offer Comparison Scraper with Python

Scrape product listings, prices, seller offers, and reviews from Yandex Market. Search by keyword, browse a category, pull a product's full seller-offer comparison, or collect product and seller reviews.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "categoryUrls": [
    "https://market.yandex.ru/catalog--smartfony/54726/list"
  ],
  "maxItems": 5,
  "mode": "searchProducts",
  "productUrls": [
    "https://market.yandex.ru/product--smartfon-apple-iphone-15-6-gb128-gb-chernyy-nano-simesim/6307259609"
  ],
  "searchQueries": [
    "iPhone 15"
  ],
  "sellerUrls": []
}

Download input.example.json and save your reviewed copy as input.json.

FieldTypeRequiredDescription
modestringrequiredWhat to scrape. searchProducts: find products by keyword. browseCategory: scrape a product category. getProductDetails: full details + all seller offers for specific product URLs. getReviews: scrape product or seller reviews.
searchQueriesarrayoptionalOne or more search queries (mode=searchProducts). Examples: 'iPhone 15', 'Samsung Galaxy S24', or Russian keywords.
categoryUrlsarrayoptionalYandex Market category page URLs (mode=browseCategory). Use the /list form, e.g. https://market.yandex.ru/catalog--smartfony/54726/list.
productUrlsarrayoptionalYandex Market product page URLs (mode=getProductDetails or getReviews). Format: https://market.yandex.ru/product--{slug}/{id}
sellerUrlsarrayoptionalYandex Market seller page URLs (mode=getReviews only). Format: https://market.yandex.ru/shop--{slug}/{id}
maxItemsintegeroptionalMaximum number of records to return per query/URL. Also caps offers per product and reviews per URL.
sortOrderstringoptionalHow to sort search results. Only applies in searchProducts and browseCategory modes.
minPriceintegeroptionalMinimum price filter in Russian rubles. Only applies in searchProducts and browseCategory modes.
maxPriceintegeroptionalMaximum price filter in Russian rubles. Only applies in searchProducts and browseCategory modes.
minRatingstringoptionalFilter out products below this rating. Only applies in searchProducts and browseCategory modes.
reviewsSortOrderstringoptionalHow to sort reviews. Only applies in getReviews mode.
proxyConfigurationobjectoptionalOptional. No proxy is required: listing modes use cookieless HTTP first. If Yandex Market proves a request is blocked, the actor automatically tries its residential proxy and then a browser fallback. Provide this only to override that automatic fallback.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/XOsDPtQpdza8krB4z/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
