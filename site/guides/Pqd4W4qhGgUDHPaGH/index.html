Use Facebook Ad Library Byline & Advertiser Ad Finder with Python

Pull Facebook Ad Library ads by advertiser Page ID, keyword, Ad ID, or "Paid for by" byline, with ad text, media, run dates, creative-reuse counts, and spend or impression ranges for political ads.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "resultsPerSearch": 3,
  "searchTerms": [
    "coffee"
  ]
}

Download input.example.json and save your reviewed copy as input.json.

FieldTypeRequiredDescription
searchTermsarrayoptionalKeywords or page names to search for in the Facebook Ad Library. Each term will be searched separately.
countrystringoptionalCountry to filter ads by, or ALL for every country.
adActiveStatusstringoptionalFilter by ad active status.
adTypestringoptionalFilter by ad category type.
mediaTypestringoptionalFilter by media type in the ad.
pageIdsarrayoptionalFacebook Page IDs to fetch all ads for a specific advertiser (mode=byPage). Each Page ID is searched separately, same as searchTerms.
adIdsarrayoptionalFetch specific ads directly by their Ad Library ID (bypasses keyword/page search entirely for these).
bylinesarrayoptionalSearch by the funding entity/committee name shown as "Paid for by" on political and issue ads. Implemented as a keyword search filtered to ads whose byline matches, since Facebook's Ad Library does not support a dedicated URL-level byline filter.
countriesarrayoptionalCountry code(s) to search. Only the first entry is currently applied (multi-country filtering is not yet supported server-side). Takes precedence over the single 'country' field when set.
contentLanguagesarrayoptional2-letter ISO language codes to filter ad content language.
startDatestringoptionalOnly include ads that started running on or after this date (YYYY-MM-DD). Best-effort; not yet confirmed to filter results server-side.
endDatestringoptionalOnly include ads that started running on or before this date (YYYY-MM-DD). Best-effort; not yet confirmed to filter results server-side.
sortBystringoptionalOrder results by relevance (Facebook's default) or by total impressions.
resultsPerSearchintegeroptionalMaximum number of ads to extract per search term.
cookiesstringoptionalCookies from a logged-in Facebook browser session, as Netscape cookie-file text or a JSON array. IMPORTANT: Facebook gates Ads Library search behind login on many residential IPs — supplying cookies makes search reliably return results (export with a browser cookie extension, e.g. 'Get cookies.txt LOCALLY'). Leave empty to search unauthenticated (works on a subset of IPs).

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/Pqd4W4qhGgUDHPaGH/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
