    LinkedIn Company Pages with Funding & Affiliates: export to CSV, Excel or JSON

    Pull full LinkedIn company pages, including industry, headcount, headquarters, specialties, and Crunchbase-sourced funding, with optional affiliated-company and showcase-page records for each input company.

    What people export it for

    • Sales intelligence — enrich a target-account list with headcount, HQ, industry, and funding stage before outreach
    • Investor and M&A research — pull funding totals and last-round details across a portfolio or watchlist of companies
    • Corporate structure mapping — use includeAffiliates and includeShowcases to surface a parent company's full family of LinkedIn pages
    • Competitive benchmarking — compare headcount, follower growth, and specialties across a set of competitors
    • Recruiting and market research — gather company-level context (industry, size, locations) for a list of employers

    Get an API token

    Copy it from Console, Settings, API and Integrations.

    Choose the input

    2 fields are required:

    • companyUrls: LinkedIn company page URLs or slugs. Accepts: https://www.linkedin.com/company/apple/, https://www.linkedin.com/company/apple/about/, or just the slug: apple
    • cookie: Your LinkedIn session cookie. Accepts either: (1) the li_at value from browser DevTools Application Cookies, or (2) full cookies JSON array exported from an extension like EditThisCookie.

    The schema gives no example for cookie; supply a value before you run it.

    Fix common problems

    Why is a LinkedIn cookie required?

    Full company-page data, including funding and affiliate links, is only exposed to a signed-in LinkedIn session, so a valid session cookie is mandatory for every run.

    Why do some companies have no funding fields?

    Funding fields only appear when includeFundingDetails is on and LinkedIn has linked Crunchbase funding data to that company; many companies, especially non-startups, have none to show.

    Why might a field like phone or stockTicker be missing?

    Those fields only exist for companies that have published that information on their LinkedIn page; most companies don't list a phone number or a ticker, so the field is simply omitted.

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.
