Use Google Fonts Library Metadata Extractor with Python

Look up Google Fonts families by name, browse a category, or export the full library with weights, variable-font axes, language subsets, designers, popularity, and ready-to-use CSS embed URLs.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "brandOnly": false,
  "category": "Sans Serif",
  "colorOnly": false,
  "designers": [],
  "families": [
    "Roboto"
  ],
  "includeFiles": false,
  "includeLicense": false,
  "maxFilesPerFamily": 10,
  "maxItems": 3,
  "mode": "byFamily",
  "notoOnly": false,
  "search": "",
  "sortBy": "default",
  "subsets": [],
  "variableOnly": false
}

FieldTypeRequiredDescription
modestringrequiredWhat to fetch from Google Fonts. `icons` fetches the separate Material icon metadata document once and emits icon records; it does not return font-family records.
familiesarrayoptionalFont family names, e.g. `Roboto`, `Open Sans`, `Lora`, `Playfair Display`. Case-insensitive; `displayName` aliases and duplicates are handled. Defaults to `Roboto` when empty.
categorystringoptionalFilter the library to a single font category. Defaults to `Sans Serif` when empty. An unknown category emits a typed `invalid_category` error record.
maxItemsintegeroptionalHard cap on records emitted per run (1-5000). Defaults to 5000 so the whole font catalog (~1,959 families) fits without truncation. The icon endpoint currently reports about 6,139 icons, so `icons` mode can truncate at the cap.
searchstringoptionalFree-text search over family, display name, category, classifications, subsets, designers, and primary script/language. In `icons` mode it searches icon name, categories, tags, and supported families. All space-separated tokens must match.
subsetsarrayoptionalOnly keep families that include every listed subset, e.g. `latin`, `cyrillic`, `greek`, `vietnamese`. The synthetic `menu` subset is present on every family.
designersarrayoptionalOnly keep families whose designer/foundry list contains every listed value (case-insensitive substring match).
variableOnlybooleanoptionalKeep only families that ship a variable font with one or more axes.
colorOnlybooleanoptionalKeep only families with color font capabilities (COLRV0/COLRV1/OTSVG).
brandOnlybooleanoptionalKeep only families where the upstream `isBrandFont` flag is true. In the current catalog this flag equals `isNoto`; it is not a generic brand filter.
notoOnlybooleanoptionalKeep only families in the Noto collection.
sortBystringoptionalOrder the matched families. `popularity` and `trending` are sparse upstream snapshot ranks where lower is better (not dense 1..N positions); `dateAdded` and `lastModified` put newest first. In `icons` mode only `popularity` and `name` change the order; other values keep upstream order.
includeLicensebooleanoptionalEnrich each family with license, license URL, copyright, source repository, source date, languages, unicode coverage, and description. Uses the per-family metadata endpoint, then METADATA.pb, then the download manifest. When omitted, defaults to on for `byFamily` and off for `byCategory`/`listAll`/`icons`; set false explicitly to disable it. The catalog-level `languages` array is always empty upstream, so `languages` can only come from this per-family enrichment. Ignored in `icons` mode.
includeFilesbooleanoptionalFetch the full CSS2 stylesheet (woff2/unicode-range) and the download manifest (TTF URLs). Capped by `maxFilesPerFamily`. CSS2 output depends on the user agent: the actor requests a modern Chrome UA and retries once with Safari when Chrome receives only TTF. Large CJK families can exceed the file cap. When omitted, defaults to on for `byFamily` and off for `byCategory`/`listAll`/`icons`; set false explicitly to disable it. Ignored in `icons` mode.
maxFilesPerFamilyintegeroptionalCap applied separately to `fontFiles` (CSS2) and `ttfFiles` (manifest). CJK families can expose hundreds of files; for example M PLUS 1p has 882 CSS2 blocks, so the 200 default truncates it and `filesTruncated` is set. Raise to 1000 to keep them all.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/A4QB3ojaS4j3hOMXS/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])

4. Inspect the actual results

Open the run in Apify Console and wait for a successful completion. Use the published output schema to locate results and the dataset schema to understand declared views. Missing or optional record fields must not be treated as guaranteed values.

Google Fonts family records with category, weights, variable-font axes, subsets, designers, sparse popularity/trending ranks, dates, and specimen/CSS URLs. Optional enrichment adds license/attribution, source repository, languages/unicode coverage, CSS2 woff2 files with unicode ranges, and TTF download URLs. The icons mode emits icon records (name, codepoint, version, popularity, categories, tags, sizes, supported/unsupported families) from a single request. Typed error records use recordType=error; font records use recordType=font; icon records use recordType=icon.
