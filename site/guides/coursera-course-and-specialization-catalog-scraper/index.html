Use Coursera Course & Specialization Catalog Scraper with Python

Search Coursera's course and specialization catalog by keyword, difficulty or partner university, with rating, learner count, enrollment type and course links.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

FieldTypeRequiredDescription
modestringrequiredWhat to fetch. `bySlug`, `byUrl` and `byIds` always return detail fields for the looked-up products.
querystringoptionalKeyword search (mode=search, searchSpecializations). Optional narrowing keyword for byCategory and byPartner.
startUrlsarrayoptionalCourse, specialization, professional certificate, guided project, degree or certificate page, or a Coursera search / courses URL. Search URLs are converted into catalog filters.
slugsarrayoptionalCourse or specialization slugs, e.g. `machine-learning`. A full Coursera URL is also accepted.
productIdsarrayoptionalCoursera product IDs such as `course~8UjeMk-mEeit4g4GsxE4dg` or `s12n~nOOfCDWeEeuiZgo2K4rorQ`. Bare course IDs are also accepted.
productTypesarrayoptionalLimit results to these Coursera product types. Leave empty for every type.
difficultiesarrayoptionalOnly include products at these difficulty levels.
durationsarrayoptionalOnly include products in these duration bands.
costsarrayoptionalOnly include products with these cost labels.
topicsarrayoptionalOnly include products in these subject areas (mode=byCategory requires at least one).
languagesarrayoptionalOnly include products available in these content languages.
subtitleLanguagesarrayoptionalOnly include products with subtitles in these languages.
handsOnLearningTypesarrayoptionalOnly include products with these hands-on learning formats.
toolsarrayoptionalOnly include products that teach these tools or software skills.
partnersarrayoptionalPartner or university names, e.g. `IBM`, `Google`, `Stanford Online`, `DeepLearning.AI`. Matched to the live Coursera partner filter; partial names such as `Stanford` are resolved to the closest partner.
skillsarrayoptionalSkill names, e.g. `Python Programming`, `Machine Learning`. Matched to the live skill filter; partial names are resolved when possible.
courseraPlusStatusstringoptionalFilter by Coursera Plus inclusion.
freeOnlybooleanoptionalOnly return products whose Coursera cost label is Free. The older audit/verified filter is no longer exposed by Coursera; access flags are included in every record.
sortBystringoptionalResult order for search, browse, byCategory and byPartner modes.
maxItemsintegeroptionalMaximum number of records to return (1-1000).
includeDetailsbooleanoptionalFetch each product page to add instructors, syllabus/modules, total enrollment, page views, rating breakdown, top reviews, learning objectives, recommended background and membership. Slower: one extra request per record. Lookup modes (bySlug/byUrl/byIds) always return detail fields.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/z5wasRpKZDqZTdNyM/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
