    Wellfound Startup Jobs Finder with Pay & Remote Filters is an Apify Actor published by Nimbryxo Studio. It accepts 36 input fields, and mode is required. Each result can carry up to 75 declared fields, including jobId, title, companyName, jobUrl, jobType and remote. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per job”, “Output per company”, “Input”, “Use cases” and “FAQ”.

    What it costs

    Wellfound Startup Jobs Finder with Pay & Remote Filters uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.
