    Michelin Guide Star & Bib Gourmand Restaurant Finder is an Apify Actor published by Nimbryxo Studio. It accepts 10 input fields, and mode is required. Each result can carry up to 11 declared fields, including name, stars, bibGourmand, michelinSelected, cuisine and city. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per restaurant”, “Input”, “Sample output”, “Use cases” and “FAQ”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (all 3-star restaurants in france). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 20, maximum 5000) caps how many results a run collects, and so what it costs.

    What it costs

    Michelin Guide Star & Bib Gourmand Restaurant Finder uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 10 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredWhat to fetch from the Michelin Guide.Default "starredRestaurants"; Allowed starredRestaurants, search, byCity, byUrl
    searchQuerySearch querystringRestaurant name or keyword to search for (mode=search).
    cityCitystringCity name to browse restaurants in (mode=byCity), e.g. Paris, Tokyo, New York.
    countryCountrystringFilter by country slug used in Michelin Guide URLs. Use lowercase slug format (e.g. 'france', 'japan', 'united-states'). The value is automatically normalized to lowercase if entered manually.Default ""; Allowed , france, japan, united-states, united-kingdom, italy, spain, germany and 19 more
    starFilterStar / distinction filterstringFilter restaurants by Michelin distinction (applies to all modes).Default ""; Allowed , 1, 2, 3, bib, selected
    cuisineFilterCuisine filterstringFilter by cuisine type. Note: 'Classic Cuisine' and 'Traditional Cuisine' are how Michelin labels most French/regional cuisine in France — use those options to find French cuisine restaurants in Paris, Lyon, etc. 'French' matches restaurants explicitly labeled 'French' by Michelin, which is more common outside France.Default ""; Allowed , classic, traditional, french, japanese, italian, chinese, mediterranean and 16 more
    startUrlsStart URLs (mode=byUrl)arrayList of Michelin Guide restaurant page URLs to scrape (mode=byUrl). Each item must have a url key, e.g. https://guide.michelin.com/en/ile-de-france/paris/restaurant/guy-savoy.Default []
    maxItemsMax itemsintegerMaximum number of restaurant records to emit.Default 20; Example 5; Allowed 1 to 5000
    includeDetailsFetch restaurant detail pagesbooleanIf enabled, the scraper visits each individual restaurant page for additional data (phone, website, geo-coordinates, opening hours, full description). Note: detail pages may be rate-limited or blocked in some regions; listing data is always scraped regardless of this setting.Default false
    proxyConfigurationProxy configurationobjectApify proxy settings. AUTO datacenter proxy is used by default for Michelin Guide bot-detection bypass.Default {"useApifyProxy": true}
