    YouTube Video, Playlist & Channel Downloader with Metadata is an Apify Actor published by Nimbryxo Studio. It accepts 29 input fields, and mode is required. Each result can carry up to 20 declared fields, including video_url, title, uploader, duration_seconds, download_status and failure_code. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per video”, “Input”, “Examples”, “Use cases” and “FAQ”.

    What it costs

    YouTube Video, Playlist & Channel Downloader with Metadata uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.
