    ImportYeti US Importer & Global Supplier Search is an Apify Actor published by Nimbryxo Studio. It accepts 9 input fields, and mode is required. Each result can carry up to 14 declared fields, including recordType, companyName, type, dataset, country and address. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    Search ImportYeti and pull three kinds of data from one actor across its public US import, US export, and Mexico datasets:

    • Company and supplier records from keyword search, profile URLs, or an HS code.
    • Full profile enrichment for importers, exporters, and overseas suppliers: website, phone/contact info, geography, 12-month activity, quarterly growth, monthly time series, partners, ports and lanes, carriers/SCAC, containers, HS and HTS breakdowns, notify parties, other addresses, other websites, trademarks, and UFLPA status.
    • Shipment rows — one record per recent bill of lading, with BOL/master BOL, date, counterparty, route, transport type, weight, containers, quantity, product description, and CIF value when the source publishes it.

    No ImportYeti account, cookie, or API key is required. Every record has a recordType (company, supplier, hsCode, or shipment) so you can split the dataset into streams. Every record also carries dataset (us-import, us-export, or mx), and profile/shipment records carry sourceDomain, so records from different datasets stay distinguishable.

    Modes

    Mode Input What you get
    searchImporters query US importer summaries, paged until maxItems
    searchSuppliers query Overseas supplier summaries, paged until maxItems
    companyProfile startUrls (URL or slug) One enriched profile per US import company/supplier, US export company, or Mexico company/supplier
    searchByHsCode hsCode (2–10 digits) HS summary, top importing companies, top suppliers, and optionally recent shipments under that code

    includeShipments adds shipment rows in companyProfile and searchByHsCode, and in the two search modes it fetches each matched company profile once to add its recent shipments.

    Use cases

    • Sourcing — find suppliers that already ship a product category, then inspect their lanes and carriers.
    • B2B lead generation — build importer lists by keyword, address, or HS code.
    • Competitive intelligence — compare shipment volume, 12-month activity, quarterly growth, and recent BOLs.
    • Supply-chain risk — map countries, ports, carriers, and notify parties for a counterparty.
    • Trade finance — use shipment recency and CIF values as activity signals.
    • Tariff and product research — start from an HS code and see who imports it and under which HTS lines.

    Examples

    Search US importers:

    {
  "mode": "searchImporters",
  "query": "lithium battery",
  "maxItems": 100
}

    Load a company profile and its recent shipments:

    {
  "mode": "companyProfile",
  "startUrls": [
    {"url": "https://www.importyeti.com/company/samsung-electronics-america"}
  ],
  "includeShipments": true,
  "maxItems": 60
}

    Load a supplier by URL or slug:

    {
  "mode": "companyProfile",
  "startUrls": [{"url": "supplier/foxconn"}],
  "maxItems": 5
}

    Load US export and Mexico profiles:

    {
  "mode": "companyProfile",
  "startUrls": [
    {"url": "https://www.importyeti.com/us-export/company/ikea-supply"},
    {"url": "https://www.importyeti.com/mx/company/latex-centroamericana"},
    {"url": "https://www.importyeti.com/mx/supplier/mic650113792"}
  ],
  "includeShipments": true,
  "maxItems": 60
}

    Explore a 4-digit HS heading:

    {
  "mode": "searchByHsCode",
  "hsCode": "8418",
  "includeShipments": true,
  "maxItems": 25
}

    Explore an HS subheading:

    {
  "mode": "searchByHsCode",
  "hsCode": "841810",
  "includeShipments": true,
  "maxItems": 25
}

    Search with filters:

    {
  "mode": "searchImporters",
  "query": "furniture",
  "addressContains": "North Carolina",
  "since": "2026-01-01",
  "maxItems": 50
}

    Questions

    Where does this data come from?

    Public records ImportYeti indexes: US Customs ocean bills of lading (US import dataset), US export bills of lading, and Mexico's SAT customs records (the mx dataset). Each profile record reports its dataset.

    Is this affiliated with ImportYeti?

    No. This is a third-party actor that reads ImportYeti's public pages.

    Do I need an ImportYeti account?

    No. The actor uses only public pages. It never logs in, and it does not bypass login walls or paid views.

    What are the hard limits?

    ImportYeti allows roughly 25 pageviews per IP before asking for a login. Public profiles expose at most 100 recent BOLs for US import companies (two 50-row views merged by BOL) and up to 50 for US export and Mexico profiles; that is the source ceiling, not an actor cap. Full BOL details, full contact records, and power-query exports require an ImportYeti login or paid plan and are out of scope. The US import dataset covers ocean imports only (no air freight); the US export and Mexico datasets are separate and the Mexico records include truck/air/sea transport types where the source publishes them.

    Why enable proxy?

    On Apify cloud many runs share exit IPs. AUTO datacenter proxy rotation keeps the request budget fresh; no residential proxy is required. The daily-test prefill stays on the cheapest path that returns records.

    What happens when the limit is hit?

    The run rotates proxy sessions when configured, keeps the records already collected, and ends with a status message instead of failing. A profile that cannot be loaded is skipped with a log line.

    Why do some 2- and 4-digit HS pages lack a tariff?

    ImportYeti publishes tariff/AHTN detail on 6+ digit subheading pages. Chapter and heading pages still return the summary, top companies/suppliers, and recent BOL rows.

    Why do some shipment rows lack CIF values?

    ImportYeti publishes two recent-BOL views for US import profiles. The actor merges them by BOL number; fields only one view carries are filled when present and omitted otherwise.

    How current are the dates?

    Customs data is published with a lag of a few weeks, so the latest shipment date usually trails today even for very active importers.
