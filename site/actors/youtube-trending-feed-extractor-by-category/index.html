    YouTube Trending Feed Extractor by Category & Market is an Apify Actor published by Nimbryxo Studio. It accepts 13 input fields, and mode is required. Each result can carry up to 70 declared fields, including position, sourceName, title, channelName, chartViewCount and viewCount. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per chart entry”, “Output per category-hub video”, “Output per status record”, “Input” and “Use cases”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (trending music videos in the united states). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 100, maximum 10000) and maxItemsPerChart (default 100, maximum 100) cap how many results a run collects, and so what it costs.

    What it costs

    YouTube Trending Feed Extractor by Category & Market uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 13 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredWhat to read. 'charts' uses YouTube's official music, trailer and podcast charts. 'hubs' uses YouTube's category pages such as Gaming trending, News, Sports, Learning and Courses.Default "charts"; Allowed charts, hubs
    chartsCharts (mode=charts)arrayOne or more YouTube charts. Trending music videos is the official replacement for the retired general Trending page. Top songs and top artists are weekly; Shorts songs is daily or weekly. Music and Shorts charts include rank movement and optional history.Default ["trendingVideos"]; Allowed trendingVideos, topVideos, topSongs, topArtists, shortsSongs, movieTrailers, podcasts
    categoriesCategory hubs (mode=hubs)arrayOne or more category pages. Gaming trending and Gaming live return up to 50 videos. News reads the selected news sections. Sports, Learning and Courses are editorial category feeds.Default ["gaming"]; Allowed gaming, gamingLive, news, sports, learning, courses
    newsSectionsNews sections (mode=hubs, categories includes news)arrayWhich News tabs to read. 'Top stories' is the main /news page; the other sections are direct news-destination feeds. Available sections vary by country.Default ["top"]; Allowed top, sports, entertainment, business, world, national, health, technology
    countriesCountriesarrayOne or more markets. The 68 YouTube Charts markets are supported; 'global' is supported only for charts that publish a global ranking (top videos, top songs, top artists, Shorts songs).Default ["US"]; Allowed AR, AU, AT, BE, BO, BR, CA, CL and 61 more
    periodChart period (mode=charts)stringDaily or weekly ranking. Weekly-only charts automatically use weekly. Current-only charts such as Trending music videos and Trending movie trailers ignore this setting.Default "daily"; Allowed daily, weekly
    dateChart date (mode=charts)stringHistorical chart date in YYYY-MM-DD format. Leave empty for the latest chart. Supported by Top music videos, Top songs, Top artists and Shorts songs; current-only charts ignore it.Default ""
    maxItemsMax itemsintegerTotal data rows to return across all charts, categories and countries.Default 100; Example 3; Allowed 1 to 10000
    maxItemsPerChartMax items per chart or feedintegerRows to take from each chart/country or category/country combination. Source ceilings still apply.Default 100; Example 3; Allowed 1 to 100
    includeVideoDetailsInclude exact video detailsbooleanFetch exact lifetime views, likes, upload dates and descriptions for every video. YouTube category, tags, Shorts eligibility and family-safe flags are filled when YouTube's player response is available and may be omitted on some cloud IPs. Adds one or more detail requests per video.Default true; Example false
    maxConcurrencyDetail concurrencyintegerHow many exact-detail requests may run in parallel.Default 5; Example 3; Allowed 1 to 10
    onlyNewOnly new itemsbooleanSkip rows already emitted by a previous run with the same monitor name.Default false
    monitorNameMonitor namestringSeparate only-new histories by monitor name.Default "default"
