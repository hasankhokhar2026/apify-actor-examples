    Amazon All Offers & Buy Box Tracker is an Apify Actor published by Nimbryxo Studio. It accepts 8 input fields, none of them required at the top level. Each result can carry up to 10 declared fields, including productAsin, offerPosition, condition, conditionBucket, price and soldBy. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per offer”, “Output: status records”, “Input”, “Limitations” and “Use cases”.

    What you get

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (single asin, all conditions). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxOffersPerProduct (default 20, maximum 50) caps how many results a run collects, and so what it costs.

    What it costs

    Amazon All Offers & Buy Box Tracker uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 8 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    asinsASINsarrayAmazon ASINs to fetch offers for, e.g. B0DCH8VDXF. Provide at least one ASIN or product URL.Default []; Example ["B0DXXYS4BJ"]
    productUrlsProduct URLsarrayFull Amazon product URLs (any /dp/{ASIN} link). The marketplace domain and ASIN are both extracted from each URL. Provide at least one ASIN or product URL.Default []
    conditionsCondition filterstringOnly emit offers of this condition. Amazon's offer panel surfaces 4 distinct condition buckets -- New, Used, Collectible, and Renewed (Amazon Renewed program) -- each matched exactly ("Used only" never silently includes Collectible/Renewed offers).Default "ALL"; Allowed ALL, NEW, USED, COLLECTIBLE, RENEWED
    fulfillmentTypesFulfillment type filterarrayOnly emit offers with this fulfillment type. Derived from Amazon's own explicit "Ships from"/"Sold by" labels: FBA (Fulfilled by Amazon -- ships from Amazon, sold by a third-party seller), AMAZON (sold and shipped by Amazon itself), FBM (Fulfilled by Merchant -- the seller ships it themselves). Leave empty for no filter. Offers where the fulfillment type couldn't be confidently derived are excluded whenever a filter is set (but still included when this filter is empty).Default []; Allowed FBA, FBM, AMAZON
    maxOffersPerProductMax offers per ASINintegerHard cap on the number of offer records emitted per ASIN (the buy-box/pinned offer counts as one). The actor pages through Amazon's offer list 10 offers at a time until this cap, Amazon's reported total, or a bounded 10-page safety ceiling is reached.Default 20; Example 5; Allowed 1 to 50
    deliveryCountryDelivery countrystring2-letter destination country. Offer sets are destination-dependent; also selects the default marketplace domain for bare ASINs (ignored when productUrls supplies its own domain).Default ""; Example "US"; Allowed , US, CA, MX, BR, GB, DE, FR and 16 more
    postalCodePostal / ZIP codestringDestination postal code to refine delivery estimates. Optional.Example "10001"
    proxyConfigurationProxy configurationobjectUses the free AUTO (datacenter) proxy group by default. Some marketplaces (e.g. amazon.co.uk, amazon.de) drop datacenter connections outright, so the actor fast-fails a network-level timeout on a target and automatically retries it once under a RESIDENTIAL session -- a bounded fallback, never the default.Default {"useApifyProxy": true}
