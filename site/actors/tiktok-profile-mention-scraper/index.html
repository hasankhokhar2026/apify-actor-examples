    TikTok Verified Mention Tracker is an Apify Actor published by Nimbryxo Studio. It accepts 14 input fields, and usernames is required. Each result can carry up to 12 declared fields, including targetUsername, mentionType, postUrl, caption, createdAt and author.username. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per post”, “Input”, “Use cases”, “FAQ” and “Known limits”.

    What you get

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (brand mentions from the last 30 days, most liked first). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxResultsPerProfile (default 50, maximum 500) and maxItems (maximum 10000) cap how many results a run collects, and so what it costs.

    What it costs

    TikTok Verified Mention Tracker uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 14 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    usernamesTikTok accounts to trackarray requiredBrand or creator accounts whose mentions you want. Type a handle (nike), a handle with @ (@nike) or paste a profile link (https://www.tiktok.com/@nike). One account per line; duplicates are merged.Example ["billieeilish"]
    mentionFilterWhich posts to keepstringEvery saved post carries a mentionType label: 'tagged' (the caption contains TikTok's clickable tag of the account), 'captionText' (the caption types @handle without a working tag) or 'searchResult' (TikTok search returned it for the handle, but the caption doesn't name the account). By default you get real mentions: tagged posts plus @handle captions.Default "taggedOrCaption"; Example "all"; Allowed taggedOrCaption, tagged, all
    excludeOwnPostsSkip the account's own postsbooleanLeave out posts published by the tracked account itself, so you only see what other people say about it.Default true
    datePostedPosted withinstringOnly look at posts published in this period.Default "anyTime"; Allowed anyTime, past24Hours, pastWeek, pastMonth, past3Months, past6Months
    postedAfterPosted on or afterstringExact cut-off date. Use a date (2026-10-01) or a relative age such as '3 days' or '2 weeks'. Works together with 'Posted within'; the stricter of the two applies.
    sortByOrder of resultsstringHow saved posts are ordered for each account. 'Most liked' and 'Newest first' look at every post found before keeping the top ones.Default "relevance"; Allowed relevance, mostLiked, newest
    minPlayCountMinimum viewsintegerSkip posts with fewer views than this. Leave empty to keep posts of any size.Allowed 0 to 2147483647
    searchDepthSearch depthstring'Standard' runs one search per account and reads every page TikTok returns. 'Deep' adds searches by plain handle, display name and #handle, a most-liked pass, several date ranges and the Photo tab, then merges them without duplicates. Deep finds noticeably more mentions but takes a few minutes per account. Set the run memory to at least 2048 MB for deep search.Default "standard"; Allowed standard, deep
    searchCountrySearch from countrystringTikTok shows different posts in different countries. Pick a country to see the mentions people there get in their search results (for example Japan for Japanese posts). 'Any' uses the fastest connection. Runs with a country are slower.Default "any"; Allowed any, AR, AU, AT, BD, BE, BR, CA and 43 more
    followRelatedVideosAlso follow related videosbooleanAfter searching, open TikTok's related videos for every post that tags the account and keep related posts that also mention it (repeating a few hops). Often finds many extra tagged posts, mostly from creators who tag the account regularly. Slower, and needs at least 4096 MB of run memory.Default false
    maxResultsPerProfileMax posts per accountintegerStop after this many saved posts for each account. TikTok search usually yields tens to a few hundred posts per account, so very high values simply mean 'everything found'.Default 50; Example 3; Allowed 1 to 500
    maxItemsMax posts in totalintegerOptional limit across all accounts in this run. Leave empty for no overall limit.Allowed 1 to 10000
    downloadVideosSave video filesbooleanDownload each saved video into this run's key-value store and add a permanent link to it (downloadedVideoUrl). TikTok's own video links only play inside TikTok, so turn this on when you need playable files. It makes runs slower and uses storage.Default false
    addPostCountryAdd the country each post was made inbooleanLook up the country TikTok records for every saved post (locationCreated, e.g. US, BR, JP). Useful for market breakdowns of who mentions you. Adds a few seconds per post.Default false
