    YouTube Ad Creative & Advertiser Tracker is an Apify Actor published by Nimbryxo Studio. It accepts 16 input fields, none of them required at the top level. Each result can carry up to 38 declared fields, including recordType, advertiserName, countryCode, format, firstShown and lastShown. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Dataset records”, “Input”, “Use cases” and “FAQ and hard limits”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (discover by keyword or domain). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxAdvertisersPerTerm (default 5, maximum 50), maxAdsPerAdvertiser (default 100, maximum 5000) and maxItems (default 100, maximum 5000) cap how many results a run collects, and so what it costs.

    What it costs

    YouTube Ad Creative & Advertiser Tracker uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 1 GB, so a run starts with 1 start event, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 16 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    advertisersAdvertisersarrayAdvertiser names, AR-IDs, Transparency Center URLs, or landing domains to scrape YouTube ads for (e.g. 'Nike, Inc.', 'AR16735076323512287233', 'nike.com'). Names are matched to the strongest suggestion (exact name first, then ad count). Leave empty to use searchTerms.
    searchTermsSearch Terms (keywords or domains)arrayKeywords or domains used to discover advertisers and domains, then scrape their YouTube ads (e.g. 'electric car', 'nike.com'). Keyword searches also use domain suggestions returned by Google.Example ["nike.com"]
    countriesCountries (queried regions)arrayISO 3166-1 alpha-2 queried regions sent to the Transparency Center as the ad filter (e.g. US, GB). This is the region the ads were served in, not the advertiser's headquarters country. The advertiser's own country is reported separately as advertiserCountryCode.Example ["US"]; Allowed AD, AE, AG, AI, AL, AM, AO, AQ and 229 more
    dateFromShown during window: from (YYYY-MM-DD)stringKeep ads whose observed flight overlaps this window. An ad is kept when firstShown <= dateTo and lastShown >= dateFrom, so ads that started earlier but were still running inside the window are included.
    dateToShown during window: to (YYYY-MM-DD)stringKeep ads whose observed flight overlaps this window (inclusive). Works together with dateFrom and is no longer compared only against firstShown.
    formatAd formatstringServer-side creative format filter. TEXT, IMAGE and VIDEO map to Google's verified format codes 1, 2 and 3.Default "all"; Allowed all, text, image, video
    includeVideoDetailsInclude creative detail enrichmentbooleanFetch GetCreativeById for every creative to enrich last-shown dates, served regions and preview assets. Video IDs are resolved from previews even when this is off.Default false
    resolveVideoIdsResolve YouTube video IDs from previewsbooleanExtract videoId, watch URL, thumbnail and duration from creative previews (ytimg/youtube URLs). Missing IDs are omitted, never fabricated. Turn off to save preview requests.Default true; Example false
    maxAdvertisersPerTermMax advertisers per search termintegerMaximum advertiser matches (and domain suggestions) to scrape per keyword (when searchTerms is used).Default 5; Allowed 1 to 50
    maxAdsPerAdvertiserMax ads per advertiserintegerCursor-pagination cap per advertiser or domain, applied before the global maxItems cap.Default 100; Example 3; Allowed 1 to 5000
    maxItemsMax itemsintegerHard cap on total ad records returned (1-5000). Advertiser and run-summary records do not count toward this cap.Default 100; Example 3; Allowed 1 to 5000
    maxConcurrencyMax concurrencyintegerAdvertisers scraped in parallel. Higher is faster but increases rate-limit risk.Default 2; Allowed 1 to 5
