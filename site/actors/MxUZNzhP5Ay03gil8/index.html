Actors/Amazon Multi-Domain Product Price & Detail Scraper

Amazon Multi-Domain Product Price & Detail Scraper

Pull pricing, ratings, seller, variant and technical detail for Amazon products by URL or ASIN, across 21 country domains, with optional delivery postal-code targeting.

Open on ApifyGitHub source

Input schema

Input fields, types, required flags, descriptions, defaults, and prefills come from the published definition. Prefill examples are distinct from defaults.

productUrlsarrayoptionalAmazon product URLs to scrape. Any mix of the 21 supported country domains is allowed, e.g. https://www.amazon.com/dp/B0B8PD8TTP.
asinsarrayoptionalBare 10-character Amazon ASINs. Builds /dp/{ASIN} URLs on the selected marketplace, or on every domain listed in `domains` for cross-marketplace runs.

FieldTypeRequiredDescription
productUrlsarrayoptionalAmazon product URLs to scrape. Any mix of the 21 supported country domains is allowed, e.g. https://www.amazon.com/dp/B0B8PD8TTP.
asinsarrayoptionalBare 10-character Amazon ASINs. Builds /dp/{ASIN} URLs on the selected marketplace, or on every domain listed in `domains` for cross-marketplace runs.
searchTermsarrayoptionalKeyword queries to run on Amazon search pages. Price/rating/deal/condition/sort filters are applied as URL parameters.
searchUrlsarrayoptionalFull Amazon search URLs to pass through, including your own `i=`, `rh=`, `low-price`, and `s=` parameters. Pagination is added automatically.
bestsellerUrlsarrayoptionalAmazon bestseller /zgbs/ or /gp/bestsellers/ list URLs. Returns the ranked product cards, optionally enriched with product-detail fields.
marketplacestringoptionalMarketplace used for bare ASINs and keyword search terms. `auto` uses the first product URL's domain, or amazon.com.
domainsarrayoptionalOptional list of marketplaces (e.g. amazon.com, amazon.de) to run bare ASINs and search terms across. Leave empty to use `marketplace` only.
languagestringoptionalPage language. `auto` uses the marketplace's own default. Explicit values set `?language=` and the matching Accept-Language header.
currencystringoptionalISO currency for the displayed price. `auto` uses the marketplace currency. Note: Amazon converts display currency; it is not guaranteed local retail pricing.
deliveryCountrystringoptionalOptional country hint. When `postalCode` is empty, a representative local ZIP for that country is used. A country alone is not sent to Amazon.
postalCodestringoptionalLocal ZIP/postal code for the delivery location. The actor validates it against the marketplace format and skips the location change if it does not match.
minPricenumberoptionalMinimum price for discovery (search) results. Leave empty for no lower bound.
maxPricenumberoptionalMaximum price for discovery (search) results. Leave empty for no upper bound.
minRatingstringoptionalMinimum star rating for discovery results. `4` is the live-validated 4+ stars filter; lower values are best effort.
dealsOnlybooleanoptionalApply Amazon's deals filter to keyword searches. Only affects discovery.
primeOnlybooleanoptionalApply Amazon's Prime filter to keyword searches. Prime eligibility itself is not emitted because the page does not expose a reliable per-item signal.
conditionstringoptionalItem condition filter for keyword searches. `new` is live-validated; other values are best effort.
brandstringoptionalOptional brand word added to keyword search terms and used as a title/brand post-filter. This is not a structured Amazon brand-facet resolver.
stockstringoptionalBest-effort stock filter applied after parsing. Records with unknown stock pass through.
sortBystringoptionalSort order for keyword searches. Search-URL pass-through keeps its own sort.
maxItemsintegeroptionalMaximum number of search/bestseller rows across all discovery inputs. Explicit product URLs/ASINs are always processed.
maxPagesintegeroptionalMaximum search-result pages to read per keyword or search URL (1-20).
includeDetailsbooleanoptionalFetch each discovery result's product page for full price, seller, variants, specs, reviews, and media fields. Disable for a cheaper search-card-only run.
includeSponsoredbooleanoptionalKeep sponsored search cards. The isSponsored flag is always preserved.
includeVariantsbooleanoptionalInclude parent ASIN, child ASINs, and variant dimensions. Per-variant price and stock are not available from the product page.
includeTopReviewsbooleanoptionalInclude the inline top-review snippets Amazon renders publicly. Full review pagination is login-gated and is not supported.
includeFailedbooleanoptionalEmit an error row (recordType=error, reason, httpStatus) when a product or discovery input fails instead of silently dropping it.
failOnEmptybooleanoptionalMark the run as FAILED when no product/search records are emitted.
rateLimitDelayintegeroptionalBase pause in seconds between product/search requests (0-10). A random value between this and twice this is used.
proxyConfigurationobjectoptionalOptional. The actor starts direct and escalates through Apify Proxy automatically only if Amazon blocks the request. No setup is required.
proxyCountrystringoptionalOptional proxy exit country. `AUTO` uses the marketplace's own country for every domain.

Amazon Multi-Domain Product Price & Detail Scraper

Scrape Amazon products and discovery lists across 21 country marketplaces. Give it product URLs or ASINs and get back price, coupon, deal badges, rating, review count, bestseller rank, seller and buy-box details, offers, availability, variants, images, videos, specs, A+ text, and public top-review snippets. You can also start from keyword terms, full search URLs, or bestseller list URLs. No login, cookies, or API key is needed.

What this actor does

  • Products by URL or ASIN across amazon.com, .co.uk, .de, .fr, .it, .es, .ca, .com.au, .co.jp, .in, .com.br, .com.mx, .nl, .se, .pl, .com.tr, .ae, .sa, .sg, .com.be, and .eg.
  • Discovery by keyword, search URL, or bestseller list with price, rating, deal, condition, and sort filters on keyword searches.
  • Locale-aware output: marketplace language, display currency, delivery ZIP, and the rendered locationText are carried on every record.
  • Commercial fields: coupon, deal badge, status badges, bought-past-month, list price, discount percent, offer count, and lowest offer.
  • Explicit failure rows with a reason code instead of silently dropping an input.
  • Empty fields are omitted from each record.

Output per product

  • recordType - product, searchResult, bestseller, or error
  • asin, parentAsin, title, brand, url, marketplace, status, warnings[]
  • price (value, currency, display), listPrice, currency, discountPercent, onSale, savingsPercentage
  • coupon (text, percent, amount, type), dealBadge, badges[]
  • stars, reviewsCount, starsBreakdown, ratingHistogram, customersSay
  • topReviews[] - inline public snippets (author, rating, title, date, text, verified)
  • boughtPastMonth (text, value)
  • bestsellerRanks[] (rank, category), category, categories[]
  • inStock, inStockText, availability, delivery, fastestDelivery, locationText
  • seller (name, id, url, soldById, sellerRatingText)
  • buybox (shipsFrom, soldBy, soldByAmazon, isFBA)
  • offers (count, lowestPrice), offerCount, lowestOfferPrice
  • variantAsins[], variants[] (asin, isCurrent), variantAttributes[]
  • images[], thumbnailImage, videos[], features[], description, aplusText
  • details[], specifications (upc, ean, gtin, modelNumber, dimensions, and more)
  • documents[], sizeChart[], returnPolicy, support, sustainabilityFeatures
  • productType, book for book listings
  • manufacturer, modelNumber, weight, productDimensions, countryOfOrigin, dateFirstAvailable
  • scrapedAt - ISO-8601 UTC timestamp

Output per search or bestseller row

Search rows also carry query, page, position, isSponsored, and searchUrl. Bestseller rows carry rank, listUrl, and listType: "bestseller". When includeDetails is on, the row is enriched with the full product fields above and foundVia is set.

Output per failure

  • recordType: "error"
  • reason - INVALID_INPUT, NOT_FOUND, BLOCKED_WAF, BLOCKED_CAPTCHA, UNAVAILABLE, NO_BUYBOX, PARSE_DEGRADED, TIMEOUT, or SEARCH_NO_RESULTS
  • asin, url, marketplace, httpStatus, attempts, retryable, message, scrapedAt

Use cases

  • Price and buy-box monitoring - track price, list price, coupon, seller, offers, and stock per marketplace
  • Catalog enrichment - pull images, specs, variants, A+ text, and identifiers into your own catalog
  • Keyword and category research - find products by search filters or bestseller rank, then enrich the winners
  • Cross-marketplace comparison - run the same ASIN across several country sites in one job
  • Review and reputation tracking - monitor star ratings, review counts, rating breakdowns, and public review snippets
  • Deal monitoring - surface coupons, limited-time deals, and discount percentages

FAQ

Which marketplaces are supported? 21 country domains: amazon.com, amazon.ca, amazon.com.mx, amazon.com.br, amazon.co.uk, amazon.de, amazon.fr, amazon.it, amazon.es, amazon.nl, amazon.com.be, amazon.se, amazon.pl, amazon.com.tr, amazon.ae, amazon.sa, amazon.eg, amazon.in, amazon.co.jp, amazon.com.au, and amazon.sg.

Do I need cookies or an API key? No. Everything the actor returns comes from public Amazon pages. There is no login step and no credential input.

Do I need to set up a proxy? No. The actor chooses a working connection automatically and only escalates when Amazon blocks a request. You can leave proxyConfiguration at its default.

Why does the displayed price differ from the local shelf price? Amazon converts display currency when you request a different currency from the marketplace. The record always carries currency and locationText so you can see which currency and delivery location were used. For exact local retail pricing, keep currency on auto and set a local postalCode.

Can I get Prime eligibility? No. The 2026 Amazon page exposes only promotional or hidden Prime icons, not a reliable per-item eligibility signal. primeOnly applies Amazon's own search filter, but no Prime field is emitted.

Can I get full reviews or per-variant prices? No. Full review pages require a login, so only the inline public snippets are returned. Variants expose parent and child ASINs plus dimensions, but the product page does not carry per-variant prices or stock.

Why is a field missing from a record? Empty values are omitted. Fields such as coupon, dealBadge, aplusText, videos, topReviews, and specifications only appear when that product or marketplace actually renders them.

What happens to a bad ASIN or a blocked page? With includeFailed on, the actor emits an error row with a reason code and continues with the rest of the batch. A 404, a WAF challenge, and an out-of-stock product are reported as different reasons.

Does the brand filter use Amazon's brand facets? No. brand is added to the keyword text and used as a title/brand post-filter. It is not a structured Amazon brand-ID resolver; use searchUrls when you already have a facet URL.

Can I scrape category browse pages? Not directly. Category /b?node= pages do not expose product cards reliably. Use a keyword search URL with the category parameter (/s?k=...&i=...) or a bestseller list URL instead.

Why are some commercial fields only best effort? Coupons, deal badges, bought-past-month, A+ text, videos, and top-review snippets are rendered only for some products, marketplaces, or session variants. When Amazon does not render one, the field is omitted rather than guessed.

Is this affiliated with Amazon? No. This is a third-party actor that reads publicly available Amazon pages. It is not affiliated with, endorsed by, or sponsored by Amazon.
