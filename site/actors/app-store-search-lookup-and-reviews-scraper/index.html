    App Store Search, Lookup & Reviews Scraper is an Apify Actor published by Nimbryxo Studio. It accepts 15 input fields, and mode is required. Each result can carry up to 55 declared fields, including id, name, developer, price, currency and rating. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Modes”, “Output per app”, “Output per review”, “Input” and “What is available and what is not”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (search with rich details). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 100, maximum 5000) caps how many results a run collects, and so what it costs.

    What it costs

    App Store Search, Lookup & Reviews Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 15 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredWhat to collect. Search finds apps by keyword, Lookup resolves IDs/URLs, Reviews collects customer feedback, Developer lists a publisher's apps, and Charts reads a top list.Default "search"; Allowed search, lookup, reviews, developer, charts
    searchTermsSearch termsarrayKeywords to search for (mode=search). Each term returns up to 200 ranked apps, and results are de-duplicated across terms.Example ["calculator"]
    appIdsApp IDs, bundle IDs, or URLsarrayApps to look up or review (mode=lookup/reviews). Accepts numeric App Store IDs, bundle IDs, app URLs, and developer URLs. Separate multiple values with commas or new lines.
    startUrlsApp Store URLsarrayPaste App Store app or developer URLs (mode=lookup/reviews). App URLs resolve to one app; developer URLs expand to that publisher's catalog.
    developerIdDeveloper ID or URLstringApple artist ID or developer page URL (mode=developer). For example 281956209 or https://apps.apple.com/us/developer/google/id281956209. Comma-separated values are accepted.
    developerNameDeveloper namestringPublisher name to resolve when you do not know the developer ID (mode=developer). The actor searches App Store listings and matches the publisher name.
    countryStorefront countrystringTwo-letter App Store storefront. Changes pricing, availability, chart contents, and review language.Default "us"; Allowed us, gb, de, fr, jp, in, br, ca and 54 more
    languageStorefront languagestringLanguage used for App Store metadata and reviews. Defaults to English (United States).Default "en-US"; Allowed en-US, en-GB, de-DE, fr-FR, es-ES, it-IT, ja-JP, ko-KR and 8 more
    maxItemsMaximum recordsintegerHard cap on rows pushed per run (1-5000). Applies to apps, chart rows, and reviews combined. For very large review corpora, raise this and set maxReviewsPerApp.Default 100; Example 3; Allowed 1 to 5000
    maxReviewsPerAppMaximum reviews per appintegerReviews to collect for each app (1-50000). The deep review route returns 20 per request; RSS enrichment is available for the first 500 reviews when version or helpful-vote data exists.Default 200; Example 20; Allowed 1 to 50000
    reviewSortReview orderstringMost recent first, or Apple's most-helpful ordering (mode=reviews).Default "recent"; Allowed recent, helpful
    includeDeveloperResponsesInclude developer responsesbooleanKeep developer replies when Apple exposes them (mode=reviews). Replies are available only for apps where the developer actually responded.Default true; Example false
    includeDetailsInclude rich app detailsbooleanAdd App Store detail fields such as privacy labels, version history, rating histogram, support URL, and subtitle (app-producing modes). Disable it for the fastest, cheapest search runs.Default true; Example false
    chartTypeChartstringTop chart to read (mode=charts). Mac charts use the App Store Mac catalog.Default "top-free"; Allowed top-free, top-paid, top-grossing, top-free-ipad, top-paid-ipad, top-free-mac
    proxyConfigurationProxy configurationobjectOptional. The actor works without a proxy. Add an Apify Proxy configuration only if your own network or a future Apple rate limit needs it.Default {"useApifyProxy": false}
