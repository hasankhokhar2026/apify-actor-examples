    LinkedIn Jobs Scraper with Salary & Company Enrichment is an Apify Actor published by Nimbryxo Studio. It accepts 29 input fields, none of them required at the top level. Each result can carry up to 22 declared fields, including title, companyName, location, salary, salarySource and applicantCount. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per job”, “Input”, “Choosing the right depth”, “How many jobs can I collect?” and “Use cases”.

    What it costs

    LinkedIn Jobs Scraper with Salary & Company Enrichment uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 29 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    searchQueriesSearch keywordsarrayJob titles, skills or phrases to search for, one per line (e.g. 'data analyst', 'registered nurse'). Each keyword is searched in every location you list, and results are merged without duplicates.Example ["Python Developer"]
    searchUrlsLinkedIn job search linksarrayPaste job search links copied from LinkedIn (linkedin.com/jobs/search/?...). The keywords, location and filters inside each link are kept.
    jobUrlsJob links or IDsarrayScrape specific job postings: paste job links (linkedin.com/jobs/view/...) or numeric job IDs. Postings that have been taken down are skipped.
    locationsLocationsarrayCities, regions or countries in English (e.g. 'Germany', 'Austin, Texas', 'London Area, United Kingdom'). Every keyword is searched in each location. A location LinkedIn doesn't recognise is reported and skipped rather than silently searched as the United States. Leave empty to search worldwide.Example ["United States"]
    geoIdsLinkedIn location IDsarrayOptional numeric LinkedIn location IDs (the geoId value in a LinkedIn search link, e.g. 101282230 for Germany). Use these for exact places in any language.
    distanceDistance from locationstringSearch radius around a city-level location, in miles.Default ""; Allowed , 0, 5, 10, 25, 50, 100
    timePostedDate postedstringOnly jobs posted (or reposted) within this period.Default ""; Allowed , r3600, r86400, r259200, r604800, r1209600, r2592000, r7776000
    companiesCompaniesarrayOnly jobs from these employers. Enter company names (e.g. 'General Motors'), LinkedIn company or university page links, or numeric company IDs. Leave the keywords empty to get all of a company's open jobs.
    excludeCompaniesExclude companiesarraySkip jobs from these employers (exact company name or LinkedIn company page link).
    easyApplyEasy Apply onlybooleanOnly jobs you can apply to directly on LinkedIn.Default false
    under10ApplicantsFewer than 10 applicantsbooleanOnly jobs that have had fewer than 10 applicants so far.Default false
    experienceLevelExperience levelstringOnly jobs listed at this seniority level on LinkedIn. Jobs that LinkedIn lists as 'Not Applicable' are left out when a level is chosen.Default ""; Allowed , 1, 2, 3, 4, 5, 6

    excludeTitleKeywordsTitle must not containarraySkip jobs whose title contains any of these words, e.g. 'Senior' or 'Intern'.
    excludeJobIdsSkip these job IDsarrayJob IDs (the 'id' field of an earlier run) to leave out, so scheduled runs return only new postings.

    includeCompanyDetailsInclude company profilebooleanAdd each employer's LinkedIn profile: industry, size, headquarters, website, founding year, office locations, followers, tagline and description. Fetched once per company.Default true; Example false
    enrichmentDepthJob page depthstringStandard returns each job's core details.     languageLanguage of LinkedIn labelsstringLanguage LinkedIn uses for labels such as job type and seniority. Job descriptions stay in the language they were written in. Locations must still be typed in English.Default "en"; Allowed en, es, fr, de, pt
    splitLargeSearchesGo past 1,000 jobs per searchbooleanLinkedIn returns at most 1,000 jobs for one search. When a search reaches that limit, continue with the same search limited to the past month, week, 3 days and 24 hours, which surfaces many more jobs (duplicates removed).Default true
    maxItemsMaximum jobsintegerStop after saving this many jobs. A single keyword + location search returns at most 1,000 jobs; add keywords or locations to collect more.Default 100; Example 3; Allowed 1 to 10000
