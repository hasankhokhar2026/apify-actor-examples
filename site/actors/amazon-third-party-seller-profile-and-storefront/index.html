    Amazon Third-Party Seller Profile & Storefront Catalog is an Apify Actor published by Nimbryxo Studio. It accepts 14 input fields, and mode is required. Each result can carry up to 9 declared fields, including recordType, sellerId, sellerName, title, price and starRating. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per seller profile record (recordType: "sellerProfile")”, “Output per seller product record (recordType: "sellerProduct")”, “Output per storefront facets record (recordType: "storefrontFacets")”, “Output per error/terminal record (recordType: "sellerError")” and “Input”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (look up two sellers directly). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxProductsPerSeller (default 200, maximum 1000) and maxFeedbackEntries (default 20, maximum 200) cap how many results a run collects, and so what it costs.

    What it costs

    Amazon Third-Party Seller Profile & Storefront Catalog uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 14 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredPROFILE fetches only the seller profile page (including recent individual feedback entries when enabled). PRODUCTS fetches only the seller's storefront catalog. BOTH fetches both for every resolved seller.Default "BOTH"; Allowed PROFILE, PRODUCTS, BOTH
    sellerIdsSeller IDsarrayAmazon seller/merchant IDs (e.g. A294P4X9EWVXLJ). Accepts bare IDs or IDs embedded in a seller/storefront URL.Default []; Example ["A294P4X9EWVXLJ"]
    productUrlsProduct URLsarrayAmazon product page URLs (e.g. https://www.amazon.com/dp/ASIN). The seller ID is auto-derived from each product's buy-box "sold by" seller link.Default []
    marketplaceMarketplacestringAmazon marketplace/domain to scrape sellers on. Overrides the domain inferred from productUrls when both are provided.Default "US"; Allowed US, CA, MX, BR, IE, ES, GB, FR and 15 more
    proxyCountryProxy CountrystringOptional geo-targeting override. AUTO follows the selected marketplace and needs no setup; the actor picks a working connection automatically.Default "AUTO"; Allowed AUTO, US, CA, MX, BR, IE, ES, GB and 16 more
    maxProductPagesMax Storefront Pages Per SellerintegerMaximum number of /s?me= storefront pages to fetch per seller (mode=PRODUCTS or BOTH). Each page holds up to ~16 products; Amazon stops pagination at the seller's own result count.Default 3; Example 1; Allowed 1 to 100
    maxProductsPerSellerMax Products Per SellerintegerHard cap on product records emitted per seller, applied in addition to Max Storefront Pages. (mode=PRODUCTS or BOTH)Default 200; Example 16; Allowed 1 to 1000
    categoryFilterCategory / Refinement FilterstringOptional. Narrow the storefront to one category or facet by pasting a refinement token (e.g. n:172282) or a full Amazon facet URL from the storefrontFacets record. Leave blank for the full storefront. (mode=PRODUCTS or BOTH)Default ""
    sortByStorefront Sort OrderstringSort order for the seller's storefront catalog (mode=PRODUCTS or BOTH), matching Amazon's own storefront "Sort by" dropdown. Leave blank for Amazon's default (Featured).Default ""; Allowed , relevanceblender, price-asc-rank, price-desc-rank, review-rank, date-desc-rank, exact-aware-popularity-rank
    includeBusinessDetailsInclude Business DetailsbooleanIf true, includes the seller's publicly-displayed legal business name, business address, and customer-service phone number (data Amazon itself shows on the public seller profile page -- not customer-level personal data).Default true
    includeFeedbackEntriesInclude Individual Feedback EntriesbooleanInclude the seller's recent individual feedback entries (star rating, text, rater, date) in each seller profile record, when Amazon displays them.Default true
    maxFeedbackEntriesMax Feedback Entries Per SellerintegerMaximum individual feedback entries to include per seller (Amazon returns 5 per page). Applies when Include Individual Feedback Entries is on.Default 20; Example 5; Allowed 1 to 200
    feedbackRatingFeedback Star FilterstringOnly include feedback entries with this exact star rating. 'All stars' returns every rating.Default "all"; Allowed all, 5, 4, 3, 2, 1
    feedbackPeriodFeedback PeriodstringTime window Amazon applies to the individual feedback entries and the profile rating summary.Default "12 months"; Allowed 30 days, 90 days, 12 months, lifetime
