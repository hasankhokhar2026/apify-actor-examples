    GitHub Repository Metadata & README Extractor is an Apify Actor published by Nimbryxo Studio. It accepts 28 input fields, none of them required at the top level. Each result can carry up to 19 declared fields, including fullName, htmlUrl, description, primaryLanguage, stars and forks. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per repository”, “Input”, “Use cases”, “Rate limits and behaviour” and “Limitations”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (search for maintained rust projects). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    What it costs

    GitHub Repository Metadata & README Extractor uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 28 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestringHow to find repositories. 'search' runs a GitHub search query, 'direct' fetches an explicit list, 'owner' lists a user or organisation's repositories, and 'topic' lists repositories tagged with a topic.Default "search"; Allowed search, direct, owner, topic
    searchQuerySearch querystringGitHub search expression (mode=search). Supports qualifiers such as 'stars:>10000', 'language:python', 'topic:llm', 'user:apify', 'pushed:>2025-01-01', and 'in:name,description'. In owner/topic mode it is an optional keyword filter added to the owner or topic.Default ""; Example "stars:>10000 language:python"
    repositoryUrlsRepository URLs or slugsarrayRepositories to fetch (mode=direct). Accepts https://github.com/owner/repo, a trailing slash, .git, the git@github.com:owner/repo.git SSH form, or a plain owner/repo slug. Duplicates are removed.Default []; Example ["https://github.com/apify/crawlee"]
    ownerOwnerstringGitHub user or organisation whose repositories should be listed (mode=owner). Accepts 'apify' or 'https://github.com/apify'.Default ""
    topicTopicstringTopic tag to browse (mode=topic), e.g. 'llm', 'machine-learning', or 'web-scraping'. A leading 'topic:' is accepted and stripped.Default ""
    sortBySort bystringSort key for search, owner, and topic results.Default "stars"; Allowed stars, forks, updated, help-wanted-issues
    sortOrderSort directionstringAscending or descending order for the selected sort key.Default "desc"; Allowed desc, asc
    languageLanguagestringOnly repositories whose primary language matches. Pick a common language here, or type any other language in 'Custom language'.Default ""; Allowed , python, javascript, typescript, java, go, rust, c and 44 more
    languageCustomCustom languagestringAny GitHub language name not listed above (e.g. 'Hare', 'Gleam'). Overrides the Language dropdown when non-empty.Default ""
    licenseLicensestringOnly repositories released under this license.Default ""; Allowed , mit, apache-2.0, gpl-3.0, gpl-2.0, lgpl-3.0, lgpl-2.1, agpl-3.0 and 16 more
    searchInSearch text instringWhere the free-text part of searchQuery must match (mode=search). Applies only when searchQuery contains free text.Default ""; Allowed , name,description, name, description, readme, topics
    minStarsMinimum starsintegerOnly repositories with at least this many stars. 0 means no star filter.Default 0; Allowed 0 to 1000000000

    pushedAfterPushed afterstringOnly repositories with a push on or after this date (YYYY-MM-DD). Useful for finding maintained projects.Default ""
