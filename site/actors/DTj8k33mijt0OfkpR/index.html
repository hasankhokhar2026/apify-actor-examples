Actors/Facebook Marketplace Listing & Price Extractor

Facebook Marketplace Listing & Price Extractor

Extract public Facebook Marketplace listings by city feed, category, keyword search, or direct item URL, with price, location, photos, delivery method, seller, and listing status per item.

Open on ApifyGitHub source

Input schema

Input fields, types, required flags, descriptions, defaults, and prefills come from the published definition. Prefill examples are distinct from defaults.

FieldTypeRequiredDescription
modestringoptionalWhat to scrape. auto uses startUrls when present and otherwise builds a keyword search. search builds a search from searchQueries plus location. urls scrapes the given Marketplace search, category, or city-feed URLs. items fetches direct item URLs or numeric IDs.
startUrlsarrayoptionalMarketplace search, city-category, global-category, city-feed, or /marketplace/item/ URLs. In mode=items, a bare numeric listing ID is also accepted.
searchQueriesarrayoptionalOne to 20 keywords or phrases (mode=search or mode=auto without URLs). Each query becomes one source.

FieldTypeRequiredDescription
modestringoptionalWhat to scrape. auto uses startUrls when present and otherwise builds a keyword search. search builds a search from searchQueries plus location. urls scrapes the given Marketplace search, category, or city-feed URLs. items fetches direct item URLs or numeric IDs.
startUrlsarrayoptionalMarketplace search, city-category, global-category, city-feed, or /marketplace/item/ URLs. In mode=items, a bare numeric listing ID is also accepted.
searchQueriesarrayoptionalOne to 20 keywords or phrases (mode=search or mode=auto without URLs). Each query becomes one source.
locationstringoptionalMarketplace location slug, city, postal code, or address used by keyword search (mode=search or mode=auto without URLs). Examples: nyc, Austin, Texas, 90210, London.
countrystringoptionalISO 3166-1 alpha-2 country used when resolving a human location. Use GB for London, CA for Toronto, and so on.
latitudenumberoptionalOptional search center latitude. Provide longitude too.
longitudenumberoptionalOptional search center longitude. Provide latitude too.
radiusKmintegeroptionalSearch radius in kilometres for keyword or category search. URL mode keeps the radius in the URL unless you set this explicitly.
categorystringoptionalMarketplace category. If searchQueries is empty, the actor opens the city category feed (or the global category feed for a human location). Books, shoes, games, motorcycles, cell-phones, computers, video-games, and cameras were verified as category feeds but expose no server category ID, so they are not usable as keyword filters; use categoryId or a category URL for those.
categoryIdstringoptionalAdvanced numeric Facebook category ID. Takes precedence over category when set.
sortBystringoptionalServer-side sort where Marketplace supports it, plus a client-side re-sort by price or posting time. Rows without a price sort last.
minPricenumberoptionalOnly listings at or above this price. Rows without a price are dropped.
maxPricenumberoptionalOnly listings at or below this price. Rows without a price are dropped.
conditionstringoptionalServer-side condition filter in search/category modes. In deep mode the detail condition is checked too; fast URL rows without condition data are kept.
deliveryMethodstringoptionalClient-side filter over the listing's delivery types. Listings without delivery data are dropped when this filter is active. Legacy local_pickup is accepted as local.
daysSinceListedintegeroptionalOnly listings created within this many days. Rows without a posting time are dropped.
availabilitystringoptionalClient-side status filter. Search feeds are mostly available; sold and pending are more common on direct item pages.
exactMatchbooleanoptionalKeep only rows whose title (and description in deep mode) contains every query word.
maxItemsintegeroptionalGlobal output limit across all sources.
maxItemsPerUrlintegeroptionalPer-source output limit.
maxPagesPerUrlintegeroptionalCost guard for cursor pagination. The actor stops earlier on source exhaustion, a repeated cursor, two empty pages, or maxItems. There is no fixed row cap: a Phase 6 probe reached 1,694 unique search rows across 71 pages before Facebook returned an empty page 72.
scrapeModestringoptionalfast streams feed rows. deep fetches each listing page for description, condition, attributes, seller, coordinates, and photos. auto follows includeListingDetails and includeAllPhotos.
includeListingDetailsbooleanoptionalCompatibility alias that enables deep mode unless scrapeMode=fast is explicit.
includeAllPhotosbooleanoptionalEnables deep mode and adds the full photo gallery.
rehostImagesbooleanoptionalCopy primary photos and seller avatars into the actor key-value store so the emitted URLs do not expire. The original Facebook URL is kept in primaryPhotoUrlOriginal. When off, mediaUrlTemporary is emitted.
deduplicateAcrossInputsbooleanoptionalEmit each listing ID once across sources. Disable to preserve repeats from repeated input URLs.
proxyConfigurationobjectoptionalOptional advanced override. The actor works without a proxy and automatically escalates only when Facebook blocks a request. A missing value never stops a run.

Facebook Marketplace Listing & Price Extractor

Extract public Facebook Marketplace listings without cookies, login, or a proxy of your own. Point the actor at Marketplace search, category, city-feed, or direct item URLs, or give it a keyword plus a city, and get one structured row per listing with price, location, delivery, status, seller, photos, and optional detail fields.

What this actor does

  • Scrapes keyword searches, city categories, global categories, city/location feeds, and direct item pages in one run.
  • Builds a Marketplace search from searchQueries + location, resolving city names, postal codes, and addresses server-side.
  • Paginates search and category feeds with Facebook's cursor, stopping on source exhaustion, a repeated cursor, two empty pages, maxPagesPerUrl, or maxItems. There is no fixed row cap: the Phase 6 probe reached 1,694 unique search rows across 71 pages before Facebook returned an empty page 72.
  • Reads feed rows in fast mode and fetches each listing page in deep mode for description, condition, attributes, seller, coordinates, gallery, and vehicle fields.
  • Applies price, condition, delivery, age, availability, category, and exact-keyword filters against the data each row actually carries.
  • Rehosts the primary photo into the actor key-value store by default so the emitted URL does not expire; the original signed URL is retained. If a download fails, the original signed URL is kept and flagged mediaUrlTemporary: true.
  • Empty fields are omitted: null, empty-string, empty-list, and empty-object values are never emitted. 0 and false are preserved.
  • Works without user cookies. The proxy ladder starts direct and only escalates when Facebook blocks a request; residential is a hardcoded last resort after free rungs fail, never a schema default.

Field Type Default Description

country string US ISO 3166-1 alpha-2 country used when resolving a human location. Use GB for London, CA for Toronto, and so on.
latitude number none Optional search center latitude. Provide longitude too. Overrides location when both are set.
longitude number none Optional search center longitude. Provide latitude too.

Rows whose coordinates are absent cannot be distance-checked and are kept; the status message reports how many were kept that way. URL-mode sources use the radius embedded in the page unless radiusKm is set explicitly.
category string all Curated Marketplace category: vehicles, electronics, furniture, home, tools, sports, toys, appliances, jewelry, autoparts, garden, pets, books, shoes, games, motorcycles, boats, antiques, arts, health, cell-phones, computers, video-games, cameras, or all. With no searchQueries, opens the city or global category feed instead. Books, shoes, games, motorcycles, cell-phones, computers, video-games, and cameras were verified as category feeds but expose no server category ID, so they cannot be used as keyword filters; use categoryId or a category URL instead. Location

Delivery, status, and age

  • dataMode (fast or deep), extractionSource, qualityStatus (complete or partial)
  • missingFields — expected canonical fields that were absent
  • accessState, detailFetchStatus (deep/direct rows)

Use cases

  • Price monitoring — track asking prices for a product or category across cities over time.
  • Resale and arbitrage — scan multiple city feeds for underpriced items.
  • Vehicle shopping — pull vehicle listings by location, price range, and condition.
  • Apartment hunting — collect rental and furniture listings from several neighborhoods.
  • Market research — compare listing volume and pricing across regions.

Verified hard limits

These limits were measured in the Phase 6 research and are not configurable away:

  • 24 listings per search page. count 24/50/100/250 all return 24; the cursor still advances.
  • City feed: 20 listings, no cursor. The actor keeps the mode for compatibility, warns in the status message, and returns at most 20 rows. Use a keyword or category URL for volume.
  • Delivery filter is client-side. Facebook's delivery server parameters are no-ops (shipping-only returned 0 rows, local-only did not filter). The actor filters on delivery_types after fetching.
  • Private-seller contact is not exposed. No phone, email, or messaging path appears logged out. The actor never fabricates contact data. Dealer rows with DIRECT_DEALERSHIP can expose dealership_name, listing_address, and seller_phone_number; those are emitted in seller.dealer only for dealer rows.
  • Vehicle features, Carfax, registration plate, and website link are null logged out. They are not emitted. VIN is different: structured VIN is always null, but a checksum-valid VIN pasted in the description is emitted with vehicleVinSource: "description".
  • Signed media URLs expire in roughly 4.3–4.5 days. Primary photos and avatars are rehosted when rehostImages is true; gallery photos are rehosted when includeAllPhotos is enabled. If a download fails (including CDN blocking one network path), the actor retries over an alternate proxy and then keeps the original signed URL with mediaUrlTemporary: true. Videos remain signed and temporary (mediaUrlTemporary: true); safe video rehosting is not implemented.
  • Property rentals category is unsupported. /marketplace/<city>/propertyrentals redirects without usable variables. Use a keyword search such as query=apartment as the workaround.
  • Cloud free proxy rungs are blocked. Direct, fresh-session, and Apify Proxy AUTO returned the login wall on the cloud; residential is the hardcoded last resort after those free rungs and is never a schema default.

FAQ

Why did I get fewer rows than maxItems? maxItems and maxItemsPerUrl are ceilings, not guarantees. The source may have fewer matches, Facebook may stop paginating, or client filters may remove rows that lack the evidence they check. If nothing can be returned and no source produced a valid empty result, the run fails with the access states in its status message.

What is the difference between fast and deep mode? fast reads only the search/category feed and streams rows. deep also fetches each listing page for description, condition, attributes, seller, coordinates, photos, and vehicle detail. Deep rows keep the fast row if a detail fetch fails, with detailFetchStatus set.

Why is the seller or currency missing on some rows? Facebook does not expose every field in every view. Feed rows usually omit currency, condition, and some seller details; deep mode fills them when available. price.currency is intentionally absent when it cannot be determined rather than guessed.

Does this need Facebook login or cookies? No. It reads publicly accessible Marketplace pages without signing in. Private-seller contact details and private profile scraping are not available logged out and are not collected. A seller.profileUrl is derived only from stable numeric seller IDs; session-scoped pfbid... tokens are not linked. Dealer name/address/phone are emitted only for dealer rows that expose them.

Do I need to configure a proxy? No. The actor starts with a direct TLS-impersonated request and escalates to a fresh session and then Apify Proxy AUTO only when a request is actually blocked. Cloud verification showed all free rungs still return Facebook's login wall, so residential is the hardcoded last resort after them; it is never a schema default. An explicit proxyConfiguration is honored as provided.

Why is the city feed capped at 20 listings? Facebook's city/location feed returns one page of about 20 listings with no cursor. The actor keeps the mode for compatibility and warns in the status message. Use a keyword or category URL for volume.

How many listings can a search return? Search and category feeds paginate with a 24-item page. There is no hardcoded 600-row stop. Phase 6 reached 71 pages / 1,694 unique rows, then page 72 returned an empty payload while still reporting has_next_page. The actor stops on source exhaustion, a repeated cursor, two consecutive empty pages, maxPagesPerUrl, or maxItems, so larger jobs need a higher maxPagesPerUrl and maxItems rather than price/category splitting.

Do photo URLs expire? Facebook CDN URLs are signed and expire in roughly 4.3–4.5 days. With rehostImages: true the primary photo and seller avatar are copied into the actor key-value store so primaryPhotoUrl and the avatar URL are stable; the signed primary URL remains in primaryPhotoUrlOriginal. With rehostImages: false, signed primary and avatar URLs are emitted as-is with mediaUrlTemporary: true. Gallery photos are also rehosted with includeAllPhotos; any photo whose download fails keeps its original signed URL and the row is marked mediaUrlTemporary: true, so the gallery is never silently dropped. Video URLs always remain temporary and are marked with mediaUrlTemporary.

Is this affiliated with Facebook or Meta? No. This is an independent third-party actor that reads publicly accessible Facebook Marketplace pages. It is not affiliated with or endorsed by Meta.
