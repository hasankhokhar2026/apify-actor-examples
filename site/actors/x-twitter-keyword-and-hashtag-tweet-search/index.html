    X/Twitter Keyword & Hashtag Tweet Search is an Apify Actor published by Nimbryxo Studio. It accepts 33 input fields, and keywords is required. Each result can carry up to 18 declared fields, including type, searchTerm, text, author.username, createdAt and language. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per post”, “Output per status row”, “Known hard limits”, “Input” and “Use cases”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (two unrelated topics in one run). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxTweets (default 20, maximum 1000), maxItems (maximum 1000), maxWindows (default 0, maximum 1000) and maxPasses (default 0, maximum 5000) cap how many results a run collects, and so what it costs.

    What it costs

    X/Twitter Keyword & Hashtag Tweet Search uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input fields in the published schema
    FieldTypeDescription
    keywordsSearch keywordsarray requiredWords, phrases, hashtags or full X search queries to monitor. Each keyword is searched separately, and every result row tells you which keyword found it (searchTerm).Default []; Example ["apify"]
    maxTweetsMaximum tweets per keywordintegerStop after this many tweets for each keyword. This is a target, not a guarantee: guest X search returns ~20 posts per answered page, the Phase 6 probes measured 300 unique rows for a 300-row target, and 500/1,000 are unverified.Default 20; Allowed 1 to 1000
    maxItemsMax tweets per keywordintegerAlias of Maximum tweets per keyword. The actor accepts either name.Allowed 1 to 1000
    searchTypeResult orderstringLatest returns the newest posts first. Top is engagement-ranked output: X's logged-out search never serves the real Top timeline, so the actor collects Latest pages and sorts them by like count client-side.Default "Top"; Example "Latest"; Allowed Top, Latest
    sortResult order (alias)stringAlias of Result order. The actor accepts either name.Allowed Top, Latest
    languageLanguagestringOnly return tweets written in this language. Leave the default to search all languages.Default "Any language"; Allowed Any language, en, es, zh, hi, ar, bn, pt and 33 more

    dateToEnd datestringOnly return tweets posted on or before this date (inclusive). Leave empty for no upper bound.
