    Open Food Facts UK Scraper is an Apify Actor published by Nimbryxo Studio. It accepts 7 input fields, and mode is required. Each result can carry up to 7 declared fields, including barcode, productName, brand, categories, nutritionGrade and calories. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per product”, “Input”, “Use cases” and “FAQ”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 7 fields in 1 dataset view, and the README documents 8 more. Fields without a value can be left out of a record.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (resolve a shopping list of barcodes). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 50, maximum 500) caps how many results a run collects, and so what it costs.

    What it costs

    Open Food Facts UK Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 7 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredWhat to scrape.Default "search"; Allowed search, byBarcode, byCategory, byBrand
    searchQuerySearch querystringFree-text search term (mode=search). Examples: 'cheddar', 'digestive biscuits', 'baked beans', 'tea'.Default "cheddar"
    barcodesBarcodes / EANs (mode=byBarcode)arrayList of EAN-13 or EAN-8 barcodes to look up.Default []
    categoryTagCategory tag (mode=byCategory)stringOpen Food Facts category tag. Examples: 'cheeses', 'biscuits', 'cereals', 'crisps', 'teas', 'chocolates'.
    brandNameBrand name (mode=byBrand)stringBrand to filter by, e.g. 'Walkers', 'Cadbury', 'Heinz', 'Tesco', 'Waitrose'.
    nutritionGradeFilterNutrition grade filterstringOnly return products with this Nutri-Score grade or better.Default ""; Allowed , a, b, c, d, e
    maxItemsMax itemsintegerMaximum number of products to return.Default 50; Allowed 1 to 500
