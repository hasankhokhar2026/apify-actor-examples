    Open Food Facts UK Scraper is an Apify Actor published by Nimbryxo Studio. It accepts 13 input fields, and mode is required. Each result can carry up to 12 declared fields, including barcode, productName, brand, categories, nutritionGrade and novaGroup. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (a healthier basket search). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 50, maximum 50000) caps how many results a run collects, and so what it costs.

    What it costs

    Open Food Facts UK Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 13 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredWhat to scrape: a keyword search, the whole UK catalogue, a category, a brand, a retailer, exact barcodes, or products with a recorded GBP price.Default "search"; Allowed search, browse, byBarcode, byCategory, byBrand, byStore, byOpenPrices
    searchQuerySearch querystringKeyword used in any discovery mode. UK examples: 'cheddar', 'digestive biscuits', 'baked beans', 'tea bags'. Leave empty in browse mode to list products without a keyword.Example "cheddar"
    barcodesBarcodes or product URLsarrayEAN-8, EAN-13, UPC or GTIN codes, or Open Food Facts product URLs (mode=byBarcode). One per item; duplicates are removed.Default []
    categoryTagCategory (mode=byCategory)stringCategory name, taxonomy tag, or Open Food Facts category URL. Examples: 'crisps', 'cheeses', 'breakfast cereals', 'en:teas'.
    brandNameBrand (mode=byBrand)stringBrand name, taxonomy tag, or Open Food Facts brand URL. Examples: 'Tesco', 'Walkers', 'Heinz', 'Cadbury', 'Marks & Spencer'.
    storeTagRetailer (mode=byStore)stringUK retailer name, tag, or Open Food Facts store URL. Examples: 'Tesco', 'Sainsbury's', 'Asda', 'Morrisons', 'Waitrose', 'Aldi', 'Lidl', 'Co-op', 'Iceland', 'Ocado'.
    labelFilterLabel filterstringKeep products carrying this label. Examples: 'organic', 'vegan', 'gluten-free', 'fair-trade'. Works in every discovery mode.
    nutritionGradeFilterNutri-Score filterstringKeep products with this Nutri-Score grade or better. Applies to discovery and barcode modes.Default ""; Allowed , a, b, c, d, e
    novaGroupFilterNOVA group filterstringKeep only products in this NOVA processing group: 1 = unprocessed, 2 = processed ingredients, 3 = processed, 4 = ultra-processed.Default ""; Allowed , 1, 2, 3, 4
    ecoscoreGradeFilterGreen-Score filterstringKeep products with this Green-Score (Eco-Score) grade or better. A+ is best; F is worst.Default ""; Allowed , a-plus, a, b, c, d, e, f
    sortBySort bystringResult order. 'Best match' uses keyword relevance; browse modes default to most scanned.Default "relevance"; Allowed relevance, popularity, lastModified, created, nutriscore, ecoscore
    maxItemsMax itemsintegerMaximum number of products to return. Values above 10,000 automatically use 92 created-time partitions because the search index caps a single query at 10,000 results.Default 50; Example 3; Allowed 1 to 50000
    includePricesInclude Open PricesbooleanAttach the latest Open Prices record (GBP price, date, retailer and location) to each product. Prices are sparse and add one request per 100 products. The byOpenPrices mode always attaches the price it used for discovery.Default false
