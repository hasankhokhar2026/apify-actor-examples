    LinkedIn Company Headcount & Team Directory Scraper is an Apify Actor published by Nimbryxo Studio. It accepts 15 input fields, none of them required at the top level. Each result can carry up to 9 declared fields, including recordType, companyName, linkedinEmployeeCount, companySizeRange, followerCount and industry. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (cookieless headcount for mixed inputs). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxEmployees (default 100, maximum 2500) and maxItemsTotal (default 500, maximum 10000) cap how many results a run collects, and so what it costs.

    What it costs

    LinkedIn Company Headcount & Team Directory Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    All 15 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    companyUrlsCompany LinkedIn URLsarrayLinkedIn company page URLs. Accepts https://www.linkedin.com/company/stripe/, linkedin.com/company/stripe, or company/stripe.Default []
    companyDomainsCompany domainsarrayCompany website domains, e.g. stripe.com or notion.so. The resolver follows LinkedIn's page website to pick the correct same-name company.Default []; Example ["stripe.com"]
    companyNamesCompany namesarrayCompany display names, e.g. Stripe or Microsoft. Name-only input is validated; ambiguous bare names (Notion, Linear, Cal) return an error row asking for a URL or domain.Default []
    includeEmployeesInclude employee rosterbooleanWhen true, also request the employee roster. Requires a valid LinkedIn session cookie and is capped by LinkedIn at 2,500 visible results per query.Default false
    maxEmployeesMax employees per companyintegerRoster cap per company (1-2500). Ignored when includeEmployees is false. Large companies are sampled.Default 100; Allowed 1 to 2500
    maxItemsTotalMax dataset itemsintegerHard cap across company summaries, employee rows, and error rows (1-10000).Default 500; Example 1; Allowed 1 to 10000
    startPageRoster start pageintegerResume the roster from this page (1-250, 10 employees per page). Use it to continue a capped run.Default 1; Allowed 1 to 250
    titleKeywordsTitle / headline keywordsstringRoster filter: free-text role or headline match, e.g. Software Engineer or VP Sales. Cookie roster only.Example ""
    locationLocationstringRoster filter: best-effort location match on the employee's LinkedIn location, e.g. London. Cookie roster only.Example ""
    seniorityLevelsSeniority levelsarrayRoster filter: one or more LinkedIn seniority levels. Empty means all levels. Cookie roster only. Allowed values: Entry, Associate, Mid-Senior, Director, Executive.Default []
    functionsJob functionsarrayRoster filter: one or more LinkedIn job functions. Empty means all functions. Cookie roster only. Allowed values: Engineering, Sales, Marketing, Operations, Finance, Human Resources, Design, Product, Customer Service, Information Technology, Legal, Other.Default []
    connectionDegreeConnection degreestringRoster filter: restrict to 1st, 2nd, or 3rd+ degree connections. Cookie roster only.Default ""; Allowed , F, S, O
    languageProfile languagestringRoster filter: primary profile language. Cookie roster only.Default ""; Allowed , en, es, fr, de, pt, it, nl and 2 more
    cookiesLinkedIn cookie (optional)stringOptional LinkedIn session cookie for the employee roster. Accepts the li_at value or a full cookies JSON array. Never required for headcount/firmographics.
    proxyConfigurationProxy configurationobjectOptional advanced override. The actor works without a proxy and chooses a working connection automatically.
