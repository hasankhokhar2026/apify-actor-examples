    Website Sitemap URL Inventory Extractor is an Apify Actor published by Nimbryxo Studio. It accepts 17 input fields, and startUrls is required. Each result can carry up to 15 declared fields, including url, lastmod, changefreq, priority, host and sourceType. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output”, “Input”, “Examples”, “Limits and honest notes” and “FAQ”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 15 fields in 2 dataset views, and the README documents 2 more. Fields without a value can be left out of a record.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (read a known sitemap index). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxSitemapDepth (default 5, maximum 10) caps how many results a run collects, and so what it costs.

    What it costs

    Website Sitemap URL Inventory Extractor uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 17 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    startUrlsSitemap, site or feed URLsarray requiredOne or more URLs. Accepts a sitemap, sitemap index, .xml.gz file, sitemap.txt, RSS/Atom feed, robots.txt URL, bare domain (example.com) or homepage. With discovery on, site URLs are resolved through robots.txt, the homepage's sitemap link and common sitemap paths.Example ["https://onescales.com/sitemap.xml"]
    discoverSitemapsFind sitemaps automaticallybooleanWhen the input is a domain or homepage, read robots.txt, the homepage <link rel="sitemap"> hint, common sitemap paths and—when no sitemap is advertised—the homepage's RSS/Atom autodiscovery links. Turn off to read only the exact URLs you supplied.Default true
    followSitemapIndexesFollow sitemap indexesbooleanWhen a sitemap index points to child sitemaps, fetch and merge them. Turn off to read only the sitemap files you supplied and stop at any index.Default true
    maxSitemapDepthMaximum sitemap-index depthintegerHow many levels of nested sitemap indexes to follow. 0 reads only the supplied sitemaps, 1 follows one index level, and so on.Default 5; Allowed 0 to 10
    maxSitemapsMaximum sitemap filesintegerStop after attempting this many sitemap files (indexes and child sitemaps both count). Protects very large sitemap trees such as newspaper archives.Default 1000; Allowed 1 to 10000
    maxUrlsMaximum URLsintegerTotal URL rows to emit across all inputs. Set to 0 for no limit. Filtered and duplicate URLs do not count toward this cap.Default 0; Example 500; Allowed 0 to 1000000
    lastmodAfterOnly URLs modified on or afterstringKeep URLs whose lastmod, feed date or news publication date is on or after this point. Use an ISO date (2026-01-01), a full timestamp, or a relative window such as "7 days", "24 hours" or "2 weeks". Leave blank to keep every URL.
    keepUrlsWithoutLastmodKeep URLs without a datebooleanWhen a date filter is set, also keep URLs and feed items that carry no usable date. Without this, undated entries are dropped by the date filter.Default false
    urlFilterIncludeURLs matching (include filter)stringKeep only URLs that match this pattern. Interpretation depends on URL match mode: a regular expression, a plain-text substring, or a wildcard pattern. Leave blank to keep every URL.
    urlFilterExcludeURLs matching (exclude filter)stringDrop URLs that match this pattern, applied after the include filter. Uses the same URL match mode.
    urlMatchModeURL filter modestringHow the include and exclude filters are interpreted. Regular expressions are case-insensitive. Plain text matches a literal substring. Wildcards use * for any characters except /, ** for any characters including /, and ? for one character.Default "regex"; Allowed regex, text, glob
    sameHostOnlyOnly URLs on the input hostbooleanDrop URLs whose hostname differs from the host of your input URLs. Useful when a sitemap includes CDN or alternate-domain pages you do not want.Default false
