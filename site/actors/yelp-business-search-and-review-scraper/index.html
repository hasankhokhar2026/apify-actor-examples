    Yelp Business Search & Review Scraper is an Apify Actor published by Nimbryxo Studio. It accepts 15 input fields, and mode is required. Each result can carry up to 32 declared fields, including name, rating, reviewCount, price, phone and city. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per business”, “Input”, “Use cases” and “FAQ”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 32 fields in 2 dataset views, and the README documents 17 more. Fields without a value can be left out of a record.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (keyword search). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 50, maximum 500) caps how many results a run collects, and so what it costs.

    What it costs

    Yelp Business Search & Review Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 15 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredSearch Yelp by keyword and location, or look up specific business URLs, aliases, or 22-character business IDs.Default "search"; Example "direct"; Allowed search, direct
    searchQuerySearch querystringKeyword to search for in mode=search, for example 'pizza', 'plumber', or 'coffee shop'.Default "pizza"; Example ""
    locationLocationstringCity, neighborhood, or ZIP code to search in mode=search, for example 'New York, NY' or '10012'.Default "New York, NY"; Example ""
    startUrlsStart URLsarrayIn mode=search, paste Yelp search URLs. In mode=direct, paste business URLs, aliases, or 22-character business IDs.Default []; Example ["https://www.yelp.com/biz/prince-street-pizza-new-york-2"]
    categoriesCategoriesarrayOptional Yelp category aliases or names used to narrow search results, for example 'pizza', 'coffee', or 'home_services'. They are combined with the search query.Default []
    sortBySearch result orderstringOrdering for mode=search result pages.Default "recommended"; Allowed recommended, rating, reviewCount
    pricePrice levelsarrayOptional price levels for mode=search. Leave empty for every price level.Default []; Allowed $, $$, $$$, $$$$
    minRatingMinimum ratingnumberDrop businesses rated below this value. Set to 0 to keep every rating.Default 0; Allowed 0 to 5
    maxItemsMaximum businessesintegerHard cap on business records in the dataset. Search is limited to Yelp's 240-result ceiling per query.Default 50; Example 1; Allowed 1 to 500
    maxReviewsPerBusinessReviews per businessintegerMaximum reviews collected for each business. Reviews are paged 49 at a time from Yelp's public review feed.Default 20; Example 5; Allowed 1 to 1000
    includeReviewsInclude reviewsbooleanTurn off to collect only business profiles and skip the review feed.Default true
    reviewSortReview orderstringOrdering applied to each business's review feed.Default "DATE_DESC"; Allowed DATE_DESC, DATE_ASC, RATING_DESC, RATING_ASC, RELEVANCE_DESC, ELITES_DESC
    reviewRatingsReview star ratingsarrayOnly collect reviews with these star ratings. Choose one or more values.Default ["5", "4", "3", "2", "1"]; Allowed 1, 2, 3, 4, 5
    reviewLanguageReview languagestringLanguage for the review feed. Choose 'all' to page through every language Yelp reports for the business.Default "en"; Allowed all, en, es, fr, de, it, pt, nl and 23 more
    proxyConfigurationProxy configurationobjectOptional. The actor automatically uses Apify Proxy when Yelp blocks a request; add a country or custom proxy here only when you need a specific route.
