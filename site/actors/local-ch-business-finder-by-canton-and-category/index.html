    local.ch Business Finder by Canton & Category is an Apify Actor published by Nimbryxo Studio. It accepts 12 input fields, and mode is required. Each result can carry up to 9 declared fields, including name, category, city, street, phone and rating. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it costs

    local.ch Business Finder by Canton & Category uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 12 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredWhat to fetch: search a category + city/canton, or fetch full business profiles from direct local.ch URLs.Default "search"; Allowed search, detail
    categoryCategorystringBusiness category to search for. Pick a common category, or choose 'Custom category' and type your own below (mode=search).Default "restaurant"; Allowed custom, restaurant, bar, internet-cafe, bakery-pastry-shop, butcher, hotel, bed-and-breakfast and 68 more
    customCategoryCustom category (overrides selection above)stringFree-text category not in the curated list above, e.g. 'Locksmith' or 'IT services' (mode=search). Takes priority over 'Category' when set. local.ch matches this like a keyword search, so most English/German/French/Italian business terms work.
    locationCity or townstringSwiss city or town to search in, e.g. Zurich, Geneva, Lugano, Basel. Use the Canton field for a whole-canton search (mode=search).Default "Zurich"
    cantonCanton (overrides city/canton above)stringSearch an entire Swiss canton instead of a single city. Takes priority over 'City or canton' when set (mode=search).Default ""; Allowed , zurich, bern, lucerne, uri, schwyz, obwalden, nidwalden and 19 more
    languageSite languagestringLanguage edition of local.ch to scrape from. Same underlying business data; affects category/label translations in the raw page (does not change output field names).Default "en"; Allowed en, de, fr, it
    sortBySort orderstringHow to order search results after fetching (mode=search). local.ch itself only returns relevance order, so 'rating' and 'name' are applied client-side across the fetched batch.Default "relevance"; Allowed relevance, rating, name
    openNowOnlyOpen now onlybooleanOnly return businesses that are currently open, based on local.ch's own open/closed badge (mode=search).Default false
    minRatingMinimum ratingintegerOnly return businesses rated at least this many stars, e.g. 4 for 4.0+ (mode=search). 0 means no minimum. Applied client-side; businesses with no rating are excluded once this is set above 0.Default 0; Allowed 0 to 5
    fetchDetailsFetch full business profilesbooleanFor each search result, also visit its business profile page to collect email, website, social links, precise coordinates, full opening hours, and photos. Slower -- one extra request per result (mode=search).Default false
    businessUrlsBusiness profile URLs (mode=detail)arrayDirect local.ch business profile URLs to fetch, e.g. https://www.local.ch/en/d/zurich/8001/restaurant/some-business-abc123. Use the 'sourceUrl' field from search results.Default []
    maxItemsMax itemsintegerHard cap on the number of business records to return.Default 20; Example 3; Allowed 1 to 1000
