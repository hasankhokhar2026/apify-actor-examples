    Amazon Best Sellers & Rankings Scraper is an Apify Actor published by Nimbryxo Studio. It accepts 13 input fields, and chartType is required. Each result can carry up to 28 declared fields, including rank, asin, title, brand, byline and format. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (best sellers in electronics). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItemsPerCategory (default 100, maximum 100), maxItems (default 200, maximum 2000) and maxProductDetails (default 10, maximum 100) cap how many results a run collects, and so what it costs.

    What it costs

    Amazon Best Sellers & Rankings Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 1 GB, so a run starts with 1 start event, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 13 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    chartTypeChart typestring requiredWhich Amazon chart to scrape. A full chart URL pasted into categoryUrls overrides this with the URL's own chart type.Default "bestSellers"; Allowed bestSellers, newReleases, mostWishedFor, mostGifted, moversAndShakers
    domainAmazon domainstringWhich Amazon marketplace to scrape the chart from. A full chart URL pasted into categoryUrls overrides this with the URL's own marketplace.Default "amazon.com"; Allowed amazon.com, amazon.co.uk, amazon.de, amazon.fr, amazon.it, amazon.es, amazon.ca, amazon.com.au and 12 more
    categoryUrlsCategory URLs or slugsarrayAmazon category slugs (e.g. electronics, electronics/172541) or full chart URLs to scrape. A full chart URL supplies its own chart type and marketplace, e.g. https://www.amazon.co.uk/gp/new-releases/electronics.Default ["electronics"]
    categoryNodeIdsCategory node IDsarrayAmazon browse-node IDs in rootSlug/nodeId form (e.g. electronics/172541 for Headphones). Combined with categoryUrls if both are provided.Default []
    maxDepthSubcategory recursion depthintegerWhen > 0, also walk each category's left-nav subcategory links this many levels deep, scraping each subcategory's own chart too. 0 = only the given categories.Default 0; Allowed 0 to 3
    startPageStart pageintegerFirst chart page to fetch (1 or 2). Pages are capped at 2 so a chart never exceeds the real top-100 boundary.Default 1; Allowed 1 to 2
    maxPagesMax pages per categoryintegerMaximum number of chart pages to fetch per category, starting at startPage. Capped at 2 (top 100).Default 2; Allowed 1 to 2
    maxItemsPerCategoryMax items per categoryintegerHard cap on chart items emitted per category (across all its pages). Maximum 100; coverage fields still report the full listed-rank range.Default 100; Example 20; Allowed 1 to 100
    maxItemsMax total itemsintegerHard cap on total chart items emitted across all categories in this run.Default 200; Example 20; Allowed 1 to 2000
    includeProductDetailsEnrich with product detail pagebooleanFor each chart item, also fetch its product detail page for list-price and in-stock data. Slower and bounded by maxProductDetails.Default false
    maxProductDetailsMax product detail fetchesintegerHard cap on how many chart items get product-detail enrichment when includeProductDetails is on.Default 10; Example 5; Allowed 1 to 100
    maxMissingDetailFetchesMax missing-detail product fetchesintegerPer-category cap on best-effort product-page fetches used to fill ranks the nextPage response did not cover. Set 0 to disable product-page fill.Default 50; Example 0; Allowed 0 to 100
    proxyConfigurationProxy configurationobjectApify proxy used to fetch chart pages. Datacenter (AUTO) is used by default and works for most requests; the actor escalates to residential only after repeated blocks on a session.Default {"useApifyProxy": true}
