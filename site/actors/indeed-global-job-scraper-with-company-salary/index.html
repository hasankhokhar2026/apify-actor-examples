    Indeed Global Job Scraper with Company Salary Reports is an Apify Actor published by Nimbryxo Studio. It accepts 23 input fields, none of them required at the top level. Each result can carry up to 42 declared fields, including positionName, displayTitle, company, rating, location and salary. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per job”, “Input”, “Use cases” and “FAQ”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (remote full-time data analyst jobs from the last week). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItemsPerSearch (default 100, maximum 10000) and maxItems (maximum 10000) cap how many results a run collects, and so what it costs.

    What it costs

    Indeed Global Job Scraper with Company Salary Reports uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 23 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    positionPosition or keywordsstringJob title, skill or keywords, e.g. web developer, nurse. Search one company's jobs with company:Amazon, titles only with title:(data analyst); quotes, OR and -exclusions work too.Example "web developer"
    locationLocationstringCity, region or postal code, e.g. San Francisco, Austin, TX, 10001, London. Leave empty to search the whole country.Example "San Francisco"
    companyCompanystringOnly jobs from one employer, e.g. Amazon, Visa, DocuSign. The name is resolved to Indeed's employer key so the company filter is applied by Indeed itself, then verified per job.
    locationShardsCity or region shardsarrayOptional list of extra locations to search separately with the same keywords and filters, e.g. New York, NY, Chicago, IL, Remote. Deduplication removes jobs found by more than one shard. This is the reliable way past the roughly 1,000-row cursor ceiling.
    countryCountrystringIndeed country site to search. Results come in the site's language and salaries in its currency.Default "US"; Allowed US, AR, AU, AT, BH, BE, BR, CA and 54 more
    maxItemsPerSearchMax jobs per searchintegerMaximum number of jobs to save for each search (the keyword search and each search URL). Indeed's cursor stops at roughly 1,000 fetched rows, including duplicates; use locationShards or more search URLs to collect more.Default 100; Example 3; Allowed 1 to 10000
    maxItemsMax jobs for the whole runintegerOptional hard cap across every search and pasted job URL. The run stops as soon as this many jobs are saved. Leave empty for no global cap.Example 3; Allowed 1 to 10000
    shardByDateSplit by date windowbooleanRun each keyword search five times, for the last 1, 3, 7, 14 and 30 days, and remove duplicates. Useful for freshness coverage when you need more than one cursor walk per search.Default false
    jobTypeJob typestringEmployment type.Default ""; Allowed , fulltime, parttime, contract, temporary, internship, permanent, seasonal and 4 more
    workplaceTypeRemote / hybrid / in-personstringWhere the work happens.Default ""; Allowed , remote, hybrid, inPerson
    datePostedDate postedstringOnly jobs added to Indeed within this period.Default ""; Allowed , 1, 3, 7, 14, 30
    experienceLevelExperience levelstringRequired experience level.Default ""; Allowed , noExperience, entry, mid, senior
