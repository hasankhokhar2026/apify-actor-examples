    Zomato City Restaurant & Cuisine Filter Scraper is an Apify Actor published by Nimbryxo Studio. It accepts 15 input fields, none of them required at the top level. Each result can carry up to 8 declared fields, including name, cuisines, ratings.aggregate, price.for_two, location.locality and location.city. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per restaurant”, “Input”, “Use cases” and “FAQ”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (dining listings by url). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: max_items_per_url (default 9, maximum 9) caps how many results a run collects, and so what it costs.

    What it costs

    Zomato City Restaurant & Cuisine Filter Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 15 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    start_urlsZomato URLsarrayZomato restaurant/search/locality URLs. Examples: - https://www.zomato.com/mumbai/restaurants - https://www.zomato.com/ncr/restaurants/biryani - https://www.zomato.com/mumbai/bandra-west-restaurants - https://www.zomato.com/dubai/delivery Each URL returns up to 9 restaurants (Zomato server-side cap).Default ["https://www.zomato.com/mumbai/restaurants"]
    cityCitystringPick a supported city to build a search URL from filters below. Supported: major Indian cities + UAE.Example "mumbai"; Allowed mumbai, ncr, bangalore, pune, hyderabad, chennai, kolkata, ahmedabad and 5 more
    search_modeSearch ModestringWhich Zomato surface to scrape.Default "dining"; Allowed dining, delivery, cafes, nightlife
    cuisineCuisinestringCuisine ID filter (e.g. 55=Italian, 25=Chinese, 50=North Indian). See README for full list.
    categoryCategorystringCategory ID filter (e.g. 2=Fine Dining, 6=Cafes, 11=Pubs and Bars).
    min_ratingMinimum RatingstringFilter to restaurants at or above this rating.Default ""; Allowed , 3.5, 4, 4.5, 5
    sortSort BystringResult ordering.Default ""; Allowed , popularity, rating, cost
    min_costMin Cost (for two)integerLower bound of cost-for-two.Allowed at least 0
    max_costMax Cost (for two)integerUpper bound of cost-for-two.Allowed at least 0
    expand_cuisinesExpand CuisinesbooleanWhen set, fan out across 15 top cuisines for the chosen city — 9 × 15 ≈ 135 restaurants per city.Default false
    expand_localitiesExpand LocalitiesbooleanWhen set, also scrape each locality page Zomato exposes for the chosen city.Default false
    max_items_per_urlMax Items Per URLintegerUp to 9 (Zomato server-side cap). Pagination beyond 9 is not available.Default 9; Allowed 1 to 9
    enrich_detailsFetch Full DetailsbooleanFetch the detail page for each restaurant (menu highlights, hours, contact, features). Disable for speed.Default true
    max_retries_per_urlMax Retries Per URLintegerRetries on 5xx / 429 / connection errors.Default 2; Allowed at least 0
    ignore_url_failuresIgnore URL FailuresbooleanContinue the run if some URLs fail after retries.Default true
