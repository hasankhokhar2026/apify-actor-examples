    ESPN Live Scores, Schedules & Game Odds Scraper is an Apify Actor published by Nimbryxo Studio. It accepts 15 input fields, and mode is required. Each result can carry up to 20 declared fields, including recordType, gameId, league, sport, status and statusDetail. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per game (mode = scoreboard or schedule)”, “Output per team (mode = teams)”, “Output per odds line (mode = odds)”, “Output per game detail (mode = gameDetail)” and “Input”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (today's nba and nhl scoreboard). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 100, maximum 10000) caps how many results a run collects, and so what it costs.

    What it costs

    ESPN Live Scores, Schedules & Game Odds Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 15 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredWhat to return: games for a scoreboard, a schedule, the league team directory, one record per sportsbook odds line, or a full game detail record.Default "scoreboard"; Allowed scoreboard, schedule, teams, odds, gameDetail
    sportSportstringOptional sport filter. Use it with League = All supported leagues to cover every supported competition in one sport.Default "any"; Allowed any, basketball, football, baseball, hockey, soccer
    leagueLeaguestringCompetition to read. Choose All supported leagues only with a specific sport when you need broad coverage. Defaults to NBA when omitted.Example "nba"; Allowed all, nba, wnba, ncaam, ncaaw, nfl, ncaaf, mlb and 55 more
    dateDatestringA day (YYYY-MM-DD or YYYYMMDD), a month (YYYY-MM), or a year (YYYY). Leave empty to use today, or use Season / Week instead. (mode=scoreboard, schedule, odds, gameDetail)Example "20240115"
    startDateStart datestringFirst day of a custom window (YYYY-MM-DD or YYYYMMDD). Requires End date. (mode=scoreboard, schedule, odds, gameDetail)
    endDateEnd datestringLast day of a custom window (YYYY-MM-DD or YYYYMMDD). Maximum 366 days. (mode=scoreboard, schedule, odds, gameDetail)
    seasonSeasonintegerESPN season year, for example 2024. Use it with Week for a single football week, or alone for the whole season. (mode=scoreboard, schedule, odds, gameDetail)Allowed 2000 to 2100
    seasonTypeSeason typestringWhich part of the season to read when Season is set. (mode=scoreboard, schedule, odds, gameDetail)Default "2"; Allowed 1, 2, 3, 4, 5
    weekWeekintegerWeek number for football and other week-based competitions. Requires Season. (mode=scoreboard, schedule, odds, gameDetail)Allowed 1 to 30
    teamTeamstringKeep only games or teams matching this ESPN team ID, abbreviation, or name, for example 13, LAL, or Lakers. Prefix with a league code to disambiguate: nba:LAL. (mode=scoreboard, schedule, teams, odds, gameDetail)
    eventIdsEvent IDsarrayESPN event IDs for game detail or odds, for example 401585183. Leave empty to discover games from the date or season. (mode=odds, gameDetail)Default []
    statusGame statusstringKeep only games in this state. Postponed and cancelled games are reported as their own values.Default "any"; Allowed any, scheduled, in_progress, final, postponed, cancelled
    includeDetailsInclude game detailsbooleanAdd leaders, odds, attendance, officials, article text, team stats, player stats and injuries to each game. (mode=scoreboard, schedule)Default false
    maxItemsMaximum recordsintegerHard cap on records returned across all selected leagues.Default 100; Example 3; Allowed 1 to 10000
    timezoneTimezonestringIANA timezone used for today/yesterday/tomorrow and for dateLocal, for example America/New_York.Default "UTC"
