    Ashby Job Board Compensation & Openings Scraper is an Apify Actor published by Nimbryxo Studio. It accepts 25 input fields, and mode is required. Each result can carry up to 7 declared fields, including title, organizationName, department, location, workplaceType and compensationSummary. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Modes”, “Output per job”, “Output per company summary”, “Input” and “Use cases”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (every open role at one company). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItemsPerOrg (default 0, maximum 5000) and maxItems (default 100, maximum 5000) cap how many results a run collects, and so what it costs.

    What it costs

    Ashby Job Board Compensation & Openings Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 25 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredWhat to collect. byOrg lists jobs from one or more companies; jobDetail fetches specific postings by URL or ID; boardSummary returns one departments/locations/compensation summary per company. The legacy values are kept so saved tasks continue to run.Default "byOrg"; Allowed byOrg, jobDetail, boardSummary, companies, job, detail, summary
    orgSlugsCompanies (mode=byOrg, boardSummary)arrayAshby board slugs, company names, or board URLs. Examples: Ramp, Neko Health, https://jobs.ashbyhq.com/Ramp. Names are matched to the closest live board automatically.Default ["Ramp"]
    jobUrlsJob URLs (mode=jobDetail)arrayPublic Ashby job posting URLs, e.g. https://jobs.ashbyhq.com/Ramp/<job-id>. The /application suffix and query strings are accepted.Default []
    orgSlugCompany slug (mode=jobDetail)stringUsed with jobId when you do not have a full job URL. Example: Ramp.
    jobIdJob ID (mode=jobDetail)stringThe Ashby posting UUID or a full job URL. Used alone or with orgSlug.
    searchQuerySearch text (mode=byOrg, boardSummary)stringCase-insensitive text match over title, department, team, location, and description. Descriptions are searched even when includeDescriptionPlain is off and in boardSummary mode. Examples: engineer, payments, München.
    departmentDepartment or team (mode=byOrg, boardSummary)stringCase-insensitive text match over department and team. Examples: Engineering, Sales, Design.
    locationLocation (mode=byOrg, boardSummary)stringCase-insensitive text match over the primary location, secondary locations, city, region, and country. Examples: New York, Remote, London.
    workplaceTypeWorkplace type (mode=byOrg, boardSummary)stringKeep only fully remote, hybrid, or on-site jobs. Unlike isRemoteOnly, this separates Remote from Hybrid. Jobs with no workplace type are excluded when a specific value is chosen.Default "any"; Allowed any, Remote, Hybrid, OnSite
    employmentTypeEmployment type (mode=byOrg, boardSummary)stringKeep only one employment type.Default "any"; Allowed any, FullTime, PartTime, Contract, Intern, Temporary
    isRemoteOnlyRemote-friendly only (mode=byOrg, boardSummary)booleanKeep jobs the board marks as remote. Ashby sets this for both Remote and Hybrid roles; use workplaceType=Remote for fully remote jobs.Default false
    publishedAfterPublished after (mode=byOrg, boardSummary)stringOnly jobs published on or after this date. Accepts YYYY-MM-DD, an ISO datetime, or a relative window such as 24h, 7d, or 2w.
