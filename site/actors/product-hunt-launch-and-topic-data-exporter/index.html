    Product Hunt Launch & Topic Data Exporter is an Apify Actor published by Nimbryxo Studio. It accepts 20 input fields, and mode is required. Each result can carry up to 11 declared fields, including name, tagline, votesCount, commentsCount, reviewsCount and reviewsRating. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “Modes”, “Input”, “Output”, “Examples”, “How it works” and “Reliability and limits”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 11 fields in 1 dataset view. Fields without a value can be left out of a record.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (full feed for one busy day). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 50, maximum 1000) and maxComments (default 50, maximum 500) cap how many results a run collects, and so what it costs.

    What it costs

    Product Hunt Launch & Topic Data Exporter uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 20 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeWhat to scrapestring requiredPick the launch feed, a leaderboard period, a date range, a topic, a category, a keyword search, specific products, or specific launches.Default "latest"; Allowed latest, leaderboard, dailyRange, topic, category, search, product, launch
    periodLeaderboard periodstringUsed when mode is leaderboard. Daily = one day, weekly = ISO week, monthly = calendar month, yearly = calendar year.Default "daily"; Allowed daily, weekly, monthly, yearly
    dateLeaderboard datestringOptional date for mode=leaderboard, in YYYY-MM-DD form. The daily period uses the exact day; weekly, monthly and yearly use that day's ISO week, month or year. Defaults to today.
    fromFrom datestringOptional first day for mode=dailyRange, in YYYY-MM-DD form. Defaults to the to date, or yesterday.
    toTo datestringOptional last day for mode=dailyRange, in YYYY-MM-DD form. Defaults to the from date, or yesterday.
    topicSlugsTopic slugs or URLsarrayTopics for mode=topic, e.g. artificial-intelligence, developer-tools, or a full /topics/... URL.Default []
    categorySlugsCategory slugs or URLsarrayCategories for mode=category, e.g. ai-code-editors, productivity, or a full /categories/... URL.Default []
    searchQuerySearch querystringKeyword for mode=search, e.g. notion, ai browser, invoice. Product Hunt searches products, then the actor resolves each product's latest launch.
    productSlugsProduct slugs or URLsarrayProducts for mode=product, e.g. notion, figma, or full https://www.producthunt.com/products/... URLs. Each product's latest launch is returned.Default []
    postIdsLaunch slugs or URLsarrayLaunches for mode=launch, e.g. strawberry-1-0, or full https://www.producthunt.com/products/...?launch=... URLs.Default []
    maxItemsMaximum recordsintegerStop after this many launch records. One record is one launch (comments and reviews stay attached to it).Default 50; Example 3; Allowed 1 to 1000
    maxPagesMaximum pages per sourceintegerPage cap per feed, topic, category, search query, product history, comment thread or review feed. A full Product Hunt day is about 40-60 pages of 20 launches.Default 10; Example 1; Allowed 1 to 60
