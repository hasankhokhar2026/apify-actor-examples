    TikTok Follow Graph & Audience Export Scraper is an Apify Actor published by Nimbryxo Studio. It accepts 13 input fields, none of them required at the top level. Each result can carry up to 17 declared fields, including sourceUsername, listType, position, userId, username and displayName. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (followers). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxUsersPerProfile (default 100, maximum 5000) caps how many results a run collects, and so what it costs.

    What it costs

    TikTok Follow Graph & Audience Export Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 2 GB, so a run starts with 2 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.
