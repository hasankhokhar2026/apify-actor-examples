    NCAA Stats & Scores: Leaderboards, Polls & Standings is an Apify Actor published by Nimbryxo Studio. It accepts 21 input fields, and mode is required. Each result can carry up to 38 declared fields, including recordType, optionType, value, title, rank and team. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    Scrape official NCAA.com stats and scores for 14 college sports: team and individual statistical leaderboards, national ranking polls, conference standings, the NCAA school directory, schedules and scores, full team season schedules, championship / March Madness brackets, game details (venue, linescores, box score, play-by-play), and championship history. Every record comes from public NCAA.com pages and the official NCAA scoreboard/championship feeds — no account, cookies, or API key required.

    What this actor does

    • Eleven modes: teamStats, individualStats, rankings, standings, teams, schedules, teamSchedule, brackets, gameDetail, history, listOptions
    • listOptions returns the valid modes, sports, divisions, categories, polls, and conferences from the built-in catalog for a given sport/division; it makes no NCAA.com requests and uses no paid API
    • Fourteen sports across Division I, II, and III, plus FBS/FCS football and National Collegiate men's volleyball and women's ice hockey
    • Every leaderboard column NCAA.com publishes for the selected category, including games played, class year, height, and position where available
    • Every NCAA-hosted poll, including AP, NET, RPI, committee rankings, NPI, WAB, and regional rankings
    • Conference standings with conference and overall records, win percentage, streak, and sport-specific extra columns
    • School directory with school name, short name, logo, and NCAA.com school URL
    • Schedules and scores with home/away teams, scores, status, conferences, ranks, seeds, and championship context
    • Full team season schedules (teamSchedule) from NCAA.com's season-wide schedule dates or football week calendar — not limited to the 31-day schedules window
    • Championship / March Madness brackets (brackets) with rounds, regions, seeds, scores, and bracket position, from NCAA.com's official championship GraphQL route
    • Game detail with venue, city/state, linescores, team records, box-score blocks, and play-by-play when NCAA.com publishes them
    • Optional schedule enrichment adds venue, linescores, records, and box-score/play-by-play availability flags to schedule and team-schedule rows
    • Championship history with year, champion, record, coach, score, runner-up, and site
    • Filters for team, player, rank range, minimum games, conference, and final games only
    • Empty fields are omitted — no null, no placeholders, no fabricated values

    Use cases

    • Sports media and content sites — auto-publish weekly leaderboard, poll, and standings roundups
    • Fantasy sports and betting research — track team and player statistical trends over time
    • Recruiting and scouting — search player leaderboards by name, team, class year, or position
    • Sports analytics — build historical datasets from leaderboards, polls, and championship results
    • Fan dashboards — power live score, schedule, and conference-standings widgets
    • Academic research — compare competitive trends across NCAA divisions and sports

    Output per team-schedule game (mode: teamSchedule)

    Same fields as a schedules row, returned for one team across the whole NCAA.com season. team is required (a school name or NCAA.com slug such as duke). The mode reads NCAA.com's season-wide game-date list (or football's week calendar) and does not apply the 31-day window; scheduleDateFrom, scheduleDateTo, and week are ignored. includeGameDetails works the same as in schedules.

    Questions

    Do I need an NCAA.com account, cookies, or an API key?

    No. The actor reads public NCAA.com pages and the public NCAA scoreboard feed.

    Why does stats or pollStats vary between records?

    NCAA.com publishes a different set of columns for every statistical category and every poll. The actor captures every column the source page shows for the requested category or poll, with numeric values parsed as numbers.

    What do statValue and statLabel mean?

    NCAA.com's rightmost column is the category's headline number. statLabel is that column's label (for example PPG) and statValue is the number.

    How far back does season go?

    Archive depth is set by NCAA.com and varies by sport. Men's basketball has the deepest archive; several other sports have only recent seasons. When a season is not published, the run finishes with a clear status message.

    Why do two rows share the same rank?

    NCAA.com renders a tied row's rank as - instead of repeating the number. The actor carries the previous rank forward and adds tiedRank: true rather than dropping the row.

    Why are some polls missing for my sport?

    The actor exposes only polls hosted on NCAA.com. Some polls (for example USA Today coaches polls) live on third-party sites and are not scraped.

    Can I scrape multiple categories or polls in one run?

    Run the actor once per category or poll. Each run is focused on one leaderboard or poll, matching how NCAA.com organizes the data.

    Why is standings only available for a few sports?

    NCAA.com publishes its conference-standings widget only for Division I men's and women's basketball and FBS/FCS football. Other sport/division combinations return a status message.

    Why did my schedule run return no games?

    Check the date window and finalOnly. Football schedules runs are week-based: set week instead of a date range. Dates outside the current or archived season may have no games. For a whole team season, use mode=teamSchedule with team; it is not limited to the 31-day window.

    How do I get one team's full season schedule?

    Use mode=teamSchedule with team (a school name or NCAA.com slug such as duke). The actor reads NCAA.com's season-wide game-date feed (or football's week calendar), then queries each date and keeps only that team's games. It is not limited to 31 days and ignores scheduleDateFrom/scheduleDateTo. Set includeGameDetails for venue, linescores, records, and availability flags.

    Are March Madness and other championship brackets included?

    Yes, with mode=brackets. The actor calls NCAA.com's official get_championship_ncaa GraphQL route, which returns the same bracket data as the public bracket pages, including round, region, seeds, scores, and bracket position. Set season to the tournament year (for example 2026); YYYY-YY labels try the ending year first and then the starting year. Brackets appear after the field is announced, and some sports/divisions publish only recent years. Unplayed TBA slots are returned without invented teams or scores. If NCAA.com rotates its persisted query, the run finishes with a clear status message instead of returning a partial or fabricated bracket.

    Do you include rosters, injuries, or betting odds?

    No. These are out-of-scope external-source limitations, not hidden data limits. The public NCAA.com pages and GraphQL feeds this actor uses do not publish rosters, injury reports, or odds: rosters live on school athletics sites (and stats.ncaa.org is Akamai/robots-blocked), injuries are team/third-party announcements, and odds come from licensed sportsbooks or ESPN. Adding them would require a different non-NCAA source, so the actor does not fabricate or guess them.

    Are schedules and scores live?

    They reflect the public NCAA scoreboard at the time of the run. Scheduled games show their start time; completed games show final scores and a winner.

    How do I get venue, box score, or play-by-play?

    Use mode: gameDetail with one or more gameIds. Set includeBoxscore and/or includePlayByPlay to add those blocks. You can also set includeGameDetails: true on schedules to add venue, linescores, records, and availability flags to each schedule row without fetching full box scores or play-by-play.

    Why is a venue or box score missing for some games?

    NCAA.com publishes those fields only for games it has complete data for. The actor adds hasBoxscore, hasPbp, hasTeamStats, and hasScoringSummary flags so you can tell what is available; it never fabricates a missing venue or stat.

    What happens if I leave the default category or poll selected for another sport?

    The schema default is treated as "no explicit choice". If it is not valid for the selected sport/mode, the actor uses a curated default — for example AP for D1 basketball and FBS football, AFCA Coaches for FCS, and the primary coaches/RPI/AVCA poll elsewhere; Points Per Game for basketball players, Passing Yards Per Game for FBS players, and Batting Average for baseball/softball — and reports the substitution in the run status. It never picks the alphabetically first option.

    How do I find the valid categories, polls, or conferences?

    Run mode: listOptions with the sport/division you care about. It returns the exact value strings to use in statCategory, pollSlug, conference, and the other select fields. You can also run it without a sport to list every mode, sport, division, and conference.

    What time zone is used for the default schedule date?

    When both schedule dates are empty, the actor uses today's date in America/New_York (the zone NCAA.com's scoreboard uses) and keeps startTimeEpoch in UTC. Set scheduleDateFrom/scheduleDateTo explicitly for archival dates.

    Why does a category or poll return a "no data" message instead of an empty dataset?

    NCAA.com sometimes publishes a category page that has no rows for a sport/division/season, or a poll that is not yet live. The actor detects that page state and returns the valid alternatives in the run status instead of reporting a generic "no rows" result. The catalog was also scrubbed of category IDs that NCAA.com returns 404.

    What do the filters do when a field is missing?

    team, playerName, rank, conference, and finalOnly are strict when set: a record without the filtered field is excluded. minGames is the exception — rows without a games-played column pass through, as documented in the input description.

    Why is nc accepted for women's ice hockey schedules if NCAA.com's nc page is 404?

    The actor maps that combination to NCAA.com's d1 scoreboard page, which is where NCAA.com serves the National Collegiate schedule. The output keeps the division you requested.

    Why did a large run stop before reaching maxItems?

    Leaderboard modes are capped at 2,000 source rows (40 pages of 50). If the page cap is reached first, the run sets a status message; split by category or season to collect more. The same applies when maxItems truncates standings, teams, rankings, schedules, or history — the status message says which cap stopped the run and how many source rows were available.

    Why is maxItems optional now?

    The old fixed default of 50 silently truncated large exports. maxItems now has a mode-aware default (for example 5,000 for the school directory, 2,000 for leaderboards, 100 for game detail) while the daily-test prefill stays at 3. The schema maximum is 5,000.

    Is this affiliated with the NCAA?

    No. This is a third-party actor using publicly available NCAA.com statistics, rankings, standings, school, schedule, game-detail, and history pages.
