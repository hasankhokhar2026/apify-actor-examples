    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredWhat to scrape from NCAA.com. listOptions returns the valid modes, sports, divisions, categories, polls, and conferences from the built-in catalog (optionally scoped with sport/division) without making any NCAA.com requests. teamSchedule returns one team's full season (no 31-day limit); brackets returns championship / March Madness bracket games from NCAA.com's official championship route.Default "teamStats"; Allowed teamStats, individualStats, rankings, standings, teams, schedules, teamSchedule, brackets and 3 more
    sportSportstringNCAA sport to scrape. Required for the sport-specific modes; ignored by mode=teams and mode=gameDetail; optional scope for mode=listOptions.Default "basketball-men"; Allowed baseball, basketball-men, basketball-women, fieldhockey, football, icehockey-men, icehockey-women, lacrosse-men and 6 more
    divisionDivisionstringNCAA competition division. Football uses FBS/FCS; men's volleyball and women's ice hockey use nc (National Collegiate) for polls and history. The actor maps women's ice hockey nc schedules to NCAA.com's d1 scoreboard page. Not every division is offered for every sport; an unsupported combination returns a clear status message instead of data. Optional scope for mode=listOptions.Default "d1"; Allowed d1, d2, d3, fbs, fcs, nc
    statCategoryStatistical categorystring(mode=teamStats or individualStats) The statistic to rank by. Every NCAA.com category is listed; the valid set depends on the chosen sport and mode. If the default Scoring Offense is not valid for the chosen sport/mode, the actor uses a curated per-sport default (for example Points Per Game for men's/women's basketball players, Passing Yards Per Game for FBS players, Batting Average for baseball/softball) and reports the substitution in the run status. An explicitly unavailable category returns a clear status message.Default "Scoring Offense"; Allowed 3rd Down Conversion Pct, 3rd Down Conversion Pct Defense, 4th Down Conversion Pct, 4th Down Conversion Pct Defense, Aces Per Set, All Purpose, Assist/Turnover Ratio, Assists and 278 more
    seasonSeasonstring(mode=teamStats, individualStats, teamSchedule, or brackets) Season/year. Current season follows whichever season NCAA.com is actively showing. YYYY-YY labels such as 2025-26 are accepted and mapped to their starting year for leaderboards and team schedules. For mode=brackets, enter the tournament year shown in NCAA.com's bracket URL (for example 2026); a YYYY-YY label tries the ending year first and then the starting year, and current tries the current calendar year then the previous year. Historical depth varies by sport; unsupported seasons return a clear status message.Default "current"; Allowed current, 2026-27, 2025-26, 2024-25, 2026, 2025, 2024, 2023 and 6 more
    pollSlugRanking pollstring(mode=rankings) Which NCAA-hosted poll to scrape. The valid set depends on the chosen sport and division. If the default poll is not valid for the chosen sport/division, the actor uses a curated default (AP for D1 basketball and FBS football, AFCA Coaches for FCS, and the primary coaches/RPI/AVCA poll elsewhere) and reports the substitution in the run status. An explicitly unavailable poll returns a clear status message.Default "di-mens-basketball-associated-press"; Allowed 2026-march-madness-womens-seeding, afca-fcs-coaches-poll, associated-press, avca-rankings, college-football-playoff, d1baseballcom-top-25, di-committees-top-10, di-committees-top-16 and 29 more
    gameIdsGame IDs or URLsarray(mode=gameDetail) NCAA game IDs or game-page URLs, e.g. 6649632 or https://www.ncaa.com/game/6649632.Default []
    teamTeam filterstringOptional case-insensitive team/school name or NCAA.com school slug filter. Applies to leaderboards, polls, standings, schedules, teamSchedule, brackets, game detail, and the school directory. mode=teamSchedule requires this field; for example duke or Duke matches either team in each contest. Leave empty for all teams in the other modes.
    playerNamePlayer filterstring(mode=individualStats) Optional case-insensitive player-name filter, e.g. Dybantsa. Searches the rows of the selected player leaderboard.
    conferenceConferencestring(mode=standings or schedules) Optional conference filter.
