    DoorDash Store Menu & FAQ Data Finder is an Apify Actor published by Nimbryxo Studio. It accepts 2 input fields, none of them required at the top level. Each result can carry up to 25 declared fields, including storeName, address, city, state, ratingValue and reviewCount. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    Find restaurant details and complete menus from DoorDash store pages — name, structured address and geo, rating and review count, price range, cuisines, image, cuisine breadcrumbs, menu sections with item names, descriptions and prices, and the store's published FAQ. Provide one or more store URLs and get a flat, fully-populated record back for each.

    What this actor does

    • Full menu extraction — every section and item, including nested sections behind Restaurant.hasMenu, with name, description, and price
    • Restaurant enrichment — aggregate rating, review count, price range, cuisines, image URL, latitude/longitude, and structured postal address
    • FAQ extraction — questions and answers published on the restaurant's store page
    • Breadcrumb extraction — cuisine type and neighborhood, as shown on the page
    • Deduplication — the same store ID is only emitted once per run, even if its URL is listed twice
    • Empty fields omitted — missing values are omitted instead of written as empty strings, zeros, or nulls
    • Failed-URL reporting — URLs that cannot be loaded are named in the run status instead of being silently skipped

    Use cases

    • Competitor menu intelligence — track pricing and item offerings for named restaurants over time
    • Cuisine analysis — group restaurants by their breadcrumb cuisine tag
    • Menu engineering research — compare which sections and items are common across similar restaurants
    • Franchise auditing — pull menus for every location of a chain by store URL
    • Customer support/FAQ research — collect how restaurants answer common ordering questions

    Questions

    Why doesn't this return individual customer reviews?

    DoorDash store pages no longer expose individual customer reviews — only aggregate signals surfaced elsewhere on the page. This actor extracts everything the store page actually publishes: menu, address, FAQ, and breadcrumbs.

    How do I find a store's URL?

    Visit the restaurant on doordash.com and copy its page URL, in the form https://www.doordash.com/store/<id>.

    Can I get prices as numbers instead of strings?

    Prices are returned as strings (e.g. "$8.50") because DoorDash sometimes shows ranges or non-numeric formatting. Convert them downstream if you need numeric values.

    Will this work for every DoorDash store?

    It works for any restaurant with a published menu. Some stores — closed restaurants, catering/aggregator brands, or convenience-store and grocery listings — don't expose a structured menu; for those, this actor still returns the restaurant's info, FAQ, breadcrumbs, and address, but menuSections and menuItems come back empty.

    Does this include duplicate stores if I list the same URL twice?

    No — each store ID is only emitted once per run even if its URL appears more than once in storeUrls.

    Do I need to configure a proxy?

    No. The actor handles connections automatically and needs no proxy setup.

    What happens if some store URLs fail?

    The run status names every URL that could not be loaded, so a partial success is never reported as a clean run.

    Is this affiliated with DoorDash?

    No. This is an independent third-party actor that reads DoorDash's public store pages.
