    Talent.com Multi-Country Job Listings Scraper is an Apify Actor published by Nimbryxo Studio. It accepts 18 input fields, and mode is required. Each result can carry up to 19 declared fields, including recordType, title, company, location, city and isRemote. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “Modes”, “What a job record contains”, “Input”, “Use cases”, “Data source and independence” and “FAQ and limits”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (search in the united states). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 50, maximum 1000) caps how many results a run collects, and so what it costs.

    What it costs

    Talent.com Multi-Country Job Listings Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 18 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredWhat to collect: job search results, saved search URLs, individual job pages, or salary statistics.Default "search"; Allowed search, bySearchUrls, byJobUrls, salary
    searchQueriesSearch keywordsarrayOne or more job titles or keywords (mode=search or salary). Each query runs as its own search; results are deduplicated by job id. The legacy single 'keyword' field is combined with this list.
    keywordJob keyword / titlestringA single job title or keyword (mode=search or salary). Example: "software engineer", "nurse", "warehouse". Combined with Search keywords when both are set.Example "software engineer"
    locationLocationstringCity, state, or region (mode=search or salary). Example: "New York, NY", "London", "Toronto". Leave empty to search all locations. Location text is matched loosely, like the site's own search box.Example "New York, NY"
    countryCountry sitestringWhich local Talent.com site to use. Each country is a separate job index with its own listings, currency and language. Canada and Russia sites may block non-local networks.Default "www"; Allowed www, dz, ao, ar, au, at, bh, be and 70 more
    companyNameCompany name filterstringOnly return jobs matching this employer name (mode=search). Works on the United States, Canada and United Kingdom sites; Talent.com ignores it elsewhere, so the actor does too.
    radiusMilesDistance (miles)integerSearch radius around the location, in miles (mode=search). Mapped to Talent.com's supported distance stops: 2, 5, 10, 15, 30 or 60 miles (nearest stop).Default 25; Allowed 5 to 100
    datePostedDate postedstringOnly return jobs found within this many days (mode=search). Leave empty for any time.Allowed 1, 3, 7, 14, 30, 90
    jobTypeJob typestringOnly return jobs of this employment type (mode=search). Supported on the United States, Canada and United Kingdom sites only; ignored elsewhere with a warning.Allowed full-time, part-time, permanent, temporary, internship
    remoteOnlyRemote onlybooleanOnly return remote/work-from-home jobs (mode=search). Supported on ca, www (US), uk, in, ch, es, nl, it, de and fr sites; ignored elsewhere with a warning.Default false
    quickApplyOnlyQuick Apply onlybooleanOnly return jobs with Talent.com's one-click Quick Apply (mode=search). Supported on the same country sites as Remote only; ignored elsewhere with a warning.Default false
    searchUrlsSearch URLsarrayTalent.com search or category URLs to replay (mode=bySearchUrls). Examples: https://www.talent.com/jobs?k=nurse&l=London or https://uk.talent.com/jobs/k-nurse-l-london. Unsupported filters in a pasted URL are removed.
