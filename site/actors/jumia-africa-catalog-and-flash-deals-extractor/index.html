    Jumia Africa Catalog & Flash Deals Extractor is an Apify Actor published by Nimbryxo Studio. It accepts 22 input fields, and mode is required. Each result can carry up to 21 declared fields, including name, price, currency, discountRate, rating and brand. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “Active storefronts”, “Modes”, “What each record contains”, “Input”, “Examples” and “How it works”.

    What you get

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (search a market). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    What it costs

    Jumia Africa Catalog & Flash Deals Extractor uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input fields in the published schema
    FieldTypeDescription
    modeCollection modestring requiredHow to find products. Search uses a keyword, category browses a catalog section, flashSales reads today's deals, productDetails opens specific URLs, sellerProducts reads a seller storefront, and brandProducts reads a brand page.Default "search"; Allowed search, categoryBrowse, flashSales, productDetails, sellerProducts, brandProducts
    countryJumia storefrontstringThe active Jumia country storefront to use. Prices are returned in that market's local currency.Default "nigeria"; Allowed nigeria, kenya, ghana, egypt, morocco, senegal, uganda, cote_divoire and 3 more
    keywordKeywordstringProduct words to search for. Also narrows brand listings when set.Default ""; Example "smartphone"
    categorySlugCategorystringA category path or a friendly key. Examples: phones-tablets, electronics, fashion, home-office. The actor translates the key to the selected market's own URL (for example telephone-tablette on jumia.ma). A full Jumia category URL also works.
    productUrlsProduct URLsarrayJumia product page URLs for the specific product mode. The market is detected from each URL.Default []
    sellerUrlsSeller URLs or slugsarraySeller storefront URLs (or slugs like 'jckm-cod') for the seller mode. A full seller profile URL is accepted too.Default []
    brandBrandstringBrand name, slug or brand URL. Used by the brand mode and to narrow search/category results. Examples: samsung, apple, tecno, or https://www.jumia.com.ng/brands/apple/.
    sortSort orderstringOrder of listing results, using the sort options Jumia itself offers.Default "popularity"; Allowed popularity, newest, lowest-price, highest-price, rating
    minPriceMinimum pricenumberLowest price to keep, in the selected market's local currency.Allowed at least 0
    maxPriceMaximum pricenumberHighest price to keep, in the selected market's local currency.Allowed at least 0
    minRatingMinimum ratingnumberKeep products rated at least this many stars (0-5).Allowed 0 to 5
    minDiscountMinimum discountstringKeep products discounted by at least this percentage.Default "0"; Allowed 0, 10, 20, 30, 40, 50
