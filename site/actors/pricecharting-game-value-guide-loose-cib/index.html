    PriceCharting Game Value Guide: Loose, CIB & Graded is an Apify Actor published by Nimbryxo Studio. It accepts 5 input fields, and mode is required. Each result can carry up to 6 declared fields, including title, consoleName, loosePrice, cibPrice, newPrice and gameUrl. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per game”, “Input”, “Use cases” and “FAQ”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 6 fields in 1 dataset view, and the README documents 7 more. Fields without a value can be left out of a record.

    Output fields
    FieldLabelWhat it holds
    titleGame title
    consoleNameConsole/platform name
    loosePricePrice for the cartridge or disc alone
    cibPriceComplete-in-box price (game, case, and manual)
    newPriceSealed/new price
    gameUrlPriceCharting page URL for the game
    slugPriceCharting's URL slug for the game
    genreGame genre (gameDetails mode only)
    gradedPriceProfessionally graded copy price
    boxOnlyPricePrice for the box alone, without the game (gameDetails mode only)
    manualOnlyPricePrice for the manual alone (gameDetails mode only)
    imageUrlCover art image URL
    scrapedAtUTC timestamp of the scrape

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (search a title across all consoles). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 20, maximum 500) caps how many results a run collects, and so what it costs.

    What it costs

    PriceCharting Game Value Guide: Loose, CIB & Graded uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.
