    eBay Seller Reputation & DSR Feedback Lookup is an Apify Actor published by Nimbryxo Studio. It accepts 16 input fields, and mode is required. Each result can carry up to 19 declared fields, including sellerUsername, rating, comment, dateRange, itemTitle and priceFormatted. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Input”, “Output per feedback row (recordType: "feedback")”, “Output per seller profile (recordType: "sellerProfile")”, “Output per error row (recordType: "error")” and “Examples”.

    What you get

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (get seller profile summaries). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 25, maximum 10000) and maxFeedbackPerSeller (default 500, maximum 10000) cap how many results a run collects, and so what it costs.

    What it costs

    eBay Seller Reputation & DSR Feedback Lookup uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 16 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredChoose feedback rows, one seller profile summary per seller, or both.Default "feedback"; Allowed feedback, sellerProfile, both
    sellerUsernamesSeller usernamesarrayeBay seller usernames or profile URLs, e.g. "musicmagpie" or https://www.ebay.com/usr/musicmagpie. At least one of sellerUsernames or storeUrls must be given.Default []; Example ["musicmagpie"]
    storeUrlsStore URLsarrayFull eBay store URLs (https://www.ebay.com/str/<seller>). The URL's eBay site is used for that seller.Default []
    marketplaceMarketplacestringeBay site used for plain usernames and as the default for store URLs.Default "US"; Allowed US, UK, DE, AU, CA, FR, IT, ES and 6 more
    feedbackTypeFeedback rolestringWhich side of the seller's feedback ledger to read.Default "All"; Allowed All, Seller, Buyer, LeftForOthers
    ratingTypeRating typestringFilter feedback rows by rating.Default "All"; Allowed All, Positive, Neutral, Negative
    periodPeriodstringOnly feedback left in this period. eBay applies this within the last 12 months.Default "All"; Allowed All, PastMonth, Past6Months, Past12Months
    sortBySort orderstringNewest first is best for monitoring; relevance follows eBay's own ranking.Default "Newest"; Allowed Newest, Relevance
    itemSearchItem title or ID searchstringOnly feedback for matching items. eBay searches the last 5 years and cannot combine this with its period or rating filters; the rating filter is checked by the actor instead.Default ""
    imagesOnlyOnly feedback with photosbooleanReturn only feedback entries where the buyer attached a photo.Default false
    includePhotosInclude full photo galleriesbooleanFetch every buyer photo for feedback entries that have more than one. Adds one public feedback-detail request per such entry.Default false
    includeAutomatedInclude automated feedbackbooleanInclude eBay's automated positive feedback entries. Turn off to keep only feedback written by buyers.Default true
