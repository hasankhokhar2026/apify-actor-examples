    Bilibili Video Search, Ranking & Metadata Scraper is an Apify Actor published by Nimbryxo Studio. It accepts 13 input fields, and mode is required. Each result can carry up to 6 declared fields, including title, author, viewCount, likeCount, publishTime and videoUrl. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per video”, “Output per error record”, “Input”, “Use cases” and “FAQ”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 6 fields in 1 dataset view, and the README documents 35 more. Fields without a value can be left out of a record.

    What it costs

    Bilibili Video Search, Ranking & Metadata Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 13 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredWhat to collect.Default "search"; Allowed search, byVideoUrl, popular, ranking
    searchQueriesSearch queries / aliases (mode=search)arrayOne keyword per entry, e.g. python, 原神, Genshin. Provide Chinese and English aliases explicitly; Bilibili does not translate them.Default []; Example ["python"]
    videoUrlsVideo URLs or IDs (mode=byVideoUrl)arrayAccepts https://www.bilibili.com/video/BV..., https://b23.tv/... short links, bare BV IDs, av123... IDs, or numeric aids.Default []
    maxItemsMax videosintegerHard cap on emitted video records. Error records do not count toward it.Default 20; Example 3; Allowed 1 to 1000
    sortSearch sort (mode=search)stringResult ordering. dm is most danmaku and scores is most comments.Default "totalrank"; Allowed totalrank, click, pubdate, dm, stow, scores
    publishedAfterPublished after (UTC)stringOnly videos published on or after this date, YYYY-MM-DD (mode=search). Can be used alone.
    publishedBeforePublished before (UTC)stringOnly videos published on or before this date, YYYY-MM-DD (mode=search). Can be used alone.
    durationDuration filter (mode=search)stringKeep only videos in this length range.Default "all"; Allowed all, short, medium, long, verylong
    partitionPartitionstringSearch partition filter (mode=search) or ranking chart (mode=ranking). Ignored for weekly charts.Default "0"; Allowed 0, 1, 3, 4, 5, 36, 119, 129 and 7 more
    rankingTypeRanking type (mode=ranking)stringAll-time, originals-only, rookie, or the weekly series.Default "all"; Allowed all, origin, rookie, weekly
    weekNumberWeekly issue number (mode=ranking)integerSpecific weekly issue. Omit to use the latest issue.Allowed 1 to 10000
    enrichDetailsEnrich with video detailsbooleanAdd one detail request per unique video in search, popular, and ranking modes to fill tags, coin/share counts, cid, parts, resolution, and uploader followers. Usually adds 3-10 seconds per video, depending on Bilibili latency. byVideoUrl lookups are always enriched.Default false
    proxyConfigurationProxy configuration (optional)objectOptional. The actor starts direct and retries through fresh and anonymous browser sessions; this proxy is used only as the final escalation stage.
