    Carousell Marketplace Listing Search (Hong Kong) is an Apify Actor published by Nimbryxo Studio. It accepts 15 input fields, and mode is required. Each result can carry up to 7 declared fields, including title, price, condition, countryCode, seller and categoryName. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per listing”, “Input”, “Use cases” and “FAQ”.

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (search hong kong listings). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    What it costs

    Carousell Marketplace Listing Search (Hong Kong) uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 15 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredSearch listings, browse one category, fetch listing detail URLs, or pull a seller profile with its listings.Default "search"; Allowed search, category, listingDetails, seller
    queriesSearch queriesarrayOne or more keywords (mode=search). Each query returns Carousell's first page of up to 48 listings per market.Default ["iPhone"]
    categoryCategory (mode=category)stringTop-level category. The actor resolves the correct market-specific collection ID and URL.Allowed mobile-phones, electronics, cars, property, motorbikes, womens-fashion, mens-fashion, luxury and 13 more
    sellerUsernamesSeller usernames (mode=seller)arrayCarousell usernames to fetch. Each seller returns profile fields plus the first page of their listings.Default []
    listingUrlsListing URLs or IDs (mode=listingDetails)arrayCarousell /p/ listing URLs or bare listing IDs. Bare IDs use Hong Kong. URLs from unsupported markets are skipped.Default []
    sortBySort bystringServer-side sort. Best match is Carousell's default and sends no sort parameter.Default "best_match"; Allowed best_match, recent, price_low, price_high
    conditionConditionstringServer-side layered condition filter. Carousell uses codes 3, 4, 7, 5 and 6 for these labels.Default "any"; Allowed any, brand_new, like_new, lightly_used, well_used, heavily_used
    priceMinMinimum priceintegerMinimum price in the market's local currency (server-side).Allowed 0 to 1000000000
    priceMaxMaximum priceintegerMaximum price in the market's local currency (server-side).Allowed 0 to 1000000000
    dealOptionDeal optionstringServer-side mailing/delivery or meet-up filter.Default "any"; Allowed any, mailing, meetup
    postedWithinDaysPosted within (days)integerClient-side filter over the first page. Listings without a visible creation timestamp are excluded when this is set.Allowed 1 to 365
    maxItemsMaximum recordsintegerOverall record cap. Carousell returns at most 48 listings per query, so larger values cannot exceed that first-page limit.Default 20; Example 3; Allowed 1 to 500
    includeDetailsFetch detail pagesbooleanFetch and merge full detail pages for search, category or seller results. Adds one request per listing.Default false
    maxDetailItemsMaximum detail pagesintegerCap on detail-page requests when includeDetails is enabled (or in listingDetails mode).Default 10; Example 1; Allowed 1 to 50
    countryMarketstringVerified market: hong_kong only. Other Carousell markets are blocked or unreliable from Apify cloud and are not offered.Default "hong_kong"; Allowed hong_kong
