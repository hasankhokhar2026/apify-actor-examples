    LinkedIn Learning Course & Learning Path Finder is an Apify Actor published by Nimbryxo Studio. It accepts 8 input fields, and searchQuery is required. Each result can carry up to 6 declared fields, including title, instructorName, durationFormatted, difficultyLevel, assetType and courseUrl. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    Search the LinkedIn Learning catalog by keyword and get back structured data for the matching courses, learning paths, or videos — no LinkedIn login or Learning subscription needed.

    What this actor does

    • Searches LinkedIn Learning's public catalog by keyword, with an optional topic to narrow it further
    • Visits each matching course/path/video page and extracts its published schema.org course data
    • Filters by difficulty level and asset type (course, learning path, video)
    • Returns instructor name/profile, duration, topics and the skills it teaches, when LinkedIn Learning lists them
    • Empty fields are omitted from records rather than returned as null

    Use cases

    • Curriculum planning — survey what courses and learning paths already exist for a skill before building internal training
    • Skill-gap research — pull the topics and skills taught across a batch of search queries to map a domain
    • L&D catalog building — compile course metadata (duration, difficulty, instructor) into an internal learning catalog
    • Instructor research — find which instructors are teaching in a given subject area
    • Competitive content tracking — monitor how LinkedIn Learning's catalog for a topic changes over time

    Questions

    Do I need a LinkedIn account or Learning subscription?

    No. The search page and individual course pages used by this actor are publicly accessible without logging in.

    Why do some records have fewer fields than others?

    Course pages don't all publish the same schema.org fields — things like popularityScore, learnerCount, releaseDate and certificate depend on what LinkedIn Learning itself has published for that particular course.

    Why is courseId sometimes missing?

    It's parsed from a numeric suffix in the course's URL slug; some slugs don't end in one, so there's nothing to extract.

    What's the difference between topics and skillsTaught?

    topics are the broader subject areas a course is filed under; skillsTaught are the specific skills LinkedIn Learning lists as learning outcomes.

    How is assetType different from a learning path search?

    Setting assetType to LEARNING_PATH searches LinkedIn's curated multi-course paths instead of individual courses or standalone videos; the rest of the fields are extracted the same way.

    Does language translate the results?

    No — it selects the LinkedIn Learning locale used for the search and reflects whatever language the matching content was actually published in.

    Why did I get fewer results than maxResults?

    LinkedIn Learning's catalog for a given keyword and asset type may simply have fewer matches than the limit you set.

    Is this affiliated with LinkedIn?

    No. This actor reads LinkedIn Learning's public catalog pages; it is not operated by or affiliated with LinkedIn.
