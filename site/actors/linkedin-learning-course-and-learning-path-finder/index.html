    LinkedIn Learning Course & Learning Path Finder is an Apify Actor published by Nimbryxo Studio. It accepts 12 input fields, and mode is required. Each result can carry up to 8 declared fields, including title, assetType, instructorName, durationFormatted, difficultyLevel and ratingValue. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Modes”, “Input”, “Output per record”, “Use cases” and “Limitations”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 8 fields in 1 dataset view, and the README documents 10 more. Fields without a value can be left out of a record.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (beginner python courses, most viewed). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxResults (default 50, maximum 500) caps how many results a run collects, and so what it costs.

    What it costs

    LinkedIn Learning Course & Learning Path Finder uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 12 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredWhat to collect. 'Search the catalog' needs searchQuery. 'Read specific URLs' needs urls. 'Browse learning paths' reads the public all-paths page.Default "search"; Allowed search, byUrls, learningPaths
    searchQuerySearch querystringKeyword or skill to search for, e.g. 'Python machine learning' or 'project management'. Put one query per line to run several searches in one run; each line is labelled in the output.Example "Python machine learning"
    urlsLinkedIn Learning URLsarrayCourse, learning-path, chapter/lesson, topic or filtered search URLs. Used only in 'Read specific LinkedIn Learning URLs' mode.Default []
    maxResultsMax results per queryintegerMaximum records per query (or per URL list in URL mode). LinkedIn's guest catalog exposes at most 50 cards per filter slice; the actor re-runs the query across its own filters to collect more.Default 50; Example 3; Allowed 1 to 500
    difficultyLevelDifficulty levelstringFilter by skill level. 'All levels' returns every level.Default ""; Allowed , BEGINNER, INTERMEDIATE, ADVANCED
    assetTypeAsset typestringKind of learning content. 'All types' mixes courses, learning paths and videos.Default "COURSE"; Allowed COURSE, LEARNING_PATH, VIDEO, ALL
    sortBySort bystringOrder of the results: LinkedIn's best match, view count, or newest release.Default "RELEVANCE"; Allowed RELEVANCE, POPULARITY, RECENCY
    durationTime to completestringFilter by total course length. 'Any length' returns every length.Default ""; Allowed , BETWEEN_0_TO_10_MIN, BETWEEN_10_TO_30_MIN, BETWEEN_30_TO_60_MIN, BETWEEN_1_TO_2_HOURS, BETWEEN_2_TO_3_HOURS, MORE_THAN_3_HOURS
    softwareSoftwarestringKeep only content that teaches this LinkedIn Learning software label, e.g. 'Python', 'Microsoft Excel', 'SQL' or 'ChatGPT'. LinkedIn applies only one software label per request.
    topicExtra keywordsstringOptional words appended to every search query to narrow it, e.g. 'AWS' or 'for beginners'.
    includeDetailsInclude full course detailsbooleanOpen each record's public page for description, skills, syllabus, chapters, free-preview flags, reviews, rating, learner count, provider and certificate. Turn off for a faster, cheaper catalog snapshot.Default true; Example false
    proxyConfigurationProxy configurationobjectOptional. The actor connects directly by default and only escalates to a datacenter proxy if LinkedIn blocks a request. Change this only if you need a specific proxy setup.Default {"useApifyProxy": false}
