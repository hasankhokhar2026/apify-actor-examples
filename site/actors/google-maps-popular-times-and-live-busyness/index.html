    Google Maps Place Data & Popular Times (When Available) is an Apify Actor published by Nimbryxo Studio. It accepts 17 input fields, none of them required at the top level. Each result can carry up to 51 declared fields, including recordType, businessName, placeId, featureId, cid and searchQuery. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “At a glance”, “What is Google Maps Popular Times?”, “What does this scraper extract?”, “Use cases”, “How to scrape Google Maps place data and Popular Times” and “Input”.

    What you get

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (input examples). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxAttemptsPerPlace (default 8, maximum 12) and maxPhotos (default 10, maximum 50) cap how many results a run collects, and so what it costs.

    What it costs

    Google Maps Place Data & Popular Times (When Available) uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    placeIdsGoogle Place IDsarrayGoogle Place IDs beginning with ChIJ (for example ChIJaXQRs6lZwokRY6EFpJnhNNE). Recommended for monitoring fixed lists: each ID always points to the same place. IDs that do not match a place are reported as unavailable, never guessed.
    searchQueriesSearch queriesarrayGoogle Maps search terms, for example "McDonald's Times Square New York" or "coffee shop Vancouver". Each query opens Google Maps search and resolves the best organic matching place; a query that cannot be matched to exactly one place is reported as unavailable (or as a failed record with Include unavailable places).
    languageGoogle Maps languagestringLanguage of the Google Maps pages; text fields such as the live label and open status are returned in this language.Default "en"; Allowed en, es, fr, de, it, pt, ja, ko and 3 more
    maxConcurrencyPlaces scraped in parallelintegerHow many places are scraped at the same time. Higher values finish large lists faster and need more run memory (about 1 GB per parallel place; the actor lowers this automatically if the run has less memory).Default 3; Allowed 1 to 8
    maxAttemptsPerPlaceMax attempts per placeintegerMaximum number of fresh attempts for one place before it is reported as unavailable. Lower values cap time and cost for hard-to-reach places; higher values maximise coverage.Default 8; Allowed 1 to 12
    placeTimeoutSecsTime limit per placeintegerHard time limit for one place across all of its attempts.Default 240; Allowed 30 to 600
    includeFailedPlacesInclude unavailable places in the outputbooleanAlso output one record per place (or search query) for which no place data could be resolved, with the reason and number of attempts. A limited view that still resolves to a place is a normal basic record, not a failure. Recommended for monitoring lists so every input appears in the results.Default false
    includeOpeningHoursInclude weekly opening hoursbooleanReturn the week's opening hours as structured day-by-day entries. The actor opens Google's "See more hours" panel when needed and reads only the hours Google publishes; closed days and 24-hour entries keep Google's own text.Default true
    includePhotosInclude photo URLsbooleanReturn absolute URLs of the place photos Google shows, including its gallery when available. Photos are omitted by default to keep records compact.Default false
    maxPhotosMaximum photos per placeintegerHow many photo URLs to return per place when photos are included.Default 10; Allowed 1 to 50
    includeLatestReviewsInclude newest reviews and closure mentionsbooleanAlso return each place's newest Google reviews (exact date, rating, text) and flag reviews that mention the place closing, such as "final weekend", "it was closed" or "permanently closed". Diners often report a closure in reviews before Google updates the listing.Default false
