    Coupang Best Sellers & Rocket Delivery Flags is an Apify Actor published by Nimbryxo Studio. It accepts 12 input fields, and mode is required. Each result can carry up to 15 declared fields, including productName, price, originalPrice, discountRate, unitPrice and coupon. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per best-seller product”, “Input”, “Use cases”, “Limits and behavior” and “FAQ”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 15 fields in 2 dataset views, and the README documents 14 more. Fields without a value can be left out of a record.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (best sellers in electronics). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 20, maximum 5000) and maxSuggestions (default 10, maximum 10) cap how many results a run collects, and so what it costs.

    What it costs

    Coupang Best Sellers & Rocket Delivery Flags uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 1 GB, so a run starts with 1 start event, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.
