    X Trends Lookup by Country, City & WOEID is an Apify Actor published by Nimbryxo Studio. It accepts 10 input fields, and mode is required. Each result can carry up to 10 declared fields, including type, location, rank, trend, trendType and countryCode. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per trend (mode = trends)”, “Output per location (mode = locations)”, “Output: status rows”, “Input” and “Examples”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 10 fields in 1 dataset view, and the README documents 20 more. Fields without a value can be left out of a record.

    What it costs

    X Trends Lookup by Country, City & WOEID uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 10 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredChoose whether to collect the current trends or list the places X publishes trends for.Default "trends"; Allowed trends, locations
    locationsLocationsarrayCountries, cities, country codes, slugs or WOEIDs (mode=trends). Examples: Worldwide, United States, US, United Kingdom, GB, London, Tokyo, sao-paulo, 23424977. Put "all" to collect every location. Add a country after a comma when two places share a name, for example "Barcelona, ES".Default ["Worldwide"]
    allLocationsAll available locationsbooleanCollect trends for every place X serves (currently 467 countries and cities, up to 50 trends each). When enabled, the Locations list is ignored.Default false
    maxTrendsPerLocationMaximum trends per locationintegerHow many ranked trends to keep for each location. X publishes up to 50.Default 50; Example 3; Allowed 1 to 50
    excludeHashtagsExclude hashtagsbooleanSkip trends that start with #. X applies this filter before returning the list.Default false
    trendNameContainsOnly trends containing these wordsarrayOptional case-insensitive keyword filter. A trend is kept when its name contains at least one of these words. Useful for brand or topic monitoring.Default []
    dedupeAcrossLocationsMerge repeated trends across locationsbooleanWhen the same trend appears in several requested locations, keep one row with all locations and the best rank instead of one row per location.Default false
    includeSearchUrlsInclude search linksbooleanInclude a ready-made X search link for every trend.Default true
    placeTypeFilterPlace type (mode=locations)stringLimit the location list to countries, cities and towns, the worldwide entry, or X's unknown place type.Default "all"; Allowed all, country, town, worldwide, unknown
    proxyConfigurationProxy configurationobjectOptional. Use a proxy if you plan very large or repeated runs.
