    TikTok Video, Audio & Cover Downloader is an Apify Actor published by Nimbryxo Studio. It accepts 9 input fields, and postUrls is required. Each result can carry up to 12 declared fields, including postId, postUrl, assetType, variant, quality and mimeType. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (one clean video at 540p). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 1000, maximum 1000) caps how many results a run collects, and so what it costs.

    What it costs

    TikTok Video, Audio & Cover Downloader uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 9 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    postUrlsPost URLsarray requiredTikTok post URLs or IDs. Accepts /@user/video/ID, /@user/photo/ID, /video/ID, /photo/ID, embed URLs (/embed/v2/ID), vm.tiktok.com / vt.tiktok.com / /t/ short links, m.tiktok.com/v/ID.html, and bare numeric post IDs. Duplicates are processed once.Example ["https://www.tiktok.com/@nba/video/7693329153680035102"]
    assetTypesAsset TypesarrayAssets to produce for each post. 'video' = MP4; 'audio' = TikTok sound; 'cover' = cover image; 'slideshow' = ordered photo frames; 'metadata' = post/author/stats/music row.Default ["video"]; Allowed video, audio, cover, slideshow, metadata
    videoVariantVideo Variantstring'clean' = no-watermark MP4 (requires a same-page browser session and is always re-hosted). 'watermarked' = logo copy, usable as an expiring CDN URL. 'both' = one row per variant.Default "clean"; Allowed clean, watermarked, both
    qualityVideo QualitystringTarget clean-video quality. 'best' sorts by resolution first, then bitrate. Watermarked copies are single-resolution.Default "best"; Example "540p"; Allowed best, 1080p, 720p, 540p, 360p, smallest
    downloadToKvDownload Files to Apify Key-Value StorebooleanStore watermarked video, audio, cover, and slideshow files in the run's Key-Value Store and return stable kvsUrl links. Clean video is always stored because its source URL is session-bound. Set false to return expiring CDN URLs only.Default true
    maxFileSizeMbMax File Size (MB)integerPer-file size cap. Files above the cap produce a 'too_large' status row instead of a partial download.Default 100; Allowed 1 to 100
    maxItemsMax PostsintegerMaximum number of unique posts to process. Inputs beyond the cap receive a 'limit_reached' status row.Default 1000; Example 1; Allowed 1 to 1000
    maxConcurrencyMax ConcurrencyintegerNumber of posts processed in parallel (1-3). Embed requests are retried with backoff when TikTok rate-limits them.Default 3; Example 1; Allowed 1 to 3
    proxyConfigurationProxy ConfigurationobjectOptional. The actor uses a direct connection by default and does not require a proxy. Use this only if you want to route requests through Apify Proxy.
