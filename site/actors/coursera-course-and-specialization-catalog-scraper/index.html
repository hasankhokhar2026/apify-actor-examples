    Coursera Course & Specialization Catalog Scraper is an Apify Actor published by Nimbryxo Studio. It accepts 21 input fields, and mode is required. Each result can carry up to 7 declared fields, including recordType, name, partnerName, difficultyLevel, avgRating and learnerCount. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    Coursera publishes tens of thousands of learning products: individual courses, multi-course specializations, professional certificates, guided projects, degrees and shorter credentials. This actor turns that public catalog into structured records you can filter, compare and export. Give it a keyword, a category, a university, a slug or a URL, and it returns the matching products with ratings, skills, providers, level, duration, language coverage, access flags and direct links.

    Optional detail enrichment adds the parts that only exist on each product page: instructors, module-by-module syllabus, lecture durations, total enrollment, monthly page views, star distribution, top reviews, learning objectives and recommended background.

    What this actor does

    • Keyword search across every Coursera learning product type
    • Category (topic) browse and partner/university browse
    • Slug, URL and product-ID lookups
    • All 10 live product types: courses, specializations, guided projects, projects, professional certificates, degrees, graduate certificates, MasterTrack certificates, university certificates and postgraduate diplomas
    • Filters for level, duration band, cost label, topic, content language, subtitle language, hands-on learning format, tool/software, partner, skill and Coursera Plus inclusion
    • Best-match and newest ordering
    • Optional instructor, syllabus, enrollment, page-view, rating-breakdown and review fields
    • Search rank and page metadata so repeated runs can be compared

    Modes

    Mode Required input What it does
    search query Keyword search with every filter
    byCategory topics Browse one or more subject areas; query is optional
    byPartner partners Browse a university or company; query is optional
    bySlug slugs Look up products by slug (a full URL also works)
    byUrl startUrls Product URLs return one detail record; search or /courses?query= URLs become catalog queries
    byIds productIds Look up course~... and s12n~... product IDs
    browse none Top products with filters and no keyword
    searchSpecializations query Legacy alias for a search limited to specializations and professional certificates

    Lookup modes (bySlug, byUrl, byIds) always return detail fields. Search modes return detail fields only when includeDetails is true.

    Data source and reliability

    The actor reads Coursera's public catalog through the same endpoints the public website uses:

    • The catalog search endpoint at https://www.coursera.org/graphql-gateway?opname=Search for keyword search, facets, sorting and pagination.
    • Public batch endpoints (courses.v1, onDemandSpecializations.v1) for description, workload, certificates, languages and subject areas.
    • Public product pages for the optional detail fields.

    No account, cookie, API key or proxy setup is needed. Results are deduplicated by product ID. The actor retries transient HTTP errors with exponential backoff and, if a cloud exit is ever blocked, falls back to an Apify datacenter proxy automatically. Runs stop on the requested item count, the end of the source or an exhausted result window; there is no wall-clock cut.

    Use cases

    • Curriculum research - map which universities and companies teach a subject and at what level
    • Competitive analysis - compare ratings, enrollment signals, duration and skills across course providers
    • Learning and development - build internal training shortlists filtered by topic, language and difficulty
    • Edtech market intelligence - track new specializations, professional certificates and guided projects
    • Academic research - export a reproducible catalog slice with search rank and page metadata

    Questions

    Do I need a Coursera account?

    No. Every request is cookieless and unauthenticated.

    How many records can one run return?

    Up to 1,000. Coursera's own search window is 10,000 products; the actor never needs more than 1,000 for a run and partitions by filters when you need different slices of a large topic.

    Why do some records lack a rating or review count?

    Coursera does not publish ratings for every new or low-traffic product. The field is omitted rather than filled with zero.

    Why is enrollmentType shown as AUDIT or VERIFIED?

    Coursera's current public catalog no longer exposes the old enrollment-form value. The actor keeps the historic values meaningful by deriving them from isCourseFree (free products become AUDIT, others VERIFIED). The authoritative access signals are isCourseFree, isPartOfCourseraPlus and isCreditEligible.

    What does includeDetails cost?

    One extra product-page request per record. It is the only setting that adds per-record requests; leave it off for fast catalog exports.

    Can I get exact prices or discounts?

    No. Coursera does not publish a stable price in the public catalog payload; it depends on region, session and promotions. Free/paid/trial/preview labels and Coursera Plus inclusion are available.

    Can I get every review for a course?

    The product page exposes a curated set of top reviews (typically 12-20). Bulk review export is outside this catalog actor's scope.

    Do degree and certificate pages have the same detail fields?

    Degrees and graduate certificates use a different Coursera page template with sparse public metadata. They are returned from the search catalog with list-level fields; course, project, specialization and professional-certificate pages have the full detail set.

    Why did a slug or ID return nothing?

    Some legacy products are retired or moved. Try the product URL in byUrl, or use a search query to find the current slug. Unsupported ID prefixes are reported in the run log.

    A slug exists as both a course and a guided project. Which one is returned?

    A bare slug is ambiguous; bySlug follows the first catalog hit. Use byUrl with the full product URL when you need a specific product type.

    Is this affiliated with Coursera?

    No. This is an independent, third-party actor that reads public catalog data. It is not operated by or affiliated with Coursera, Inc.

    Limits and notes

    Limitations

    • Coursera's search index returns at most 10,000 products per query. The actor caps runs at 1,000 records; use filters (product type, topic, level, duration, language, partner) to cover a large topic in several runs.
    • Exact price and discount data are not part of the public catalog payload.
    • Bulk/all reviews are not available from the catalog page; only the page's top reviews are returned.
    • Degree and graduate-certificate detail pages expose a different, sparse schema; those product types are list-level only.
    • One legacy professional certificate was missing from the public batch endpoint during research; the actor falls back to the product page for such IDs and reports a shortfall in the status message if the page is also gone.

    Responsible use

    Use the actor for lawful catalog research and export. Respect Coursera's terms, copyright and privacy rules, and do not republish course content. The actor collects public catalog metadata and top review excerpts, not learner records or paid course materials.
