    Snapchat EU Ads Library Impressions & Targeting Extractor is an Apify Actor published by Nimbryxo Studio. It accepts 12 input fields, none of them required at the top level. Its build declares no dataset fields; the published README describes the output. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (multiple active advertisers in france, germany and turkey). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxResults (default 200, maximum 10000) caps how many results a run collects, and so what it costs.

    What it costs

    Snapchat EU Ads Library Impressions & Targeting Extractor uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 1 GB, so a run starts with 1 start event, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 12 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeScraping ModestringadSearch searches ads by paying advertiser, sponsoredContent browses all live sponsored content, and creatorSearch searches sponsored content by creator.Default "adSearch"; Allowed adSearch, sponsoredContent, creatorSearch
    payingAdvertiserNamesAdvertiser NamesarrayFor adSearch mode: one or more paying-advertiser names, e.g. Nike, Amazon, Zalando. The API matches partial names case-insensitively; set Advertiser Match to exact for case-insensitive exact payer matching.Example ["nike"]
    payingAdvertiserNameAdvertiser Name (single, legacy)stringSingle-advertiser legacy input, still supported. Prefer Advertiser Names. If both are set, the names are merged and deduplicated.
    advertiserMatchAdvertiser Matchstringcontains (default) uses Snap's partial payer-name search. exact keeps only ads whose paying advertiser exactly equals one of your names, ignoring case and extra whitespace.Default "contains"; Allowed contains, exact
    countriesCountriesarray2-letter country codes to filter ads by. Leave empty for all. Supported: the 27 EU codes at, be, bg, cy, cz, de, dk, ee, el (Greece), es, fi, fr, hr, hu, ie, it, lt, lu, lv, mt, nl, pl, pt, ro, se, si, sk, tr (Turkey). gr is accepted as an alias for el. UK (gb/uk) and US are not in the library.Example []
    startDateStart DatestringFilter ads that ran on or after this date (ISO 8601 or YYYY-MM-DD). The library only covers the last 12 months; older dates may return nothing.
    endDateEnd DatestringFilter ads that ran on or before this date (ISO 8601 or YYYY-MM-DD). The API does not publish an ad end date in records.
    statusAd StatusstringFilter ads by current status: ACTIVE, PAUSED, or ALL.Default "ALL"; Allowed ACTIVE, PAUSED, ALL
    creatorNameCreator NamestringFor creatorSearch mode: creator username or display name used to search sponsored content.Example "beauty"
    maxResultsMax Results per AdvertiserintegerMaximum records to save per advertiser in adSearch, or total records in sponsoredContent/creatorSearch. The actor paginates the public API automatically (10 ads per request for adSearch, up to 200 items per page for sponsored content).Default 200; Allowed 1 to 10000
    includeCoverageInclude Coverage RowsbooleanAdd one coverage row per advertiser/creator listing matched payer names, status, pages fetched, duplicates removed, countries, and impression coverage.Default true
    proxyConfigurationProxy ConfigurationobjectOptional proxy. The Ads Library API is public and normally works without a proxy; enable one only if your runs keep hitting rate limits.
