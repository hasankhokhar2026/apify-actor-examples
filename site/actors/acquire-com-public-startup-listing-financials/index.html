    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (newest saas listings with disclosed profit). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 50, maximum 1250) and maxScan (default 0, maximum 1250) cap how many results a run collects, and so what it costs.

    What it costs

    Acquire.com Public Startup Listing Financials Extractor uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.
