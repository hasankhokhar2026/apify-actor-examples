    Username Search & Cross-Platform Identity Resolution is an Apify Actor published by Nimbryxo Studio. It accepts 16 input fields, and mode is required. Each result can carry up to 5 declared fields, including username, foundCount, verifiedCount, checkedCount and searchMode. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output: per username (mode = broadSearch)”, “Output: per target network (mode = identityResolution)”, “Input”, “Use cases” and “Data source and coverage”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 5 fields in 1 dataset view, and the README documents 16 more. Fields without a value can be left out of a record.

    Output fields
    FieldLabelWhat it holds
    usernamethe handle that was searched
    foundCountprofile URLs in links (usable found profiles)
    verifiedCountprofiles that passed verification
    checkedCountsites actually checked
    searchModefocused when targetNetworks was supplied, otherwise broad
    linksprofile URLs that passed the active checks
    profilesper-site evidence, each with:
    statusfound, unreliable, blocked, error
    verificationStatusverified, gated, missing, unverified
    verificationRequiredtrue when the result needs a human look
    unreliablepresent on known false-positive sites
    statusCountsclaimed found / verified / unreliable / notFound / blocked / error / invalid
    sitesRequestedthe shortlist you sent (omitted for a broad sweep)
    sitesInvalidnames the actor did not recognize
    warningsnon-fatal notes, including why a site could not be checked
    sourceUrlthe first profile URL in links (verified when verification is on), for traceability
    sourceProfileplatform, handle, profileUrl, displayName, verified, plus optional bio, avatarUrl, followers, location, websiteUrl, joinedAt, sourceUrl
    candidateModediscover or verify
    discoveryMethodsearch, heuristic, or verify
    bestMatchthe highest-confidence candidate above minConfidenceScore and supported by at least one independent signal (or a verified profile), with handle, profileUrl, confidenceScore, confidenceLabel, signals, profileExists, verificationStatus, and the same optional profile fields
    candidatesevery scored candidate, ranked by confidence, each with its own signals breakdown and profileExists/verificationStatus. A candidate the target network says does not exist is never a bestMatch; a username-only match is capped below high.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (focused broad search with details). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxUsernames (default 100, maximum 500) caps how many results a run collects, and so what it costs.

    What it costs

    Username Search & Cross-Platform Identity Resolution uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 16 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredbroadSearch: check usernames across networks (optionally filtered) and return every found profile with its status. identityResolution: disambiguate which candidate account on a target network matches a source profile.Default "broadSearch"; Allowed broadSearch, identityResolution
    usernamesUsernamesarrayUsernames to search for (mode=broadSearch). Accepts one to 500, but only maxUsernames (default 100) are processed per run; the status message and record warnings report any shortfall. Supports the {?} wildcard (e.g. 'john{?}doe' expands to 'john_doe', 'john-doe', 'john.doe'). A leading @ is ignored. The legacy single username field is still accepted.Example ["torvalds"]
    targetNetworksTarget NetworksarrayLimit the search/resolution to these networks. Omit to check the 410-site safe sweep (435 vendored sites minus 17 adult/NSFW and 8 known-false-positive sites; Reddit is only checked when explicitly targeted). In identityResolution this field is required; candidateMode 'verify' requires exactly one network. Discord, Diskusjon.no, and Kvinneguiden are skipped with a warning in identity mode because the site database has no username profile URL template for them. Reddit is checked through its public JSON endpoint.Example ["GitHub"]; Allowed 1337x, 2Dimensions, 7Cups, 9GAG, AWS Skills Profile, About.me, Academia.edu, AdmireMe.Vip and 428 more
    includeNsfwInclude adult / NSFW sitesbooleanWhen no targetNetworks are supplied, also check the 17 adult/NSFW sites in the site database. Off by default.Default false
    includeUnreliableInclude sites with known false positivesbooleanWhen no targetNetworks are supplied, also check the 8 sites that reported random control handles as found in live testing. Their results are marked unreliable. Off by default.Default false
    verifyResultsVerify found profilesbooleanRe-open each found profile page. broadSearch drops dead URLs and keeps gated pages flagged; identityResolution marks every candidate with profileExists/verificationStatus and only emits a bestMatch supported by independent evidence or a verified profile. Soft-404 and login pages are never marked verified. Adds one request per found profile. On by default.Default true
    extractProfileFieldsExtract profile detailsbooleanOpt in to public profile details (display name, bio, avatar, location, follower count where the source exposes them) in both modes. Identity resolution always fetches what it needs for scoring, but emits the optional detail fields only when this is on. Adds one request per found profile. Off by default; empty and unverifiable avatar URLs are omitted.Default false
    maxUsernamesMax usernamesintegerHow many usernames a broadSearch run will process. Defaults to 100; raise it to 500 for larger batches. When input is truncated, the status message and each record's warnings state how many usernames were skipped.Default 100; Example 1; Allowed 1 to 500
    maxConcurrencyMax concurrent usernamesintegerHow many usernames are searched at the same time in broadSearch. Lower this on a small-memory run.Default 2; Example 1; Allowed 1 to 5
    requestTimeoutSecsRequest timeout (seconds)integerPer-site timeout for existence checks and profile verification.Default 20; Example 15; Allowed 5 to 60
    sourceProfileSource ProfileobjectThe known account to resolve against (mode=identityResolution). Example: {"platform": "github", "handle": "torvalds"}. The legacy profile key is still accepted.Example {"platform": "github", "handle": "torvalds"}
    sourceOverridesSource OverridesobjectOptional manual displayName/bio/avatarUrl for the source profile, used when the source platform cannot be read or to supplement missing data.
