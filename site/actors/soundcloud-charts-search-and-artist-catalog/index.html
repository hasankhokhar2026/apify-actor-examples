    SoundCloud Charts, Search & Artist Catalog Scraper is an Apify Actor published by Nimbryxo Studio. It accepts 22 input fields, and mode is required. Each result can carry up to 8 declared fields, including recordType, title, artist, playCount, likeCount and genre. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    Pull public SoundCloud data into one clean dataset: the current global New & Hot chart, 20 genre trending lists, keyword search across tracks, artists, playlists and albums, complete artist catalogs, playlist contents, track comments, and artist followers. No SoundCloud account, cookie or API key is required.

    What this actor does

    • Search tracks, users/artists, playlists or albums by keyword, with a real SoundCloud genre filter for tracks and playlists.
    • Charts the global New & Hot list (up to 100 tracks) or one of 20 current genre trending lists (about 50 tracks each).
    • Artist catalog exports the profile row plus uploaded tracks and, optionally, albums, playlists, top tracks and public web profiles.
    • URLs resolves any public track, playlist/album or artist URL. Playlist URLs expand into every track, not just the first page. Artist URLs return the profile and uploaded tracks.
    • Comments collects public comments for one or more tracks, including the commenter's profile fields and the time in the track.
    • Followers collects an artist's followers or the accounts the artist follows.
    • Empty fields are omitted from records. No null, blank strings or empty arrays are pushed.

  "maxItems": 100

    { "mode": "charts", "chartGenre": "trap", "maxItems": 50 }

    {

    Questions

    Do I need a SoundCloud account or API key?

    No. The actor reads the same public pages and public v2 JSON the SoundCloud web player uses, with no login.

    Why is streamUrl sometimes missing?

    SoundCloud may expose only encrypted/DRM transcodings or a preview for that track. streamUrlApi, policy and the preview flag still describe what is available.

    Why does a search stop at 300 rows?

    That is SoundCloud's public search window per query. Split the job into more queries or use searchGenre to partition it.

    Why is waveformUrl a JSON file?

    SoundCloud's waveform field points to amplitude JSON, not an image. It is kept under the existing field name for compatibility.

    Can I schedule monitoring?

    Yes. Run the actor on a schedule and compare playCount, likeCount, repostCount and followersCount snapshots. Monitoring helpers are not part of this version; the dataset is designed for external diffing.

    Is this affiliated with SoundCloud?

    No. This is an independent actor that reads publicly visible data and is not endorsed by SoundCloud.

    Limits and notes

    Charts: what is available

    SoundCloud's current public chart surface is New & Hot, not the retired all-time Top chart. The actor returns:

    • the global New & Hot list (up to 100 tracks), and
    • 20 current genre trending lists (about 50 tracks each).

    The old per-genre chart endpoint and the all-time Top chart are no longer available from SoundCloud's public API. Requests for the legacy top value are mapped to the current global New & Hot list and the status message says so.

    Stream URLs, previews and rights

    Stream metadata comes from SoundCloud's public transcodings. streamUrl is a signed media URL and expires after about two hours; streamUrlExpiresAt records the exact time. streamUrlApi is the stable API endpoint, but it is not playable on its own without a client_id.

    Not every track is fully playable: SoundCloud may return a 30-second preview (streamUrlIsPreview=true), use DRM/encrypted transcodings, or disable downloads. The actor reports the metadata it can see and never fabricates an audio file. This actor does not download or rehost audio.

    Limitations

    • Search returns at most 300 rows per query. Use more queries or a genre filter to reach further.
    • The all-time Top chart and regional/country charts are not available from the current public surface.
    • Server-side BPM, duration, upload-date, license and access filters are not available on SoundCloud's public v2 search; the actor only exposes the real genre filter. sortBy and the minimum play/like thresholds are applied to the rows already fetched.
    • SoundCloud does not publish a user join date or a user repost count in this API.
    • BPM and musical key are not exposed for tracks.
    • City/country, description, genre, tags, ISRC, UPC, label and release date are conditional; fields are omitted when SoundCloud does not provide them.
    • Only public tracks, playlists and profiles are reachable. Private/unlisted content is out of scope.
    • Huge follower lists can be expensive; use maxItems to cap them.
