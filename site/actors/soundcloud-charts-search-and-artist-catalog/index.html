    SoundCloud Charts, Search & Artist Catalog Scraper is an Apify Actor published by Nimbryxo Studio. It accepts 22 input fields, and mode is required. Each result can carry up to 8 declared fields, including recordType, title, artist, playCount, likeCount and genre. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output records”, “Input”, “Examples”, “Charts: what is available” and “Stream URLs, previews and rights”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (s). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    What it costs

    SoundCloud Charts, Search & Artist Catalog Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 1 GB, so a run starts with 1 start event, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input fields in the published schema
    FieldTypeDescription
    modeWhat to collectstring requiredChoose the intent. Keyword search, New & Hot charts, an artist catalog, specific URLs, track comments, or an artist's followers.Default "search"; Allowed search, charts, artistTracks, byUrl, comments, followers
    searchQueriesSearch queriesarrayOne or more keywords or artist names (mode=search). Example: lofi, techno, ambient jazz.Default []; Example ["lofi"]
    searchTypeSearch result typestringWhat kind of results to return (mode=search).Default "tracks"; Allowed tracks, users, playlists, albums, all
    chartGenreChart genrestringGlobal New & Hot returns up to 100 tracks. Genre values use SoundCloud's current trending-by-genre lists (about 50 tracks each).Default "all"; Allowed all, all-genres, trap, hip-hop, pop, electronic, r-n-b, alternative-hip-hop and 13 more
    searchGenreGenre filterstringOptional SoundCloud genre filter for track and playlist searches. Leave as any genre to search everything. This is a real SoundCloud filter, not a client-side guess.Default ""; Allowed , Alternative Rock, Ambient, Classical, Country, Dance & EDM, Dancehall, Deep House and 25 more
    sortBySort fetched rowsstringHow to order the rows already fetched. SoundCloud search itself is relevance-ordered, so this is a client-side sort of that result set.Default "relevance"; Allowed relevance, newest, mostPlayed, mostLiked
    minPlayCountMinimum playsintegerDrop track/playlist rows below this play count after fetching. 0 means no filter.Default 0; Allowed 0 to 1000000000
    minLikeCountMinimum likesintegerDrop track/playlist rows below this like count after fetching. 0 means no filter.Default 0; Allowed 0 to 1000000000
    artistUrlsArtistsarrayArtist profile URLs, usernames, or numeric user IDs. Used by artistTracks and followers modes.Default []
    includeTracksInclude tracksbooleanInclude the artist's uploaded tracks.Default true
    includeAlbumsInclude albumsbooleanInclude the artist's albums/EPs as playlist rows.Default false
    includePlaylistsInclude playlistsbooleanInclude the artist's playlists as playlist rows.Default false
