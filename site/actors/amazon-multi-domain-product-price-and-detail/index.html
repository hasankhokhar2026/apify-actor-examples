    Amazon Multi-Domain Product Price & Detail Scraper is an Apify Actor published by Nimbryxo Studio. It accepts 31 input fields, none of them required at the top level. Each result can carry up to 9 declared fields, including recordType, title, asin, price, stars and reviewsCount. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per product”, “Output per search or bestseller row”, “Output per failure”, “Input” and “Use cases”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 9 fields in 1 dataset view, and the README documents 3 more. Fields without a value can be left out of a record.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (one product). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 50, maximum 1000) caps how many results a run collects, and so what it costs.

    What it costs

    Amazon Multi-Domain Product Price & Detail Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.
