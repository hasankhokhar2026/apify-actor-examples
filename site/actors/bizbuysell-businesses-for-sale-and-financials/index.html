    BizBuySell Businesses-for-Sale & Financials Scraper is an Apify Actor published by Nimbryxo Studio. It accepts 32 input fields, and mode is required. Each result can carry up to 31 declared fields, including title, location, askingPrice, cashFlow, listingType and url. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per listing”, “Input”, “Use cases” and “FAQ”.

    What it costs

    BizBuySell Businesses-for-Sale & Financials Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 1 GB, so a run starts with 1 start event, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.
