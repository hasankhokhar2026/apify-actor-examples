    Gumroad Product Search & Storefront Extractor is an Apify Actor published by Nimbryxo Studio. It accepts 24 input fields, and mode is required. Each result can carry up to 9 declared fields, including title, sellerName, price, currencyCode, priceUsd and ratingAverage. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    Gumroad is where independent creators sell ebooks, courses, templates, memberships, 3D assets, presets, music packs and software. This actor turns Gumroad's public marketplace into structured product and creator data — keyword, tag and category search, whole creator catalogs, exact product URLs, written reviews, sales signals, variants, file formats and seller profiles — with no login, cookies or API key.

    It reads Gumroad's own public JSON endpoints over plain HTTP. No browser, no CAPTCHA service and no user-supplied proxy are required.

    What it does

    • Searches Gumroad Discover by one or more keywords, tags or categories, with Gumroad's own sort order and pagination.
    • Pulls a creator's complete public catalog from one storefront URL, deduplicated across all profile sections.
    • Reads exact product URLs in full, including description, covers, variants, billing recurrences, file formats/sizes, refund policy, sales count and the USD price Gumroad displays.
    • Applies price, type, rating, pricing-model, seller-verification and file-format filters.
    • Optionally collects public written reviews with creator replies.
    • Optionally emits one seller row per unique creator, with bio, links, socials and rating stats (the first 50 unique creators in a search/product run are profile-enriched; seller mode is always complete).
    • Can run as a monitor: schedule the same input and receive only new or changed products.
    • Omits empty fields at every depth. A field appears only when Gumroad publishes it for that item.

    Modes

    Mode What it reads
    searchProducts Keyword search, tag browse, category/subcategory browse, or the whole Discover catalog when no query/tag/category is set.
    byProductUrls Each product URL in full. Filters still apply to explicit URLs.
    bySellerUrls Every public product in a creator's catalog, plus an optional seller row.

    Data source and coverage

    • Marketplace search: Gumroad's public products/search.json endpoint (9 products per page, offset pagination).
    • Creator catalog: Gumroad's public /<username>.json profile endpoint.
    • Product detail: the public /l/<permalink>.json product endpoint plus the rendered product page for file summaries, bundle contents, creator profile and the USD price in the page's JSON-LD block.
    • Reviews: Gumroad's public product_reviews endpoint (10 written reviews per page).

    Gumroad caps a single search at roughly 10,000 products; this actor caps maxItems at 5,000 and stops at the source total. Custom-domain stores are supported through the rendered-page fallback when their .json endpoint is unavailable.

    Honest limits

    • salesCount appears only when the creator enables Gumroad's public sales counter.
    • Price filters use the listed currency; exact USD prices come from includeDetails.
    • Written reviews only: star-only ratings are counted but not individually fetchable.
    • One search can return at most ~10,000 products; maxItems stops at 5,000.
    • Seller profile enrichment is capped at 50 unique creators per search/product run.
    • Creator emails are not exposed by Gumroad's public JSON; the actor collects public bio links, not email addresses.
    • Per-product tags/categories are not in the public product payload; category filtering happens at the search level.

    Output: sellers

    Any run with includeSellerRecord can emit recordType: "seller" rows:

    sellerId, sellerUsername, sellerName, sellerAvatarUrl, sellerProfileUrl, sellerSubdomain, sellerBio, sellerBioLinks, sellerTwitterHandle, sellerYoutubeChannelId, sellerVerified, sellerRatingAverage, sellerRatingCount, sellerProductsWithRatings, sellerProductCount, productCount, productTypes, sellerReputation, scrapedAt.

    Output: errors

    Malformed or unresolvable explicit URLs produce a typed error row instead of failing the run:

    recordType: "error", errorType: "invalid_input", message, mode, field, scrapedAt.

    Quick start

    Search Notion templates and read three products:

    {
  "mode": "searchProducts",
  "searchQueries": ["notion template"],
  "maxItems": 3
}

    The default saved prefill uses this shape (three products, one search request, no enrichment).

    Example: filtered market research

    {
  "mode": "searchProducts",
  "searchQueries": ["lightroom presets"],
  "sort": "most_reviewed",
  "nativeTypes": ["digital", "bundle"],
  "minPrice": 10,
  "maxPrice": 80,
  "minRating": 4,
  "fileTypes": ["pdf", "xmp"],
  "includeDetails": true,
  "includeReviews": true,
  "maxItems": 100
}

    Example: whole creator catalog + seller row

    {
  "mode": "bySellerUrls",
  "sellerUrls": ["https://productivesetups.gumroad.com"],
  "sellerQuery": "notion",
  "includeSellerRecord": true,
  "maxItems": 200
}

    Example: monitor a niche

    {
  "mode": "searchProducts",
  "searchQueries": ["vrchat avatar"],
  "sort": "newest",
  "monitorMode": true,
  "monitorKey": "vrchat-newest",
  "maxItems": 300
}

    The first run emits every product as monitorStatus: "new". Later runs emit only new or changed products, with a changes array (field, previous, current) covering name, price, currency, rating count/average, sales count, quantity and sales-limit state.

    Questions

    Do I need a Gumroad account or API key?

    No. Only public marketplace, product and review data is read. The actor never accesses purchases, downloads or anything behind a login.

    Why is salesCount missing on many products?

    Gumroad only publishes a sales counter when the creator enables it. An absent field means the creator hides it, not that the product sold zero.

    Why don't price filters use USD?

    Gumroad's search filters the listed price in each product's own currency; cookie and header currency overrides are ignored by the public endpoints. Enable includeDetails to receive priceUsd, the exact USD price Gumroad displays on the product page, for cross-currency comparison. For memberships, priceUsd is the displayed starting recurrence price.

    How many reviews can I get?

    Written reviews only, 10 per page. Star-only ratings are counted in ratingCount but cannot be fetched individually. maxReviewsPerProduct controls the cap.

    What counts toward maxItems?

    Product rows only. Seller rows are additional, capped at 1,000 unique creators per run, and profile-enriched for the first 50 in search/product runs.

    Why does a seller row have no bio?

    Search and product runs enrich the first 50 unique creators. Beyond that, or when Gumroad does not expose a public creator profile, the seller row contains the product-card data observed in that run. Use bySellerUrls for the complete profile of a specific creator.

    Do custom-domain stores work?

    Gumroad subdomains, gumroad.com/<username> and custom domains that still serve Gumroad's public product/profile data work. Older custom landing pages that no longer expose Gumroad's public data produce a typed error row and a no-results status message rather than fabricated rows.

    Why did a product URL return an error row?

    The URL did not resolve to a public product — a deleted product, a misspelled permalink or a non-Gumroad link. The run continues with the remaining URLs.

    Does it work without a proxy?

    Yes. Direct HTTP is the default. If Gumroad ever blocks the platform's IPs, the actor reports the failure instead of fabricating data.

    Is this affiliated with Gumroad?

    No. This is an independent third-party actor that reads publicly available pages and JSON endpoints. Gumroad and other names are trademarks of their owners.
