    Gumroad Product Search & Storefront Extractor is an Apify Actor published by Nimbryxo Studio. It accepts 24 input fields, and mode is required. Each result can carry up to 9 declared fields, including title, sellerName, price, currencyCode, priceUsd and ratingAverage. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What it does”, “Quick start”, “Modes”, “Input”, “Example: filtered market research” and “Example: whole creator catalog + seller row”.

    What you get

    What it costs

    Gumroad Product Search & Storefront Extractor uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 24 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredsearchProducts searches Gumroad Discover. byProductUrls reads exact product pages in full. bySellerUrls reads every public product of a creator.Default "searchProducts"; Allowed searchProducts, byProductUrls, bySellerUrls
    searchQueriesSearch queriesarrayKeywords to search on Gumroad Discover (mode=searchProducts). One query per line, e.g. notion template, lightroom presets, vrchat avatar.Default []; Example ["notion"]
    productUrlsProduct URLsarrayGumroad product links to read in full (mode=byProductUrls), e.g. https://creator.gumroad.com/l/product. Filters still apply.Default []
    sellerUrlsCreator storefront URLsarrayGumroad creator stores to read in full (mode=bySellerUrls), e.g. https://creator.gumroad.com or https://gumroad.com/creator. Every public product in the store is collected once.Default []
    tagsTagsarrayGumroad Discover tags (mode=searchProducts). Multiple tags are combined with AND, e.g. notion and template.Default []
    categoryCategorystringTop-level Gumroad category to browse. Leave 'All categories' to search the whole marketplace.Default "all"; Allowed all, drawing-and-painting, 3d, design, music-and-sound-design, gaming, self-improvement, films and 10 more
    subcategorySubcategory path (optional)stringNested Gumroad category path that overrides Category, e.g. 3d/vrchat, design/icons, software-development/web-development.
    sortSort resultsstringGumroad's own result order for keyword, tag and category searches.Default "featured"; Allowed featured, best_sellers, most_reviewed, highest_rated, newest, hot_and_new, curated, price_asc and 1 more
    nativeTypesProduct typesarrayOnly include these Gumroad product types: digital, course, ebook, membership, bundle, podcast, audiobook, newsletter, physical, commission, call, coffee, ticket. Leave empty for all types.Default []
    fileTypesIncluded file typesarrayOnly include products that ship at least one of these formats, e.g. pdf, zip, mp4, psd, epub, blend. In creator mode this reads product pages to verify formats.Default []
    minPriceMinimum listed pricenumberMinimum price in the product's own listed currency. Free products are 0. Use USD prices from details mode for cross-currency comparisons.Allowed 0 to 1000000
    maxPriceMaximum listed pricenumberMaximum price in the product's own listed currency. Use 0 for free products only.Allowed 0 to 1000000
