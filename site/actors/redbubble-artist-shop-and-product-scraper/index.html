    Redbubble Artist Shop & Product Scraper is an Apify Actor published by Nimbryxo Studio. It accepts 15 input fields, and mode is required. Each result can carry up to 6 declared fields, including title, artistShopDisplayName, productType, priceAmount, priceCurrency and productUrl. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per product”, “Input”, “Use cases” and “FAQ”.

    What you get

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (search stickers under $5). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 50, maximum 1000) caps how many results a run collects, and so what it costs.

    What it costs

    Redbubble Artist Shop & Product Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    styleProduct style (advanced)stringOptional product-style filter code, e.g. u-active-t-shirt (Active) or u-tee-boxy (Boxy) within the T-Shirts category. Ignored if the chosen category has no style variants (mode=search and mode=byArtist).
    extraFiltersExtra filters (advanced)arrayOptional raw key=value filter pairs for category-specific sidebar filters not covered by the fields above — e.g. tShirtColor=tShirtColor-black, fit=fit-slim-fit, neckType=neckType-crew-neck, sleeveLength=sleeveLength-short-sleeve, tShirtSize=tShirtSize-m, priceFilter=price-low. Each product category on redbubble.com/shop exposes its own set — open the desired category, apply a filter in the sidebar, and copy the resulting key=value pair from the URL.
