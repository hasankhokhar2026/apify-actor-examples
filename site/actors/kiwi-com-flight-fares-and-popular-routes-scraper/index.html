    Kiwi.com Flight Fares & Popular Routes Scraper is an Apify Actor published by Nimbryxo Studio. It accepts 15 input fields, and mode is required. Each result can carry up to 9 declared fields, including originCity, destinationCity, departureTime, arrivalTime, price and currency. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per flight (mode = search)”, “Output per popular route (mode = popularRoutes)”, “Output per station (mode = stationLookup)”, “Input” and “Use cases”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 9 fields in 1 dataset view, and the README documents 2 more. Fields without a value can be left out of a record.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (cheap direct flights from london to paris). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 20, maximum 500) caps how many results a run collects, and so what it costs.

    What it costs

    Kiwi.com Flight Fares & Popular Routes Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 15 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredWhat to fetch.Default "search"; Allowed search, popularRoutes, stationLookup
    originOriginstringAirport code, city name, or Kiwi place ID (mode=search, popularRoutes). Examples: LTN, london, City:london_gb.Default "london"
    destinationDestinationstringAirport code, city name, or Kiwi place ID (mode=search). Use anywhere to search all destinations.Default "paris"
    stationQueryStation lookup querystringFree-text term to search airports, cities, countries and points of interest (mode=stationLookup).
    travelDateTravel datestringDeparture date (mode=search). Format YYYY-MM-DD. When omitted, the actor uses today + 30 days.
    returnDateReturn datestringOptional return date (mode=search). Format YYYY-MM-DD. When omitted, Kiwi returns flights with any return date.
    currencyCurrencystringCurrency for all prices (ISO 4217).Default "usd"; Allowed usd, eur, gbp, jpy, aud, cad, chf, cny and 24 more
    stopsMax stopsstringFilter itineraries by the number of stops on the outbound journey.Default "any"; Allowed any, nonstop, 1plus, 2plus
    passengersPassengersintegerNumber of adult passengers (1-9).Default 1; Allowed 1 to 9
    cabinClassCabin classstringCabin class for the search (mode=search, popularRoutes).Default "economy"; Allowed economy, premium, business, first
    sortBySort orderstringHow Kiwi.com sorts the returned itineraries.Default "QUALITY"; Allowed QUALITY, PRICE, DURATION, TAKEOFF_ASC, LANDING_ASC
    maxPriceMax pricenumberDrop itineraries priced above this amount (in the selected currency).Allowed 1 to 1000000
    containsKeywordContains keywordstringOnly keep flights whose airline, flight number, origin or destination contains this text (case-insensitive).
    maxItemsMax itemsintegerHard cap on emitted records.Default 20; Example 10; Allowed 1 to 500
    proxyConfigurationProxy configurationobjectOptional Apify proxy. The actor runs without a proxy and only uses it lazily if the Kiwi API starts rate-limiting (429) or blocking (403).Default {"useApifyProxy": true}
