    Chrome Web Store Extension Manifest & Permissions Scraper is an Apify Actor published by Nimbryxo Studio. It accepts 10 input fields, and mode is required. Each result can carry up to 9 declared fields, including name, extension_id, developer, rating, rating_count and install_count. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The Chrome Web Store doesn't offer a bulk export of its listings, so comparing extensions at scale usually means opening each page by hand. This actor looks up Chrome Web Store extensions by direct URL, category page, search query, or top-charts ranking, and returns every listing as a structured record — ratings, install count, manifest permissions, supported locales and related extensions included.

    What this actor does

    • Fetches specific extensions directly from their Chrome Web Store URLs or IDs
    • Walks a category page to collect every extension listed under it
    • Searches the Chrome Web Store by free-text keyword
    • Pulls the top-charts ranking for a category, or the global top list when no category is set
    • Filters results by minimum rating, minimum install count, verified-developer status, and a developer-name substring
    • Empty fields are omitted from records — a field only appears when the Chrome Web Store actually publishes that data for the extension

    Use cases

    • Competitive analysis — pull every extension in a category to study install and rating distribution
    • Version tracking — monitor a competitor's version and manifest_version for changes over time
    • Permissions auditing — scan extensions whose host_permissions include <all_urls> for a security review
    • Developer outreach — filter by developerNameContains to build a contact list of extension makers
    • Install-leader research — set a high minInstalls to surface only the most widely adopted extensions in a niche

    Questions

    Does this need a login or cookies?

    No — the Chrome Web Store is public, and no login or API key is required.

    What happens if an extension ID isn't found?

    It's skipped and the run finishes cleanly; if nothing at all was found, the run's status message explains why.

    What if my filters reject every result?

    The run finishes without fabricating rows and sets a status message so you know to loosen the filters.

    How do I search by exact description text?

    Use mode: "search" with that text as searchQuery — the Chrome Web Store's own search ranks results by relevance.

    What value does topChartsCategory expect?

    The exact schema slug, not a human label — for example productivity/tools, productivity/communication, or make_chrome_yours/themes.

    Why is related_extensions sometimes empty?

    Not every listing shows a "similar extensions" carousel; when the Chrome Web Store doesn't show one, the field is omitted.

    Is this affiliated with Google or the Chrome Web Store?

    No. This is an independent, third-party actor that reads the Chrome Web Store's publicly available listing pages; it is not operated by or affiliated with Google.
