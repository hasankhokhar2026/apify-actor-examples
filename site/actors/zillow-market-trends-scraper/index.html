    Zillow Market Trends Scraper is an Apify Actor published by Nimbryxo Studio. It accepts 11 input fields, and mode is required. Each result can carry up to 76 declared fields, including location, locationType, regionName, zhviLatest, zhviChange12mPct and zoriLatest. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Modes”, “Supported locations”, “Input”, “Output per record type” and “Datasets available in marketScan”.

    What it costs

    Zillow Market Trends Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    FieldTypeDescription
    modeModestring requiredWhat to collect. regionTrends = one detailed record per location. history = tidy monthly rows per location. marketScan = one row per region from a Zillow Research dataset.Default "regionTrends"; Allowed regionTrends, history, marketScan
    locationsLocationsarray(mode=regionTrends, history) Cities, states, counties, ZIP codes or neighborhoods, e.g. 'Austin, TX', 'Travis County, TX', '78701', 'Barton Hills, Austin, TX', 'Texas'.Default []; Example ["Austin, TX"]

    datasetDatasetstring(mode=marketScan) Zillow Research series to scan.
