    Eniro.se Company Directory & Contact Finder is an Apify Actor published by Nimbryxo Studio. It accepts 19 input fields, and mode is required. Each result can carry up to 14 declared fields, including name, category, city, municipality, street and phone. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What you can do”, “Output per company”, “Input”, “Use cases”, “FAQ” and “Limitations”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 14 fields in 1 dataset view, and the README documents 15 more. Fields without a value can be left out of a record.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (one trade in one city). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 50, maximum 1000) caps how many results a run collects, and so what it costs.

    What it costs

    Eniro.se Company Directory & Contact Finder uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 19 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredWhat to scrape: keyword/category searches, direct company profiles, or a list of Eniro search/profile URLs.Default "search"; Allowed search, detail, urls
    queryCategory / keywordstringBusiness category or keyword to search for (mode=search). Pick a common category from the list, or choose 'Custom' and type your own in the field below. Ignored when 'Search terms' is filled.Default "pizzeria"; Allowed custom, pizzeria, restaurang, frisör, tandläkare, advokat, elektriker, rörmokare and 23 more
    customQueryCustom category/keyword (overrides selection above)stringFree-text category or keyword not in the curated list above, e.g. 'skorstensfejare' or 'IT-konsult' (mode=search). Takes priority over 'Category / keyword' when set. Use correct Swedish spelling with å/ä/ö -- Eniro's search does not fuzzy-match ASCII-folded keywords.
    searchTermsSearch terms (one or more)arrayOne or more categories/keywords (mode=search). Every term is combined with every city below, so ['rörmokare', 'elektriker'] x ['Stockholm', 'Göteborg'] covers four searches. Leave empty to use the single 'Category / keyword' selection above.Default []
    cityCitystringSwedish city or town to search in, e.g. 'Stockholm', 'Göteborg', 'Malmö' (mode=search). Leave empty to search all of Sweden. Ignored when 'Cities' is filled.Default "Stockholm"
    locationsCities (one or more)arrayOne or more Swedish cities/towns (mode=search), used with every search term. Leave empty to use the single 'City' field above, or to search nationwide when both are empty.Default []
    searchCoordinatesSearch around coordinates (optional)stringOptional 'latitude,longitude' point for a nearby search, e.g. '57.6346,12.8574' (mode=search). Uses Eniro's own coordinates filter; leave empty for a normal city/nationwide search.
    sortBySort orderstringHow to order the returned results (search modes). Applied after fetching, since Eniro's own listing order is relevance-based.Default "relevance"; Allowed relevance, rating, name
    ratedOnlyOnly companies with ratingsbooleanOnly return companies that have at least one customer rating. Ratings are read from Eniro search cards when present and from the profile page when 'Fetch full company profiles' is enabled.Default false
    minRatingMinimum ratingstringOnly return companies rated at least this many stars, e.g. '4' for 4.0+ (search modes). Unrated companies are excluded when a minimum is set.Default ""; Allowed , 1, 2, 3, 4, 5
    hasWebsiteOnlyOnly companies with a websitebooleanOnly return companies that list a website (search modes). Websites appear on profile pages, so enable 'Fetch full company profiles' for this filter to find any matches.Default false
    hasPhoneOnlyOnly companies with a phone numberbooleanOnly return companies that publish at least one phone number (search modes).Default false
