    Jobs.ac.uk Academic Vacancy & Studentship Scraper is an Apify Actor published by Nimbryxo Studio. It accepts 20 input fields, and mode is required. Each result can carry up to 15 declared fields, including advertId, title, employer, department, locationRegion and salaryRaw. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What you can collect”, “Output”, “Input”, “How it reads the board”, “Use cases” and “FAQ”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 15 fields in 1 dataset view, and the README documents 9 more. Fields without a value can be left out of a record.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (computer-science lecturers, newest first). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 25, maximum 3000) caps how many results a run collects, and so what it costs.

    What it costs

    Jobs.ac.uk Academic Vacancy & Studentship Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 20 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredWhat to fetch: run a search, fetch specific posting URLs, or enumerate every live vacancy from jobs.ac.uk's sitemap.Default "search"; Allowed search, byUrls, allJobs
    keywordsKeywordsstringFree-text terms matched by jobs.ac.uk against the job title, employer, department, disciplines and location (e.g. lecturer, research fellow, PhD studentship). Leave empty to browse all jobs that match the other filters.Example "lecturer"
    sectorSectorstringjobs.ac.uk's top-level vacancy sector. All sectors does not filter.Default "All sectors"; Allowed All sectors, Academic & Research, Professional & Support Services, PhD / Studentship
    regionRegionstringjobs.ac.uk's own regional facet: 13 published regions plus All locations, which does not filter. England covers London and the four English sub-regions; Asia and Middle East both match the source label Asia & the Middle East; South America matches South & Central America.Default "All locations"; Allowed All locations, London, England, Scotland, Wales, Northern Ireland, Republic of Ireland, Europe and 6 more
    sortOrderSort bystringDate placed returns the newest vacancies first; closing date returns the vacancies closing soonest first. relevance is a legacy value kept for saved tasks; it behaves as date placed.Default "datePlaced"; Allowed datePlaced, closingDate, relevance
    disciplinesDisciplinesarrayClient-side discipline filter. Values are matched against the live board's discipline labels (e.g. Computer Sciences, Cyber Security, Economics); old saved-task slugs such as computer-sciences or agriculture-food-and-veterinary are also accepted. Leave empty for all disciplines.Default []
    jobTypesJob typesarrayClient-side job-type filter. Older saved tasks use the values phds and masters.Default []; Allowed Academic, Research, Teaching, PhDs, phds, Masters, masters, Professional and Managerial and 1 more
    hoursTypesHoursarrayClient-side working-hours filter. Older saved tasks use full-time / part-time.Default []; Allowed Full Time, Part Time, full-time, part-time
    contractTypesContract typearrayClient-side contract filter. Older saved tasks use permanent, fixed-term-contract and temporary.Default []; Allowed Fixed-Term/Contract, Permanent, Temporary, permanent, fixed-term-contract, temporary
    workplaceTypesWorkplacearrayClient-side workplace filter. Older saved tasks use on-site, hybrid and remote.Default []; Allowed On Site, Hybrid, Remote, on-site, hybrid, remote
    salaryBandsSalary bands (legacy)arrayLegacy annual salary bands (GBP). Matched client-side against the advert's numeric salary range; adverts without a numeric salary are excluded when a band is selected. Use salaryMin / salaryMax for an exact range.Default []; Allowed up-to-9999, 10000-14999, 15000-19999, 20000-24999, 25000-29999, 30000-39999, 40000-49999, 50000-59999 and 5 more
    salaryMinMinimum salary (GBP)integerClient-side annual salary floor: keeps adverts whose own minimum advertised salary is at least this value. Adverts without a numeric salary are excluded when set.Allowed 0 to 10000000
