App Store Search, Lookup & Reviews Scraper

Search the Apple App Store by keyword, or look up specific apps by App Store ID or URL, and get back structured app records — pricing, ratings, developer details, screenshots, supported languages — for any App Store country. Optionally add each app's most recent customer reviews.

What this actor does

  • Searches the App Store by keyword, or looks up apps directly by numeric App Store ID or App Store URL
  • Returns app metadata: pricing, ratings, current version and its release notes, content rating, file size, and more
  • Fetches developer details including the developer's App Store page and external website
  • Optionally pulls an app's most recent customer reviews, several pages deep
  • Targets any App Store country/region, affecting pricing, availability, and review language
  • Every field below is always present on each app record; values Apple didn't return come back as an empty string, an empty array, or 0 (for price and rating fields) rather than being left out

Output per app

  • appId — unique Apple App Store ID
  • name — app name
  • url — direct App Store URL
  • developer, developerId, developerUrl, developerWebsite — developer name, Apple artist ID, App Store page, and external site
  • price, formattedPrice, currency — numeric price, human-readable price (e.g. "Free", "$4.99"), and currency code for the chosen country
  • rating, ratingCount — average rating (rounded to 2 decimals) and rating count across all versions; 0 when the app has no ratings
  • currentVersionRating, currentVersionRatingCount — rating and count for the current version only; 0 when unavailable
  • description — full app description
  • releaseNotes — latest version's release notes
  • version — current version number
  • releaseDate, lastUpdated — original release date and latest update date (ISO 8601)
  • category — primary genre
  • genres — array of all genres/categories
  • contentRating — age advisory (e.g. "4+", "17+")
  • bundleId — app bundle identifier
  • minimumOs — minimum required iOS/iPadOS version
  • fileSize — file size in bytes, as a string
  • icon — app icon URL
  • screenshots, ipadScreenshots — arrays of iPhone and iPad screenshot URLs
  • languages — array of supported language codes
  • reviews — array of recent customer reviews from the chosen country's store, newest first, populated only when includeReviews is enabled (otherwise an empty array); each review has id, author, rating, title, text, version
  • scrapedAt — ISO 8601 collection timestamp

Input

Field Type Default Description
searchTerms array of strings – Keywords to search for on the App Store
appIds array of strings – Specific App Store app IDs to look up (e.g. 544007664 for YouTube)
startUrls array – Direct App Store URLs; the app ID is extracted automatically. The store region still comes from country, not from the URL
country string us Two-letter ISO country code for the App Store region, affects pricing, availability, and review language
maxResults integer 50 Maximum total apps to return for the whole run, across all search terms, app IDs, and URLs combined (1–200). Search terms are processed first, so IDs and URLs are only looked up while there is room left
includeReviews boolean false Fetch customer reviews for each app
reviewPages integer 1 Review pages to fetch per app when includeReviews is on (50 reviews per page, up to 10 pages)

At least one of searchTerms, appIds, or startUrls must be provided.

Example: keyword search

{
  "searchTerms": ["photo editor", "fitness tracker"],
  "country": "us",
  "maxResults": 50
}

Example: direct app lookup with reviews

{
  "appIds": ["544007664"],
  "includeReviews": true,
  "reviewPages": 3
}

Example: App Store URLs in another region

{
  "startUrls": [
    { "url": "https://apps.apple.com/gb/app/youtube/id544007664" }
  ],
  "country": "gb"
}

Use cases

  • Competitor monitoring — track rivals' ratings, pricing, and update cadence over time
  • ASO research — compare keyword search results to see which apps rank where
  • Market analysis — survey a category's pricing and rating distribution
  • Reputation tracking — pull recent reviews to spot recurring complaints or praise
  • Localization research — compare the same app's pricing and availability across App Store countries

FAQ

Do I need an Apple developer account or API key? No. The actor reads Apple's public App Store listings and review feeds, with no login or key required.

Where do I find an app's App Store ID? Open the app at apps.apple.com in a browser — the numeric ID sits at the end of the URL, e.g. https://apps.apple.com/us/app/youtube/id544007664 → 544007664.

How many results can one run return? Up to 200 apps total per run (maxResults), shared across every search term, app ID, and URL in that run — not 200 per term. Search terms fill the quota first. Split large jobs across multiple runs for more coverage. If nothing at all is found, the run ends as failed with the message "No apps found".

Can I get customer reviews? Yes — enable includeReviews and set reviewPages to fetch up to 500 reviews per app (50 per page, up to 10 pages), sorted by most recent.

Why are some fields empty? Fields like developerWebsite or releaseNotes are only filled when the developer has actually provided them; otherwise they are empty strings. A rating of 0 means the app has no ratings yet in that country.

Does the country setting change the results? Yes. country changes currency and pricing, which apps are available, and the language of any fetched reviews.

Are duplicate apps removed? Yes. When the same app appears across multiple search terms or lookup methods, it is only included once.

Is this affiliated with Apple? No. This is an independent, third-party actor that reads Apple's public App Store pages; it isn't affiliated with or endorsed by Apple Inc.
