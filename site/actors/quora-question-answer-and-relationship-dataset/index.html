    Quora Question, Answer & Relationship Dataset Builder is an Apify Actor published by Nimbryxo Studio. It accepts 84 input fields, none of them required at the top level. Each result can carry up to 407 declared fields, including content_type, event_type, state_snapshot_hash, previous_snapshot_hash, state_scope_fingerprint and state_store_state. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per record”, “Trimming rows, depth, sessions and caps”, “Complete schema input inventory”, “Example inputs” and “Use cases”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (full detail for a question). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxAnswers (default 0, maximum 50000), maxCommentsPerAnswer (default 0, maximum 500), maxItems (default 0, maximum 5000), maxGraphEdges (default 5000, maximum 50000), maxRawEvidenceBytes (default 100000, maximum 2000000) and maxItemsPerSource (default 0, maximum 5000) cap how many results a run collects, and so what it costs.

    What it costs

    Quora Question, Answer & Relationship Dataset Builder uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.
