    Our World in Data Chart & Article Extractor is an Apify Actor published by Nimbryxo Studio. It accepts 21 input fields, and mode is required. Each result can carry up to 21 declared fields, including recordType, title, authors, publishedAt, articleUrl and chartSlug. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (example input). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxIndicatorsPerCountry (default 100, maximum 5000) and maxItems (default 100, maximum 25000) cap how many results a run collects, and so what it costs.

    What it costs

    Our World in Data Chart & Article Extractor uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.
