    Etsy Product Listings & Shop Research Scraper is an Apify Actor published by Nimbryxo Studio. It accepts 10 input fields, none of them required at the top level. Each result can carry up to 8 declared fields, including title, priceValue, currencyCode, shopName, rating and reviewCount. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “How it works”, “What you get per listing”, “Input”, “Pagination, deduplication, and limits” and “FAQ”.

    What it costs

    Etsy Product Listings & Shop Research Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 10 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    startUrlsEtsy URLsarrayEtsy market URLs such as https://www.etsy.com/market/handmade_jewelry are the reliable route. Category URLs such as https://www.etsy.com/c/jewelry also work and expose more cards per page. Legacy /search?q= URLs are converted to the matching market URL automatically. Shop and individual listing URLs are usually blocked by Etsy's DataDome protection; they are accepted for backward compatibility and reported as blocked instead of silently returning nothing.
    searchQueriesSearch QueriesarrayKeywords to search on Etsy. Each query is mapped to Etsy's market page (https://www.etsy.com/market/<slug>), the route that works without a browser or login. If Etsy redirects a keyword to a category page, the actor follows that category route. Each query is scraped as a separate task.Example ["handmade jewelry"]
    maxItemsMax ItemsintegerMaximum number of listings to collect per URL or search query. A keyword market exposes at most 25 pages (about 200 listings); category URLs can expose more pages. Larger values return what Etsy exposes and report a partial result instead of pretending the request was complete.Default 100; Example 1; Allowed 1 to 1000
    includeDetailsInclude Listing DetailsbooleanAttempts to open each listing page for description, materials, tags, variations, images, and seller details. Etsy often blocks listing pages with DataDome. When that happens, rows are still returned with detailsStatus set to 'blocked' and the unavailable detail fields omitted; they are never filled with placeholders.Default false
    sortBySort results bystringServer-side Etsy ordering for market and category pages.Default ""; Allowed , most_relevant, price_asc, price_desc, date_desc, highest_reviews
    minPriceMinimum pricenumberDrop listings below this price in the selected market currency. Etsy does not expose a reliable server-side price filter on market pages, so this is applied to fetched cards. 0 disables the lower bound.Default 0; Allowed 0 to 1000000
    maxPriceMaximum pricenumberDrop listings above this price in the selected market currency. 0 disables the upper bound.Default 0; Allowed 0 to 1000000
    freeShippingOnlyFree shipping onlybooleanUse Etsy's free-shipping market filter. Sponsored cards can bypass it, so every returned row is also checked locally and kept only when free shipping is visible.Default false
    starSellerOnlyStar Seller onlybooleanUse Etsy's Star Seller market filter.Default false
    countryCountry / MarketstringTarget Etsy market. Sets the market URL locale and request language, so prices and ranking match the selected region (for example Germany returns EUR and Japan returns JPY).Default "US"; Allowed US, DE, GB, FR, AU, CA, IT, ES and 2 more
