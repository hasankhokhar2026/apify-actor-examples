    YouTube Channel Video Feed Quick Scraper is an Apify Actor published by Nimbryxo Studio. It accepts 16 input fields, and channelUrls is required. Each result can carry up to 52 declared fields, including recordType, title, videoId, viewCount, likeCount and publishDate. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per video row”, “Input”, “Use cases” and “FAQ”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (a few channels' latest uploads). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxVideos (default 50, maximum 10000), maxPlaylists (default 20, maximum 500) and maxShorts (default 20, maximum 2000) cap how many results a run collects, and so what it costs.

    What it costs

    YouTube Channel Video Feed Quick Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 16 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    channelUrlsChannel URLsarray requiredYouTube channel URLs, handles (@username), or channel IDs (UCxxx). Accepts any format.Example ["https://www.youtube.com/@Apify"]
    maxVideosMax Videos Per ChannelintegerMaximum number of videos to scrape per channel. Set to 0 to get only channel info without videos. The 10,000 cap is an intentional policy limit for a bounded run. Exact player metadata refresh has a 900-second budget per actor run; if that budget is reached, remaining rows keep the listing metadata (title, view text, relative date) and the run still emits the full dataset.Default 50; Example 3; Allowed 0 to 10000
    videoSourceVideo SourcestringWhere to read the video list from. The uploads playlist is a complete chronological feed that also includes Shorts and uploads the Videos tab omits. 'Both' merges the two sources, de-duplicated by video ID, then applies the chosen sort.Default "videosTab"; Allowed videosTab, uploadsPlaylist, both
    sortVideosBySort Videos BystringHow to order the channel's videos. The uploads playlist is already newest-first; Popular/Oldest are applied client-side to a scan window of max(maxVideos, min(2 * maxVideos, 60)) videos. The Videos tab uses YouTube's native sort chips across its full history.Default "newest"; Allowed newest, popular, oldest
    sortShortsBySort Shorts BystringOrder of the Shorts tab when 'Include Channel Shorts' is on. The Shorts tab exposes Latest, Popular and Oldest filters.Default "latest"; Allowed latest, popular, oldest
    includeCommentCountsInclude Exact Comment CountsbooleanFetch the exact public comment count for every video. Costs up to two extra requests per video: a /next seed (reused from the description-enrichment call when that already ran) plus a comments-continuation request when the count is not in the seed. The field is skipped for videos with comments disabled.Default false
    onlyNewVideosOnly New Videos Since Last RunbooleanMonitor mode: return only videos not returned by an earlier run for the same channel. State is kept in the actor's named key-value store, which persists across runs. Only emitted rows are marked seen, so maxVideos pauses the remainder instead of skipping it.Default false
    includeAboutInclude About Page DatabooleanExtract total views, join date, location, external links and channel analytics from the channel About page and video sample.Default true
    includePlaylistsInclude Channel PlaylistsbooleanScrape the channel Playlists tab and include playlist metadata in the output.Default false
    maxPlaylistsMax PlaylistsintegerMaximum number of playlists to scrape (when includePlaylists is enabled).Default 20; Allowed 1 to 500
    includeShortsInclude Channel ShortsbooleanScrape the channel Shorts tab and include Shorts in the output. Also marks matching uploads-playlist videos with isShort.Default false
    maxShortsMax ShortsintegerMaximum number of Shorts to return (when includeShorts is enabled).Default 20; Allowed 1 to 2000
