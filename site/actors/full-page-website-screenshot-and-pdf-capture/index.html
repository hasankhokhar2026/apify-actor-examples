    Complete Page Capture - Screenshot & PDF

    Capture complete full-page screenshots or PDFs of any URL list. Scrolls lazy content, waits for images and fonts, removes fixed headers and consent overlays, emulates real devices, and reports blocks and truncation instead of returning a broken image.

    Complete Page Capture - Screenshot & PDF is an Apify Actor published by Nimbryxo Studio. It accepts 35 input fields, and urls is required. Each result can carry up to 12 declared fields, including startUrl, url, pageTitle, status, httpStatus and blocked. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (example input). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxScrollSteps (default 400, maximum 1000) caps how many results a run collects, and so what it costs.

    What it costs

    Complete Page Capture - Screenshot & PDF uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 2 GB, so a run starts with 2 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.
