    LinkedIn Ad Library Keyword & Advertiser Scraper is an Apify Actor published by Nimbryxo Studio. It accepts 23 input fields, none of them required at the top level. Each result can carry up to 19 declared fields, including advertiser_name, ad_format, headline, body_text, cta_text and start_date. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “Modes”, “Inputs”, “Output”, “Pagination, dedupe, and limits”, “Reliability and errors” and “FAQ”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (prefill). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 50, maximum 4800) caps how many results a run collects, and so what it costs.

    What it costs

    LinkedIn Ad Library Keyword & Advertiser Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 23 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestringWhat to collect: search the library, open specific ads, process pasted URLs, or count matches only.Default "search"; Allowed search, adDetails, directUrls, count
    searchTermsKeywordsarrayOne or more keyword searches, e.g. 'AI' or 'cloud computing'. Each keyword is an independent search (union), not a combination.Default []
    advertisersAdvertisersarrayAdvertiser names (fuzzy accountOwner search) or LinkedIn company URLs. Each name is an independent search. Use companyIds for exact matching.Default []
    companyIdsLinkedIn Company IDsarrayExact numeric LinkedIn company IDs (for example, Microsoft is 1035). Multiple IDs are OR-ed in one exact search. Company URLs are accepted too.Default []; Example ["1035"]
    companyUrlsCompany URLsarrayLinkedIn company page URLs. The actor resolves each public page to its numeric organization ID and searches it exactly.Default []
    payerPaid for by (payer)arraySearch ads by the legal entity that paid for them, e.g. 'Microsoft Corporation'. Each payer is an independent search.Default []
    advertiserMatchAdvertiser Name MatchstringClient-side precision for advertiser-name searches. Exact company IDs are never filtered. 'Starts with' removes partner-noise results while keeping names such as 'Microsoft in Business'.Default "startsWith"; Allowed any, startsWith, exact
    countriesCountriesarrayISO-3166 alpha-2 delivery country codes (US, GB, DE, ...) or ALL. Multiple codes are sent in one comma-separated filter.Default []
    dateOptionDate RangestringLinkedIn's date window. Use custom-date-range with startDate/endDate for an exact period (maximum 12 months back).Default "last-30-days"; Allowed any-time, last-30-days, current-month, current-year, last-year, custom-date-range
    startDateStart DatestringStart of a custom range (YYYY-MM-DD). Required when dateOption is custom-date-range.
    endDateEnd DatestringEnd of a custom range (YYYY-MM-DD). Required when dateOption is custom-date-range.
    sortOrderSort OrderstringNewest first or oldest first.Default "newest"; Allowed newest, oldest
