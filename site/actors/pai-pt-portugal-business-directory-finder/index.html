    Pai.pt Portugal Business Directory Finder is an Apify Actor published by Nimbryxo Studio. It accepts 15 input fields, and mode is required. Each result can carry up to 14 declared fields, including name, categories, city, street, phone and website. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What you can do”, “Output fields”, “Input fields”, “Examples”, “Use cases” and “FAQ and limits”.

    What you get

    What it costs

    Pai.pt Portugal Business Directory Finder uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 15 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredChoose 'Search businesses' to search by keyword/category and location, or 'Fetch profiles by URL' to read specific pai.pt profile pages.Default "search"; Allowed search, detail
    searchQueriesSearch keywordsarrayWhat you would type into pai.pt, e.g. 'canalizador' or 'restaurante'. Each keyword is searched in every location below. Leave empty when using a category instead.Default []
    categoriesCategory slugs (multi-category)arrayOne or more pai.pt category slugs, e.g. 'restaurantes', 'advogados'. Each category is searched in every location below. Takes priority over the single Category field.Default []
    categoryCategorystringA common business category. Choose 'Custom category' to type a slug below instead.Default "restaurantes"; Allowed custom, restaurantes, advogados, dentistas, cabeleireiros, hoteis, eletricistas, pintores and 24 more
    customCategoryCustom category slugstringA pai.pt category URL slug not in the list above, e.g. 'canalizadores-e-picheleiros'. Used only when the category fields are empty.
    locationsLocations (multi-location)arrayCities, municipalities, districts or islands, e.g. 'Lisboa', 'Porto', 'Distrito de Braga'. Each is resolved through pai.pt's own location suggestions. Leave empty to use the single Location field.Default []
    locationLocationstringA Portuguese city or concelho. Leave as 'Any location (nationwide)' to search across Portugal.Default ""; Example "lisboa"; Allowed , custom, lisboa, porto, coimbra, braga, faro, aveiro and 28 more
    customLocationCustom locationstringA city, district or island name not in the list above, e.g. 'Vila Franca de Xira' or 'Distrito de Braga'. Used only when the location fields are empty.
    sortBySort orderstringHow pai.pt orders search results.Default "ranked"; Allowed ranked, popular
    openNowOnlyOpen now onlybooleanKeep only businesses that are open now, computed from their published opening hours in the Europe/Lisbon timezone. Businesses without published hours are kept.Default false
    minRatingMinimum ratingstringKeep only businesses rated at least this many stars. Businesses without a rating are kept because pai.pt only shows ratings after reviews.Default ""; Allowed , 1, 2, 3, 4, 5
    startUrlsStart URLsarrayPai.pt search URLs, category URLs, business profile URLs, or a pai.pt/public listings sitemap URL (for example the public listings.xml.gz sitemap) to enumerate profiles beyond a single search.Default []
    fetchDetailsFetch full business profilesbooleanVisit each search result's profile page to add email, website, coordinates, rating, all phones, gallery, services and feature groups. Disable for a faster card-only scan.Default true
    maxItemsMax itemsintegerHard cap on the number of business records to return across all searches.Default 20; Allowed 1 to 2000
    maxPagesMax pages per searchintegerMaximum result pages to read for each keyword/category/location combination. Pai.pt caps a search at 50 pages.Default 50; Allowed 1 to 500
