    TikTok LIVE Room Status & Chat Capture Tool is an Apify Actor published by Nimbryxo Studio. It accepts 8 input fields, and mode is required. Each result can carry up to 14 declared fields, including recordType, isLive, status, hostUsername, liveTitle and currentViewers. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it costs

    TikTok LIVE Room Status & Chat Capture Tool uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 8 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredWhat to collect. 'Room status' returns one row per creator (live or offline). 'Live events' attaches to a live room and returns one row per chat/gift/like/follow/share/join/viewer event.Default "roomStatus"; Allowed roomStatus, liveEvents
    usernamesUsernamesarrayTikTok creators to monitor: bare usernames, @handles, profile URLs or LIVE URLs. Duplicates are removed. The prefill checks the National Geographic account.Example ["natgeo"]
    liveUrlsLIVE URLsarrayDirect TikTok URLs such as https://www.tiktok.com/@creator/live (or a profile URL). An alternative to usernames; both lists are merged.
    includeOfflineInclude offline creatorsbooleanWhen on, every valid creator produces a row even when they are not LIVE (status 'offline', with public profile data). This makes scheduled watchlists and the daily test reliable (mode=roomStatus; ignored in live-events mode).Default false; Example true
    includeStreamUrlsInclude stream URLsbooleanAdd the HLS/FLV playback URL map (and its expiry) for LIVE creators (mode=roomStatus). These URLs are signed by TikTok and stop working when the signature or the stream ends.Default true
    connectionDurationConnection duration (seconds)integerHow long to stay attached to each LIVE room and collect events (mode=liveEvents). A short window is enough for a status check; events need a longer window.Default 60; Example 10; Allowed 10 to 3600
    eventCapEvent capintegerStop collecting from a stream after this many events. Applies per stream (mode=liveEvents).Default 500; Example 100; Allowed 1 to 10000
    eventTypesEvent typesarrayWhich event categories to keep (mode=liveEvents). 'All' keeps every category. 'Other' keeps TikTok message types that do not map to a named category.Default ["all"]; Allowed all, chat, gift, like, follow, share, join, stats and 1 more
