    TikTok Hashtag Video Feed & Stats Extractor is an Apify Actor published by Nimbryxo Studio. It accepts 7 input fields, and hashtags is required. Each result can carry up to 16 declared fields, including recordType, searchedHashtag, hashtagName, videoCount, viewCount and source. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it costs

    TikTok Hashtag Video Feed & Stats Extractor uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 7 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    hashtagsHashtagsarray requiredHashtags to collect. Accepts a bare tag, #tag, or a TikTok tag URL. Case-insensitive, duplicates removed. Up to 10.Example ["fitness"]
    modeModestringWhat to collect. 'stats' returns one aggregate row per hashtag (cheapest). 'feed' returns the public hashtag video feed. 'search' returns one page of TikTok keyword/hashtag search results. 'auto' returns stats plus the feed and adds search results only when the feed is shorter than one page.Default "stats"; Allowed stats, feed, search, auto
    maxVideosPerHashtagMax Videos Per HashtagintegerUpper bound on videos per hashtag for feed, search and auto modes (0–300). Use 0 for stats only. TikTok usually returns fewer than requested: the feed is served in pages of about 30 and many tags stop after roughly 100–150 rows.Default 30; Example 0; Allowed 0 to 300
    maxHashtagsMax HashtagsintegerProcess no more than this many hashtags from the list (1–10). Extra hashtags are skipped.Default 10; Allowed 1 to 10
    includeStatsRowInclude Stats RowbooleanEmit the aggregate hashtag stats row before video rows in feed, search and auto modes. Stats mode always emits it.Default true
    regionRegionstringMarket used for the hashtag feed. Only the United States is verified to return a public feed; other markets are not exposed yet.Default "US"; Allowed US
    proxyConfigurationProxy ConfigurationobjectOptional. Leave empty to use the built-in US residential connection with automatic fallback. Set your own Apify proxy configuration here to override it. Feed mode uses the most residential bandwidth, which is billed by Apify proxy usage.
