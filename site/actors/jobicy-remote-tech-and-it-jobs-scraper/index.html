    Jobicy Remote Tech and IT Jobs Scraper is an Apify Actor published by Nimbryxo Studio. It accepts 20 input fields, none of them required at the top level. Each result can carry up to 19 declared fields, including title, companyName, sector, location, jobTypes and levels. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What you can collect”, “Modes”, “Inputs”, “Examples”, “Output” and “Coverage and limits”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (s). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    What it costs

    Jobicy Remote Tech and IT Jobs Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.
