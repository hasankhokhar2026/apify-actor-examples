    LinkedIn Activity Feed Scraper with Engagement Filters is an Apify Actor published by Nimbryxo Studio. It accepts 13 input fields, none of them required at the top level. Each result can carry up to 9 declared fields, including authorName, authorType, postedAt, content, postType and mediaType. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per post”, “Input”, “Use cases”, “Limitations” and “FAQ”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (one public post url). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxPostsPerProfile (default 50, maximum 500) and maxItems (default 1000, maximum 10000) cap how many results a run collects, and so what it costs.

    What it costs

    LinkedIn Activity Feed Scraper with Engagement Filters uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    postUrlsPost URLsarrayPublic LinkedIn post URLs, feed-update URLs, activity URNs or numeric activity IDs. (mode=postUrls)Example ["https://www.linkedin.com/posts/williamhgates_how-better...
    profileUrlsProfile URLsarrayLinkedIn profile URLs or public identifiers, e.g. https://www.linkedin.com/in/williamhgates/ or williamhgates. (mode=profiles)
    companyUrlsCompany URLsarrayLinkedIn company URLs or slugs, e.g. https://www.linkedin.com/company/google/ or google. (mode=companies)
    maxPostsPerProfileMax Posts Per TargetintegerMaximum posts to keep per profile or company. Public profile pages expose about 6-8 recent posts and company home pages 2-10, so larger values do not unlock more history.Default 50; Allowed 1 to 500
    mediaTypeMedia Type FilterarrayOnly keep posts of these media types. Public pages reliably expose text, image, video and article; repost is a pure reshare. Leave empty to keep all.Allowed text, image, video, article, document, carousel, repost, poll and 1 more

    datePostedDate PostedstringKeep posts published within this window, measured from the run time.Default ""; Allowed , r86400, r604800, r2592000
