    Facebook Business Page Finder by Keyword & City is an Apify Actor published by Nimbryxo Studio. It accepts 15 input fields, none of them required at the top level. Each result can carry up to 25 declared fields, including pageName, category, address, followers, recommendPercentage and facebookUrl. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per page”, “Input”, “Cookies and Facebook search”, “Honest limits” and “Scaling”.

    What it costs

    Facebook Business Page Finder by Keyword & City uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 15 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    startUrlsFacebook Page URLsarrayDirect Facebook page URLs to enrich, for example https://www.facebook.com/ozonecoffeeuk. Can be combined with pageIds and searchTerms.Default []; Example [{"url": "https://www.facebook.com/nike"}]
    pageIdsPage IDs or UsernamesarrayFacebook numeric Page IDs, usernames, or page URLs. Numeric IDs are fetched through https://www.facebook.com/<id>.Default []
    searchTermsSearch TermsarrayKeywords for Facebook page discovery, for example Coffee Shop or Dentist. Each term is combined with each location as a text query. Facebook keyword search requires a cookie containing both c_user and xs.Default []
    locationsLocationsarrayCity or region names added to the search query as a soft hint. Facebook does not expose a reliable city filter, so always verify the enriched address. Use strictLocation to drop rows whose address does not contain the location.Default []
    strictLocationStrict Location Post-FilterbooleanDrop pages whose enriched address does not contain the search location. This is a best-effort post-filter, not an exact city boundary.Default false
    categoryFilterCategory FilterarrayKeep pages whose enriched category contains any of these terms (case-insensitive). Filtering happens after enrichment.Default []
    minFollowersMinimum FollowersintegerKeep pages with at least this many followers. Pages with no follower count are dropped when this is above 0.Default 0; Allowed 0 to 100000000
    verifiedOnlyVerified Pages OnlybooleanKeep only pages whose public payload explicitly marks them as verified.Default false
    contactFilterContact FilterstringKeep only lead-ready pages that expose the selected contact field.Default "any"; Allowed any, email, phone, website
    includeReviewsInclude ReviewsbooleanFetch the public reviews tab and include reviews when Facebook exposes them. Adds one request per page. Review coverage is partial.Default true; Example false
    includeFailedPagesInclude Failed PagesbooleanEmit diagnostic rows with errorCode, detailsError, and fieldsFound for pages that cannot be enriched. This prevents silent empty runs.Default true
    failOnEmptyFail When EmptybooleanFail the run when zero page rows are produced. Leave off to finish successfully with diagnostic rows explaining why nothing was found.Default false
    maxItemsMaximum PagesintegerMaximum number of successful page rows. Failed rows do not consume this limit.Default 100; Example 1; Allowed 1 to 5000
    cookiesFacebook Session CookiesstringOptional. Needed only for keyword discovery. c_user and xs are enough. Accepts a JSON array of cookie objects or a raw name=value; name2=value2 Cookie header. Page enrichment works without cookies.
    proxyConfigurationProxy ConfigurationobjectUsed only for keyword discovery. Defaults to Apify residential proxy because Facebook search blocks datacenter IPs. Public page enrichment does not use it.Default {"useApifyProxy": true, "apifyProxyGroups": ["RESIDENTIAL"]}
