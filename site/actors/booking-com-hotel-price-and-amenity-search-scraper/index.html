    Booking.com Hotel Price & Amenity Search Scraper is an Apify Actor published by Nimbryxo Studio. It accepts 21 input fields, none of them required at the top level. Each result can carry up to 45 declared fields, including name, price, pricePerNight, currency, rating and reviewCount. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    Search Booking.com for a destination and travel dates, or paste hotel links directly, and get one row per property with the stay price, room and rate options, guest scores, review subscores, facilities, photos, description and booking policies.

    What this actor does

    • Search mode runs a Booking.com destination search for your dates, guests and filters, then scrolls and clicks Load more results to go beyond the first page. It collects up to 250 properties per run.
    • Details mode loads Booking.com hotel URLs you provide and returns the same rich row for each one.
    • Solves Booking.com's AWS WAF challenge once in a browser, then reuses the session cookie over HTTP for the rest of the run. If a detail request is challenged again, the actor refreshes the cookie and falls back to the browser for that page.
    • Applies Booking.com's own filters for property type, review score, stars, free cancellation, breakfast, pool and nightly price.
    • Returns the cheapest room-table price for the whole stay, plus every room and rate option when includeRooms is on.
    • Optionally renders each hotel in a browser to collect the complete facility list, not just the headline amenities.
    • If some detail pages fail, the run finishes with a PARTIAL warning and keeps the search rows instead of failing the whole run.

    Use cases

    • Price comparison — compare stay totals for the same dates across a destination
    • Rate tracking — schedule runs to watch prices and discounts move
    • Room-level analysis — compare room types, breakfast and cancellation terms
    • Travel apps and spreadsheets — feed structured hotel data into your own tools
    • Market research — analyse ratings, review subscores and facilities by city or property type

    Questions

    Do I need a Booking.com account?

    No. The actor reads public hotel and search pages. It solves the site's technical challenge without you providing cookies or a login.

    Why does the first request take longer?

    Booking.com uses an AWS WAF JavaScript challenge. The actor opens one browser page to solve it, then reuses the resulting cookie over HTTP. That bootstrap is a few seconds per run.

    What does price mean?

    It is the cheapest total for the whole stay, for the dates, guest count and room count in your input. pricePerNight divides that total by the number of nights. Use originalPrice when Booking.com shows a strike-through price.

    Why do some prices differ from the search card?

    The search card can show a promotional or selected-room price. The detail parser takes the cheapest valid room-table price, which is the same number Booking.com uses for the cheapest rate on that page.

    Why is fullAmenities missing?

    It is only collected when includeFullAmenities is on. That setting renders a hotel page in a browser, so it is slower and costs more than the default HTTP-only detail fetch.

    What happens when Booking.com blocks the run?

    The actor fails with a BLOCKED status instead of returning an empty dataset. If only some detail pages fail, it finishes with a PARTIAL status and keeps the rows it did collect.

    What happens when a search has no results?

    A valid search with no matches fails with NO_RESULTS, so you can tell it apart from a block. Loosen your filters or check the destination spelling.

    How many results can I get?

    Set maxItems up to 250. Booking.com loads 25 cards at a time and exposes a "Load more results" button; the actor scrolls and clicks it until your cap or the page stops growing. Booking.com itself caps a single query at about 1,000 results.

    Are prices and availability live?

    Yes. They are captured when the actor runs and can change as availability changes.

    Is this affiliated with Booking.com?

    No. This is an independent third-party actor that reads publicly available Booking.com pages.
