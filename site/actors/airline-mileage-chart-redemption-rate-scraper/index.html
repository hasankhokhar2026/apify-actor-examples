    Airline Mileage Chart Redemption Rate Scraper is an Apify Actor published by Nimbryxo Studio. It accepts 13 input fields, and originRegion and destinationRegion are required. Each result can carry up to 29 declared fields, including recordType, issuer, issuerName, originRegion, destinationRegion and originZone. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Supported live charts”, “Output per rate”, “Input”, “Status and provenance” and “Region mapping and native zones”.

    What it costs

    Airline Mileage Chart Redemption Rate Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    All 13 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    originRegionOrigin regionstring requiredMacro region the trip departs from. Native chart zones are mapped onto these regions and are also returned in originZone/destinationZone.Default "north_america"; Allowed north_america, south_america, europe, africa, middle_east, asia, oceania
    destinationRegionDestination regionstring requiredMacro region the trip ends in.Default "europe"; Allowed north_america, south_america, europe, africa, middle_east, asia, oceania
    cabinCabin classstringCabin to return. Charts that do not publish a cabin are skipped for that request rather than estimated.Default "business"; Allowed economy, premium, business, first
    issuersLoyalty programs (issuers)arrayLive chart adapters: aeroplan, anaMileage, jal, lufthansa, qantas, singaporeKrisflyer, turkishMilesAndSmiles. Legacy issuer keys from saved tasks are still accepted and produce an explicit chart_status record instead of failing input validation.Default ["lufthansa"]
    oneWayOne-way ratebooleanReturn one-way rates. Charts published as round-trip are halved and the derived field is named in derivedFields.Default false
    partnerOnlyPartner redemption onlybooleanKeep only rows for partner-operated awards. Programs whose chart is entirely partner-based return all their rows.Default false
    maxResultsMax mileage rowsintegerCap on pushed mileage_chart rows. Status records do not count toward this cap.Default 5; Allowed 1 to 1000
    distanceMilesFlight distance (miles)integerOptional distance filter for distance-priced charts (Aeroplan and Qantas Classic). Zone-priced charts ignore it because their price does not depend on distance.Allowed 0 to 50000

    destinationZoneNative destination zone containsstringOptional case-insensitive text match on the issuer's own destination zone, e.g. "North America" or "Europe".
    awardTypeAward typestringOptional filter on the published award product. Choose "any" to keep every product.Default "any"; Allowed any, fixed_chart, saver, advantage, classic, partner_classic, oneworld_classic, emirates_classic and 4 more
    fallbackModeFallback when a live fetch failsstringlive_only never reuses old data. snapshot replays the most recent successful parse cached in this actor's key-value store, marked verificationStatus=static_snapshot.Default "live_only"; Allowed live_only, snapshot
