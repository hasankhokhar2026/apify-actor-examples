    Airline Mileage Chart Redemption Rate Scraper is an Apify Actor published by Nimbryxo Studio. It accepts 7 input fields, and originRegion and destinationRegion are required. Each result can carry up to 13 declared fields, including issuer, issuerName, originRegion, destinationRegion, cabin and miles. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    Most frequent-flyer programs publish a fixed mileage chart showing how many miles (plus taxes) a redemption costs between two regions — separate from the live seat-availability search. This actor reads those published charts directly from each program's own page and returns one row per chart rate, so you can compare redemption cost across programs without opening a dozen airline websites.

    What this actor does

    • Looks up published award-chart rates between an origin and destination region for the loyalty programs you select.
    • Filters results by cabin class, one-way vs. roundtrip, and partner-only redemptions.
    • Returns the miles cost, tax estimate, and any chart notes (e.g. distance band) exactly as published by the program.
    • Cleanly skips any selected program whose chart isn't implemented yet, without emitting placeholder rows for it.
    • Fields a given program's chart doesn't publish (e.g. a one-way rate, or a partner name) are left out of that row.

    Use cases

    • Redemption comparison — see which program charges the fewest miles for the same route and cabin before booking.
    • Travel-hacking content — source up-to-date published chart values for blog posts, spreadsheets, or redemption calculators.
    • Points valuation — combine miles and taxes_min_usd/taxes_max_usd with a program's point value to estimate true redemption cost.
    • Partner-award research — set partnerOnly: true to focus on the partner-airline rates that are often cheaper or open up routes the issuer doesn't fly itself.

    Questions

    Is this live seat availability?

    No. It's the published mileage chart — the fixed miles-and-taxes rate a program advertises for a region pair and cabin, not a live search for bookable award seats on a specific date.

    Why did some of my selected programs return no rows?

    A few programs listed in the issuers input aren't implemented yet (see the list above); they're skipped cleanly rather than returning empty or fake rows.

    Why is sourceUrl included?

    So you can open the exact page a rate was read from and confirm it against the program's own published chart.

    What does partnerOnly: true change?

    It keeps only rows for redemptions on a partner airline rather than the issuer's own flights, for programs that publish a distinct partner rate.

    Why do some rows have milesOneWay and others don't?

    Only programs that publish a separate one-way chart value populate milesOneWay; others publish roundtrip-only pricing.

    Does maxResults limit results per program or overall?

    It's a hard cap on the total number of rows returned across every selected program.

    Will re-running this actor pick up a chart change the same day a program updates it?

    Not necessarily. Each program's rates are a snapshot of its published chart rather than a page fetched fresh on every run, so a same-day change on the program's own site may not be reflected until the snapshot is refreshed. Use sourceUrl to confirm the current published rate.

    Is this affiliated with any airline or loyalty program?

    No. This actor reads publicly published mileage charts and is not affiliated with or endorsed by any airline, alliance, or frequent-flyer program named above.

    Limits and notes

    Supported loyalty programs

    Chart data is currently implemented for: Air Canada Aeroplan (aeroplan), Alaska Mileage Plan (alaska), American AAdvantage (american), ANA Mileage Club (anaMileage), British Airways Avios (britishAirways), Emirates Skywards (emirates), Air France/KLM Flying Blue (flyingBlue), Avianca LifeMiles (lifemiles), Lufthansa Miles & More (lufthansa), Qatar Privilege Club (qatar), Singapore KrisFlyer (singaporeKrisflyer), United MileagePlus (united), and Virgin Atlantic Flying Club (virginAtlantic).

    The input also lists Aeromexico Club Premier, Azul TudoAzul, Copa ConnectMiles, Delta SkyMiles, Etihad Guest, Finnair Plus, JAL Mileage Bank, Qantas Frequent Flyer, SAS EuroBonus, and Turkish Miles&Smiles for forward compatibility — selecting one of these today simply returns no rows for that program, with no effect on the others you selected.
