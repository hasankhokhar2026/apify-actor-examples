    Google Earth Location Coordinate Finder is an Apify Actor published by Nimbryxo Studio. It accepts 3 input fields, and searchQueries is required. Each result can carry up to 9 declared fields, including place_name, google_place_id, latitude, longitude, description and search_query. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    Turn a place name or address into precise coordinates the way Google Earth itself resolves it. Give it a list of queries — landmarks, addresses, business names — and get back the latitude/longitude, place name, a short description when one exists, and Google's internal place ID for each one. No Google Maps API key needed.

    What this actor does

    • One result per query — returns Google Earth's own top-ranked match for each search term
    • Precise coordinates — latitude and longitude as resolved by Google Earth's location search, not an approximate geocoder
    • Place identity — place name, short description (when Google Earth has one) and Google's internal place ID
    • Configurable pacing — set a random delay range between queries
    • Empty fields are omitted from every record; a query that doesn't resolve to a location produces no record at all

    Use cases

    • GIS data collection — bulk-resolve a list of place names into coordinates for mapping
    • Travel research — get exact coordinates for landmarks before planning routes or itineraries
    • Location intelligence — attach Google's place ID and coordinates to a list of business names or addresses
    • Dataset enrichment — add latitude/longitude to records that only have a place name
    • Franchise mapping — resolve multiple locations of the same chain into individual coordinate records

    Questions

    What's the data source?

    Google Earth's own location search, the same lookup used when you type a place into Google Earth's search box.

    Do I need a Google Maps API key?

    No, this actor doesn't use the Google Maps API at all.

    Why did a query return no record?

    Google Earth genuinely couldn't resolve that query to a location — a typo, an overly vague query, or a place Google Earth doesn't recognize.

    Can one query return multiple results?

    No — each query returns at most one record, Google Earth's own top match for that search term. For multiple locations of the same name (e.g. franchise branches), submit more specific queries like "KFC New York" and "KFC Los Angeles".

    Why would description or google_place_id be missing?

    Those fields are only included when Google Earth's response actually provides them; many places have coordinates and a name but no short description or place ID.

    What's the difference between the two data_source values?

    search_api means the coordinates came directly from Google Earth's own search response; url_fallback means they were read from the map URL after navigation when that response wasn't captured in time. Both reflect real, resolved locations.

    Is this affiliated with Google?

    No. This is an independent, third-party actor that reads Google Earth's public location search; it is not operated by or affiliated with Google.
