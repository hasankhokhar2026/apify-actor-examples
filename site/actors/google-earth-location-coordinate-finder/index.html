    Google Earth Location Coordinate Finder is an Apify Actor published by Nimbryxo Studio. It accepts 10 input fields, and mode is required. Each result can carry up to 11 declared fields, including place_name, google_place_id, latitude, longitude, elevation_meters and description. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Input”, “Output per location”, “Use cases”, “FAQ” and “Limitations”.

    What you get

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (landmarks). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 100, maximum 10000) and maxResultsPerQuery (default 1, maximum 200) cap how many results a run collects, and so what it costs.

    What it costs

    Google Earth Location Coordinate Finder uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 10 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredChoose whether to search by text or resolve Google Earth URLs. (mode=search / mode=byUrls)Default "search"; Allowed search, byUrls
    searchQueriesSearch queriesarrayPlace names, addresses, postal codes or coordinate strings to search on Google Earth. (mode=search) Each query returns one result by default; raise 'Results per query' to collect more. Use specific queries such as 'KFC New York' for a particular branch.Example ["Eiffel Tower"]
    startUrlsGoogle Earth URLsarrayPublic earth.google.com/web URLs to resolve. A URL can contain a search text, a resolved view with coordinates and a data token, or both. URLs with a data token also unlock the place knowledge card (address, website, Wikipedia, photos and opening hours). (mode=byUrls)
    maxItemsMaximum recordsintegerGlobal cap on the number of location records saved across all queries or URLs.Default 100; Example 1; Allowed 1 to 10000
    maxResultsPerQueryResults per queryintegerHow many Google Earth matches to save for each search query. The default of 1 keeps the exact-name match. Raise it to collect every ranked match; the 'rank' field preserves Google's original order.Default 1; Allowed 1 to 200
    languageLanguagestringLanguage used for place names, descriptions and details returned by Google Earth.Default "en"; Allowed en, ar, bn, cs, da, de, el, es and 24 more
    searchAreaSearch area (viewport)objectOptional north/south/east/west bounding box that biases Google Earth's ranking toward a region. Leave it unset to search worldwide. All four bounds are recommended; missing bounds fall back to the world.
    includeAddressMatch addressesbooleanAdd a street address when Google's suggestion results identify the same place unambiguously. Adds one lightweight request per query.Default true; Example false
    includeElevationTerrain elevationbooleanAdd terrain elevation in metres above sea level for every resolved coordinate, using Google Earth's public elevation service.Default true; Example false
    includeKmlGenerate KMLbooleanAdd a ready-to-import KML Placemark string to every record. Useful for opening the results in Google Earth, QGIS or other GIS tools.Default false
