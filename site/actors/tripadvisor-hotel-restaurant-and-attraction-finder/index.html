    TripAdvisor Hotel, Restaurant & Attraction Finder is an Apify Actor published by Nimbryxo Studio. It accepts 14 input fields, none of them required at the top level. Each result can carry up to 24 declared fields, including recordType, name, title, type, rating and reviewCount. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “Modes”, “Place fields”, “Review fields”, “Input”, “Examples” and “How search works”.

    What it costs

    TripAdvisor Hotel, Restaurant & Attraction Finder uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 14 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestringsearch finds ranked places from a query; details reads one place per URL or ID; reviews exports review rows with optional filters.Default "search"; Allowed search, details, reviews
    querySearch querystringWhat to search for, for example 'hotels in New York', 'restaurants Paris' or 'Eiffel Tower'. The place family is inferred from words such as hotels, restaurants, museums or things to do.Example "Eiffel Tower"
    locationLocationstringOptional destination used with query, for example 'New York' or 'Paris'. When set, query can be just 'hotels' or 'restaurants'.
    startUrlsPlace URLs or IDsarrayTripadvisor place URLs (Hotel_Review, Restaurant_Review or Attraction_Review) or numeric location IDs. Used by details and reviews modes.
    maxItemsMaximum placesintegerMaximum search results, detail places, or review target places to process. One place can return many reviews.Default 20; Example 1; Allowed 1 to 500
    includeDetailsEnrich place detailsbooleanFetches amenities and a larger photo for place rows. HTML enrichment is used in details mode when the JSON fields are missing.Default true; Example false
    maxReviewsMaximum reviews per placeintegerReviews to collect for each target place in reviews mode. Upstream returns 20 per request; the actor paginates until this cap.Default 20; Allowed 1 to 500
    reviewSortReview sortstringOrder of the review stream. Attractions automatically use DETAILED for MOST_RECENT so product reviews do not mix into the attraction's own reviews.Default "MOST_RECENT"; Allowed MOST_RECENT, MOST_HELPFUL, DETAILED
    reviewRatingReview ratingstringOnly return reviews with this bubble rating.Default "ANY"; Allowed ANY, 1, 2, 3, 4, 5
    reviewLanguageReview languagestringOnly return reviews written in this language.Default "ANY"; Allowed ANY, en, es, de, fr, it, pt, nl and 33 more
    reviewTripTypeTraveler typestringOnly return reviews from this traveler type.Default "ANY"; Allowed ANY, FAMILY, COUPLES, SOLO, BUSINESS, FRIENDS
    reviewMonthMonth of visitstringOnly return reviews submitted in this month.Default "ANY"; Allowed ANY, JANUARY, FEBRUARY, MARCH, APRIL, MAY, JUNE, JULY and 5 more
    reviewKeywordReview keywordstringOnly return reviews whose text matches this keyword, for example 'pool' or 'breakfast'.
    proxyConfigurationProxy configurationobjectOptional. The actor tries direct access first, then the free Apify datacenter proxy, and only escalates after a real block. You do not need to configure a proxy to run it.
