    WebsiteClosers Business-for-Sale Listings Scraper is an Apify Actor published by Nimbryxo Studio. It accepts 23 input fields, and mode is required. Each result can carry up to 8 declared fields, including title, dealStatus, askingPrice, cashFlow, revenue and yearEstablished. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What it does”, “Input”, “Output”, “How filters behave”, “Backward compatibility” and “FAQ and limits”.

    What it costs

    WebsiteClosers Business-for-Sale Listings Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    sortSort bystringOrder of the result list.Default "newest"; Allowed newest, priceDesc, priceAsc, cashFlowDesc, cashFlowAsc, revenueDesc, revenueAsc
    searchScopeSearch scope (mode=search)stringSearch live listings, sold deals, or both. 'Both' spends about half the result budget on live deals first, then fills the rest from the sold archive.Default "live"; Allowed live, sold, both
    sbaOnlySBA pre-qualified onlybooleanKeep only listings whose title or description says SBA pre-qualified or pre-approved.Default false
