    Facebook Ad Library Byline & Advertiser Ad Finder is an Apify Actor published by Nimbryxo Studio. It accepts 21 input fields, and mode is required. Each result can carry up to 55 declared fields, including ad_id, page_name, ad_text, start_date, status and media_type. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per ad”, “Input”, “Use cases”, “FAQ” and “Limitations”.

    What it costs

    Facebook Ad Library Byline & Advertiser Ad Finder uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 21 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredWhat to scrape. Leave empty to process every target list you filled in (searchTerms, pageIds, adIds, bylines) in one run.Default ""; Example "search"; Allowed , search, byPage, byAdId, byByline
    searchTermsSearch TermsarrayKeywords to search for in the Ad Library, one search per term. Example: ["coffee", "nike"].Default []; Example ["coffee"]
    pageIdsPage IDs / Advertiser SearcharrayFacebook Page IDs to fetch all ads from (numeric IDs, or URLs containing view_all_page_id= or profile.php?id=). Each page is searched separately.Default []
    adIdsDirect Ad IDsarrayAd Library IDs to fetch directly (numeric IDs or Ads Library URLs containing ?id=). All other filters are ignored in this mode.Default []
    bylinesSearch by "Paid for by" namearrayFunding-entity / committee names from the "Paid for by" disclaimer on political and issue ads. The actor tries the exact-cased name, retries the original casing, and re-checks each returned ad's byline client-side. Non-EU targets search the political & issue archive; EU/EEA targets use the all-ad-types EU DSA stream (the political archive returns zero there) and may return no byline match because Meta does not always expose it.Default []
    countryCountrystringCountry to search ads in, or ALL for every country. Ignored when the Countries multi-select below is set.Default "ALL"; Allowed ALL, AF, AL, DZ, AS, AD, AO, AI and 209 more
    countriesCountries (multi-select)arrayOne or more country codes, searched together as a union (unlike the single Country field). Takes precedence over Country when set.Default []; Allowed ALL, AF, AL, DZ, AS, AD, AO, AI and 209 more
    adActiveStatusAd StatusstringFilter by ad active status.Default "active"; Allowed all, active, inactive
    adTypeAd TypestringFilter by ad category. Note: the political-and-issue archive excludes EU/EEA countries, so EU political searches automatically use All Types (EU transparency stream).Default "all"; Allowed all, political_and_issue_ads, housing, employment, credit
    mediaTypeMedia TypestringFilter by the ad's creative media type. meme is applied server-side only; Meta's payload has no meme marker, so output media_type is always image, video or none.Default "all"; Allowed all, image, video, meme, none
    publisherPlatformsPublisher PlatformsarrayOnly return ads shown on these platforms. Leave empty for all platforms.Default []; Allowed FACEBOOK, INSTAGRAM, MESSENGER, AUDIENCE_NETWORK, WHATSAPP, THREADS
    contentLanguagesAd Content LanguagesarrayOnly return ads whose creative is written in one of these languages. 2-letter ISO 639-1 codes; leave empty for every language.Default []; Allowed aa, ab, ae, af, ak, am, an, ar and 175 more
