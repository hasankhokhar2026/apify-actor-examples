    Google Image Search Results & Metadata Scraper is an Apify Actor published by Nimbryxo Studio. It accepts 15 input fields, none of them required at the top level. Each result can carry up to 29 declared fields, including query, position, engine, imageUrlType, title and sourceDomain. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Google-first with labelled fallback”, “Output fields”, “Input”, “Example input” and “How to read a run”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 29 fields in 2 dataset views. Fields without a value can be left out of a record.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (example input). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxResults (default 100, maximum 500) caps how many results a run collects, and so what it costs.

    What it costs

    Google Image Search Results & Metadata Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 15 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    queriesSearch queriesarrayOne or more image search queries. Each query is searched independently. Google operators such as site:, quoted phrases and -exclusions are passed through. The legacy single query key is still accepted by the actor code.Example ["Alfons Mucha"]
    maxResultsMax results per queryintegerMaximum number of image rows to return for each query. Google Images usually runs out around 300-400 results for a query; this is a ceiling, not a guarantee.Default 100; Example 3; Allowed 1 to 500
    minWidthMinimum image widthintegerDrop images narrower than this many pixels. Rows without published dimensions are dropped when this is set. 0 disables the filter.Default 0; Allowed 0 to 10000
    minHeightMinimum image heightintegerDrop images shorter than this many pixels. Rows without published dimensions are dropped when this is set. 0 disables the filter.Default 0; Allowed 0 to 10000
    countryCountrystringTwo-letter country used for Google's gl parameter (and Bing's cc parameter). Local sites rank higher in local results.Default "US"; Allowed US, GB, CA, AU, DE, FR, ES, IT and 256 more
    languageLanguagestringInterface and result language used for Google's hl parameter (and Bing's setlang parameter).Default "en"; Allowed en, es, de, fr, pt, pt-BR, it, nl and 179 more
    safeSearchSafe searchstringGoogle SafeSearch level. 'active' filters explicit images; 'off' does not.Default "active"; Allowed active, off
    imageSizeImage sizestringGoogle Images size filter. The MP values are minimum megapixels. Bing fallback applies the nearest size category and enforces the exact MP floor locally when dimensions are known.Default ""; Allowed , large, medium, icon, 2mp, 4mp, 8mp, 12mp and 3 more
    imageColorImage colorstringGoogle Images color filter. 'black_and_white' is grayscale; 'transparent' looks for a transparent background.Default ""; Allowed , color, black_and_white, transparent, red, orange, yellow, green and 8 more
    imageTypeImage typestringGoogle Images type filter: photographs, faces, clip art, line drawings or animated images.Default ""; Allowed , photo, face, clipart, lineart, animated
    fileTypeFile typestringOnly images in this format. Google applies this server-side; Bing fallback applies it to the image URL extension locally.Default ""; Allowed , jpg, png, gif, bmp, svg, webp, ico
    timeRangeTime rangestringOnly images Google found within this period. Bing fallback maps 'hour' to its 24-hour window.Default ""; Allowed , hour, day, week, month, year
    usageRightsUsage rightsstringGoogle's usage-rights labels. These are Google's labels, not a legal guarantee; check the licence on the source page before reuse.Default ""; Allowed , free_to_use_or_share, free_to_use_or_share_commercially, free_to_use_share_or_modify, free_to_use_share_or_modify_commercially
    googleOnlyGoogle onlybooleanWhen true, a failed or empty Google search fails that query with a clear status instead of using another engine. The default is false so legacy saved tasks keep working; set this true for a strict Google-only contract.Default false
    enableFallbackEnable labelled fallbackbooleanWhen googleOnly is false, allow labelled Bing Images and then DuckDuckGo Images. Every fallback row carries engine, isFallback=true and fallbackReason.Default true
