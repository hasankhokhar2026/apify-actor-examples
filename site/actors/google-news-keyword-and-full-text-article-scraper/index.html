    Google News Keyword & Full-Text Article Scraper is an Apify Actor published by Nimbryxo Studio. It accepts 16 input fields, and mode is required. Each result can carry up to 11 declared fields, including query, title, source, domain, publishedAt and url. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per article”, “Input”, “Examples”, “Use cases” and “FAQ”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 11 fields in 3 dataset views, and the README documents 4 more. Fields without a value can be left out of a record.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (keyword scan, fastest mode). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxResultsPerQuery (default 20, maximum 100), maxItems (default 500, maximum 5000) and maxFullText (default 100, maximum 500) cap how many results a run collects, and so what it costs.

    What it costs

    Google News Keyword & Full-Text Article Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 16 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredWhat to scrape. Each mode reads its own list field below.Default "keyword"; Allowed keyword, topic, newsUrl, rss, articleUrls
    queriesSearch queries (mode=keyword)arrayOne or more keyword queries. Google operators such as site:, intitle: and OR are supported. Results are deduplicated across queries.Default []; Example ["artificial intelligence"]
    topicsTopics (mode=topic)arrayTopic names (WORLD, NATION, BUSINESS, TECHNOLOGY, ENTERTAINMENT, SPORTS, SCIENCE, HEALTH), TOP for top stories, Google News topic hashes/section URLs, or topic URLs. Topic feeds ignore server-side date filters; results are filtered after download.Default []
    newsUrlsGoogle News URLs (mode=newsUrl)arrayGoogle News search URLs, topic URLs, RSS search/topic URLs, or RSS/Atom feed URLs to convert into a feed.Default []
    rssUrlsRSS / Atom feeds (mode=rss)arrayAny public RSS or Atom feed. Google News links inside the feed are resolved to publisher URLs automatically.Default []
    articleUrlsArticle URLs (mode=articleUrls)arrayPublisher article URLs or Google News article URLs. Every page is fetched and full text is extracted, with a per-record status when a publisher blocks or paywalls it.Default []
    languageLanguagestringLanguage of the Google News edition. Combined with country in the edition token (for example US:en, DE:de, JP:ja).Default "en"; Allowed en, de, fr, es, it, pt, nl, pl and 66 more
    countryCountry / editionstringCountry edition for Google News. The actor always pins the edition so results do not change with the machine's IP.Default "US"; Allowed US, GB, CA, AU, NZ, IE, IN, PK and 91 more
    dateRangeDate rangestringRecency window. Every item is post-filtered by its real publication time, so items newer than the window never leak. 'custom' uses startDate/endDate. Multi-day ranges can be walked day by day to collect more than one feed page.Default "any"; Allowed any, 1h, 6h, 12h, 1d, 7d, 30d, 1y and 1 more
    startDateStart datestringCustom range start (YYYY-MM-DD, inclusive). Also used when dateRange=custom.
    endDateEnd datestringCustom range end (YYYY-MM-DD, inclusive). Items published after the end are dropped client-side.
    maxResultsPerQueryMax results per query windowintegerMaximum records taken from each Google News feed request (1-100, Google's own cap is about 100). When a date range spans several days, the actor walks day windows and can collect more than 100 for one query, up to maxItems.Default 20; Example 3; Allowed 1 to 100
