    Google Maps Photo Gallery Extractor by Category is an Apify Actor published by Nimbryxo Studio. It accepts 11 input fields, and mode is required. Each result can carry up to 42 declared fields, including recordType, photoId, photoIndex, photoUrl, thumbnailUrl and businessName. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per media item”, “Input”, “Use cases” and “FAQ”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 42 fields in 1 dataset view. Fields without a value can be left out of a record.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (a batch of place links). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxPlacesPerQuery (default 20, maximum 100) and maxPhotos (default 100, maximum 10000) cap how many results a run collects, and so what it costs.

    What it costs

    Google Maps Photo Gallery Extractor by Category uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 1 GB, so a run starts with 1 start event, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 11 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredChoose whether to read photos for specific places or to search for places first.Default "place"; Allowed place, search
    placeUrlsPlace URLs or IDsarrayGoogle Maps place links, share links, Place IDs (ChIJ...), feature IDs (0x...:0x...), numeric CIDs, or business names. Used when mode is place.Default []; Example ["https://www.google.com/maps/place/Empire+State+Building...
    searchQueriesSearch queriesarrayPlaces to find, for example "coffee shops in New York". Include a city or area for precise matches. Used when mode is search.Default []
    maxPlacesPerQueryMax places per queryintegerMaximum number of places to take from each search query (1-100).Default 20; Example 3; Allowed 1 to 100
    maxPhotosMax media per placeintegerMaximum number of photos and videos to return for each place (1-10000). The actor stops earlier when Google's public sample ends.Default 100; Example 1; Allowed 1 to 10000
    photoCategoryMedia filterstringChoose which media to return. Owner and visitor filters read each photo's public contributor and only return media whose owner/visitor status is known.Default "all"; Allowed all, photos, videos, by_owner, by_visitors, street_view
    enrichDetailsInclude photo detailsbooleanRead the contributor name and profile, exact upload date, caption, video download link and video length when Google publishes them.Default true; Example false
    languageLanguagestringLanguage for place names, categories and dates.Default "en"; Allowed en, es, fr, de, it, pt, pt-BR, ja and 15 more
    imageSizeImage sizestringResolution for the main photo URL. Thumbnail is about 200 px, medium about 800 px, large about 1600 px, original is the largest Google serves.Default "original"; Allowed original, large, medium, thumbnail
    minWidthMinimum width (px)integerDrop media narrower than this. Set to 0 to keep every width.Default 0; Allowed 0 to 100000
    minHeightMinimum height (px)integerDrop media shorter than this. Set to 0 to keep every height.Default 0; Allowed 0 to 100000
