    Y Combinator Company Lookup with Size & Hiring Filters is an Apify Actor published by Nimbryxo Studio. It accepts 35 input fields, and directoryUrl is required. Each result can carry up to 15 declared fields, including name, slug, batch, batchLong, industry and stage. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Data source”, “Input”, “Output per company”, “How the directory is fetched” and “Limitations”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (active fintechs launched after 2020 with open jobs). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 3, maximum 10000) caps how many results a run collects, and so what it costs.

    What it costs

    Y Combinator Company Lookup with Size & Hiring Filters uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 35 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    directoryUrlDirectory URLstring requiredY Combinator directory URL. Paste a pre-filtered URL (e.g. https://www.ycombinator.com/companies?batch=S24&industry=AI) to apply its query-string filters. Defaults to the full directory.Default "https://www.ycombinator.com/companies"
    companyUrlsCompany URLsarrayDirect YC company profile URLs, e.g. https://www.ycombinator.com/companies/airbnb. Each URL is fetched independently of the directory search.Default []
    companySlugsCompany slugsarrayDirect YC company slugs, e.g. airbnb, stripe. Use this instead of URLs when you already have slugs.Default []
    querySearch querystringFree-text search across company names, descriptions and tags. Leave empty to browse the directory by filters only.
    batchesBatchesarrayYC batches, either short codes or full names: S24, W24, F24, SP25, or Summer 2024. Leave empty for every batch. All batches are fetched when you need more than 1,000 companies.Default []
    industriesIndustriesarrayExact YC industry values, e.g. B2B, Consumer, Fintech, Healthcare, Industrials. Values are matched against YC's industry facet.Default []
    subIndustriesSub-industriesarrayExact or leaf sub-industry values, e.g. Infrastructure, Productivity, or 'Consumer -> Travel, Leisure and Tourism'.Default []
    statusesStatusesarrayCompany operating status: Active, Inactive, Acquired, Public. Leave empty for all statuses.Default []
    stagesStagesarrayFunding stage: Early or Growth. YC's index does not expose stage as a facet, so this filter is applied to each fetched record.Default []
    regionsRegionsarrayExact YC region values, e.g. Europe, America / Canada, Remote, Fully Remote. Also accepts a free-text location match.Default []
    tagsTagsarrayExact YC tags, e.g. AI, B2B, SaaS, Fintech, Developer Tools. Any one match is enough.Default []
    teamSizeMinMinimum team sizeintegerDrop companies with fewer employees than this. Uses YC's numeric team-size field.Allowed 0 to 100000
