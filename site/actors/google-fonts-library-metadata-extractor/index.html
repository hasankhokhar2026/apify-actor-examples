    Google Fonts Library Metadata Extractor is an Apify Actor published by Nimbryxo Studio. It accepts 15 input fields, and mode is required. Each result can carry up to 20 declared fields, including family, category, isVariable, weights, subsets and designers. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per font family”, “Output per icon (mode = "icons")”, “Optional license & attribution fields (includeLicense)”, “Optional self-hosting fields (includeFiles)” and “Output per error (recordType = "error")”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 20 fields in 2 dataset views, and the README documents 23 more. Fields without a value can be left out of a record.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (look up specific families). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 5000, maximum 5000) and maxFilesPerFamily (default 200, maximum 1000) cap how many results a run collects, and so what it costs.

    What it costs

    Google Fonts Library Metadata Extractor uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 512 MB, so a run starts with 1 start event, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 15 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredWhat to fetch from Google Fonts. icons fetches the separate Material icon metadata document once and emits icon records; it does not return font-family records.Default "byFamily"; Allowed byFamily, byCategory, listAll, icons
    familiesFont families (mode=byFamily)arrayFont family names, e.g. Roboto, Open Sans, Lora, Playfair Display. Case-insensitive; displayName aliases and duplicates are handled. Defaults to Roboto when empty.Default ["Roboto"]
    categoryCategory (mode=byCategory)stringFilter the library to a single font category. Defaults to Sans Serif when empty. An unknown category emits a typed invalid_category error record.Default "Sans Serif"; Allowed Sans Serif, Serif, Display, Handwriting, Monospace
    maxItemsMax itemsintegerHard cap on records emitted per run (1-5000). Defaults to 5000 so the whole font catalog (~1,959 families) fits without truncation. The icon endpoint currently reports about 6,139 icons, so icons mode can truncate at the cap.Default 5000; Example 3; Allowed 1 to 5000
    searchSearch textstringFree-text search over family, display name, category, classifications, subsets, designers, and primary script/language. In icons mode it searches icon name, categories, tags, and supported families. All space-separated tokens must match.Default ""
    subsetsLanguage subsetsarrayOnly keep families that include every listed subset, e.g. latin, cyrillic, greek, vietnamese. The synthetic menu subset is present on every family.Default []
    designersDesignersarrayOnly keep families whose designer/foundry list contains every listed value (case-insensitive substring match).Default []
    variableOnlyVariable fonts onlybooleanKeep only families that ship a variable font with one or more axes.Default false
    colorOnlyColor fonts onlybooleanKeep only families with color font capabilities (COLRV0/COLRV1/OTSVG).Default false
    brandOnlyGoogle-branded flag onlybooleanKeep only families where the upstream isBrandFont flag is true. In the current catalog this flag equals isNoto; it is not a generic brand filter.Default false
    notoOnlyNoto families onlybooleanKeep only families in the Noto collection.Default false
    sortBySort bystringOrder the matched families. popularity and trending are sparse upstream snapshot ranks where lower is better (not dense 1..N positions); dateAdded and lastModified put newest first. In icons mode only popularity and name change the order; other values keep upstream order.Default "default"; Allowed default, popularity, trending, dateAdded, lastModified, name, defaultSort
    includeLicenseInclude license & attributionbooleanEnrich each family with license, license URL, copyright, source repository, source date, languages, unicode coverage, and description. Uses the per-family metadata endpoint, then METADATA.pb, then the download manifest. Off by default; enable it to add these fields. Raw API calls that omit the key retain the legacy byFamily auto-enable. The catalog-level languages array is always empty upstream, so languages can only come from this per-family enrichment. Ignored in icons mode.Default false
    includeFilesInclude font file URLsbooleanFetch the full CSS2 stylesheet (woff2/unicode-range) and the download manifest (TTF URLs). Capped by maxFilesPerFamily. CSS2 output depends on the user agent: the actor requests a modern Chrome UA and retries once with Safari when Chrome receives only TTF. Large CJK families can exceed the file cap. Off by default; enable it to add these fields. Raw API calls that omit the key retain the legacy byFamily auto-enable. Ignored in icons mode.Default false
    maxFilesPerFamilyMax files per familyintegerCap applied separately to fontFiles (CSS2) and ttfFiles (manifest). CJK families can expose hundreds of files; for example M PLUS 1p has 882 CSS2 blocks, so the 200 default truncates it and filesTruncated is set. Raise to 1000 to keep them all.Default 200; Example 10; Allowed 1 to 1000
