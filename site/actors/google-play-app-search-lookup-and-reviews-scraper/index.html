    Google Play App Search, Lookup & Reviews Scraper is an Apify Actor published by Nimbryxo Studio. It accepts 16 input fields, and mode is required. Each result can carry up to 87 declared fields, including packageName, name, developer, rating, ratingCount and installs. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “Modes”, “What you can collect”, “Input”, “Output behaviour”, “Limits and honest caps” and “FAQ”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (s). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    What it costs

    Google Play App Search, Lookup & Reviews Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 16 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredWhat to scrape.Default "search"; Allowed search, details, reviews, developer, similar, permissions, dataSafety
    searchQuerySearch querystringKeyword to search for in mode=search, for example photo editor or calculator.Default "calculator"
    appIdsApp IDsarrayPackage names or Google Play URLs. Used by details, reviews, similar, permissions, and dataSafety modes.Default []
    packageNamesPackage namesarrayAndroid package names such as com.whatsapp. Play URLs are also accepted.Default []
    startUrlsGoogle Play app URLsarrayFull Google Play app URLs, for example https://play.google.com/store/apps/details?id=com.whatsapp.Default []
    developerIdDeveloper IDstringNumeric Google Play developer ID or a developer page URL, used in mode=developer.
    developerNameDeveloper namestringDisplay name shown on Google Play, for example Google LLC, used in mode=developer.
    countryCountrystringStorefront for search results, pricing, and availability. Reviews are selected by Language, not Country.Default "us"; Allowed us, gb, ca, au, in, de, fr, es and 42 more
    languageLanguagestringLanguage for app pages and the review bucket. Google Play uses this language, not Country, to choose reviews.Default "en"; Allowed en, es, fr, de, it, pt, ja, ko and 22 more
    maxItemsMax itemsintegerHard cap on dataset rows. Search returns at most 250 apps per query. For similar mode one seed app is one row.Default 100; Example 3; Allowed 1 to 10000
    maxReviewsPerAppMax reviews per appintegerReviews to collect for each app. Google Play returns at most 4,500 reviews per page; the actor paginates up to this cap.Default 100; Allowed 1 to 50000
    reviewSortReview sortstringOrder used when fetching reviews.Default "newest"; Allowed newest, rating, helpfulness
