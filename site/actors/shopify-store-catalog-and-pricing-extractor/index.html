    Shopify Store Catalog & Pricing Extractor is an Apify Actor published by Nimbryxo Studio. It accepts 19 input fields, and mode is required. Each result can carry up to 42 declared fields, including recordType, title, price, currency, compareAtPrice and available. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “Modes”, “Input”, “Product output”, “Variant output”, “Collection output” and “Run summary”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (s). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 1000, maximum 50000) caps how many results a run collects, and so what it costs.

    What it costs

    Shopify Store Catalog & Pricing Extractor uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 19 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredWhat to scrape. catalog walks the public product feed, collection walks specific collections, product fetches exact product handles, search uses the storefront search suggestions, collections lists collection metadata, and auto detects the type of each URL in startUrls.Default "catalog"; Allowed catalog, collection, product, search, collections, auto
    storeUrlsShopify store URLsarrayStore domains or URLs, e.g. deathwishcoffee.com or https://www.allbirds.com. Accepts custom domains and *.myshopify.com. A product or collection URL is reduced to its store for catalog/collections/search modes.Example ["https://deathwishcoffee.com"]
    startUrlsStart URLs (mixed, optional)arrayStore, collection or product URLs. In auto mode each URL selects its own job: /products/<handle> fetches one product, /collections/<handle> fetches a collection, any other store URL fetches the catalog. In the other modes these URLs add stores and, for collection/product modes, their handles.Default []
    collectionHandlesCollection handles (mode=collection)arrayCollection handles or collection URLs, e.g. new-arrivals, sale, or https://store.com/collections/sale. Handles are applied to every store in storeUrls; a full collection URL is applied to its own store.Default []
    productHandlesProduct handles (mode=product)arrayProduct handles or product URLs, e.g. dark-roast-coffee or https://store.com/products/dark-roast-coffee. Handles are applied to every store in storeUrls; a full product URL is applied to its own store.Default []
    searchQuerySearch query (mode=search)stringIn-store search term. Shopify's public suggest endpoint returns at most 10 products per store and has no pagination.
    currencyCurrencystringISO 4217 code to pin prices to, e.g. USD, EUR, GBP. Use store to use the store's base currency from /meta.json. Pinning is important because Shopify localizes prices by IP.Default "store"; Example "USD"
    countryCountry (optional)stringTwo-letter ISO country code passed as ?country= to the storefront, e.g. US, GB, DE.
    vendorVendor containsstringKeep products whose vendor contains this text (case-insensitive).
    productTypeProduct type containsstringKeep products whose product type contains this text (case-insensitive).
    tagTag containsstringKeep products with at least one tag containing this text (case-insensitive).
    minPriceMinimum pricenumberDrop products whose lowest variant price is below this value.Allowed 0 to 1000000
