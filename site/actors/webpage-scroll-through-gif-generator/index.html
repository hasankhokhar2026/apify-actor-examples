    Webpage Scroll-Through GIF Generator is an Apify Actor published by Nimbryxo Studio. It accepts 37 input fields, and url is required. Each result can carry up to 11 declared fields, including url, gifUrl, outputFormat, frameCount, width and height. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What it does”, “Output per run”, “Input”, “How capture works” and “FAQ”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (default scroll capture). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxFrames (default 60, maximum 300) caps how many results a run collects, and so what it costs.

    What it costs

    Webpage Scroll-Through GIF Generator uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    viewportHeightViewport height (px)integerBrowser viewport height.Default 720; Allowed 240 to 1440

    localeBrowser localestringLanguage/region used by the browser (e.g. en-US, de-DE, ja-JP). Leave en-US for English.Default "en-US"

    scrollStartPxStart scroll at (px)integerPixel offset from the top where capture starts. Use it to skip a hero section or header.Default 0; Allowed 0 to 200000
