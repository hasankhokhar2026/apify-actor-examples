    Website Contact Page Email & Phone Crawler is an Apify Actor published by Nimbryxo Studio. It accepts 13 input fields, and urls is required. Its build declares no dataset fields; the published README describes the output. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per website”, “Input”, “Use cases”, “FAQ” and “Limitations”.

    What you get

    The Actor saves one record per result to an Apify dataset. The build declares no dataset view; the README documents 26 fields. Fields without a value can be left out of a record.

    Output fields
    FieldLabelWhat it holds
    typeAlways website_contacts.
    websiteUrlThe normalised input URL.
    statussuccess when an email, phone, social profile or contact form was found; no_contacts when pages loaded but none was found; failed when nothing could be fetched.
    failureReasonOn failed rows: invalid_url, blocked, no_pages_fetched or crawl_error.
    errorHuman-readable explanation on failed rows.
    companyNameOrganisation name from JSON-LD, og:site_name, the page title or microdata.
    companyNameSourcejsonld, og_site_name, title or microdata.
    emailsSorted unique email addresses.

    What it costs

    Website Contact Page Email & Phone Crawler uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 13 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    urlsWebsite URLsarray requiredWebsites to scan for public contact details. You can paste full URLs or bare domains; duplicates are removed.Example ["https://apify.com"]
    maxPagesPerSiteMax Pages Per SiteintegerMaximum number of pages to fetch per website. Contact, about, team and imprint pages are prioritised.Default 20; Example 5; Allowed 1 to 200
    maxConcurrencyPage Concurrency Per SiteintegerHow many pages of the same website may be fetched in parallel.Default 5; Allowed 1 to 20
    maxSitesConcurrencyWebsite ConcurrencyintegerHow many websites are scanned in parallel. Lower this if you hit rate limits.Default 3; Allowed 1 to 10
    requestTimeoutSecsRequest Timeout (seconds)integerMaximum time to wait for one page before trying the next proxy tier.Default 15; Allowed 5 to 60
    defaultCountryDefault phone countrystringISO 3166-1 alpha-2 country used to interpret phone numbers written without an international prefix. Leave empty to infer from the website domain.Default ""; Allowed , AC, AD, AE, AF, AG, AI, AL and 238 more
    useProxyUse Proxy FirstbooleanStart with the Apify proxy ladder instead of trying direct requests first. The actor always retries blocked requests through the proxy ladder automatically.Default false
    smartPrioritiseSmart Page PrioritisationbooleanTry common contact, about, team, imprint and support paths first, and queue contact-like links ahead of other internal links.Default true
    respectRobotsTxtRespect robots.txtbooleanSkip pages that the website's robots.txt disallows. Turn this off only when you own the site or have permission to crawl it.Default true
    useSitemapDiscover Pages From SitemapbooleanRead sitemap.xml and robots.txt sitemap entries to find contact and about pages that are not linked from the homepage.Default true
    renderFallbackRender JavaScript Pages When NeededbooleanIf plain HTML contains no email or phone, render up to two pages in a headless browser to capture contacts loaded by JavaScript.Default true
    onlyWithContactsOnly Output Sites With ContactsbooleanDrop records for websites where no email, phone, social profile or contact form was found.Default false
    includeNamedEmailsInclude Personal EmailsbooleanInclude personal addresses such as jane.smith@company.com. When off, only role addresses such as info@, sales@ and support@ are kept.Default true
