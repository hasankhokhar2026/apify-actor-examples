    Facebook Business Page Recommendation & Review Scraper is an Apify Actor published by Nimbryxo Studio. It accepts 17 input fields, none of them required at the top level. Each result can carry up to 30 declared fields, including recordType, pageName, authorName, isRecommended, text and createdAt. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per review”, “Output per page”, “Error rows”, “Input” and “Use cases”.

    What it costs

    Facebook Business Page Recommendation & Review Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 17 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    startUrlsFacebook Page URLsarrayFacebook business page URLs or /reviews URLs (e.g. https://www.facebook.com/mcdonalds/reviews). /reviews is added automatically when missing. Invalid or dead page URLs fail fast instead of being guessed.Default []; Example [{"url": "https://www.facebook.com/mcdonalds/reviews"}]
    pageIdsFacebook Page IDs or UsernamesarrayNumeric Facebook Page IDs (e.g. 100064458773195) or page usernames (e.g. mcdonalds). Use this when you do not have a full URL.Default []
    maxItemsMax ReviewsintegerMaximum number of review rows to return across all pages (1-2000). Facebook returns roughly 2-3 reviews per request (about 2.7 on average) even when a larger count is requested, so 100 reviews needs about 35-40 requests.Default 100; Example 5; Allowed 1 to 2000
    maxPerPageMax Reviews Per PageintegerOptional cap per Facebook page for multi-page runs. Leave empty to share the global Max Reviews cap across pages.Allowed 1 to 2000
    includeRepliesInclude Comments and Owner RepliesbooleanInclude the visible top comments and business owner replies inside each review row. When disabled, commentCount is still returned.Default true; Example false
    includePageSummaryInclude Page Summary RowbooleanEmit one recordType=page row per page with the recommendation percentage, total review count, followers, and talking-about count. This adds no extra requests.Default true
    onlyNewOnly New Reviews (Monitor Mode)booleanReturn only reviews not seen in the saved state for this page. The state is stored in a named key-value store that persists across runs, so scheduled runs can monitor for new reviews.Default false
    stateKeyMonitor State KeystringOptional prefix for the key-value store key used by monitor mode. Each page's state is stored separately. Leave empty to use the page ID.
    recommendationRecommendation FilterstringOnly return reviews with the selected recommendation status. Facebook uses binary Recommended / Not Recommended, not star ratings.Default "all"; Allowed all, recommended, not
    dateFromDate From (YYYY-MM-DD)stringOnly return reviews posted on or after this date. Reviews are newest-first, so collection stops when it passes this date.
    dateToDate To (YYYY-MM-DD)stringOnly return reviews posted on or before this date.
    keywordKeyword FilterstringOnly return reviews whose text contains this word or phrase (case-insensitive).
    Show the other 5 input fields
    Input fields in the published schema, continued
    FieldTypeDescription
    requestDelayMsDelay Between Requests (ms)integerPause between review requests. 500-800 ms is a polite pace and keeps long runs stable.Default 600; Allowed 0 to 5000
    maxRuntimeSecsRun Time Budget (seconds)integerStop collecting after this many seconds and return what has been collected so far.Default 1800; Allowed 30 to 7200

    cookiesOptional Facebook CookiesarrayOptional Facebook cookies exported from a logged-in browser. They are not required and do not increase how many reviews Facebook serves per request; the actor returns real reviews without them.Default []
