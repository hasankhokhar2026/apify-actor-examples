    Bing Organic Search Results Scraper is an Apify Actor published by Nimbryxo Studio. It accepts 9 input fields, and mode is required. Each result can carry up to 31 declared fields, including query, resultType, position, title, url and description. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per result”, “Input”, “Use cases”, “FAQ” and “Limitations”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (organic web results for several keywords). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxResultsPerQuery (default 10, maximum 250) caps how many results a run collects, and so what it costs.

    What it costs

    Bing Organic Search Results Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 9 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeResult typestring requiredWhich Bing surface to collect. Web returns organic web results; News, Images and Videos return that vertical; Autocomplete returns query suggestions.Default "webSearch"; Allowed webSearch, newsSearch, imageSearch, videoSearch, autocomplete
    queriesSearch queriesarrayOne or more searches, exactly as you would type them into Bing. Quotes and search operators work. Repeat queries are searched once.Example ["best coffee shops seattle"]
    maxResultsPerQueryResults per queryintegerMaximum records to collect for each query, across result pages. Bing may return fewer when its own list ends.Default 10; Example 3; Allowed 1 to 250
    marketMarketstringThe Bing market and language to search in. Results, interface language and ranking can differ by market.Default "en-US"; Allowed en-US, en-GB, en-AU, en-CA, en-IN, en-ID, en-MY, en-NZ and 30 more
    safeSearchSafeSearchstringBing's adult-content filter. Moderate is Bing's own default; Strict removes adult pages and images; Off keeps everything Bing returns.Default "moderate"; Allowed moderate, strict, off
    dateRangePublished withinstringKeep results published inside this window when Bing prints a date for them. Results without a printed date are kept.Default "anyTime"; Allowed anyTime, past24Hours, pastWeek, pastMonth, pastYear
    imageSizeImage size (mode=imageSearch)stringPrefer small, medium or large images. The choice is applied through Bing's image-size filter.Default "any"; Allowed any, small, medium, large
    videoDurationVideo length (mode=videoSearch)stringKeep short (under 5 minutes), medium (5–20 minutes) or long (over 20 minutes) videos.Default "any"; Allowed any, short, medium, long
    newsSortNews order (mode=newsSearch)stringOrder news articles by Bing's relevance or newest first.Default "relevance"; Allowed relevance, mostRecent
