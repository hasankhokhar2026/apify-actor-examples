    Resident Advisor Lineup, Artist & Venue Extractor is an Apify Actor published by Nimbryxo Studio. It accepts 8 input fields, none of them required at the top level. Each result can carry up to 10 declared fields, including title, date, startTime, venue, city and country. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per record”, “Input”, “Use cases” and “FAQ”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (events in a city and date range). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 20, maximum 200) caps how many results a run collects, and so what it costs.

    What it costs

    Resident Advisor Lineup, Artist & Venue Extractor uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 8 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription

    countryCodeCountry codestringCountry for event search (mode=eventsByCity). Two-letter code.Default "gb"; Allowed gb, de, us, nl, fr, au, jp, be and 27 more
    cityCitystringCity name for event search (mode=eventsByCity). Examples: london, berlin, new-york, amsterdam, paris.Example "london"
    dateFromDate from (YYYY-MM-DD)stringFetch events from this date onwards. Defaults to today if empty. Format: YYYY-MM-DD.

    venueSlugVenue slug or search termstringVenue slug or name for venue profile (mode=venueProfile). Example: fabric, berghain, panorama-bar.
