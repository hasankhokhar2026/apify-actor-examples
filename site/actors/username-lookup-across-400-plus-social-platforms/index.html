    Username Lookup Across 400+ Social Platforms is an Apify Actor published by Nimbryxo Studio. It accepts 8 input fields, and mode is required. Each result can carry up to 21 declared fields, including recordType, query, platform, url, exists and status. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (lookup one handle on the verified set). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxResults (default 500, maximum 5000) caps how many results a run collects, and so what it costs.

    What it costs

    Username Lookup Across 400+ Social Platforms uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 8 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredlookup returns found profiles (plus blocked/unknown checks), availability returns one row per platform with available/taken/unknown, and name_search generates handle candidates from a full name.Default "lookup"; Allowed lookup, availability, name_search
    usernamesUsernames / handlesarrayHandles to check. Accepts plain handles, @handles and profile URLs. Required for lookup and availability. Maximum 50 per run (10 when extended coverage is active).Example ["torvalds"]
    namesFull names (name_search)arrayFull names for name_search. The actor builds up to 10 handle candidates per name, checks them, and scores the matches. Maximum 50 per run.
    coverageCoveragestringverified uses the 29 platforms that passed a known-handle plus random-handle gate. extended adds 400+ best-effort platforms at low confidence.Default "verified"; Allowed verified, extended
    platformsPlatforms (optional)arrayLimit the run to specific platforms. Leave empty to use all verified platforms, or all verified + extended platforms when coverage=extended. Extended-only platform names are rejected when coverage=verified.Example ["GitHub", "YouTube", "TikTok", "Pinterest", "X/Twitter",...; Allowed GitHub, GitLab, YouTube, TikTok, Instagram, Pinterest, Twitch, X/Twitter and 427 more
    maxConcurrencyMax concurrencyintegerConcurrent checks. The default of 12 is the validated safe value for the verified set; per-host requests are limited further.Default 12; Allowed 1 to 12
    maxResultsMax resultsintegerMaximum profile/check rows to emit. The summary row is always emitted and is not counted.Default 500; Example 10; Allowed 1 to 5000
    proxyConfigurationProxy configuration (optional)objectThe actor works without a proxy. Supply one only if you want requests routed through your own Apify proxy configuration.
