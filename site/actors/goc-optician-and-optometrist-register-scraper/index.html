    GOC Optician & Optometrist Register Scraper is an Apify Actor published by Nimbryxo Studio. It accepts 15 input fields, and mode is required. Each result can carry up to 15 declared fields, including name, companyName, gocNumber, registerType, registrationStatus and registrationDate. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Modes”, “Output fields”, “Input”, “How it works” and “Limits and accuracy”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 15 fields in 1 dataset view, and the README documents 12 more. Fields without a value can be left out of a record.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (s). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    What it costs

    GOC Optician & Optometrist Register Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 1 GB, so a run starts with 1 start event, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input fields in the published schema
    FieldTypeDescription
    modeWhat do you want to collect?string requiredChoose the task. registrant searches individuals by name, register type, specialty, address, postcode, or GOC number. bodyCorporate searches registered businesses. byGocNumber checks a list of exact GOC numbers and detects registrants vs businesses automatically. allBusinesses exports the full registered-business list (~3,000 records).Default "registrant"; Example "byGocNumber"; Allowed registrant, bodyCorporate, byGocNumber, allBusinesses
    surnamesSurnames (one or more)arrayOne or more surnames to search. Each surname runs its own search and results are merged without duplicates. Leave empty if you search by company, register type, specialty, address, postcode, or GOC number instead. Latin-script values only: the GOC search ignores non-Latin text.Default []
    forenameFirst name containsstringOptional first-name filter applied to every surname search in registrant mode.Default ""
    soundsLikeSurnameSounds-like surname matchingbooleanMatch surnames phonetically (e.g. 'Smyth' also finds 'Smith') instead of as a literal substring.Default false
    registerTypeRegistered asstringRestrict registrant searches to one registration category.Default ""; Allowed , Optometrist, Dispensing Optician, Student Optometrist, Student Dispensing Optician, Dispensing Optician, Student Optometrist, Student Dispensing Optician, Student Optometrist

    companyNamesCompany names (one or more)arrayOne or more optical-business names to search in bodyCorporate mode. Each value runs its own search and results are merged. Latin-script values only.Default []
    gocNumbersGOC number(s)arrayExact GOC registration numbers, e.g. 01-12294, D-9396, SO-44231, CO-4310. In byGocNumber mode this is the whole lookup list (registrants and businesses can be mixed). Missing hyphens, lowercase, and a missing leading zero are normalised. In search modes the numbers are combined (AND) with the other filters.Default []; Example ["01-12294"]
    postcodePostcode for a distance searchstringUK postcode or outward code (SW1A 1AA or EH1) used with radiusMiles. Works for registrant and business searches. Only real postcodes return results.Default ""
    radiusMilesDistance radius (miles)integerDistance in miles from the postcode. Only used when postcode is set.Default 50; Allowed 1 to 100
    sortBySort order (registrant searches)stringSort registrant results by surname. The GOC register ignores this for business searches.Default ""; Allowed , Registrant Surname (a - z), Registrant Surname (z - a)
