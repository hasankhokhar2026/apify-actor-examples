    Trustpilot Review & Business Rating Scraper is an Apify Actor published by Nimbryxo Studio. It accepts 13 input fields, and businessDomains, mode and proxyConfiguration are required. Each result can carry up to 9 declared fields, including businessDomain, rating, title, body, reviewerName and reviewerCountry. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output: per-review (mode = reviews)”, “Output: per-business (mode = summary)”, “Input”, “Use cases” and “FAQ”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 9 fields in 1 dataset view, and the README documents 3 more. Fields without a value can be left out of a record.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (prefilled input). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 500, maximum 50000) caps how many results a run collects, and so what it costs.

    What it costs

    Trustpilot Review & Business Rating Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    All 13 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    businessDomainsBusiness domainsarray requiredList of business domains as they appear on Trustpilot URLs (e.g. amazon.com, airbnb.com, apple.com). The domain is the part after /review/ in the Trustpilot URL.Default ["amazon.com"]
    modeModestring requiredWhat to emit. reviews returns one record per review (default). summary returns one record per business with TrustScore, total reviews, and rating distribution.Default "reviews"; Allowed reviews, summary
    maxReviewsPerBusinessMax reviews per businessintegerHard cap on reviews fetched per business domain (mode=reviews). Trustpilot shows 20 reviews per page; this paginates.Default 100; Allowed 1 to 1000
    languageLanguage filterstringLimit reviews to a specific language code (e.g. en for English, de for German). Leave empty for all languages.Default ""; Allowed , en, de, fr, es, it, nl, da and 5 more
    minRatingMin rating (1-5)integerDrop reviews with a rating below this value.Allowed 1 to 5
    maxRatingMax rating (1-5)integerDrop reviews with a rating above this value.Allowed 1 to 5
    verifiedOnlyVerified onlybooleanOnly emit reviews flagged as verified.Default false
    dateRangeFromDate range from (YYYY-MM-DD)stringDrop reviews older than this date.
    dateRangeToDate range to (YYYY-MM-DD)stringDrop reviews newer than this date.
    containsKeywordContains keywordstringOnly emit reviews whose title or body contains this substring (case-insensitive).
