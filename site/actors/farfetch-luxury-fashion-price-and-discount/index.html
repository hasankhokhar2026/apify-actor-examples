    Farfetch Luxury Fashion Price & Discount Extractor is an Apify Actor published by Nimbryxo Studio. It accepts 14 input fields, and mode is required. Each result can carry up to 15 declared fields, including brand, title, boutique, styleCode, price and originalPrice. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Data source”, “Output per product”, “Input”, “Use cases” and “FAQ”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 15 fields in 1 dataset view, and the README documents 17 more. Fields without a value can be left out of a record.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (keyword search in usd). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 20, maximum 2500) caps how many results a run collects, and so what it costs.

    What it costs

    Farfetch Luxury Fashion Price & Discount Extractor uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 14 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredWhat to browse on Farfetch.Default "search"; Allowed search, searchByBrand, category, newIn, saleItems, listingUrls, productDetails
    localeStorefront / currencystringRegional Farfetch storefront. Prices and availability are local to the selected market.Default "nz"; Allowed nz, uk, fr, de, it, es, ie, hk and 9 more
    keywordSearch keywordstringProduct keyword to search for (mode=search), e.g. 'Gucci bag', 'Prada shoes'.Default "Gucci bag"
    brandBrand (mode=searchByBrand)stringBrand name or slug to browse (e.g. 'gucci', 'prada', 'balenciaga').
    genderGenderstringFilter by gender for search, brand, new-arrivals and sale modes. Category mode follows the department in the selected category. When omitted, listings use the women's storefront.Default ""; Allowed , women, men, kids
    categoryCategory (mode=category)stringFarfetch department and category to browse. Each option is a live catalog path, e.g. 'Women - Bags' or 'Men - Shoes'.Default "women/bags-purses-1"; Allowed women/clothing-1, women/shoes-1, women/bags-purses-1, women/accessories-all-1, women/jewellery-1, women/watches-1, women/pre-owned-1, women/activewear-1 and 33 more
    sortBySort orderstringOrder of listing results. Applies to search, brand, category, new-arrivals and sale modes.Default "recommended"; Allowed recommended, newest, priceHighToLow, priceLowToHigh, saleHighToLow
    colorsColorsarrayOnly include products in these colors. Leave empty for every color.Default []; Allowed Black, White, Grey, Neutrals, Brown, Green, Blue, Red and 8 more
    priceMinMinimum priceintegerLowest price to include, in the selected storefront's currency. Leave empty for no minimum.Allowed 0 to 1000000
    priceMaxMaximum priceintegerHighest price to include, in the selected storefront's currency. Leave empty for no maximum.Allowed 0 to 1000000
    discountRangeDiscountstringOnly include products in this Farfetch sale-discount band. The matching value per product is saleDiscountPercent. Applies to search, brand, category, new-arrivals and sale modes.Default ""; Allowed , none, upTo30, 30to50, 50to60, 60plus
    listingUrlsListing URLs (mode=listingUrls)arrayFarfetch category, brand, sale, set or search listing URLs. Both farfetch.com and farfetch.cn URLs are accepted; every listing starts at page 1 with 180 products per page.Default []
    productUrlsProduct URLs (mode=productDetails)arrayFarfetch product page URLs to scrape. Both farfetch.com and farfetch.cn URLs are accepted and converted to the selected storefront.Default []
    maxItemsMax itemsintegerMaximum number of products to return (1-2500).Default 20; Example 3; Allowed 1 to 2500
