    Research Square Preprint Search & Subject Browser is an Apify Actor published by Nimbryxo Studio. It accepts 18 input fields, and mode is required. Each result can carry up to 10 declared fields, including title, primaryAuthor, articleType, statusLabel, journalTitle and postedAt. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What you can do”, “Output fields”, “Input”, “Examples”, “How it works” and “Limits worth knowing”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 10 fields in 1 dataset view, and the README documents 17 more. Fields without a value can be left out of a record.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (s). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 50, maximum 50000) caps how many results a run collects, and so what it costs.

    What it costs

    Research Square Preprint Search & Subject Browser uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 18 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredWhat to fetch. Search runs a keyword query, browseAll lists the newest preprints, the subject/type modes filter the catalog, and the URL/DOI modes fetch specific articles.Default "search"; Allowed search, browseAll, browseBySubject, browseByType, byUrl, byDoi
    searchQuerySearch querystringFree-text keyword search across titles, abstracts and keywords (mode=search). Use quotes for phrases.Example "cancer"
    authorAuthor namestringKeep preprints with this author name (substring match, e.g. 'Smith').
    titleContainsTitle containsstringKeep preprints whose title contains these words.
    abstractContainsAbstract containsstringKeep preprints whose abstract contains these words.
    subjectAreaSubject areastringBrowse one subject. Top-level categories (e.g. 'Agricultural Sciences') are expanded to all of their child subjects.Allowed Agricultural Sciences, Biochemistry, Cell Biology, Environment & Ecology, Evolutionary & Developmental Biology, Interdisciplinary Biology, Microbiology, Molecular Biology & Genetics and 366 more
    subjectPathSubject path (advanced)stringOptional exact taxonomy path such as 'Health sciences/Oncology' for newer Nature-style records. Leave empty to use Subject area.
    articleTypeArticle typestringKeep one article type. Required for mode=browseByType.Allowed Analysis, Article, Biological Sciences - Article, Brief Communication, Case Report, Data Note, Letter, Method Article and 25 more
    statusPublication statusstringKeep one publication status.Default "all"; Allowed all, posted, under-review, in-revision, published-in-journal
    journalJournalstringKeep preprints linked to one journal or platform (site slug).Default "all"; Allowed all, 3d-printing-in-medicine, abdominal-radiology, accreditation-and-quality-assurance, acoustics-australia, acta-geophysica, acta-geotechnica, acta-informatica and 1562 more
    onlyCovidCOVID-19 preprints onlybooleanKeep only preprints in the site's COVID-19 collection.Default false
    postedAfterPosted afterstringEarliest posting date, inclusive (YYYY-MM-DD).
