    Cdiscount Product Search & Price Tracker is an Apify Actor published by Nimbryxo Studio. It accepts 18 input fields, and mode is required. Each result can carry up to 14 declared fields, including recordType, title, price, originalPrice, discountPercent and brand. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What it can scrape”, “Output”, “Input”, “Examples”, “How it works” and “Limits and notes”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 14 fields in 1 dataset view, and the README documents 65 more. Fields without a value can be left out of a record.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (s). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 20, maximum 10000) caps how many results a run collects, and so what it costs.

    What it costs

    Cdiscount Product Search & Price Tracker uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 18 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredWhat to scrape. Search uses a keyword, category browses listing URLs, seller reads seller shops, productDetails reads product pages, reviews collects customer reviews, and topSellers searches by best sellers.Default "search"; Allowed search, category, seller, productDetails, reviews, topSellers
    keywordSearch keywordstringKeyword to search for in search and topSellers modes. In category mode, an optional keyword narrows the listing to that keyword.Example "smartphone"
    categoryUrlsCategory or listing URLsarrayCdiscount category, department, brand or search listing URLs to browse in category mode. Example: https://www.cdiscount.com/telephonie/telephone-mobile/l-14404.htmlDefault []
    sellerIdsSeller IDs or URLsarrayMarketplace seller IDs or seller page URLs in seller mode. Example: 421705 or https://www.cdiscount.com/mpv-421705-vanterra-solutions.htmlDefault []
    productUrlsProduct URLs or IDsarrayCdiscount product page URLs or product IDs used by productDetails and reviews modes. Example: https://www.cdiscount.com/telephonie/telephone-mobile/poco/f-14404-aadde58828.html or aadde58828Default []
    sortBySort bystringResult order used in search, category, seller and topSellers modes. 'rating' is Cdiscount's composite best-rated ranking, not a strict average-rating sort.Default "relevance"; Allowed relevance, price_asc, price_desc, rating, bestsellers_7d, bestsellers_14d, new
    minPriceMin price (EUR)numberKeep only products priced at or above this value, in euros, in search, category, seller and topSellers modes.Allowed 0 to 100000
    maxPriceMax price (EUR)numberKeep only products priced at or below this value, in euros, in search, category, seller and topSellers modes.Allowed 0 to 100000
    brandsBrandsarrayFilter by one or more brand names in search, category and seller modes, for example Samsung or Apple. Cdiscount brand filters are case-insensitive here.Default []
    conditionConditionstringKeep new products only, or refurbished and used products only, in search, category and seller modes.Default "any"; Allowed any, new, used_refurbished
    freeShippingOnlyFree shipping onlybooleanKeep only offers that display free shipping in search, category and seller modes.Default false
    soldByCdiscountOnlySold by Cdiscount onlybooleanKeep only offers sold directly by Cdiscount in search, category and seller modes.Default false
