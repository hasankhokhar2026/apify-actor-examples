    BuiltIn Tech Company Directory & Hiring Signal Scraper is an Apify Actor published by Nimbryxo Studio. It accepts 20 input fields, and mode is required. Each result can carry up to 13 declared fields, including name, industries, searchLocation, matchedLocations, headquarters and employeeCount. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per company”, “Input”, “Use cases” and “FAQ”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 13 fields in 1 dataset view, and the README documents 38 more. Fields without a value can be left out of a record.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (fintech companies in chicago). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 100, maximum 10000) caps how many results a run collects, and so what it costs.

    What it costs

    BuiltIn Tech Company Directory & Hiring Signal Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 1 GB, so a run starts with 1 start event, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 20 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredWhat to fetch. browse walks the BuiltIn company directory with the filters below. search looks companies up by name. byCompany fetches specific companies by name, slug or BuiltIn URL.Default "browse"; Allowed browse, search, byCompany
    searchQueriesSearch queries (mode=search)arrayCompany names or partial names to search for, e.g. stripe, openai, data dog. Browse-only filters are ignored in search mode with a warning. Each query returns up to 50 matching companies before maxItems is applied.Default []
    companyUrlsCompany names, slugs or URLs (mode=byCompany)arrayBuiltIn company URLs (e.g. https://builtin.com/company/stripe), slugs (stripe) or exact company names (Stripe). Names are resolved through BuiltIn's company search; only an exact slug or exact name match is accepted. Unresolved inputs are emitted as error rows with input and error fields.Default []
    startUrlsStart URLs (BuiltIn directory or company profiles)arrayOptional BuiltIn URLs to process instead of the mode routes. Accepts requestListSources shapes: plain strings or objects with a url field, e.g. { "url": "https://builtin.com/companies?city=Chicago" }. Directory URLs (/companies...) are paginated and results are deduplicated; company profile URLs (/company/...) are enriched directly. Other hosts and paths are emitted as error rows. ?page= in a start URL is used as the first page.Default []
    locationsLocations (browse mode, multiple markets)arrayBrowse one or more US city/metro markets. BuiltIn does not OR repeated city parameters, so the actor requests each market separately and unions/deduplicates the results; records include searchLocation and matchedLocations. Accepts the same aliases as location (e.g. chicago, austin, new-york-city) and their display titles. Overrides location when it contains a valid market. Browse mode only.Default []
    locationLocationstringUS city or metro market to browse. Used only when locations is empty; browse mode only, while search/byCompany ignore it with a warning. All US searches every US market. Legacy values national and an empty value also mean all US.Default ""; Allowed , all, national, albuquerque, ann-arbor, atlanta, austin, baltimore and 74 more
    industryIndustrystringFilter companies by BuiltIn industry. Browse mode only; search/byCompany ignore it with a warning.Default ""; Allowed , 3d-printing, 3pl-third-party-logistics, adtech, aerospace, agency, agriculture, analytics-industry and 96 more
    technologyTechnologystringFilter companies by a technology they publish on BuiltIn. Browse mode only; search/byCompany ignore it with a warning.Default ""; Allowed , access, act, adobe-campaign, affinity-designer, aha, airtable, angular and 206 more
    companySizeCompany sizestringFilter companies by employee-count band. Browse mode only; search/byCompany ignore it with a warning.Default ""; Allowed , 1-10, 11-50, 51-200, 201-500, 501-1000, 1000
    officeTypeOffice typestringFilter by work arrangement. Browse mode only; search/byCompany ignore it with a warning. remote means fully remote companies; hybrid and on-site match the company's published office model. Values such as On-Site, On Site and onsite are normalized to OnSite. Companies with no published work model are excluded when this filter is set.Default ""; Allowed , hybrid, on-site, remote
    hiringOnlyHiring companies onlybooleanOnly return companies with at least one open job on BuiltIn. Companies without a published hiring signal are excluded when this filter is set. Browse mode only; search/byCompany ignore it with a warning.Default false
    remoteJobsOnlyCompanies with remote jobs onlybooleanOnly return companies that currently list remote jobs on BuiltIn. Browse mode only; search/byCompany ignore it with a warning.Default false
