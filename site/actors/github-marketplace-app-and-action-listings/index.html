    GitHub Marketplace App & Action Listings by Category is an Apify Actor published by Nimbryxo Studio. It accepts 12 input fields, and mode is required. Each result can carry up to 9 declared fields, including name, listingType, slug, installedCount, stars and planType. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (search for code-review apps with a free trial). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 50, maximum 1000) caps how many results a run collects, and so what it costs.

    What it costs

    GitHub Marketplace App & Action Listings by Category uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    All 12 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredWhat to collect from GitHub Marketplace.Default "searchApps"; Allowed searchApps, searchActions, searchAll, byCategory, bySlug
    searchQuerySearch querystringKeyword to search for (mode=searchApps, searchActions, searchAll). Leave empty to browse the most popular listings.Default ""; Example "code review"
    categoryCategorystringMarketplace category (mode=byCategory, or as an extra filter in the search modes).Allowed agent-apps, ai-assisted, api-management, backup-utilities, chat, code-quality, code-review, code-scanning-ready and 26 more
    categoryTypeCategory listing typestringWhether to browse apps or Actions in mode=byCategory.Default "apps"; Allowed apps, actions
    planTypePricingstringFilter by pricing model. Free-trial filtering is server-side; free/paid are checked against each listing's published plans.Default "all"; Allowed all, free, paid, free_trials
    verifiedOnlyVerified creators onlybooleanOnly return listings from GitHub-verified creators.Default false
    sortBySort bystringHow to order the results.Default "best-match"; Allowed best-match, most-installed, newest
    ownersPublisher logins (optional)arrayKeep only listings published by these GitHub accounts, e.g. 'actions' or 'hashicorp'. Case-insensitive. Needs detail data, which the actor always fetches.Default []
    minInstallsMinimum installs (apps)integerOnly return apps with at least this many installations. Actions have stars instead, so this filter excludes them.Default 0; Allowed 0 to 100000000
    minStarsMinimum stars (Actions)integerOnly return Actions whose repository has at least this many stars. Apps have install counts instead, so this filter excludes them.Default 0; Allowed 0 to 100000000
    slugsSlugs or URLs (mode=bySlug)arrayListing slugs, marketplace paths or full URLs, e.g. 'codecov', 'github-pages', '/marketplace/actions/checkout' or 'https://github.com/marketplace/snyk'. Apps and Actions are detected automatically.Default []
    maxItemsMax listingsintegerMaximum number of listings to save.Default 50; Allowed 1 to 1000
