    Zonaprop Argentina Property Search & Geolocation Scraper is an Apify Actor published by Nimbryxo Studio. It accepts 6 input fields, none of them required at the top level. Each result can carry up to 30 declared fields, including title, listingType, propertyType, price, currency and neighborhood. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    Zonaprop is Argentina's leading property portal, listing apartments, houses, land, PH units and commercial properties for sale and rent from Buenos Aires to every province. This actor runs a Zonaprop search — either from a pasted search URL or from location/property/operation filters — and returns each listing as a structured record with price, GPS coordinates, surface area, rooms, photos and publisher contact details.

    What this actor does

    • Scrapes any Zonaprop search results URL you paste in directly, respecting all filters already embedded in it (price range, rooms, neighborhood, etc.)
    • HTTP-only: no browser or account required
    • Builds a search from structured filters instead — operation type (sale, rent, temporary), property type, and location slug
    • Extracts full address-level location data, including neighborhood, city, province and GPS coordinates
    • Captures publisher details when ZonaProp publishes them, plus the gallery exposed on the search page
    • Empty fields are omitted from records — a field only appears when Zonaprop actually published that data for the listing

    Use cases

    • Market research — track asking prices and days-on-market across Buenos Aires neighborhoods or other Argentine cities
    • Investment analysis — compare pricePerSqm across barrios to spot under- or over-priced areas
    • Rental monitoring — collect rental listings across CABA and Greater Buenos Aires to analyze going rates
    • Agency lead generation — gather publisherName/publisherPhone for agencies active in a target area
    • Portfolio tracking — watch competing listings for developers and property managers in specific neighborhoods

    Questions

    How do I use a Zonaprop search URL instead of the filter fields?

    Apply whatever filters you want on zonaprop.com.ar (neighborhood, price range, rooms, etc.), copy the resulting page URL, and paste it into searchUrl. The actor follows that exact search, including every filter embedded in the URL.

    What property types are covered?

    All of Zonaprop's major categories: apartments (departamentos), houses (casas), land (terrenos), PH units, and commercial properties (locales, offices, warehouses).

    What does rooms ("ambientes") mean?

    It's the Argentine term for a property's total main living spaces — typically bedrooms plus living/dining area, not counting bathrooms. A 3-ambiente apartment usually has 2 bedrooms plus a combined living/dining room; this is captured in the rooms field.

    Why are some prices in USD and others in ARS?

    Zonaprop sellers choose which currency to list in; the currency field tells you which applies to that listing's price, so always check it before comparing prices across records.

    How many listings can one run return?

    Up to maxResults, capped at 1000. For broader coverage, run multiple searches with different locations or filters.

    Do I need a proxy to run this?

    No. The actor uses browser-fingerprinted HTTP requests by default; if the site blocks the runner, it tries free Apify Proxy. No proxy setup is required.

    Is this affiliated with Zonaprop?

    No. This is an independent, third-party actor that reads Zonaprop's publicly available listing pages; it is not operated by or affiliated with Zonaprop/Navent.
