    Jobberman Nigeria Job Listings Scraper is an Apify Actor published by Nimbryxo Studio. It accepts 19 input fields, and mode is required. Each result can carry up to 12 declared fields, including title, companyName, location, workType, experienceLevel and salaryMin. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What you can scrape”, “Input”, “Output per job”, “Use cases”, “FAQ” and “Data source”.

    What it costs

    Jobberman Nigeria Job Listings Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 19 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredChoose what to scrape: a keyword/filter search, a list of pasted Jobberman search URLs, or a list of specific job-listing URLs.Default "search"; Allowed search, byUrls, bySearchUrls
    searchQuerySearch keywordstringFree-text keyword such as a job title, skill or company name. Leave empty to browse every live listing. Legacy inputs using query, keyword or keywords are accepted.Default "sales"
    searchQueriesAdditional keywordsarrayRun several keyword searches in one run. Each query is deduplicated against the others; useful for broad market coverage.Default []
    locationLocationstringRestrict results to a Nigerian state, region, remote jobs or jobs outside Nigeria. Use the slug values from the list; legacy where inputs may still send a display name.Default ""; Allowed , nigeria, abeokuta-ogun, abuja, enugu, ibadan-oyo, imo, lagos and 5 more
    industryIndustrystringRestrict results to an employer industry, for example IT & Telecoms or Banking, Finance & Insurance.Default ""; Allowed , advertising-media-communications, agriculture-fishing-forestry, automotive-aviation, banking-finance-insurance, construction, education, energy-utilities and 15 more
    jobFunctionJob functionstringRestrict results to a job family, for example Software & Data or Sales.Default ""; Allowed , accounting-auditing-finance, admin-office, creative-design, building-architecture, consulting-strategy, customer-service-support, engineering-technology and 19 more
    workTypeWork typestringRestrict results to the site's own work-type groups: full time, part time, contract and temporary, internship and volunteer, or casual and seasonal.Default ""; Allowed , full-time, part-time, contract, internship-graduate, casual-seasonal
    experienceLevelExperience levelstringRestrict results to a Jobberman experience band.Default ""; Allowed , no-experience, graduate-trainee, entry-level, mid-level, senior-level, executive-level
    employmentTypeEmployment type (post-filter)stringKeep only records whose normalised employment type matches. Applied after fetching, so unknown values are never dropped.Default ""; Allowed , fullTime, partTime, contract, internship, temporary, volunteer
    sortBySort orderstringJobberman's own Latest, Featured or Popular order. Sorting is passed to the site and preserved across pagination.Default "latest"; Allowed latest, featured, popular
    postedWithinDaysPosted within (days)integerKeep jobs posted in the last N days. 0 means any date. Jobs with no date shown always pass through.Default 0; Allowed 0 to 3650
    minSalaryMinimum salary (NGN per month)integerDrop jobs whose disclosed salary band is entirely below this value. Jobs with no disclosed salary always pass through.Allowed 0 to 100000000
