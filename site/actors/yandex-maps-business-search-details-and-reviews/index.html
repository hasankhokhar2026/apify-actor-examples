    Yandex Maps Business Search, Details & Reviews Scraper is an Apify Actor published by Nimbryxo Studio. It accepts 30 input fields, and mode is required. Each result can carry up to 52 declared fields, including recordType, placeId, name, address, city and rating. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per record”, “Input”, “Use cases”, “How it works” and “FAQ”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (coffee shops in moscow). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 100, maximum 5000) caps how many results a run collects, and so what it costs.

    What it costs

    Yandex Maps Business Search, Details & Reviews Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredWhat to collect. searchPlaces finds businesses by keyword. getDetails returns full business cards for IDs or URLs. getReviews collects customer reviews for IDs, URLs or a search.Default "searchPlaces"; Allowed searchPlaces, getDetails, getReviews
    searchQueriesSearch queriesarrayOne query per line, for example 'coffee' or 'dentist'. Used by searchPlaces, and by getReviews when no business IDs or URLs are supplied.Example ["coffee"]
    cityCitystringCity name in any language, for example 'Moscow', 'Kazan' or 'Istanbul'. Yandex Maps resolves the city centre and passes it to the search.Example "Moscow"
    coordinatesCentre point (latitude,longitude)stringOptional point for a local search, for example '55.7558,37.6173'. When set, it overrides the city centre. Combine with Radius to search around the point.
    radiusKmRadius (km)integerKeep only places within this distance of the centre point or city centre. Results are measured by straight-line distance and filtered strictly.Allowed 1 to 50
    bboxBounding box (west,south,east,north)stringOptional rectangular area, for example '37.45,55.65,37.85,55.85'. Results outside the rectangle are dropped.
    businessIdsBusiness IDsarrayYandex Maps organization IDs, one per line. Use for getDetails or getReviews.
    startUrlsBusiness or search URLsarrayYandex Maps organization URLs, short links or search URLs, one per line. Business and search URLs work in both getDetails and getReviews.
    maxItemsMaximum recordsintegerRun-wide cap. In searchPlaces and getDetails it counts places; in getReviews it counts reviews across all businesses.Default 100; Example 3; Allowed 1 to 5000
    maxReviewsPerPlaceMaximum reviews per placeintegerReview cap for each business. Yandex exposes up to 600 reviews per sort order; the actor combines four orders to reach up to 2,400 unique reviews per business.Default 100; Allowed 1 to 2400
    reviewSortReview sort orderstringPrimary review order. When you ask for more than 600 reviews per place, the actor also walks the other three orders and merges them, removing duplicates.Default "relevance"; Allowed relevance, time, rating_desc, rating_asc
    reviewMinRatingMinimum review ratingintegerKeep only reviews with at least this many stars (1-5).Allowed 1 to 5
