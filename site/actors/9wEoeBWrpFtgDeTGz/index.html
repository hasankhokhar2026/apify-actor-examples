Published README

Read the full published documentation

Google Ads Advertiser Creative History Scraper

Look up any advertiser's ad history on Google's Ads Transparency Center, either by pasting the advertiser's own Transparency Center URL or by searching for them by name or domain. Get back the advertiser's creatives Google has on record, up to the limit you set, with format, preview media, and the dates each ad ran.

What this actor does

  • Scrapes a specific advertiser's creatives from a direct Ads Transparency Center URL, up to resultsLimit per advertiser
  • Finds one matching advertiser per name or domain and scrapes their creatives without needing the URL
  • Covers all three ad formats Google's Transparency Center exposes: text, image, and video
  • Can skip the per-ad detail fetch for a faster run that relies on the summary Google shows in the advertiser's ad list
  • Filters results to ads shown in a specific country
  • Fields that don't apply to a given ad (for example videoUrl on a text ad) come back as null rather than a placeholder

Output per ad

  • advertiserId, advertiserName — the advertiser the ad belongs to and Google's ID for them
  • creativeId — Google's unique ID for this specific ad creative
  • format — TEXT, IMAGE, or VIDEO; UNKNOWN if Google returns a format code the actor doesn't recognize
  • firstShown, lastShown — the date range Google recorded the ad as active
  • previewUrl — a link to preview the ad creative (an image link for text and image ads, a preview link for video ads)
  • imageUrl — direct image URL, image-format ads only
  • videoUrl — direct video file URL for video ads when it can be resolved; always null with skipDetails on
  • adLibraryUrl — direct link to this ad on the Ads Transparency Center
  • startUrl — the input advertiser URL that produced this ad (null for ads found via searchTerms)
  • searchTerm — the search term that found this advertiser (null for ads from startUrls)
  • scrapedAt — when the actor fetched the record

Input

Field Type Default Description
startUrls array – Direct Google Ads Transparency Center advertiser URLs, e.g. https://adstransparency.google.com/advertiser/AR08888592736429539329. A ?region= in the URL is ignored; use region instead.
searchTerms array – Advertiser names or domains to search for instead of a direct URL. Each term is resolved to a single advertiser.
region string anywhere Only return ads shown in this country; anywhere applies no region filter. Applies to every advertiser in the run.
resultsLimit integer 50 Maximum ads to return per advertiser (1–1000).
skipDetails boolean false Skip the per-ad detail fetch for a faster run; records come from the advertiser's ad list and never include videoUrl.

At least one of startUrls or searchTerms must be provided.

Example: look up an advertiser by domain

{
  "searchTerms": ["nike.com"],
  "resultsLimit": 100
}

Example: scrape a known advertiser's URL directly

{
  "startUrls": [
    { "url": "https://adstransparency.google.com/advertiser/AR08888592736429539329?region=ES" }
  ]
}

Example: quick list-only scan filtered to one country

{
  "searchTerms": ["Amazon"],
  "region": "US",
  "resultsLimit": 200,
  "skipDetails": true
}

Use cases

  • Competitive ad monitoring — track which creatives a competitor is currently running and for how long
  • Creative research — pull a brand's historical ad formats and preview media for inspiration
  • Compliance review — check whether an advertiser's ads ran in a region they shouldn't have targeted
  • Agency reporting — build a client or prospect's ad history into a pitch deck or audit
  • Ad format analysis — compare how many of an advertiser's creatives are text, image, or video

FAQ

What's the difference between startUrls and searchTerms? startUrls points directly at an advertiser's existing Transparency Center page. searchTerms looks up the advertiser by name or domain first, then scrapes their page — use it when you don't already have the direct URL. For a domain, the actor uses the advertiser Google links to that exact domain when there is one; otherwise, and for names, it picks the matching advertiser with the most ads. Terms that match no advertiser are skipped.

Why are imageUrl or videoUrl null on some ads? imageUrl is only populated for image-format ads, and videoUrl only for video ads whose video file can be resolved. Other formats simply don't have that field, and both are null when Google doesn't expose the media.

What does skipDetails change? With skipDetails enabled, the actor doesn't open each ad's own detail record. It still returns the ID, format, dates, preview link and (for image ads) image URL from the advertiser's ad list, but videoUrl stays null and dates come only from the list. With it off, ads whose details can't be loaded are left out.

Can I filter by country? Yes, set region to a country; results are limited to ads Google recorded as shown in that country. Leave it as anywhere for no filter.

How many ads can I get per advertiser? Up to resultsLimit (1,000 at most) per advertiser, limited by how many creatives the Transparency Center actually has on record for that advertiser in the chosen region.

Is this affiliated with Google? No. This is an independent, third-party actor that reads the publicly accessible Google Ads Transparency Center; it is not affiliated with or endorsed by Google.
