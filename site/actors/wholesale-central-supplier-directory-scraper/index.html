    Wholesale Central Supplier Directory Scraper is an Apify Actor published by Nimbryxo Studio. It accepts 15 input fields, and mode is required. Each result can carry up to 9 declared fields, including name, category, city, stateCode, minimumOrderUSD and phone. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    Build a clean list of US wholesale, dropship and closeout suppliers from WholesaleCentral.com. Search by keyword, browse any of the 54 live supplier categories, crawl several categories in one run, or refresh a known list of supplier URLs. Get public company contact data, location, minimum-order terms, social links and an optional product-catalog summary — with no login. Wholesale prices are not published by the source and are not claimed here.

    What this actor does

    • Three discovery modes: keyword search on the supplier tab, live-category browsing (one or up to 10 categories), and direct supplier-URL refresh
    • Supplier-first search: uses the site's supplier tab (tab=suppliers), so results are companies rather than the default product cards
    • Contact detail: phone, full address, website, company description and social profiles from each supplier page
    • Location precision: city, state name, two-letter state code, postal code and country, plus exact state filtering (NY / New York no longer matches Albany, Oregon)
    • Product-catalog summary: product count, per-category counts, collection count, up to 8 sample products (name, SKU, link) and ships-from country — no extra request
    • Optional embedded contacts: business email addresses and extra phone/fax numbers that the page payload contains but the site does not visibly publish; off by default
    • Reliable crawling: handles the site's AWS WAF browser challenge, paginates 30-card category pages and 40-card search pages, deduplicates by supplier URL, and stops at maxItems or source exhaustion
    • Empty fields are omitted — no null, blank or sentinel noise in the output

    Use cases

    • US sourcing shortlists — find domestic wholesale suppliers by category and state without browsing the directory by hand
    • Dropship and closeout research — map the Dropshippers and Closeout Suppliers departments, then compare minimum orders
    • B2B lead lists — collect public company phone, address and website data for retail-buyer outreach
    • Catalog discovery — see how many products a supplier carries and which product categories dominate its storefront
    • Geographic market mapping — compare supplier density across states and categories
    • Refresh existing vendor lists — re-scrape a saved set of supplier URLs to pick up changed contacts or catalogs

    Output per supplier

    Identity and listing fields:

    • recordType: always "supplier"
    • name, slug
    • detailUrl, sourceUrl: the supplier's public WholesaleCentral page
    • category: readable label of the category page the supplier was found on
    • supplierType: legacy label echoed only for old saved inputs that still send supplierType; omitted for new inputs
    • location, city, state, stateCode, postalCode, country
    • memberSince: year the supplier joined the directory
    • minimumOrderUSD: minimum order in USD (0 means the listing says “No minimum order”)
    • isFeaturedListing: true when the listing carries a Featured badge
    • websiteUrl: the supplier's own website
    • phone, address, companyDescription
    • socialMediaLinks: Instagram, TikTok, Facebook, X/Twitter, Pinterest, YouTube or LinkedIn links
    • categories: the supplier's main directory categories
    • scrapedAt: ISO 8601 UTC timestamp

    Added from the supplier page (when includeDetails is on):

    • productCount, collectionsCount
    • categoryCounts: array of {name, count} product categories
    • sampleProducts: up to 8 objects with name, sku (when shown) and url
    • shipsFrom: the shipping-origin country shown on the page

    Added only when includeEmbeddedContact is explicitly enabled:

    • email, emails[], salesEmail
    • fax, additionalPhones[]

    These contact values come from the supplier profile payload embedded in the public page — they are business contacts, not displayed contact buttons. Review your privacy, consent and outreach obligations before enabling this option. Website footer or directory-operator addresses are filtered out.

    Questions

    Does this need a login or a proxy?

    No login. Every supplier page used here is public. The actor connects directly first, solves the site's browser challenge, reuses that session, and automatically picks a working Apify connection if the site blocks it. You do not need to configure a proxy.

    Why are there no wholesale prices?

    The directory shows “Unlock wholesale price” to signed-in buyers. Public pages — and this actor — do not expose wholesale prices, tiers or MOQs beyond the published minimum-order amount.

    Why does search return a different number of suppliers than a category?

    The site's supplier search returns roughly 51–136 matches for common queries, while top-level categories contain 2–90 suppliers each. maxItems still caps what is emitted.

    Why did state: "NY" previously return an Oregon supplier?

    The old filter searched for ny inside city names and matched “ALbany”. This version normalizes US state names and two-letter codes and compares the state/state-code fields exactly; the city is never searched.

    What is minimumOrderUSD: 0?

    It means the listing explicitly says “No minimum order” — a real value. If the minimum order is not disclosed, the field is omitted.

    What does productCount: 0 mean?

    The supplier has no products in its public storefront. productCount is omitted when the page does not show a count at all.

    Why is includeEmbeddedContact off by default?

    The site embeds supplier business email addresses and extra phone/fax numbers in the page payload but does not display them in the contact panel. Because that is a privacy-sensitive difference, the actor emits them only when you explicitly opt in and warns you to use them lawfully.

    Why do some records lack a phone, website, description or social links?

    Not every supplier publishes every field. Empty values are omitted rather than written as null or a placeholder.

    Can I get the whole directory in one run?

    The public category/search crawl reaches about 368 unique suppliers across the 54 live categories. maxItems can be set up to 500. A single category is capped at 100 cards per run (the largest live category has 90), and a run can crawl up to 10 categories.

    Is this affiliated with WholesaleCentral.com?

    No. This is an independent tool that reads the directory's public supplier pages; it is not run or endorsed by WholesaleCentral.com.

    Limits and notes

    Limitations

    • Wholesale prices, buyer-only MOQ tiers and order terms are login-gated and are not included.
    • The site does not expose a per-supplier “verified” badge, so no verification field is invented; Featured placement is the only premium-listing signal.
    • The directory's marketing figure (“1,400+ suppliers”) is larger than what the public category and search pages expose; a full audit in October 2026 reached 368 unique supplier pages across 54 live categories.
    • The site uses an AWS WAF browser challenge, so the first request of a run can take a few seconds longer while the session is established.
