    Amazon Creator Storefront & Idea List Scraper is an Apify Actor published by Nimbryxo Studio. It accepts 13 input fields, none of them required at the top level. Each result can carry up to 11 declared fields, including recordType, handle, status, displayName, title and asin. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per record type”, “Input”, “Use cases”, “FAQ” and “Limitations”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (default — profile, idea lists, photos, and videos). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxLists (default 10, maximum 50), maxItemsPerList (default 30, maximum 100), maxVideos (default 20, maximum 100) and maxPhotos (default 20, maximum 100) cap how many results a run collects, and so what it costs.

    What it costs

    Amazon Creator Storefront & Idea List Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 13 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    handlesCreator handlesarrayAmazon influencer handles, e.g. gearvlogz (from amazon.com/shop/gearvlogz). Combined with marketplaceDomain to build the shop URL. At least one handle or shopUrls entry is required.Default []; Example ["gearvlogz"]
    shopUrlsShop URLsarrayFull creator storefront URLs, e.g. https://www.amazon.com/shop/gearvlogz. Use this for non-default marketplaces or when you already have the exact URL. Provide at least one handle or shop URL.Default []
    marketplaceDomainMarketplace domainstringAmazon domain to use when building shop URLs from handles.Default "amazon.com"; Allowed amazon.com, amazon.ca, amazon.com.mx, amazon.com.br, amazon.ie, amazon.es, amazon.co.uk, amazon.fr and 15 more
    tabsContent to scrapestringWhich storefront content to extract. all includes profile, Idea Lists, photos, videos, curations, and trending picks.Default "all"; Allowed all, profile, ideaLists, photos, videos
    searchPostsSearch postsstringOptional keyword to filter the creator's posts (Idea Lists, photos, videos) before extraction. Leave empty to return the full feed.Default ""
    crawlIdeaListsCrawl Idea List itemsbooleanWhen true, opens each Idea List (up to maxLists) and extracts individual products (up to maxItemsPerList). When false, only the list summary cards (title, declared item count, image, hearts, pinned) are emitted.Default true
    maxListsMax Idea Lists per shopintegerMaximum number of Idea Lists to process per shop.Default 10; Example 1; Allowed 1 to 50
    maxItemsPerListMax items per Idea ListintegerMaximum number of product items to extract per Idea List.Default 30; Example 3; Allowed 1 to 100
    maxVideosMax videos per shopintegerMaximum number of creator videos to extract per shop (tabs=all or videos).Default 20; Example 1; Allowed 1 to 100
    maxPhotosMax photos per shopintegerMaximum number of shoppable photo posts to extract per shop (tabs=all or photos).Default 20; Example 1; Allowed 1 to 100
    includeCurationsInclude curationsbooleanEmit the creator's curations (themed post collections shown on the profile page) when tabs=all or profile.Default true; Example false
    includeTrendingPicksInclude trending picksbooleanEmit the creator's trending-picks product carousel when tabs=all or profile.Default true; Example false
    proxyConfigurationProxy configurationobjectOptional. The actor chooses a working connection automatically (direct, then free AUTO, then residential only after repeated blocks). Change this only if you need a specific proxy setup.Default {"useApifyProxy": true}
