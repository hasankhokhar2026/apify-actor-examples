    TikTok Post & Slideshow Detail Scraper is an Apify Actor published by Nimbryxo Studio. It accepts 17 input fields, none of them required at the top level. Each result can carry up to 23 declared fields, including postId, postUrl, postType, caption, createdAt and playCount. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (s). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 100, maximum 1000), maxDetail (default 50, maximum 300) and maxCommentsPerPost (default 100, maximum 1000) cap how many results a run collects, and so what it costs.

    What it costs

    TikTok Post & Slideshow Detail Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 17 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestringWhat to scrape: individual posts, a profile's newest posts, or comment threads on posts.Default "posts"; Allowed posts, profiles, comments
    postUrlsPost URLs or IDsarrayTikTok video/photo URLs, /v/ share links, embed links, vm.tiktok.com or vt.tiktok.com short links, or bare numeric post IDs. Duplicates are scraped once.Example ["https://www.tiktok.com/@khaby.lame/video/75748441849520...
    postIdsPost IDsarrayNumeric TikTok post IDs (15-20 digits). Use this instead of, or in addition to, postUrls.
    profilesProfilesarrayTikTok usernames (@handle), profile URLs, or bare handles. Profiles mode returns up to 500 newest posts per profile; comments mode can use them as comment targets.
    maxItemsMax rowsintegerGlobal cap on output rows. Posts mode counts posts; profiles mode counts posts; comments mode counts comments and replies. Status rows do not count.Default 100; Example 1; Allowed 1 to 1000
    maxDetailMax detail lookupsintegerHow many posts get the slower page/detail enrichment (caption language, collect/repost counts, video tracks). Remaining posts use the fast embed record. Set to 1 for the smallest daily-test run.Default 50; Example 1; Allowed 1 to 300
    maxCommentsPerPostMax comments per postintegerMaximum comments plus replies to keep for each post in comments mode, or to attach to each post when Include comments is on.Default 100; Allowed 1 to 1000
    includeRepliesInclude repliesbooleanFetch the reply thread under each root comment and include replies with their parent.Default false
    includeCommentsInclude commentsbooleanIn posts/profiles mode, attach a comments array to each post. In comments mode, emit root comment rows (comments mode enables this automatically when both comment toggles are off).Default false
    proxyConfigurationProxy configurationobjectOptional. Leave empty to run directly; a proxy is not required. The actor falls back to an Apify datacenter proxy on a block signal.
    includeMediaUrlsInclude media URLsbooleanInclude signed video, cover, music, and slideshow image URLs plus mediaUrlExpiresAt. They typically expire in about 48 hours.Default true
    validateMediaUrlsValidate media URLsbooleanCheck the main media URL with a GET Range request (TikTok's CDN rejects HEAD) and add mediaUrlAccessible. Adds latency.Default false
