    Airbnb Listing Price & Location Finder is an Apify Actor published by Nimbryxo Studio. It accepts 29 input fields, none of them required at the top level. Each result can carry up to 30 declared fields, including name, nightlyPrice, totalPrice, currency, rating and reviewCount. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per listing”, “Input”, “Example: cheapest useful run”, “Example: a full city scan with filters” and “Example: exact detail, quote, reviews and calendar”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (cheapest useful run). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    What it costs

    Airbnb Listing Price & Location Finder uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.
