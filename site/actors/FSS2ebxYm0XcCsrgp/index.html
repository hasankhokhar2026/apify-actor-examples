TikTok Hashtag Video Feed & Stats Extractor

Collect a TikTok hashtag's total view/video counts plus the video feed underneath it - captions, author, music, and engagement - with automatic fallback when the feed is blocked.

Published README

TikTok Hashtag Video Feed & Stats Extractor

Pull videos and aggregate stats from any TikTok hashtag page without logging in. Point it at one or more hashtags and get back each hashtag's total view/video counts, plus the individual video feed underneath it — captions, author details, music, and engagement counts — in one dataset.

What this actor does

  • Accepts any number of hashtags, with or without the # symbol, and processes each independently
  • Pulls hashtag-level stats (total video count, total view count, commerce flag, cover images) from the hashtag's TikTok page
  • Pages through the video feed under each hashtag (posts mode) with per-video captions, author, music, and engagement metrics, up to maxPostsPerHashtag
  • In auto mode, falls back from the hashtag feed to a single page of TikTok keyword-search results (topPosts), and finally to the stats record alone, when the feed is blocked; posts mode has no such fallback
  • Empty fields are omitted from every record

Output per hashtag metadata record

  • recordType — always "hashtag_metadata"
  • searchedHashtag — the hashtag you requested, lowercased and without #
  • hashtagId — TikTok's internal challenge ID
  • hashtagName — normalized hashtag name without #
  • desc — hashtag description text
  • videoCount — total videos posted under this hashtag, as TikTok reports it (a numeric string, since counts can be very large)
  • viewCount — total views across all videos under this hashtag (numeric string)
  • isCommerce — whether TikTok classifies this as a branded/commercial hashtag
  • profileLarger / profileMedium / profileThumb / coverLarger / coverMedium / coverThumb — cover image URLs, when TikTok provides them
  • announcementTitle / announcementBody — hashtag campaign announcement text, when present
  • shareMeta — {title, desc} used for social-sharing previews

This record is written first for each hashtag when includeHashtagMetadata is on, and always in metadata mode. In topPosts mode, if TikTok doesn't return the hashtag's stats, the record still appears but holds only recordType and searchedHashtag.

Output per video record

  • recordType — always "post"
  • searchedHashtag — the hashtag this video was found under
  • postId, postType (video or slideshow), postUrl
  • caption, textLanguage, locationCreated
  • createTime (Unix epoch), createdAt (ISO 8601)
  • stitchEnabled, shareEnabled, duetEnabled, isAd
  • playCount, likeCount, commentCount, shareCount, collectCount, repostCount
  • author — {id, secUid, username, displayName, bio, verified, privateAccount, roomId, avatarUrl, followerCount, followingCount, heartCount, videoCount} (the counts appear when TikTok includes them with the video)
  • music — {id, title, authorName, original, duration, album, playUrl, coverUrl}
  • video — {width, height, duration, ratio, playUrl, cover}
  • images[] — slide images with {ordinal, width, height, urlList}, present only for slideshow posts
  • hashtags[] — hashtags tagged in the caption (including the one you searched, when present), as {name, id, isCommerce}
  • mentions[] — @ mentions in the caption, as {username, start, end, awemeId} (character offsets in the caption)
  • mediaUrlExpiresAt — expiry timestamp of the signed media URLs, when detectable

Input

Field Type Default Description
hashtags array – Hashtags to scrape, with or without # (required, at least one)
mode string auto metadata (stats only), posts (hashtag video feed), topPosts (one page of keyword-search results, at most 50 videos), or auto (posts → topPosts → stats only)
maxPostsPerHashtag integer 50 Max videos per hashtag in posts, topPosts and auto (0–500); ignored in metadata mode; 0 returns no videos
includeHashtagMetadata boolean true Also emit the hashtag stats record before the video records; metadata mode emits it regardless

Use cases

  • Brand teams measuring reach of a branded or campaign hashtag via its total view/video counts
  • Social media managers pulling the current top videos under a hashtag for competitive content review
  • Trend researchers collecting video samples from a niche hashtag to analyze creator patterns
  • Agencies comparing hashtag volume across several client or competitor tags in a single run
  • Growth marketers monitoring how fast a hashtag's video count is climbing over successive runs

FAQ

Does this need a TikTok login or cookies? No. Hashtag stats and the video feed are both pulled from TikTok's public pages without any account.

Why would a run only return the metadata record and no videos? TikTok's hashtag video feed sometimes blocks automated access. In auto mode the actor falls back to keyword search, and if that also comes back empty it still returns the hashtag stats record rather than failing the run. In posts mode there is no search fallback, so a blocked feed leaves only the stats record (or nothing, if includeHashtagMetadata is off). If TikTok won't return even the hashtag's stats after repeated attempts, that hashtag produces no records.

What's the difference between posts and topPosts? posts reads TikTok's dedicated hashtag video feed page by page. topPosts runs a TikTok keyword search for the hashtag text and takes the videos from the first page of results, so it returns at most 50 videos and some of them may not actually carry the hashtag. auto tries posts first and only falls back to topPosts if the feed comes back empty.

Why did I get fewer videos than maxPostsPerHashtag? The actor stops when TikTok reports no more pages for the hashtag feed or blocks a page mid-run, and topPosts (including the auto fallback) never goes past one search page of up to 50 videos.

Does viewCount reflect only the videos I scraped? No — it's TikTok's all-time aggregate view count for every video ever posted under that hashtag, independent of how many videos this run collected.

Do I need to include the # symbol? No. #fyp, fyp and FYP are treated identically, and duplicates in the list are processed once.

Is this affiliated with TikTok? No. This is an independent actor that reads TikTok's public hashtag pages and is not operated or endorsed by TikTok.
