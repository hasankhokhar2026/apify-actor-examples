    Letterboxd Film Metadata, Lists & Watchlist Scraper is an Apify Actor published by Nimbryxo Studio. It accepts 16 input fields, and mode is required. Each result can carry up to 7 declared fields, including recordType, title, year, averageRating, ratingsCount and directors. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per record”, “Input”, “Example output”, “Use cases” and “FAQ”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 7 fields in 1 dataset view, and the README documents 35 more. Fields without a value can be left out of a record.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (single film). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 25, maximum 500) caps how many results a run collects, and so what it costs.

    What it costs

    Letterboxd Film Metadata, Lists & Watchlist Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    All 16 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredWhat to fetch.Default "film"; Allowed film, search, userProfile, lists, popular, filmReviews, byCrew, userWatchlist
    filmSlugsFilm slugs / URLs (mode=film)arrayFilm slugs (e.g. parasite-2019) or full Letterboxd URLs (https://letterboxd.com/film/parasite-2019/).Default ["parasite-2019"]
    filmSlugFilm slug (mode=filmReviews)stringSingle film slug or URL whose reviews to scrape (e.g. parasite-2019).Example "parasite-2019"
    searchQuerySearch query (mode=search)stringFilm title query (e.g. Dune, The Godfather). Note: the underlying autocomplete API returns at most ~100 results per query; for deeper results use mode=film with explicit filmSlugs.Example "Dune"
    enrichSearchResultsEnrich search results with full film pagebooleanWhen mode=search, also visit each film's page to pull full metadata (rating, genres, cast). Adds ~0.5s per result but enables year/rating/genre filters.Default false
    usernameUsername (mode=userProfile / userWatchlist)stringLetterboxd username (without @).Example "dave"
    listUrlList URL (mode=lists)stringFull Letterboxd list URL (e.g. https://letterboxd.com/dave/list/official-top-250-narrative-feature-films/). Leave empty to fetch the popular-lists index for the chosen popularPeriod.
    popularPeriodPopular period (mode=popular / lists)stringTime window for popularity ranking.Default "week"; Allowed week, month, year, all-time
    crewTypeCrew type (mode=byCrew)stringWhich crew axis to browse films by.Default "director"; Allowed director, actor, studio, country
    crewSlugCrew slug (mode=byCrew)stringLetterboxd slug for the chosen crewType. E.g. christopher-nolan (director), timothee-chalamet (actor), a24 (studio), japan or south-korea (country).Example "christopher-nolan"
    minYearMin release yearintegerDrop films released before this year.Allowed 1880 to 2100
    maxYearMax release yearintegerDrop films released after this year.Allowed 1880 to 2100
