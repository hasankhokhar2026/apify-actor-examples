    Letterboxd Film Metadata, Lists & Watchlist Scraper is an Apify Actor published by Nimbryxo Studio. It accepts 28 input fields, and mode is required. Each result can carry up to 11 declared fields, including recordType, title, filmTitle, year, averageRating and ratingsCount. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (one film with statistics). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 25, maximum 1000) caps how many results a run collects, and so what it costs.

    What it costs

    Letterboxd Film Metadata, Lists & Watchlist Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    All 28 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeWhat to scrapestring requiredPick the kind of Letterboxd page you want. Every mode returns real public data and drops empty fields.Default "film"; Allowed film, search, userProfile, userWatchlist, userFilms, userDiary, userReviews, userLists and 5 more
    filmSlugsFilm slugs or URLsarrayUsed by Films mode. Paste slugs (parasite-2019) or full Letterboxd film URLs. One record per film.Default ["parasite-2019"]
    filmSlugFilm for reviewsstringUsed by Reviews mode. A slug or full film URL.Example "parasite-2019"
    searchQuerySearch querystringUsed by Search mode. Letterboxd's autocomplete returns at most 100 matching films per query; use Films mode with explicit slugs for a deeper list.Example "Dune"
    enrichSearchResultsLoad full film pages for search resultsbooleanSearch mode only. Off returns fast stubs. On visits each film page for full metadata, stats, and filters.Default false
    usernameMember usernamestringUsed by all member modes. The handle without @, or a profile URL.Example "dave"
    listUrlList URLstringLists mode. Paste a member or official list URL to get one list record plus its films. Leave empty to get the popular-lists index for the chosen period.
    browseUrlBrowse page URLstringBrowse mode. Paste any Letterboxd /films/ page, for example /films/genre/horror/, /films/decade/1990s/, /films/year/2024/, /films/language/japanese/, /films/country/japan/, /films/theme/..., /films/on/netflix/, or /films/by/rating/.Example "https://letterboxd.com/films/popular/this/week/"
    popularPeriodPopular periodstringUsed by Popular films and the popular-lists index.Default "week"; Allowed week, month, year, all-time
    crewTypeFilmography rolestringUsed by Filmographies mode. Choose the role Letterboxd serves for the person or entity.Default "director"; Allowed director, actor, writer, producer, composer, cinematography, editor, story and 18 more
    crewSlugPerson, studio, or country slugstringUsed by Filmographies mode. Letterboxd's URL slug, e.g. christopher-nolan, a24, or japan. Full profile URLs are accepted too.Example "christopher-nolan"
    genreGenrestringOptional genre filter. Popular films uses it in the browse URL; other modes use it to filter film records.Allowed Action, Adventure, Animation, Comedy, Crime, Documentary, Drama, Family and 11 more
