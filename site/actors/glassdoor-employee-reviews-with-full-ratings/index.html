    Glassdoor Review Export - Ratings, Pros, Cons & Replies is an Apify Actor published by Nimbryxo Studio. It accepts 25 input fields, none of them required at the top level. Each result can carry up to 17 declared fields, including title, ratingOverall, pros, cons, jobTitle and location. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Input”, “Output”, “Completeness and company summaries”, “Incremental monitoring” and “How far back and how many reviews”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 17 fields in 2 dataset views, and the README documents 15 more. Fields without a value can be left out of a record.

    What it costs

    Glassdoor Review Export - Ratings, Pros, Cons & Replies uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 1 GB, so a run starts with 1 start event, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.
