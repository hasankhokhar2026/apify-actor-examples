    M.Video Russia Electronics Product & Review Scraper is an Apify Actor published by Nimbryxo Studio. It accepts 22 input fields, and mode is required. Each result can carry up to 9 declared fields, including recordType, name, brandName, salePrice, currency and ratingStar. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (search with filters). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    What it costs

    M.Video Russia Electronics Product & Review Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.
