    X Video Subtitle & Caption Transcript Converter is an Apify Actor published by Nimbryxo Studio. It accepts 15 input fields, none of them required at the top level. Each result can carry up to 29 declared fields, including type, tweetUrl, tweetId, videoIndex, videoSource and authorUsername. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per transcript”, “Input”, “SRT/VTT downloads and multi-video posts”, “Resolution and reliability” and “Whisper models and memory”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (captions first, ai fallback, segments + srt/vtt). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxVideosPerProfile (default 10, maximum 100) caps how many results a run collects, and so what it costs.

    What it costs

    X Video Subtitle & Caption Transcript Converter uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 15 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    postUrlsPost links or IDsarrayPost links or bare post IDs that contain a video or GIF. Accepts x.com and twitter.com links, /i/status and /i/web/status links, /video/N links, and bare numeric IDs. Profile links or usernames are accepted too and are treated like profile inputs. Provide this or Profile links — at least one of the two is required.Default []; Example ["https://x.com/firesidealpha/status/2118737977824395524"]
    profileUrlsProfile links or usernamesarrayOptional. Transcribe recent video posts from these profiles. Paste x.com profile links, @handles or bare usernames. Works without Post links.Default []
    maxVideosPerProfileMax video posts per profileintegerHow many recent video posts to transcribe per profile input. Defaults to 10.Default 10; Allowed 1 to 100
    maxDurationSecondsMax video duration (seconds)integerVideos longer than this are skipped for AI transcription and get a media_too_large status row. Built-in captions are still returned when available. Defaults to 1200 seconds (20 minutes).Default 1200; Allowed 1 to 43200
    maxDownloadMbMax download size (MB)integerLargest media download allowed for AI transcription. The actor picks the audio-only or lowest-bitrate rendition first, then stops with a media_too_large status row if the limit is exceeded. Defaults to 200 MB.Default 200; Allowed 1 to 2048
    transcriptionMethodHow to transcribestringAuto tries the video's built-in captions first and only falls back to Whisper AI when none exist. Captions-only skips videos without captions. AI-only always uses Whisper speech-to-text.Default "auto"; Example "captions"; Allowed auto, captions, ai
    whisperModelAI model sizestringWhisper model used for AI transcription. Larger models are more accurate but slower and need more memory (medium and large-v2 need a run memory of at least 4096 MB and 8192 MB respectively). Base is a good balance for most videos. If the selected model does not fit the run memory, the actor automatically falls back to the next smaller model.Default "base"; Allowed tiny, base, small, medium, large-v2
    languageSpoken/caption language hintstringOptional language code, for example en, es, fr or ur. Native captions prefer this language when several tracks exist; AI transcription uses it as a spoken-language hint. Leave empty to detect automatically.
    outputFormatOutput formatstringSegments gives timestamped lines, full text gives one transcript string, and both gives both plus SRT and WebVTT text and download links. SRT and WebVTT modes return the subtitle text and a signed download link.Default "segments"; Allowed segments, fullText, both, srt, vtt
    includeTweetMetadataInclude post detailsbooleanAttach the full post and author metadata (text, counts, bio, followers, quote/repost details) to every row.Default true
    includeQuotedVideoInclude quoted videobooleanWhen a quote post has no video of its own, transcribe the video of the quoted post. The row keeps the quote post's metadata and records quotedTweetId.Default true
    segmentGranularitySegment granularitystringLevel of the timestamped segments. Segment keeps the raw caption/Whisper cues. Sentence groups real word timings into sentences (or splits cue text, sharing the cue's real time range). Word emits one entry per real word timestamp and is used only when X captions or Whisper provide per-word timings — it is never fabricated; when word timings are missing, the row says so and keeps the raw segments.Default "segment"; Allowed segment, sentence, word
    includeWordTimestampsInclude word timestampsbooleanAdd per-word start/end times to AI (Whisper) transcript segments. Automatically enabled when Segment granularity is Sentence or Word. Native captions only carry words when X included inline timing markers.Default false
    enableYtdlpFallbackEnable yt-dlp fallbackbooleanWhen the direct HTTP media download or Whisper transcription fails, try yt-dlp (requires ffmpeg). Off by default so runs stay fast, deterministic and HTTP-only.Default false
    proxyConfigurationProxy configurationobjectOptional. Use an Apify proxy if you plan large runs or see frequent rate limits.
