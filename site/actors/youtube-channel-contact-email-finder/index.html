    YouTube Channel Contact Email Finder is an Apify Actor published by Nimbryxo Studio. It accepts 10 input fields, and mode is required. Each result can carry up to 16 declared fields, including channelId, handle, name, url, subscriberCount and country. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it costs

    YouTube Channel Contact Email Finder uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 10 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredChoose whether to scrape the channels you provide or discover channels from search queries.Default "channels"; Allowed channels, search
    channelsChannelsarrayYouTube channel URLs, @handles, UC... channel IDs, or video URLs (mode=channels). Video URLs resolve to their channel.Example ["@mkbhd", "@LinusTechTips"]
    searchQueriesSearch queriesarrayKeywords used to discover channels through YouTube search (mode=search). Each query returns up to about 20 channels; duplicates and maxChannels are applied across queries.
    maxChannelsMax channelsintegerMaximum number of unique channels processed per run, across both modes.Default 100; Example 2; Allowed 1 to 500
    includeWebsiteScan linked websites and link hubsbooleanVisit up to two linked websites (home, contact/about pages and common paths) and one link-in-bio hub per channel.Default true
    includeVideoDescriptionsScan recent video descriptionsbooleanRead the descriptions of the latest five videos on each channel.Default true
    onlyWithEmailOnly channels with a public emailbooleanWhen enabled, channels with no public email are left out of the dataset. Error records are still reported.Default false
    emailDomainsEmail domain allowlistarrayOptional list of domains to keep, for example brand.com or gmail.com. Leave empty to keep every discovered email.
    maxEmailsPerChannelMax emails per channelintegerUpper bound on the emails returned for each channel. The highest-value public contact is chosen as primaryEmail.Default 5; Allowed 1 to 20
    proxyConfigurationProxy configurationobjectOptional. The actor works without a proxy; set this only when your runs need a specific Apify Proxy connection.
