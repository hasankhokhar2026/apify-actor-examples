    TikTok Explore Feed Trending Post Scraper is an Apify Actor published by Nimbryxo Studio. It accepts 17 input fields, and categories is required. Each result can carry up to 18 declared fields, including rank, marketRegion, categoryName, categoryId, itemCategoryName and feedType. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per post”, “Input”, “Use cases” and “FAQ”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (default metadata run). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItemsPerCategory (default 3, maximum 1000) and maxItems (maximum 1000) cap how many results a run collects, and so what it costs.

    What it costs

    TikTok Explore Feed Trending Post Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    All 17 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    categoriesCategoriesarray requiredCategories to collect. Accepts names, numeric IDs, or legacy {id,name} objects. All=120; topics 100-119: Anime & Comics, Shows, Beauty Care, Games, Comedy, Daily Life, Family, Relationship, Drama, Outfit, Lipsync, Food, Sports, Animals, Society, Cars, Education, Fitness & Health, Technology, Singing & Dancing. 123 is accepted as a legacy alias for All. 121/122 (empty upstream) and 124+ (invalid upstream) are skipped with a warning.Default ["All"]
    maxItemsPerCategoryMax Items Per CategoryintegerHard cap on emitted posts per category. The cap is applied before any page is pushed, so a 30-item page never overshoots. The default is 3 because media rehosting is on by default and adds one browser page plus several HTTP media fetches per emitted post.Default 3; Allowed 1 to 1000
    maxItemsMax Items (legacy alias)integerLegacy alias for maxItemsPerCategory. It is used when maxItemsPerCategory is absent or exactly the default 3; an explicitly non-default maxItemsPerCategory wins.Allowed 1 to 1000
    categoryIdCategory ID (legacy shorthand)integerLegacy shorthand for one category. It replaces the categories list. 100-120 are accepted; 123 maps to 120; other values are skipped with a warning.Allowed 1 to 100000
    autoDiscoverCategoriesAuto-Discover All CategoriesbooleanWhen true, an empty or All-only selection expands to all 21 verified Explore categories. If specific categories are selected, the missing categories are appended.Default false
    countriesCountries / MarketsarrayOptional ISO 3166-1 alpha-2 markets. Empty means the actor's current egress and no proxy. Each selected country uses a per-country Apify proxy (AUTO first, residential only after a proven block). The feed follows the egress IP, not a query parameter.Default []
    countryCountry (shorthand)stringSingle-country shorthand. Ignored when countries is non-empty.Default ""
    postedWithinPosted WithinstringClient-side filter on createTime relative to the run start.Default "any"; Allowed any, 24h, 7d, 30d, 90d
    minViewsMinimum ViewsintegerDrop posts with fewer playCount views. Missing stats fail a positive threshold.Default 0; Allowed 0 to 1000000000000
    minLikesMinimum LikesintegerDrop posts with fewer likes. Missing stats fail a positive threshold.Default 0; Allowed 0 to 1000000000000
    minCommentsMinimum CommentsintegerDrop posts with fewer comments. Missing stats fail a positive threshold.Default 0; Allowed 0 to 1000000000000
    minSharesMinimum SharesintegerDrop posts with fewer shares. Missing stats fail a positive threshold.Default 0; Allowed 0 to 1000000000000
