Facebook Business Page Recommendation & Review Scraper

Get Facebook business page reviews by direct URL, business name search, or Facebook Page ID — no login or cookies required. Returns review text, Recommended/Not Recommended status, author details, reaction breakdowns, structured recommendation tags, business owner replies, and page-level aggregate stats like follower count and overall recommendation percentage.

What this actor does

  • Scrapes reviews from any public Facebook business page — restaurants, hotels, retailers, airlines, and services
  • Three input modes: paste a page or /reviews URL, search by business name + city, or supply a Facebook Page ID (numeric) or page username
  • Filters results by date range, recommendation status (Recommended / Not Recommended), or keyword in the review text
  • Extracts review photos, structured recommendation tags (e.g. "Outdoor dining", "Fast delivery"), reaction breakdowns (Like/Love/Wow/Haha/Sad/Angry/Care counts), and top comments including business/owner replies
  • Attaches page details to each review — page name and ID, plus follower count, total review count and recommendation percentage when Facebook exposes them
  • Empty/unavailable fields are omitted from each record rather than returned as null

One record per review. Fields are only present when Facebook actually has that data — see the FAQ for why some fields (like reviewPhotos) are frequently absent.

The dataset can also contain error records with "recordType": "error", holding only error (a description) and scrapedAt. One is written when an input item returns no reviews at all or still fails after three attempts, and the run writes a single error record and stops when no input items are given for the chosen mode, the dates are invalid, or the proxy can't be set up. If reviews were fetched but your filters matched none of them, no error record is written.

Use Cases

  • Reputation monitoring — track new Recommended/Not Recommended reviews and business owner replies for a brand or franchise location
  • Competitor analysis — compare recommendation percentages, review volume, and recurring complaint keywords across competing businesses
  • Local business research — pull reviews for restaurants, hotels, or service providers before choosing where to eat, stay, or book
  • Customer feedback analysis — export review text and recommendation tags (e.g. "Fast delivery", "Disappointing food") for sentiment or NLP pipelines
  • Franchise/multi-location tracking — scrape reviews across many location-specific Page IDs in a single run to compare performance
  • Market research — measure follower counts and recommendation trends across an industry vertical

FAQ

Does this require a Facebook account or cookies? No. The actor scrapes publicly visible reviews on public business pages without logging in. Cookies are an optional input for unlocking more than the ~10-15 reviews per page that Facebook shows to logged-out visitors.

Is this an official Facebook or Meta product? No. This is an independent, third-party actor that reads publicly available Facebook business page data. It is not affiliated with, endorsed by, or connected to Meta Platforms, Inc.

Why does Facebook use Recommended/Not Recommended instead of star ratings? Facebook business pages now use a binary Recommended/Not Recommended system, so there is no per-review star rating. The page-level page.recommendationPercentage is Facebook's own figure and is not recalculated from the reviews returned here, so it may not match a simple count of them. Use isRecommended for per-review analysis.

Can I get the business's replies to reviews? Yes. When a business reply is among the comments Facebook shows on a review, it appears inside topComments with isOwnerReply: true. The flag is set when the commenter's account ID matches the page's own ID, not by comparing display names.

How many reviews can I get per page? maxReviews and maxReviewsPerPage each go up to 500. Without cookies, Facebook usually stops serving new reviews to a logged-out visitor well before that (commonly around 5-15 per page) — this is a Facebook-side limit, not a scraper failure; the run's status message notes it when it happens. Supply cookies for a logged-in session to raise this ceiling.

Do I need to configure a proxy? No separate setup is needed — a residential proxy is always used for access to Facebook. proxyCountry just lets you pick which country that proxy exits from.

Will search mode always find the right business? Facebook's own on-site search requires a login, so search mode looks your query up through a public web search; if that finds nothing, it tries a page address built from the first two words of the query. For distinctive business names this generally finds the correct page, but ambiguous queries (a common name with no location) can return the wrong page or no match. For a guaranteed exact match, use url or pageId mode instead.

Does "Most Helpful" sort actually work? Rarely. The actor looks for a sort control on the reviews page, but Facebook's current review pages generally don't show one, so in practice reviews come back in the page's default order for both sortBy values. The run continues normally either way.

What is authorIdType? Facebook identifies most regular reviewers with a rotating pfbid token rather than a permanent numeric ID, meaning the same person isn't always reliably trackable as "the same reviewer" across separate runs. Business/Page accounts (e.g. a company replying to its own reviews) do get a stable numeric ID. authorIdType tells you which kind of identifier you got ("pfbid" or "numeric").

What happens if a page has no reviews or can't be reached? A record with "recordType": "error" and a description is pushed instead of the run failing or crashing.

Are review photo URLs permanent? Facebook CDN URLs can expire after some time — use the scrapedAt timestamp to track freshness. In practice most reviews are text-only or carry a recommendation tag rather than a photo, so reviewPhotos is frequently absent — that reflects real review behavior, not a gap in the scraper.

Can this scrape a business's About info (address, phone, hours, category)? Only partly. The actor doesn't open the About tab, so it never returns opening hours. page.category, page.address, page.phone and page.website are filled in only when Facebook happens to include them with the reviews data, which is often not the case.

Limitations

  • 500 review cap — maxReviews and maxReviewsPerPage can't exceed 500, and without cookies far fewer reviews per page are usually available
  • Public pages only — private groups, personal profiles, and Marketplace listings are not supported
  • Sort control is usually missing — most_helpful falls back to the page's default order when Facebook doesn't show the control
  • Search mode resolves via external web search, not Facebook's own search — most reliable for distinctive business names
  • Reviewer identity isn't always a stable ID — see authorIdType in the FAQ
  • Business "About" details are partial at best — see the FAQ
  • Some pages are blocked more often than others — a page that still returns nothing after three attempts produces an error record
