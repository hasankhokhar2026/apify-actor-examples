    Snapchat Spotlight Video Link & Caption Downloader is an Apify Actor published by Nimbryxo Studio. It accepts 6 input fields, and spotlightUrls is required. Each result can carry up to 28 declared fields, including snapId, creatorUsername, caption, viewCount, shareCount and commentCount. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it costs

    Snapchat Spotlight Video Link & Caption Downloader uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 1 GB, so a run starts with 1 start event, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.
