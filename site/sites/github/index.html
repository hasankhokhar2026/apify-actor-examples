    GitHub scrapers and data tools

    Nimbryxo Studio publishes 2 Apify Actors that read GitHub. Each one answers a different question, so pick by the data you need. Each costs $0.99 per 1,000 results on the Free plan.

    Which GitHub Actor do you need?

    • GitHub Marketplace App & Action Listings by Category: Search GitHub Marketplace apps and Actions by keyword, browse an entire category, or fetch listings by slug. Returns pricing plans, categories, publisher verification and install counts.
    • GitHub Repository Metadata & README Extractor: Fetch stars, forks, topics, license, language breakdown and README text for GitHub repositories, by search query or a direct list of repository URLs. An optional personal token raises the request limit.
