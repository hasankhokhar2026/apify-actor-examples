    X (Twitter) scrapers and data tools

    Nimbryxo Studio publishes 5 Apify Actors that read X (Twitter). Each one answers a different question, so pick by the data you need. Each costs $0.99 per 1,000 results on the Free plan.

    Which X (Twitter) Actor do you need?

    • Twitter (X) Screenshot Generator: Capture clean screenshots of public X posts and profiles without login. Choose post cards, profile headers or full profile pages, dark/light theme, PNG/JPEG/WEBP output, 2x/3x pixel density and optional profile or post details.
    • X (Twitter) Profile & Post Engagement Extractor: Get any public X profile - bio, followers, verification, avatar, banner - plus latest, top and media posts with full engagement metrics. No login required.
    • X Trends Lookup by Country, City & WOEID: Get ranked trending topics on X for any country or city, or for all 467 locations at once, with trend type, ready-made search links and post volumes when X publishes them.
    • X Video Subtitle & Caption Transcript Converter: Convert public X (Twitter) videos into timestamped transcripts and downloadable SRT/VTT subtitle files, using native captions when available and AI speech-to-text otherwise.
    • X/Twitter Keyword & Hashtag Tweet Search: Search X (Twitter) by keyword, phrase or hashtag and get tweet text, author, engagement metrics, media and language. Every row says which keyword found it. No login required.
